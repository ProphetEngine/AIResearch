# Diffusion Language Models（LLaDA / Dream）

> **定位**：文本扩散 P1 横切——相对已入库 **B10（图像 LDM / DiT）**，本篇只立 **离散 / masked diffusion 语言模型** 作为非自回归文本生成的另一条轴。
> **攻坚线**：**架构思想（主）** + **数学原理（扩散/掩码目标，辅）**。
> **谱系两站**：LLaDA（从零训 masked diffusion 至 8B）↔ Dream 7B（AR 权重初始化 + 上下文自适应噪声重调度）。
> **硬划界（禁止重写）**：
> - **禁止重写** B10 图像潜扩散 / DiT / 文生图条件接口（→ [[扩散生成式视觉与LLM]]）。
> - **禁止写成** [[视频生成正式报告]]旗舰正式报告线（→ [[视频生成正式报告]]）。
> - **禁止**把连续 embedding 空间文本扩散（Li et al. DiffuSeq 等）扩成通史；本篇锚点是 **absorbing-state / [MASK] 离散扩散（MDM）**。
> - 与 [[DecoderOnly与GPT路线]] decoder-only AR：**只对照生成因子分解与采样形态**，不重写 GPT 谱系。
> **禁止编造**：数字、损失式、tokens、GPU 小时一律锚定官方 PDF（2026-09-22 CST）与 demo 页公开表述。

**一句话抓手：** 文本侧「扩散」不是把连续高斯噪声搬进词嵌入，而是 **用 [MASK] 做吸收态前向过程、用 Transformer 同时预测被掩码 token 的反向去噪**——LLaDA 证明可从零扩到 8B 并接近同量级 AR；Dream 证明可从 AR 权重复用起步、少数据赶超，并在约束规划上拉开差距。

## 二、问题立轴：为何另立「文本扩散」线

### 2.1 与 B10 / [[视频生成正式报告]] 的三维划界

| 轴 | B10（图像） | [[视频生成正式报告]]（视频） | **本篇（文本 MDM）** |
|---|---|---|---|
| 状态空间 | 连续像素 / 潜变量 $z$ | 视频潜空间（正式 TR 待核实线） | **离散词表**；噪声多为 **[MASK]** |
| 骨干直觉 | U-Net / DiT 预测 $\epsilon$ 或 $v$ | 时序生成报告线 | **双向 Transformer mask predictor** |
| 训练目标 | MSE 去噪（重加权 ELBO） | — | **掩码位置加权交叉熵**（ELBO / NLL 上界） |
| 采样 | 多步去噪出图 | — | 从全掩码响应迭代 **预测 + remask** |
| 评测 | FID / IS 等 | — | MMLU / GSM8K / HumanEval；另加 **reversal / planning** |

跟读：**同一「扩散」词，三条线不可混抄公式与骨干。**

### 2.2 AR vs Masked Diffusion（两文共识口径）

| | **自回归（ARM）** | **Masked / Discrete Diffusion（本篇）** |
|---|---|---|
| 因子分解 | $p(x)=\prod_i p(x_i\mid x_{<i})$ 左到右 | 前向逐步掩码 → 反向从噪声恢复；Dream Eq.(2) 称 **progressive full-context prediction** |
| 注意力 | 因果 mask + 常配 KV cache | **无因果 mask**（LLaDA §2.2）；Dream 为对齐 AR 权重仍用「shift 预测下一位置」 |
| 一次前向 | 通常产 1（或少量 MTP）token | **同时预测所有当前掩码位** |
| 长度/步数旋钮 | 续写长度；步数≈序列长 | **生成长度**与 **扩散步数** 皆可作超参；质量–速度可调 |
| 典型短板（两文主张） | reversal / 全局约束规划偏弱 | 与 KV cache 不兼容（LLaDA）；需多步采样；LLaDA 尚未做 RL 对齐 |

**动机句（LLaDA Abstract / §1）：** 作者主张 LLM 智能主要来自 **生成建模逼近语言分布（MLE / KL）**，而非「必须自回归」；用大规模 MDM 检验该主张。

**动机句（Dream §1）：** AR 在长程规划、全局一致性上有固有限制；离散扩散从全噪声并行精炼，天然双向、可控、可调质量–速度。

## 三、数学辅线：Mask 前向 + 掩码 CE（跟读级）

> 只录两文给出的工作式；连续时间 absorbing MDM 的严格推导见 LLaDA Appendix A / Dream 所引 Shi et al.、Ou et al.——**本篇不重写完整测度论。**

### 3.1 前向过程（共同图像）

- 干净序列 $x_0$（或响应 $r_0$）。
- 连续时间 $t\sim U[0,1]$（Dream 亦强调相对离散 $t\in\{1..T\}$ 的连续参数化）。
- 每位独立：以概率 $t$（或按噪声日程 $\alpha_t$）变为 **[MASK]**，否则保留。
- $t=1$：全掩码；$t=0$：干净。

### 3.2 训练损失

**LLaDA Eq.(3)**（只在掩码位算 CE，带 $1/t$）：

$$
\mathcal{L}(\theta)=-\mathbb{E}_{t,x_0,x_t}\frac{1}{t}\sum_{i=1}^{L}\mathbf{1}[x_t^i=\mathrm{M}]\,\log p_\theta(x_0^i\mid x_t).
$$

文内主张：该式是模型分布负对数似然的**上界**（Eq.4），故是原则性生成目标；相对 MaskGIT 少了启发式缺失的 $1/t$ 项、并与 MLE 有理论联系（§2.1）。

**Dream Eq.(3)**：同族加权掩码 CE，$w(t)$ 由 $\alpha_t$ 变换得到；当 $\alpha_t=1-t$ 时 $w(t)=1/t$。文称其为 ELBO 的有效改写。

**Dream CART Eq.(4)–(5)：** 把序列级 $w(t)$ 换成 **token 级** $w(t,x_t,n)$——用干净 token 相对掩码位的几何距离混合，度量「上下文信息量」再重赋噪声权重（§4.2）。$p$ 控制几何锐度：小 $p$→干净 token 对全序列掩码更均匀贡献；大 $p$→更偏邻近掩码。

### 3.3 SFT 条件化

两文同构：prompt $p_0$ **不掩码**；只对 response 做前向掩码；损失只在响应掩码位（LLaDA Eq.5；Dream §4.3）。拼接 $(p_0,r)$ 可视为「掩码全落在响应段」的预训练特例。

### 3.4 采样（反向）

1. 给定 prompt，从 **全掩码响应** 起步（长度作超参；LLaDA 称对长度不敏感，见 Appendix B.5）。
2. 每步：mask predictor **并行预测所有掩码**。
3. 再按前向一致性 **remask** 一部分预测（期望 remask 比例与时间对齐）。
4. LLaDA 默认 **low-confidence remasking**（置信度最低的 $s/t$ 比例被重新掩码；同 Chang et al. MaskGIT 思路）。
5. 亦支持 AR / **block diffusion** 采样（LLaDA Appendix B.4）；主文默认纯扩散。
6. Dream 另强调：**任意顺序 / 补全 / 中间填空**；步数调节质量–速度（§5.5.2–5.5.3）。

## 四、站 1：LLaDA — 从零扩到 8B 的 Masked Diffusion LLM

### 4.1 架构思想

| 决策 | 论文事实 | 跟读 |
|---|---|---|
| 骨干 | Transformer mask predictor；**无因果 mask** | 预测时可见全序列（含已揭开 token） |
| 规模 | **1B** 与 **8B**；Table 5：LLaDA 8B ≈ **8.02B** 总参、**6.98B** 非嵌入；32 层、dim 4096、32 heads |
| 相对 LLaMA3 8B | 用 **vanilla MHA** 而非 GQA（文称与 KV cache 不兼容）；注意力参数更多 → **缩小 FFN** 保总参接近；词表 **126,464** vs LLaMA3 **128,000** | 同量级对照，非同架构复制 |
| 组件 | RMSNorm、SwiGLU、RoPE（Appendix B.2） | 与当代 LLaMA 系常见件对齐 |
| 预训练数据 | **2.3T** tokens；协议对齐现有 LLM；含代码/数学/多语；1% 序列长度在 $[1,4096]$ 均匀采样 | 无「专为扩散发明」的数据技巧主张 |
| 算力 | **0.13M H800 GPU hours**；序列长固定 **4096** | 文称与同规模同数据量 ARM 相近 |
| LR | Warmup-Stable-Decay：升至 $4\times10^{-4}$ → 1.2T 后降至 $1\times10^{-4}$（0.8T）→ 末 0.3T 线性到 $1\times10^{-5}$ | AdamW wd=0.1；全局 batch 1280 |
| SFT | **4.5M** pairs；3 epochs；只掩码响应；短序列 pad `|EOS|` 并当普通 token 训 | **仅 SFT，无 RL**（与多数对照 Instruct 模型不同） |

Demo 页 TL;DR（辅）：*diffusion model with an unprecedented 8B scale, trained entirely from scratch, rivaling LLaMA3 8B*。

### 4.2 可扩展性（§3.1 / Fig.3）

- 同数据上自建 ARM 基线对照；1B 规模架构/数据/配置对齐。
- FLOPs 轴约 **$10^{20}\sim10^{23}$**（相对 Nie et al. 2410.18514 的更小区间上延）。
- 六任务整体趋势与 ARM **可竞争**；MMLU、GSM8K 上 LLaDA 可现更强扩展；PIQA 等较弱任务随规模差距收窄。
- 作者**刻意不拟合定量曲线**（防 outlier 误读）。
- 对「MDM 要 16× 算力才达同 likelihood」旧说：指出 likelihood 对下游间接、且扩散优化的是界——**不可直接与 ARM NLL 比**。

### 4.3 Base / Instruct 快照（Table 1–2，同协议 ∗）

**Base（选摘，shot 见括号）：**

| 任务 | LLaDA 8B | LLaMA3 8B | LLaMA2 7B |
|---|---|---|---|
| MMLU (5) | **65.9** | 65.4 | 45.9 |
| GSM8K (4) | **70.3** | 48.7 | 13.1 |
| Math (4) | **31.4** | 16.0 | 4.3 |
| HumanEval (0) | **35.4** | 34.8 | 12.8 |
| HumanEval-FIM (2) | **73.8** | 73.3 | 26.9 |
| CMMLU (5) | **69.9** | 50.7 | 32.5 |
| BBH (3) | 49.7 | **62.1** | 39.4 |
| ARC-C (0) | 45.9 | **53.1** | 46.3 |

训练 tokens：LLaDA **2.3T** vs LLaMA3 **15T** / LLaMA2 **2T**（表内）。文称整体超 LLaMA2、与 LLaMA3 Base **总体可竞争**；数学与中文偏强，部分常识任务偏弱——归因于数据质量/分布（闭源数据不可比）。

**Instruct（选摘；LLaDA 仅 SFT，对照多为 SFT+RL）：**

| 任务 | LLaDA 8B | LLaMA3 8B |
|---|---|---|
| MMLU (5) | 65.5 | **68.4** |
| GSM8K (4) | 69.4 | **78.3** |
| Math (0) | **31.9** | 29.6 |
| HumanEval (0) | 49.4 | **59.8** |
| ARC-C (0) | **88.5** | 82.4 |

注：Instruct 上若用 **block diffusion** 采样，GSM8K / Math 可到 **78.6 / 42.2**（优于表内 low-confidence 纯扩散的 69.4 / 31.9）；文解释为 SFT 大量 `|EOS|` padding 导致 low-confidence 过早停（§3.2）。

### 4.4 反转推理（Table 4）— 相对 AR 的「结构优势」证据

中文名诗句对 **496** 对；零样本续后句（forward）或补前句（reversal）。

| 模型 | Forward | Reversal |
|---|---|---|
| GPT-4o (2024-08-06) | **82.7** | 34.3 |
| Qwen2.5-7B Instruct | 75.9 | 38.0 |
| **LLaDA-8B Instruct** | 51.8 | **45.6** |

主张：无为反转任务做特殊设计；token 被均匀对待、无左到右归纳偏置 → forward/reversal 更均衡；reversal 上大幅超过 GPT-4o / Qwen2.5。

### 4.5 局限（Conclusion，照录）

生成长度仍是用户超参；同数据 ARM 对照算力未扩到与最大 LLaDA 完全对等；无专用注意力/位置编码、无 KV cache 等系统优化；采样可控性仍初阶；**尚未 RL 对齐**；模态 / agent / O1 式后训练未探索。

## 五、站 2：Dream 7B — AR 初始化 + CART

### 5.1 路线差：不从零，而从 AR 权重复用

| 决策 | 论文事实 | 跟读 |
|---|---|---|
| 配置 | **与 Qwen2.5-7B 同配置**（§4.3） | 最大化与现有 AR 栈对齐 |
| 初始化 | 沿 DiffuLLaMA（Gong et al. 2025）的 **"Shift Operation"**：隐状态 $h_i$ 仍预测位置 $i+1$，而非「原地填 mask」 | 保留 AR 预训练的位置–预测对齐，降低注意力从因果→全注意切换的破坏 |
| 预训练语料 | **580B（0.58T≈文中称 0.6T）** tokens；开源：Dolma v1.7、OpenCoder、DCLM-Baseline | 相对 LLaDA 2.3T 约为 **1/4**（Dream §5.2 原文对比口径） |
| SFT | **1.8M** pairs（Tulu 3 + SmolLM 2）；3 epochs；只噪响应 | 自称 early / lightweight post-training |
| 发布 | Dream-Base + Dream-Instruct；GitHub `DreamLM/Dream`（文头） | 演示另见 https://hkunlp.github.io/blog/2025/dream/ |

**1B 消融（Fig.4 / §5.4）：** 从 LLaMA3.2-1B 初始化的 Dream-1B，在 200B tokens 上全程 loss **低于从零训**；初期因因果→全注意切换 loss 仍高，但始终优于 scratch。学习率过大可冲掉 AR 左到右知识；过小则扩散学不动——需仔细标定。

### 5.2 CART：上下文自适应 token 级噪声重调度

问题：标准训练一个序列级 $t$，但各掩码位「真实难度」不同——上下文更丰富的掩码位应对应更低有效噪声（Fig.3 示意）。
方法：用干净 token 的几何贡献定义 $w(t,x_t,n)$（Eq.5），使学习信号与局部上下文信息量对齐。
主张：与 AR 初始化一起，解释「少数据仍全面超 LLaDA」的主因（§5.2）。

### 5.3 Base 结果（Table 1，同协议 ∗；选摘）

| 任务 | Dream 7B | LLaDA 8B | Qwen2.5 7B | LLaMA3 8B |
|---|---|---|---|---|
| Tokens | **0.6T** | 2.3T | 18T | 15T |
| MMLU (5) | 69.5 | 65.9 | **71.9** | 63.5 |
| ARC-C (0) | **59.8** | 47.5 | 51.5 | 53.6 |
| GSM8K (8) | 77.2 | 70.9 | **78.9** | 55.3 |
| MATH (4) | 39.6 | 30.7 | **41.1** | 18.0 |
| HumanEval (0) | **57.9** | 32.9 | 56.7 | 35.4 |
| **Countdown (8)** | **16.0** | 13.2 | 6.2 | 3.7 |
| **Sudoku (8)** | **81.0** | 46.0 | 21.0 | 0.0 |
| **Trip planning (2)** | **17.8** | 16.4 | 3.6 | 8.7 |

主张要点：

1. **相对 Qwen2.5：** 通用任务接近（MMLU/HellaSwag 略逊），推理类（ARC）可超；**规划三类大幅领先**。
2. **相对 LLaDA：** 约 1/4 数据下全面提升（例：ARC-C 47.5→59.8，GSM8K 70.9→77.2，Sudoku 46.0→81.0）。
3. 规划优势不独属于 Dream：LLaDA 亦稳定高于 Qwen2.5 → 文解读为 **扩散族在约束满足上的结构优势**（§5.2）。

### 5.4 Instruct（Table 2）

| 任务 | Dream 7B (SFT) | LLaDA 8B (SFT) | Qwen2.5 7B (SFT+RL) |
|---|---|---|---|
| Alignment pairs | 1.8M | 4.5M | 1M / 0.15M |
| MMLU | 67.0 | 65.5 | **76.6** |
| GSM8K | 81.0 | 78.6 | **91.6** |
| HumanEval | 55.5 | 47.6 | **84.8** |
| IFEval | 62.5 | 59.9 | **74.7** |

口径：Dream/LLaDA **仅 SFT**；强 AR Instruct 带 RL——表内差距不可直接归因于「扩散必然弱于对齐后的 AR」。

### 5.5 推理灵活性（§5.5）

- **质量–速度：** Countdown 上调扩散步数；文称 **5–20 步** 区间可同时在速度与质量上相对 Qwen2.5 7B 占优（Fig.7；具体曲线以图为准，不外推未给数字）。主张为 inference-time scaling 的**另一维度**（与 CoT / o1 式推理并行，非替代）。
- **任意顺序：** 补全、infilling（可约束结尾句）、可配置解码顺序（偏 AR 左到右 ↔ 更随机顺序）。
- **规划质性：** Fig.6 示例对比行程/Countdown/Sudoku——AR 易违反直飞或天数约束；Dream 双向精炼更易全局满足（示例级，不作统计外推）。

## 六、两站对照（跟读卡）

| 维度 | **LLaDA 8B** | **Dream 7B** |
|---|---|---|
| 起点 | **From scratch** | **AR 权重（Qwen2.5-7B 配置 + shift）** |
| 预训练量 | **2.3T** | **~0.58–0.6T** |
| 目标族 | Masked CE + $1/t$（Eq.3） | 同族 + **CART** token 级 $w$ |
| 注意力 / 预测位 | 全注意；预测掩码位本身 | 全注意；**shift：用 $h_i$ 预测 $i+1$** |
| SFT | 4.5M；无 RL | 1.8M；无 RL |
| 相对同量级 AR | ≈ LLaMA3 8B Base；Instruct 略落后（无 RL） | ≈ Qwen2.5 7B Base（规划远强）；Instruct 仍落后带 RL 的 Qwen |
| 结构优势证据 | **Reversal poem** 均衡 / 反转超 GPT-4o | **Countdown / Sudoku / Trip** 大幅超 AR |
| 采样默认 | low-confidence remask；block 可选 | 步数可调；任意序 / FIM 叙事更强 |
| 系统短板（自述） | 无 KV cache；长度超参；待 RL | 后训练仍 lightweight；依赖更强 AR 底模迭代 |

**谱系位置（Dream Related §2.2 索引，不展开）：** 连续文本扩散 → 离散 absorbing MDM → 小规模 scaling → DiffuGPT/DiffuLLaMA（AR 适配）→ **LLaDA（从零 8B）** → **Dream（AR init + CART）**；商业侧点到 Mercury Coder（Inception Labs）仅作存在性索引。

## 八、开放问题（仅论文自述 + 划界后的研究缝）

1. **RL / 偏好对齐进 MDM：** 两文 Instruct 皆停在 SFT；扩散采样下的 RL 目标与 credit assignment 未立。
2. **系统栈：** 无 KV cache 时的吞吐、与连续 batching 的匹配；LLaDA 自列 limitation。
3. **自适应长度：** 生成长度作超参 vs 学出来的停止（LLaDA）。
4. **AR init 的上限：** Dream 期望「更强 AR → 更快迭代出更强 DLLM」——依赖外部 AR 进步，非独立 scaling 叙事。
5. **何时选扩散而非 AR：** 现有硬证据集中在 **reversal** 与 **多约束规划**；通用 MMLU 级任务上强 AR（更多 tokens + RL）仍领先——需任务分解而非口号替换。
