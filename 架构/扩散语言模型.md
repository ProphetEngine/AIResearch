# Diffusion Language Models（LLaDA / Dream）：相对扩散生成式视觉的文本扩散线

> **主要来源**：[Large Language Diffusion Models](https://arxiv.org/abs/2502.09992)（LLaDA，Nie 等，v3，NeurIPS 2025）；[Dream 7B: Diffusion Large Language Models](https://arxiv.org/abs/2508.15487)（Ye 等，v1）；[LLaDA 项目页](https://ml-gsai.github.io/LLaDA-demo/)（截至 2025-10-18）。
> **研究线**：架构思想（掩码扩散作为非自回归的文本生成轴，主）· 数学原理（吸收态前向过程与掩码交叉熵，辅）
> **范围与相邻笔记**：
> - ≠ [[扩散生成式视觉与LLM]]：本篇不写图像潜扩散、DiT 与文生图接口。
> - ≠ [[DiffusionForcing族]]：本篇不写连续序列（视频、轨迹）上的逐 token 噪声级。
> - 不把连续嵌入空间的文本扩散扩成通史，锚点是以 [MASK] 为吸收态的离散扩散（MDM）。
>
> **意义**：LLaDA 显示掩码扩散可以从零扩到 8B、与同量级自回归模型大体相当，动摇了「大模型能力必须来自自回归」的默认假设；Dream 表明可以从自回归权重起步、用约四分之一的数据赶上并超过前者。两者在反转推理与多约束规划上的结构性优势，是选择非自回归架构的少数硬证据。

**一句话**：文本侧的「扩散」不是把高斯噪声加进词嵌入，而是用 [MASK] 做吸收态的前向过程、用不带因果掩码的 Transformer 同时预测所有被掩码 token 的反向去噪；LLaDA 从零训到 8B，Dream 7B 从 Qwen2.5 权重初始化并加上 token 级噪声重调度。

---

## 一、问题背景

自回归模型按 $p(x)=\prod_i p(x_i\mid x_{<i})$ 从左到右生成，配因果掩码与 KV 缓存，是当前大模型的统一骨架（[[DecoderOnly与GPT路线]]）。它在反转关系、全局约束规划上偏弱（两文的共同主张）。LLaDA 的作者进一步主张：大模型的能力主要来自用生成建模逼近语言分布（最大似然），而不是自回归这个具体形式（LLaDA 摘要、§1）；要检验这一点，需要把另一种生成建模做到同样规模。

掩码扩散提供了这个候选：前向过程逐步把 token 换成 [MASK]，反向过程从全掩码出发并行预测、逐步揭开，天然双向，生成长度与步数都可以当作质量—速度旋钮。

## 三、核心机制

**前向与训练目标。** 对干净序列 $x_0$ 取 $t\sim U[0,1]$，每个位置以概率 $t$ 独立变为 [MASK]。LLaDA 的损失只在掩码位上算交叉熵并乘 $1/t$（式 3）：

$$
\mathcal{L}(\theta)=-\mathbb{E}_{t,x_0,x_t}\frac{1}{t}\sum_{i=1}^{L}\mathbf{1}[x_t^i=\mathrm{M}]\,\log p_\theta(x_0^i\mid x_t).
$$

论文称该式是负对数似然的上界（式 4），因此是有原则的生成目标；相对 MaskGIT 多了 $1/t$ 项（§2.1）。SFT 时提示不掩码，只对回答部分做前向掩码（式 5）。

**采样。** 给定提示，从全掩码的回答出发；每步并行预测所有掩码位，再按与前向一致的比例把一部分预测重新掩码。LLaDA 默认重掩码置信最低的位置，也支持半自回归的 block diffusion 采样（附录 B.4）。

**Dream 的两点改动（§4）。**
- **自回归初始化**：配置与 Qwen2.5-7B 相同，沿用 DiffuLLaMA 的 shift 操作——隐状态 $h_i$ 仍预测位置 $i+1$，保留自回归预训练的位置—预测对齐，减小从因果注意力切到全注意力的破坏。1B 消融中，从 LLaMA3.2-1B 初始化的模型在 200B token 上损失始终低于从零训练（§5.4）。
- **CART**：标准训练对整条序列用同一个 $t$，但上下文更丰富的掩码位实际难度更低；Dream 用干净 token 相对掩码位的距离把权重细化到 token 级（式 4–5）。

## 四、结果要点

**LLaDA 8B（§3）。** 从零预训练 2.3T token、0.13M H800 GPU 小时，SFT 4.5M 对、无 RL。Base 模型 MMLU 65.9 对 LLaMA3 8B 的 65.4、GSM8K 70.3 对 48.7，但 BBH、ARC-C 落后（Table 1；LLaMA3 用了 15T token）；作者刻意不拟合定量扩展曲线（§3.1）。反转推理（Table 4，496 对中文诗句）：补前句准确率 45.6，高于 GPT-4o 的 34.3 与 Qwen2.5-7B Instruct 的 38.0，但续后句只有 51.8，正反更均衡。

**Dream 7B（§5）。** 预训练约 0.58T token（文中称 0.6T），约为 LLaDA 的四分之一。

| Base（Table 1） | Dream 7B | LLaDA 8B | Qwen2.5 7B |
|---|---|---|---|
| 预训练 token | 0.6T | 2.3T | 18T |
| MMLU | 69.5 | 65.9 | **71.9** |
| GSM8K | 77.2 | 70.9 | **78.9** |
| Countdown | **16.0** | 13.2 | 6.2 |
| Sudoku | **81.0** | 46.0 | 21.0 |
| Trip planning | **17.8** | 16.4 | 3.6 |

通用任务接近 Qwen2.5，三类规划任务大幅领先；LLaDA 在规划上同样稳定高于 Qwen2.5，作者据此认为这是扩散族在约束满足上的结构优势（§5.2）。Instruct 版两者都只做 SFT，仍明显落后带 RL 的 Qwen2.5 Instruct（如 GSM8K 81.0 对 91.6，Table 2），差距不能直接归因于扩散本身。Dream 另强调任意顺序生成、中间填空，以及在 Countdown 上调扩散步数可在速度与质量上同时优于 Qwen2.5（§5.5）。

## 五、意义

两篇把文本扩散从小规模可行性推进到 7B–8B 的可比较水平，并给出了两条起步路线：从零训练，或复用自回归权重。目前的硬证据集中在反转推理与多约束规划；在通用知识与对齐后的指令任务上，用更多数据并做过 RL 的自回归模型仍领先。是否选扩散，需要按任务分解，而不是整体替换。

## 六、局限与待核实

- LLaDA 自述：生成长度仍是超参；同数据自回归对照的算力未扩到与最大 LLaDA 对等；没有专用注意力、位置编码或 KV 缓存优化；尚未做 RL 对齐（结论节）。
- Instruct 版 LLaDA 用 block diffusion 采样时 GSM8K / Math 可到 78.6 / 42.2，高于表内纯扩散采样的 69.4 / 31.9，作者归因于 SFT 中大量结束符填充让低置信重掩码过早停止（§3.2）；主表数字对采样方式敏感。
- Dream 依赖更强的自回归底座迭代，不是独立的扩展叙事；其后训练仍属轻量。
- 无 KV 缓存时的吞吐、与连续批处理的匹配，两文均未给出系统级数字。
- LLaDA 引 v3、Dream 引 v1，均为 arXiv 最新版。
