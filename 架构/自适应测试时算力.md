# 自适应测试时算力：SelfBudgeter + Strategic Scaling（Bandit）（≠ 8 TTS 通史）

> **定位**：自适应测试时算力 **P0**——在 **[[推理时扩展TestTimeScaling]]** 已立「测试时缩放通史」（BoN / 搜索 / o1·R1 势）之后，本卡只写 **adaptive compute 方法切片**：同一总预算下，**如何按查询难度分配 token / 样本**。两条主轴正交：
> - **SelfBudgeter**（*Adaptive Token Allocation*）：**单查询内**自预测最小 token 预算 + 预算约束生成（Cold-start → budget-guided GRPO）。
> - **Strategic Scaling**（*A Bandit Learning Approach*）：**跨查询**把总样本预算当纯探索式 bandit，在线估计难度并消除已「过阈」查询。
> **补链（不升主）**：*Learning How Hard to Think*（ICLR 2025）——训练轻量难度探针 + 批内 / 平均预算分配（自适应 BoN / 路由）；Strategic Scaling 文内将其归入 **two-stage** 族对照。
> **攻坚线**：**架构思想 / 分配接口（主）** + **文内算力—精度字段（辅）**。
> **硬划界（开篇钉死，禁止滑向通史）**：
> - **≠ [[推理时扩展TestTimeScaling]]**：不写 o1/R1/s1 产品通史、「势」、训练期 RL 长 CoT 叙事；**禁止重写 Snell et al. 最优缩放通史**——仅取「推理期多算力能换分」接口。
> - **≠ [[测试时训练]]**：本卡 **不改权重**（SelfBudgeter 的 SFT/RL 是训出预算策略；推理期本身非 TTT）。不写 In-Place / TEMPO / Modular-TTT。
> - **≠ [[推理时树搜索ABMCTS]] AB-MCTS**：外层答案树宽深（GEN + Thompson）≠ 本卡的 **token 自预算** 或 **跨查询样本 bandit**；不写 TreeQuest。
> - **≠ 投机解码**：投机解码 draft–verify / margin / 各向异性树 ≠ 本卡的算力分配。
> **禁止编造**：主张与表数字一律锚定官方 PDF（2026-09-22 CST）。
> **二进制**：三篇均 **≪20MB**（见 §一）→ **官方 HTTPS 外链**。

**一句话抓手：**
- **SelfBudgeter**：别让长 CoT 模型对「2+3」也吐一万 token——先吐一个 **自估整数预算**，再用奖励把 **实际长度钉在预算附近**，用户可预填预算或提前知等待时间。
- **Strategic Scaling**：别对 batch 里每题均匀 BoN——把每题当成 bandit arm，**过阈就淘汰**，把剩余样本预算挪给仍未过阈的题；难且可解优先，不可解少浪费。
- **How Hard（补链）**：在采样前用 **隐藏态探针**预测「再多花 1 单位算力的边际收益」，再解一个带序约束的分配问题——Strategic Scaling 视其为需额外训辅模的 **two-stage** 路线。

## 三、主文 A：SelfBudgeter（2505.11274）

### 3.1 问题立轴：能控长 ≠ 能自估「够用的最短」

摘要 / §1：推理模型（O1 / R1 / QwQ 等）靠长 CoT 涨分，但对简单题仍 **overthinking**（例：文称 QwQ-32B 答「2+3」可给出 13 种解法）。既有路线：

1. **Prompt 控长**——缺精确长度控制；
2. **训时 SFT / 长度惩罚 RL**——难可靠满足用户指定长度；
3. **Router**——额外分类器开销。

SelfBudgeter 目标两件套：（1）用户未指定时 **自估最小够用 token 预算**；（2）无论自估或用户预填，**生成严格贴预算**；预算数值同时暗示等待时间，用户可提前终止。

输出格式（§4.1）：

`text
<budget>整数</budget><solution>…</solution>
`

无约束 → 模型填预算；有约束 → 预填 `<budget>`，只生成 `<solution>`。

### 3.2 训练骨架：Cold-start → budget-guided GRPO

**图 2 三步**（文）：

1. **Data preprocessing**：底座对题生成；正确则 `bmax =` 该次长度，错误则 `bmax = ∞`（式 5）。Cold-start 只留正确答。
2. **Cold-start SFT**：学会格式；数据来自 GSM8K / MATH 各 1.5k 正确样本 + s1k-1.1 中 R1 答对的 630 题 → 共 **3,630**；1 epoch，T=0.6。
3. **RL（文称 GRPO）**：STILL-3-Preview-RL-Data（约 30k，MATH / NuminaMathCoT / AIME 1983–2023）；3 epochs。附录 A.2 将 GRPO 展开为文内写法 **「Global Reward Policy Optimization」**（本笔记按原文照录，不外推为 DeepSeek 同名缩写释义）。

### 3.3 奖励：Format / Budget Penalty / PreB / Accuracy

总奖励式 (1)：格式错 → 最低分 `rf`；格式对则

`PB(b, bmax) + PreB(...)`，并按对错切换正确/错误分支的 `smin/smax`。

- **Budget Penalty（式 3）**：`b > bmax` 罚 `rb`，否则 0。正确样本的 `bmax` = 预处理长度，逼预算往「已知够用」收缩。
- **PreB（式 4，灵感自 cosine reward）**：要求实际长度 `ℓ` 落在预算 `b` 的相对带 `|ℓ−b|/b ≤ α` 内，否则掉到 `smin`；带内用 cos 峰值对准 `bbest`——**答对**偏好偏紧 `(1−α)b`，**答错**偏好偏松 `(1+α)b`（式 2）。
- **Accuracy 约束**：设计保证「正确且预算超限的最低回报」≥「错误但预算合规的最高回报」：`smin^C + rb ≥ smax^W`。

**动态 α（§4.6 / 式 6）**：固定松 α → 后期抬预算 reward hack；固定紧 α → 预算塌到长度、学不会策略。采用线性日程 `α: 6.0 → 0.1`。表 3：Linear 在三集上准确率全面优于 Fixed / Cosine，同时摘要口径称数学推理任务上 **平均响应长度压缩约 61%**。

### 3.4 主表与消融（锚 Table 1–2）

底座：**DeepSeek-R1-Distill-Qwen-1.5B / 7B**；基线含 L1-Max、E1-Math、Eurus-2-7B-PRIME、Qwen-2.5-7B-Simple-RL 等。表 1（Acc % / Len tokens，三种子平均）：

| 模型 | GSM8K Acc / Len | MATH500 Acc / Len | AIME2025 Acc / Len |
|---|---|---|---|
| R1-Distill-Qwen-1.5B | 73.09 / 2865 | 74.93 / 5327 | 22.22 / 14444 |
| L1-Max(3600) | 79.56 / 572 | 76.73 / 1753 | 17.88 / 5214 |
| **SelfBudgeter-1.5B** | **84.10 / 1232** | **78.47 / 2327** | 21.11 / 4288 |

## 四、主文 B：Strategic Scaling（Bandit）（2506.12721）

### 4.1 问题立轴：均匀 BoN 浪费在易题上

§3：总预算 `B`，查询集 `S={x1..xn}`，算力单位 = **生成一条响应**；目标最大化平均 Coverage 或 Accuracy（式 1）。Uniform 给每题相同 `B̄=B/n`——易题过剩、难题不足。

**与单查询自适应 / two-stage 的差（§2）**：
- 单查询内动态 BoN（Sun / Manvi / Tan 等）**不跨题挪预算**；
- Damani et al.（How Hard）等 **先训辅模或先均匀探难度再分配** → 文称 Two-Stage / ETC，有均匀探索开销（Proposition 1）。

本工作：把分配建成 **纯探索风格 bandit**——每题一个 action，pull = 再采 1（或 K）条；目标是「尽量多题至少有一条高质量答」，**不是**找出期望分最高的子集（与经典 BAI / thresholding bandit 目标不同，§4.1）。

### 4.2 Algorithm 1：探索规则 + 消除规则

伪代码要点（§4.2）：

1. 活跃集 `A ← S`；每题维护响应集 `g(x)`、当前最优 `y̌(x)` 与分 `ř(x)`。
2. 每轮对 `A` 中每题按 **exploration rule** 再生成 `K` 条（默认：活跃集上均匀）。
3. 若本轮最优分 `≥ γ`（消除阈值）→ **从 A 剔除**（elimination）。
4. 直到预算耗尽或 `A=∅`。Coverage 看 `g(x)`，Accuracy 看 `y̌(x)`。

奖励神谕：ORM / PRM / GT；文强调与 Uniform BoN **同量级 oracle 调用次数**。超参：`K`（粒度）、`γ`（可用专家知识或另集 CV）。

**扩展（§4.3）**：
- **聚合**：Best-of-N → Self-Consistency（推理模型如 Qwen3-4B；共识过半可消除）；
- **探索**：UCB / Gap / 文提 **Entropy**（响应模式熵高者优先；极难子集上有效）；`max_sample` 防单题吞预算；
- **Token 级预算**、**流式逐题到达**变体。

### 4.3 理论一句（锚 Theorem 1）

Bernoulli 难度 `Δx` + Assumption 1（oracle≥γ ⇔ 正确）下：为以 ≥1−δ 概率答对全集，Algorithm 1 总预算 `Θ̃(Σ_x 1/Δx)`，贴近信息下界；Uniform 需 `Ω̃(|S| / min_x Δx)`。异质难度下可差到约 **n** 倍（文举例 `Δ_i=i/n`）。ETC/Two-Stage 仍背 `Θ(m)` 均匀探索税（Prop. 1）。

### 4.4 实验字段（锚摘要 + §5）

设定：MATH-500 / AIME25 / LiveCodeBench；平均预算 `{4,8,16,32}`；模型含 Llama-3.2-1B / 3.1-8B、R1-Distill-Llama-8B、Qwen3-4B、Gemini-2.5-Flash-Lite 等；oracle 随族切换（Qwen2.5-Math-PRM-7B / LLM-as-judge / GT / SC）。

**摘要口径（同预算 vs 基线，up to）**：

| 数据集 | 绝对提升 | 相对提升 |
|---|---|---|
| MATH-500 | **11.10%** | **15.04%** |
| AIME25 | **10.82%** | **14.44%** |
| LiveCodeBench | **11.23%** | **15.29%** |

§5.2 跟读例：平均预算 8 时 Llama-3.1-8B-Instruct 上 MATH-500 **11.10%** 绝对增益 → 文标约 **3.93×** efficiency gain；AIME25 上 Qwen3-4B 预算 16 时 Coverage **10.82%** 绝对 → **4.00×** efficiency；LiveCodeBench 上亦见约 **4×** 量级（Fig.1 第四幅）。行为分析：标准设定预算流向更难查询；含不可解题时进一步偏向 **可解** 实例，减少对无解的空转。

## 五、补链：Learning How Hard to Think（2410.04707，ICLR 2025）

> **本卡角色：谱系索引，不升主。** Strategic Scaling 明确把 Damani et al. 列为 **two-stage** 对照；二者同属「跨查询自适应算力」，但 **接口不同**——探针预训练 + 离线/在线求解分配 vs 无额外训练的在线消除 bandit。

**方法骨架（文 §3）**：定义边际奖励 `Δ_{ij}=q(x_i,j)−q(x_i,j−1)`；用 LM **隐藏态上的轻量探针**预测 `Δ`；再解带序约束的 0-1 增量分配（式 5）。两种解码外壳：

1. **自适应 best-of-k**：动态决定送入 reranker 的采样数；
2. **路由**：弱解码 `pW` vs 强解码 `pS`（更大模型或更贵程序，如 VAS）。

**摘要数字（照录）**：同质量下算力最多约减 **50%**，或固定预算质量最多约升 **10%**；路由设定下仅对 **50–75%** 查询调用贵解码即可追平贵解码整体表现。表 1：Code/Math 探针相对 Avg. 基线降损，二分类 Acc 约 **74% / 84%**。

**跟读一句**：How Hard 回答「**采样前能否预测谁值得加算力**」；Strategic Scaling 回答「**采样中能否不训辅模地边采边挪预算**」；SelfBudgeter 回答「**单次生成该多长**」。三者都不是 Snell 通史，也不是 TTT。
