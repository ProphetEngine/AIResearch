# 门控注意力与注意力汇

> **主要来源**：[Quantizable Transformers: Removing Outliers by Helping Attention Heads Do Nothing](https://arxiv.org/abs/2306.12929)（简称 Bondarenko 等）；[Efficient Streaming Language Models with Attention Sinks](https://arxiv.org/abs/2309.17453)（简称 StreamingLLM）；[When Attention Sink Emerges in Language Models: An Empirical View](https://arxiv.org/abs/2410.10781)（简称 Gu 等）；[Gated Attention for Large Language Models: Non-linearity, Sparsity, and Attention-Sink-Free](https://arxiv.org/abs/2505.06708)（简称门控注意力论文）；[Attention Sink Forges Native MoE in Attention Layers: Sink-Aware Training to Address Head Collapse](https://arxiv.org/abs/2602.01203)（简称 Fu 等）；[A Unifying View of Attention Sinks: From Mechanisms to Architectural Interventions](https://arxiv.org/abs/2606.08105)（简称 Fesser 等）；[Abstention and Noise Filtering: Two Missing Primitives of Softmax Attention](https://arxiv.org/abs/2609.22005)（简称 Wang）（截至 2026-10-05）。其余来源见第十四节。
> **研究线**：架构思想（softmax 注意力为什么需要一个「什么都不做」的出口，分母偏置、汇 token、寄存器与输出门控分别在哪里提供这个出口）· 数学原理（权重和为一的约束怎样迫使注意力集中到固定位置，汇注意力与门控因子之间的等价改写）
> **范围与相邻笔记**：
> - ≠ [[DuoAttention与KVzip]]：本篇不写按头区分流式头与检索头的 KV 压缩方法，只说明它们利用了注意力汇。
> - ≠ [[KV缓存量化与压缩]]：本篇不写 KV 量化中对汇 token 的特殊处理。
> - ≠ [[SpinQuant与ARCQuant量化]]：本篇不写用旋转或通道重排处理离群值的量化方法，只写离群值的成因。
> - ≠ [[线性注意力与状态空间模型谱系]]：本篇不写线性注意力与状态空间模型中的门控，只写 softmax 注意力上的门控。
> - ≠ [[长上下文位置编码与系统侧]]：本篇不写位置编码与长度外推方法。
> - ≠ [[归一化与残差连接设计]]：本篇不写归一化层的位置与形式、QK-Norm 与残差结构。
>
> **意义**：softmax 注意力的权重必须非负且加起来等于一，一个注意力头即使在上下文里找不到要看的内容，也得把权重分出去。2023 年，量化、流式推理和视觉 Transformer 三条线几乎同时碰到了这一约束的后果：激活离群值、删掉开头 token 后模型崩溃、背景图块上的高范数伪影。此后的研究把首 token 上过量的注意力称为「注意力汇」，并逐步说明它是模型为了「不更新」或「少混合」而学出来的机制。对应的结构改动有两类：在 softmax 内给注意力一个出口（分母加一、可学习的汇偏置、汇 token、寄存器），或在注意力输出上加门控。门控注意力论文在 15B MoE 与 1.7B 稠密模型上报告了收益，随后 Qwen3-Next 采用门控注意力，gpt-oss 采用每头汇偏置。2026 年的工作则把汇、门控与寄存器放进同一框架，指出这些改动是在重新安排模型的计算，而不是简单地把汇去掉。

## 一、问题背景

**权重和为一的约束**：在标准注意力中，一个头对当前查询算出与各个键的相似度，经 softmax 变成和为一的非负权重，再对值向量加权平均。StreamingLLM 指出，softmax 不允许所有被关注的 token 权重都为零；即使当前查询与前面的大多数 token 都不匹配，模型也得把这些「用不上」的注意力放在某处（StreamingLLM 第 3.1 节）。

**头为什么需要「不做事」**：残差结构里，每个注意力头的输出加回残差流。Bondarenko 等认为，有些头在某些位置上最好的做法是不更新或只部分更新残差（no-op）。在 softmax 之下，要实现「不更新」，头只能把几乎全部注意力放在一组固定的、信息量低的 token 上（如分隔符或背景图块），并让这些 token 的值向量很小（Bondarenko 等第 3 节）。

**为什么这会成为问题**：三个后果先后被注意到：

- **量化**：要让 softmax 输出接近精确的零，softmax 的输入需要很大的动态范围；由于 softmax 永远输出不了精确的零，梯度会持续推动离群值变大，训练越久越强（Bondarenko 等第 3 节）。离群值迫使激活用更高位宽或其他变通做法（Bondarenko 等摘要）。
- **流式推理**：滑动窗口注意力只缓存最近的 KV，一旦开头的 token 被移出缓存，困惑度就会骤升（StreamingLLM 第 3.1 节）。
- **视觉表征**：大 ViT 会把信息量低的背景图块挪作内部计算用途，形成高范数伪影，损害密集预测（Vision Transformers Need Registers 摘要、第 2 节）。

## 三、现象：注意力汇、高范数 token 与巨量激活

### 3.1 语言模型中的注意力汇

StreamingLLM 在 Llama-2-7B 等模型上观察到，除最底下两层外，模型在所有层、所有头上都持续关注开头的 token（StreamingLLM 第 3.1 节）。把开头四个 token 换成换行符后，模型仍然显著关注它们，而且放回这些换行符就能恢复困惑度；作者据此认为起作用的是开头的绝对位置，而不是这些 token 的语义（StreamingLLM 第 3.1 节）。作者把这类 token 称为注意力汇，并解释为什么是开头：自回归模型中，开头的 token 对几乎所有后续 token 都可见，因此更容易被训练成汇（StreamingLLM 第 1 节）。

据此提出的 StreamingLLM 在滑动窗口之外只多保留注意力汇 token 的 KV，开头 4 个 token 就够（StreamingLLM 第 1 节）。论文称它让 Llama-2、MPT、Falcon、Pythia 在不微调的情况下稳定建模 400 万以上 token，在流式设定下比带重算的滑动窗口最多快 22.2 倍（StreamingLLM 摘要）。

Barbero 等报告，在 LLaMa 3.1 405B 中 80% 的注意力头形成强汇（Barbero 等第 1 节）。

### 3.2 视觉 Transformer 中的高范数 token

Darcet 等发现，有监督与自监督 ViT 的特征图中都存在伪影：少数 token 在输出处的范数约为其他 token 的 10 倍，约占序列的 2%，出现在中间层附近，且只在足够大的模型训练足够久之后才出现（Registers 第 1 节）。这些 token 位于与邻近图块相似、信息冗余的背景位置；线性探针显示它们丢掉了局部的位置与像素信息，却带有更多全图信息（Registers 第 1 节）。作者的解释是：大而充分训练的模型学会识别冗余 token，把它们挪作存放、处理与读取全局信息的位置（Registers 第 2.2 节）。

### 3.3 巨量激活

Sun 等在多种 LLM 中观察到极少数激活远大于其他激活，称之为巨量激活（massive activations）；它们的值基本不随输入变化，起到不可或缺的偏置作用，多出现在起始 token 和分隔符 token 上（Massive Activations 摘要、第 1 节）。在 LLaMA2-7B 中，只把四个巨量激活置零，模型性能就灾难性崩溃，而把它们设为均值则不受影响（Massive Activations 第 1 节）。巨量激活使注意力集中到对应 token 上，并在注意力输出中引入隐式偏置项（Massive Activations 摘要）。

**三者的关系**：注意力汇是注意力图上的现象，巨量激活是隐藏状态上的现象，ViT 伪影是 token 范数上的现象。Sun 等把巨量激活与注意力汇联系起来；但门控注意力论文发现，只在值投影后加门控能消除巨量激活，注意力汇却仍在，据此认为巨量激活不是注意力汇的必要条件（门控注意力论文第 4.3 节、第 5.2 节）。

## 四、成因与功能

### 4.1 「不更新」的头与离群值

Bondarenko 等在 BERT 上发现，离群值只出现在少数隐藏维度上，其中超过 97% 与分隔符 token（[SEP]、句号、逗号）的位置相关（Bondarenko 等第 3 节）。他们的假设是：为了不更新某个 token 的表示，一些头要把大部分注意力放在一组固定的低信息 token 上，并学会让这些 token 的值输出很小。softmax 要输出接近零的权重，输入就得有很大的动态范围；LayerNorm 会把离群值归一化，所以前一层 FFN 的输出必须非常大，才能在归一化后仍保有足够的动态范围。由于 softmax 输出不了精确的零，梯度会一直推动离群值增长（Bondarenko 等第 3 节）。

这一解释把量化困难和注意力行为连了起来，也直接指出了改法：让注意力可以输出很小甚至精确为零的结果，而不必产生离群值（Bondarenko 等第 4 节）。

### 4.2 汇的出现条件：键偏置

Gu 等用小模型从头预训练，系统改变优化、数据、损失与架构（Gu 等第 4 至 7 节）。主要结论：

- **出现条件**：汇在模型经过有效优化、训练数据充足之后出现；学习率小时不明显，权重衰减会促进它出现（Gu 等第 1 节）。固定的训练步数下把数据量减少，汇会消失（Gu 等第 5 节）。
- **位置由数据决定**：把某个固定 token 放在第二或第三个位置训练，汇就出现在那个固定 token 上（Gu 等第 5 节）。
- **汇像键偏置**：首 token 的键分布在与其他 token 不同的流形上、值向量范数很小（Gu 等第 3.1 节）。给注意力加可学习的键偏置后，汇从首 token 移到偏置上；只加值偏置则不影响汇。作者据此认为汇的作用像键偏置，存放多余的注意力分数，可以完全不携带信息、不参与值的计算（Gu 等第 7.3 节）。
- **源于归一化**：去掉 softmax 的归一化（如改用不归一化的 sigmoid 注意力），汇就不再出现。在 1B 参数规模上，sigmoid 注意力的验证损失为 3.10，略高于 softmax 的 3.07，而汇指标从 45.11% 降到 2.46%，也没有巨量激活（Gu 等第 7.4 节）。

### 4.3 汇的功能：避免过度混合

Barbero 等不把汇看作需要消除的缺陷，而是追问它为什么有用。他们的论点是：深层、长上下文的 Transformer 容易「过度混合」，即 token 之间的信息混合过多，导致表示塌缩；让一部分头暂时不活跃可以减缓这一过程，而注意力汇正是让头不活跃的方式（Barbero 等第 1 节）。

两项证据：

- 在 Gemma 7B 中扰动一个 token，有起始 token 作为汇时，扰动向其他 token 的传播明显更弱；去掉起始 token 后注意力图变得平滑得多（Barbero 等第 3.2 节）。
- 按他们的分析，模型越大、训练上下文越长，汇应越强。自训模型中，训练上下文越长汇越普遍，很短上下文训练的模型几乎没有汇；LLaMa 3.1 系列中，8B 模型的头明显比更大的模型更活跃（Barbero 等第 4.1、4.2 节）。

### 4.4 汇的必要性：理论结果

Ran-Milo 构造了一个触发条件任务：出现指定的触发 token 时，模型要输出前面所有 token 表示的平均；否则输出零。这对应真实模型中「遇到某种模式才工作，其余时候不做事」的头（Ran-Milo 摘要、第 2 节）。结论：

- 单层 softmax 注意力要把这个任务的误差降到零，必须在所有非触发位置把接近 1 的注意力放在固定的汇 token（BOS）上；多层模型中至少有一层要在某个非触发位置出现汇行为（Ran-Milo 第 1 节）。
- 不归一化的 ReLU 注意力可以在 BOS 上注意力为零的情况下完成同一任务，说明归一化约束是汇形成的根本原因（Ran-Milo 第 1 节）。

作者由此提出，在 softmax 内部去汇的做法（惩罚 BOS 注意力、摊开注意力质量、事后重新加权）对这类计算可能有内在局限，模型可能在别的位置、头或层重建等价的锚点（Ran-Milo 第 5 节）。这篇论文收入 ACL 2026 短文（ACL Anthology 页面）。

## 五、结构干预一：给 softmax 一个出口

这一类做法保留 softmax，但给它一个不对应任何真实内容的去处。

| 做法 | 做法要点 | 来源 |
|---|---|---|
| 分母加一 | 把 softmax 分母改为「一加上各项指数之和」；各输入都趋于负无穷时，所有权重趋于零，而普通 softmax 仍会平均分配 | Miller 博文 |
| 零汇 | 分母加一等价于在序列前加一个键与值全为零的 token | StreamingLLM 第 3.3 节 |
| 可学习的汇 token | 预训练时在每条样本开头放一个可学习的 token，专门承接多余注意力 | StreamingLLM 第 3.3 节 |
| 显式注意力偏置 | 每个头增加可学习的键向量与值向量，作为额外的注意对象 | Massive Activations 第 4.3 节 |
| 键偏置 | 只给注意力加可学习的键偏置，汇就转移到偏置上 | Gu 等第 7.3 节 |
| 每头汇偏置 | 每个头在 softmax 分母中有一个可学习的偏置，使注意力可以不分给任何 token | gpt-oss 模型卡第 2.2 节 |
| 寄存器 | 在 ViT 输入中加若干可学习 token，输出时丢弃 | Registers 第 2.2 节 |
| clipped softmax | 把 softmax 输出拉伸后再截回 0 到 1 区间，使有限输入也能得到精确的 0 | Bondarenko 等第 4.1 节 |

几项对照结果：

- **零汇不够，可学习汇 token 够**：StreamingLLM 从头预训练了三个 1.6 亿参数的模型。零汇略有改善，但仍需要其他开头 token 才能稳定流式困惑度；带可学习汇 token 的模型只保留这一个 token 就能稳定（StreamingLLM 第 1 节、第 3.3 节）。
- **显式偏置消除巨量激活**：Sun 等训练了三个 GPT-2：标准版、前置汇 token 版、带显式注意力偏置版。三者收敛时性能相同，但只有带显式偏置的版本没有巨量激活（Massive Activations 第 4.3 节）。
- **寄存器消除伪影**：加入寄存器后，有监督与自监督 ViT 的高范数伪影都消失，特征图与注意力图更平滑（Registers 摘要）。
- **clipped softmax 只需截低端**：只在 0 处截断就能带来大部分改进，在 1 处截断与原 softmax 相近（Bondarenko 等第 5.1 节）。

Miller 的博文是观点文章而非实验论文：作者自称「这是一篇观点文」，并邀请他人做实验验证（Miller 博文）。gpt-oss 模型卡在描述每头汇偏置时同时引用了这篇博文与 StreamingLLM（gpt-oss 模型卡第 2.2 节）。

## 六、结构干预二：输出门控

### 6.1 起点：为「不更新」而设的门

Bondarenko 等提出的第二种改法是在注意力输出上加一个显式的条件门：注意力输出逐 token 乘以一个 sigmoid 门值，门由一个与模型一起训练的小网络计算。这样，模型可以直接用门保留或取消对某些 token 表示的更新，不必依赖注意力概率与值向量来实现「不更新」（Bondarenko 等第 4.2 节）。门按头定义，最简单的版本每个头只用一个线性层，每层额外参数约相当于一个 token 的嵌入维度（Bondarenko 等第 4.2 节）。在 BERT、OPT 与 ViT 上，用这两种改法预训练的模型离群值显著变小，浮点精度保持甚至略有提升，激活可以直接做完整的 INT8 量化（Bondarenko 等摘要）。

### 6.2 门控注意力论文：在大规模上系统比较

Qiu 等的出发点是：门控在 LSTM、Highway 网络、状态空间模型与线性注意力中普遍使用，但很少有工作单独考察门控本身的作用（门控注意力论文摘要）。他们在标准 softmax 注意力的五个位置加门：查询、键、值投影之后，缩放点积注意力（SDPA）输出之后，以及最后的输出投影之后；并比较逐元素与按头、各头独立与各头共享、乘法与加法、sigmoid 与 SiLU 等变体（门控注意力论文第 1 节、第 2.2 节）。

**规模**：在总参 15B（激活 2.54B）的 MoE 与 1.7B 稠密模型上比较 30 余种变体，训练数据为 3.5T token（门控注意力论文摘要、第 3.1 节）。

**主要发现**：

- 在 SDPA 输出后加各头独立的 sigmoid 门效果最好，困惑度最多降低 0.2、MMLU 最多提高 2 分（门控注意力论文第 1 节）。门带来的墙钟时间开销不到 2%（门控注意力论文第 3.1 节）。
- 只要不同的头得到不同的门值，门的粒度与激活函数的影响相对较小；乘法门优于加法门，sigmoid 优于 SiLU（门控注意力论文第 3.2.1 节）。
- 门控几乎消除了损失尖峰，学习率调大后基线出现不收敛，门控模型则能用更大的学习率并取得提升（门控注意力论文第 1 节、第 3.2.2 节）。

### 6.3 为什么有效：非线性与稀疏

论文把收益归因于两点（门控注意力论文摘要、第 4 节）：

1. **非线性**：一个头的值投影与输出投影是连续的两个线性映射，可以合并成一个低秩线性映射；在 SDPA 输出或值投影后加门，就在两者之间插入了非线性，提高了这一低秩映射的表达力。这也解释了为什么在输出投影之后加门没有效果，因为它不在两个线性映射之间（门控注意力论文第 4.1 节）。在每个头的输出上单独做 RMSNorm，几乎不增加参数，也能显著降低困惑度（门控注意力论文第 4.1 节）。
2. **依赖查询的稀疏**：SDPA 输出门的门值大多集中在接近 0 的区间，稀疏程度最高；值投影门的门值更高、效果也较差。SDPA 输出门由当前查询位置的隐藏状态算出，值门由过去的键值位置算出，作者据此认为稀疏门值的作用是为当前查询滤掉无关的上下文（门控注意力论文第 4.2 节）。把门改成不依赖输入，或把 sigmoid 的取值范围限制在 0.5 到 1 以去掉稀疏，效果都不如依赖输入的稀疏门（门控注意力论文第 4.2 节）。

### 6.4 门控与注意力汇

摘要的措辞是：这种稀疏门控机制**缓解**了注意力汇，并提升长上下文外推（门控注意力论文摘要）。具体观察：

- 基线模型各层平均有 46.7% 的注意力分给首 token，加门后降到 4.8%（门控注意力论文图 2 图注）。
- 各头独立、依赖查询的 SDPA 输出门大幅减少首 token 上的注意力，同时减小巨量激活；各头共享的门或值投影门能减小巨量激活，却不减少首 token 上的注意力（门控注意力论文第 4.3 节）。
- 作者推测，稀疏门控减小巨量激活，使模型在 BF16 训练中更不容易受数值误差影响，这可能是训练更稳的原因；巨量激活主要来自早期层 FFN 的大输出，经残差流和 pre-norm 传到后续层（门控注意力论文第 4.3 节）。

**长上下文**：论文把 3.5T token 训练的模型的 RoPE 基频从 1 万调到 100 万，在 32K 长度上继续训练 800 亿 token，再用 YaRN 扩到 128K（门控注意力论文第 4.4 节）。在 32K 内门控模型略优于基线；扩到 64K 与 128K 时明显优于基线，RULER 提升超过 10 分（门控注意力论文第 1 节、第 4.4 节）。作者的解释是假设性的：基线模型依赖注意力汇调节注意力分布，改动 RoPE 基频后汇的模式难以在不训练的情况下适应；门控模型主要靠依赖输入的门值控制信息流，因而对这类改动更稳健。论文在局限中承认，没有给出注意力汇如何影响长度泛化的严格理论解释（门控注意力论文第 4.4 节、Limitations 节）。

## 七、相邻设计：在注意力内部抑制无关信息

两种设计也针对「注意力分给了无关内容」，但作用位置不同，这里只作对照：

- **Differential Transformer**：把注意力分数算成两张独立 softmax 注意力图之差，相减抵消噪声，促成稀疏的注意力模式。论文称它在长上下文建模、关键信息检索、减少幻觉、上下文学习与减少激活离群值等方面有优势（Differential Transformer 摘要）。
- **Forgetting Transformer（FoX）**：以数据依赖的方式对未归一化的注意力分数降权，把循环模型中的遗忘门引入 softmax 注意力。它兼容 FlashAttention，不需要位置编码，在长上下文语言建模、长度外推与短上下文下游任务上优于 Transformer（Forgetting Transformer 摘要）。

与本篇两类干预比较：分母偏置与汇 token 改变「多余的注意力放到哪里」，输出门控改变「注意力结果加回残差多少」，差分注意力与遗忘门改变「注意力分数本身」。

## 八、2026 年的统一视角

### 8.1 汇即隐式门控：Fu 等

Fu 等比较三种注意力：普通注意力、gpt-oss 式的汇注意力（softmax 分母加可学习的汇参数）、Qwen3-Next 式的门控注意力（Fu 等第 1 节）。

**等价改写**：普通注意力中，首 token 的值向量被学成接近零（「值排空」）；汇注意力中，汇参数本身没有值向量。两者都把多余的注意力导向对输出几乎没有贡献的对象（Fu 等第 3.1 节）。因此，一个头的有效输出等于「一减去汇上的注意力权重」乘以「在非汇 token 上重新归一化后的加权平均」。前一个因子就是一个隐式门，与门控注意力的显式门对应；它按头计算，并可以写成 sigmoid 形式（Fu 等第 3.1 节）。

**注意力层内的 MoE**：各个头是相互独立的专家，汇提供的隐式门是路由，所以注意力层内天然形成 MoE 结构（Fu 等第 3.1 节）。这解释了已有工作观察到的「头塌缩」：只有固定的一小部分头参与生成，类似 MoE 的专家塌缩。作者据此为三种注意力都设计了感知汇的辅助负载均衡损失，在 0.6B、1B、2B 从头训练的模型和 LLaMA3、Qwen3 的微调上报告了一致提升（Fu 等第 1 节）。

**去掉首 token 汇的好处**：在普通注意力中，为了让首 token 持续得到高注意力，后续 token 的查询要聚在首 token 的键附近，键又要被推离它，形成两极结构，限制了查询与键匹配的精度；汇注意力与门控注意力中没有这种两极结构（Fu 等第 3.2 节）。

**局限**：分析假设每个头只有一个汇。作者指出，在 DeepSeek-V4 等模型中，汇参数没有吸收全部多余注意力，首 token 仍会得到可观的注意力；门控注意力中也可能另外形成隐式门（Fu 等第 6.2 节）。

### 8.2 两种汇：Fesser 等

Fesser 等认为，同样的「竖条纹」注意力图背后可能是两种不同的计算（Fesser 等摘要、第 1 节）：

- **自适应不做事（no-op）**：头把注意力导向一个值接近零的 token，压制自己对残差的更新；特征是汇的值范数可以忽略。
- **广播**：汇聚合全局信息再分发给所有 token；特征是头的输出接近低秩。

他们在合成任务上形式化这两种机制并据此设计诊断方法，在预训练 ViT 中发现两者同时存在：浅层的汇在 CLS 上，深层转到图块上，并集中在特定的头（Fesser 等摘要）。

**结构干预在重组计算**（Fesser 等第 5、6 节，ViT-L LeJEPA 训练 50 个 epoch）：

- 门控把检测到的 no-op 汇从每张图 0.25 个降到 0，却把广播汇增加到每张图 3.80 个；
- 作者提出的不对应任何序列位置的「全局通路」加上惩罚项后，与门控组合，把广播汇降到每张图 0.53 个，同时 no-op 汇保持在接近零；
- 寄存器只是转移汇的计算，没有去掉它；
- 全局通路单独使用时最强地压制了广播汇，但三项探针都不如基线；门控加全局通路在密集探针上最好。

作者的结论是：汇的数量本身不能代表表征质量，有效的干预要先判断汇在算什么，再给模型提供另一条完成这种计算的通路（Fesser 等第 6 节）。这项研究的实验对象是 ViT，不是语言模型。

### 8.3 弃权与过滤：Wang

Wang 把 softmax 注意力缺的能力归为两项（Wang 摘要、第 1 节）：

- **弃权**：权重和为一，头即使没找到相关内容也必须输出点什么；
- **噪声过滤**：输出是值向量的加权平均，残差流中叠加的无关特征会和信号一样被原样传递。

作者论证，值通路上的门同时部分提供了这两项能力，这能解释为什么此前各项研究对门控收益的归因不一致（Wang 第 1 节）。为了分开测量，弃权用 gpt-oss 式的每头汇 logit 实现，相当于在 softmax 中加一个不对应任何 token、值固定为零的「幽灵键」；过滤用作用在每个值向量上的门实现（Wang 第 1 节）。

在 10M 到 350M 参数的配对模型上（Wang 摘要、第 4 节）：

- 10M 时门控的收益几乎全部来自弃权，到 350M 时过滤的贡献与弃权相当；因此一项研究看到什么，取决于它的规模；
- 两项收益大体可加，只有少量重叠；同时具备两者的变体在每个规模上验证损失都最低；
- 只由各个值自身决定的门会留下注意力汇，由查询控制的机制则能去掉它；
- 124M 的基线把 6.0% 的注意力放在第一个键位置上，有汇 logit 后降到 0.5%，多余注意力转到幽灵键上（Wang 第 4.3 节）；在 gpt-oss-20b 上，34% 到 48% 的注意力落在幽灵键上（Wang 第 4.3 节）。

作者在局限中说明，损失测量只到 350M、只用一个语料，过滤的收益在数十亿参数上是否继续增长未知（Wang 第 6 节）。

### 8.4 三项工作的共同点与分歧

| 问题 | Fu 等 | Fesser 等 | Wang |
|---|---|---|---|
| 汇是什么 | 隐式门控因子，使注意力层成为 MoE | 至少两种计算：no-op 与广播 | 模型在缺少弃权能力时的模仿 |
| 门控提供什么 | 显式门，对应汇的隐式门 | 直接的压制手段，对应 no-op | 部分弃权加部分过滤 |
| 实验对象 | 0.6B 到 2B 语言模型及 LLaMA3、Qwen3 微调 | 合成任务与 ViT | 10M 到 350M 语言模型，另测 gpt-oss-20b |

三者都把门控和汇看成同一需求的两种实现，但 Fesser 等提示，换掉一种实现后，模型可能在别处以另一种形式重建它。

## 九、工业采用

- **gpt-oss（2025-08）**：注意力块在带状窗口（带宽 128 token）与全稠密两种模式间交替；每个头在 softmax 分母中有可学习的偏置，类似分母加一与注意力汇，使注意力可以不分给任何 token（gpt-oss 模型卡第 2.2 节）。其余架构配置见 [[GPToss模型卡深读]]。
- **Qwen3-Next（2025-09）**：Qwen 官方模型卡写明，混合注意力用 Gated DeltaNet 与门控注意力的组合取代标准注意力；48 层按 12 组排列，每组 3 层「Gated DeltaNet 接 MoE」加 1 层「门控注意力接 MoE」；门控注意力层有 16 个查询头、2 个 KV 头（Qwen3-Next-80B-A3B-Instruct 模型卡）。阿里云社区 2025-09-12 的发布文同样称混合注意力由 Gated DeltaNet 与门控注意力组成（阿里云社区发布文）。Gated DeltaNet 一侧的门控属于线性注意力，见 [[线性注意力与状态空间模型谱系]]。
- **门控 MLA**：[[AXK2技术报告深读]] 与 [[KimiK3技术报告]] 记录了在 MLA 上加输出门的做法，本篇不重复其配置。

## 十、各类干预对照

| 干预 | 作用位置 | 提供什么 | 对注意力汇 | 代表来源 |
|---|---|---|---|---|
| 分母加一、每头汇偏置 | softmax 归一化 | 注意力可以整体趋于零 | 多余注意力转到偏置上 | Miller 博文；gpt-oss 模型卡 |
| 可学习汇 token、键偏置 | 序列或键 | 固定的注意对象 | 汇转移到该 token 或偏置 | StreamingLLM；Gu 等 |
| 寄存器 | 序列 | 存放全局信息的位置 | 转移而非去除 | Registers；Fesser 等 |
| SDPA 输出门 | 注意力输出 | 按头、依赖查询的缩放与稀疏 | 摘要称缓解 | 门控注意力论文 |
| 值门 | 值向量 | 逐值的噪声过滤 | 汇仍在 | 门控注意力论文；Wang |
| 去掉归一化 | 注意力算子 | 权重不再必须和为一 | 实验中不出现 | Gu 等；Ran-Milo |
| 差分注意力、遗忘门 | 注意力分数 | 抵消或衰减无关注意力 | 未作为主要目标 | Differential Transformer；FoX |

## 十一、意义

1. **把多个现象归到同一根源**：量化离群值、流式推理中删除开头 token 后的崩溃、ViT 伪影、巨量激活，都可以追溯到 softmax 权重和为一与「头需要不做事」之间的冲突。Bondarenko 等、Gu 等与 Ran-Milo 分别从量化、经验与理论三个角度给出这一解释。
2. **汇从缺陷变成功能**：早期工作以去除离群值或伪影为目标；Barbero 等、Ran-Milo 与 Fesser 等则说明汇承担了防止过度混合、实现默认输出或广播全局信息等作用。设计问题因此从「怎样去掉汇」变为「给这一功能提供什么更好的通路」。
3. **门控成为注意力的常规部件**：门控注意力论文在 15B MoE 与 1.7B 稠密规模上报告了收益、稳定性与长上下文外推的改善，Qwen3-Next 随后采用；gpt-oss 则采用汇偏置。两条路线在 2026 年被证明可以相互改写（Fu 等）。
4. **评估口径的提醒**：Fesser 等与 Wang 都指出，汇的多少不等于模型好坏，门控收益的来源随规模变化，单一实验得出的归因不宜外推。

## 十二、局限与待核实

1. **「缓解」与「消除」的措辞**：门控注意力论文摘要写门控「缓解」注意力汇，标题写「Attention-Sink-Free」，引言、第 5.2 节与结论写「消除」。本篇按摘要写「缓解」。图 2 图注中首 token 注意力平均仍有 4.8%。
2. **规模与对象差异**：门控注意力论文的结论来自 15B MoE 与 1.7B 稠密模型；Gu 等的 sigmoid 注意力实验到 1B；Fu 等到 2B；Wang 的损失测量到 350M；Fesser 等的实验对象是 ViT；Ran-Milo 的结论限于其构造的触发条件任务。各项结论能否推广到更大的语言模型，目前缺少直接证据。
3. **长上下文收益的解释**：门控注意力论文对外推提升的解释是假设，论文承认没有严格的理论说明。
4. **门控与汇是否等价**：Fu 等给出汇注意力与门控注意力的等价改写，但其分析假设每个头只有一个汇，作者自己指出 DeepSeek-V4 等模型的汇参数没有吸收全部多余注意力。Fesser 等在 ViT 中观察到，门控去掉 no-op 汇后广播汇反而增加。两者是否在大语言模型中同样成立，尚未见直接检验。
5. **工业模型缺少消融**：gpt-oss 模型卡与 Qwen3-Next 模型卡只描述了结构，没有公开汇偏置或门控注意力在各自模型上的消融结果。Qwen3-Next 的官方模型卡没有标注发布日期，本篇的 2025-09 依据阿里云社区发布文的页面日期。Hugging Face 模型卡页面未显示更新日期，按规范不计入截至。
6. **版本**：Bondarenko 等为 v2，Registers 为 v2，StreamingLLM 为 v4，Massive Activations 为 v2，Differential Transformer 为 v2，Gu 等为 v2，FoX 为 v2，Barbero 等为 v4，Fu 等为 v3，Ran-Milo 为 v5，Fesser 等为 v2，Wang 为 v2。本篇按 abs 页当前版本引用。Fesser 等 v1 的标题为「A Unifying View of Attention Sinks: Two Algorithms, Two Solutions」，v1 摘要写门控与寄存器组合带来互补收益，v2 改为门控与全局通路的组合，并写寄存器只转移汇的计算；本篇按 v2 写。Wang 的 v1 与 v2 摘要措辞也有变化，本篇按 v2 写。
