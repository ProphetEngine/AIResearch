# Periodic Weak Spots：分块 KV 压缩的相位敏感性

> **主要来源**：[Periodic Weak Spots: Phase Sensitivity from Chunked KV-Cache Compression](https://arxiv.org/abs/2609.36322)（Zhu、Yi、Cheng、Lv 等，ByteDance Seed，v1，2026-09-28 提交）（截至 2026-09-28）。下文节号、表号、图号均按 v1。
> **研究线**：架构思想（分块 KV 压缩引入的「相位」坐标与相位特化）· 评测字段（按相位扫描的检索评测）· 数学原理（最优压缩的集中性与梯度流下的静态集中）
> **范围与相邻笔记**：
> - ≠ [[DeepSeekV4技术报告深读]]、[[DeepSeekV41Flash深读]]：本篇不写 CSA、HCA、CSA2 的设计，只引用论文所述步长与相位实测。
> - ≠ [[原生稀疏注意力NSA]]：本篇不写 NSA 结构。
> - ≠ [[KV缓存量化与压缩]]：本篇不写 KV 低比特量化，对象是序列维分块压缩带来的位置周期性。
> - ≠ [[DuoAttention与KVzip]]：本篇不写按检索头分配缓存的方法。
>
> **意义**：长上下文评测早已知道「信息放在哪」会影响检索；这篇指出分块压缩还引入了一个以步长为周期的新位置坐标——同一信息平移几个 token，可检索性最多相差约 40 个百分点，而平均分完全看不出来。对用分块压缩的生产模型，可靠性需要按相位测。

**一句话**：分块 KV 压缩让每个 token 多出一个坐标「相位」（位置对压缩步长 $S$ 取模）；论文在 DeepSeek-V4 家族上测到同一信息在不同相位上的检索准确率最多相差 40.2 个百分点，在 Qwen3-0.6B 架构上从零训练的压缩模型中复现了现象，用 KV 头敲除发现不同头分管不同相位，并在理想化模型中证明最优压缩是集中的、梯度流会把集中固定为静态偏好；论文没有给出修复办法，主张按相位做评测。

## 一、问题背景

分块 KV 压缩把连续 token 按固定窗口分组，每个窗口压成少量缓存条目供长程检索，DeepSeek-V4 是论文点名的实际用例（§1）。压缩在读入上下文时完成、早于后续查询，所以每条摘要与查询无关，必须预先保留将来可能用到的信息。

这给上下文强加了周期结构：每 $S$ 个 token 开始一个新压缩窗口。在输入前插入几个 token，内容和相对位置不变，但哪些 token 被压在一起会变，同一信息可能以不同保真度保留（§1）。

| 符号 | 含义 |
|---|---|
| $W$ | 窗口大小：一条压缩条目汇总多少 token |
| $S$ | 步长：每隔多少 token 产生一条条目；$S<W$ 为重叠窗口 |
| 相位 | token 位置对 $S$ 取模，$t \bmod S$ |

**相位敏感**指某项检索指标随源信息相位系统性变化（§2.2）。论文自训模型的压缩核（§3.1）对窗口内每个位置算一个门控分数，窗口内 softmax 后加权汇总各位置的载荷；均匀平均相当于把门控固定为 $1/W$。下文 W8/S8 之类记号即窗口 8、步长 8。

## 三、前沿模型中的现象（§2、附录 B–C）

**代码补全的周期翻转（§2.1、图 1）。** DeepSeek-V4-Flash-Base 补全 V4 官方推理代码里的 `T.Cast(compute_dtype, T.Cast(FP`，原代码续写 `8`、竞争续写 `32`。只在前面加装饰性 docstring、把填充长度从 24 调到 39：$L \bmod 4\in\{2,3\}$ 时预测 `8`，其余预测 `32`，每 4 个 token 重复，与 V4 的步长 4 一致。V4.1-Flash（步长 2）也周期翻转；无分块压缩的 V3.1-Base 在同样 64 个输入中只有 4 个把 `32` 排在前面且差值很小。作者提醒这只是单例在平移下的表现，不是基准成绩。

**128K 大海捞针（§2.2、图 2、表 7）。** 每条提示 128K token、含 16k 个键值对，询问中部一个源键的值；按源键位置模 8 分组，各组的长度、查询位置与源键绝对位置的均值、方差都相同。

| 模型 | 最好−最差（pp） | 平均准确率（%） |
|---|---|---|
| V4-Flash-Base | 40.2 | 52.6 |
| V4-Flash-0731 | 19.1 | 91.4 |
| V4-Pro-Base | 34.8 | 72.1 |
| V4-Pro-0813 | 14.8 | 84.4 |
| V4.1-Flash | 6.1 | 92.38 |

最大差距在未经后训练的 base 检查点；后训练提高准确率、收窄差距，但后训练的 V4 模型差距仍大。V4.1-Flash 差距最小，但四个偶数组仍全部高于四个奇数组。

## 四、受控复现（§3、表 8）

DeepSeek-V4 与标准 Transformer 的差异不止分块压缩，也无法去掉压缩重训。作者因此以 Qwen3-0.6B 的架构为骨架从零预训练一族模型（不用其权重），KV 压缩是唯一实质改动，并用同样方式训练全注意力基线；参照模型为 W8/S8、每层 1 个 KV 头，训练 100B token、序列长 2,048。评测是 64 对单 token 键值的检索，用两种填充方式改变目标相位：整体平移所有记录，或只改记录间隙使干扰项相位不同步移动。

关键差距：
- 压缩模型都随源键相位周期变化，最好—最差差距最高 78 pp；三个全注意力基线最多 6.1 pp（§3.2）。
- 在所测配置中周期跟随步长，与窗口是否重叠无关；去掉 RoPE、用均匀平均替代学习门控、换成 DeepSeek 式压缩核后现象仍在；两种填充方式下都成立。
- **平均分会掩盖弱点**：8 个 KV 头时，W8/S8 压缩模型的平均准确率与验证损失都接近全注意力基线（59.4% 对 61.1%），最差相位组却只有 9.9%，基线为 58.4%。
- **窗口边界解释不了全部**：W8/S8 中只有相位 7 的键会把值推到下一个窗口，相位 0–6 的键值对都同窗，它们之间的准确率仍相差 50 pp 以上（图 3d）。

## 五、机制：相位特化（§4、附录 E、G、H）

**敲除。** 每次把一个 KV 头的读出替换成它在其他提示上的均值（均值替换敲除），看哪些相位的准确率下降。全注意力模型的损失在各位置大致均匀；压缩模型中部分头的损失集中在少数相位，不同头依赖的相位不同（图 4）。作者称之为**相位特化**。DeepSeek-V4-Flash-Base 每层只有一个共享 KV 头，只能做整层敲除，同样看到以 4 为周期的相位依赖。

**门控的静态集中（§4.2、图 5）。** 门控可以对每个窗口偏好相同的偏移（静态集中），也可以随内容变化（输入相关集中）；只有前者把头绑定到固定相位。训练后只有部分头形成静态集中，偏好位置因层而异，值门控比键门控晚一个偏移，即偏好「一个 token 及其后继」，与键值对结构相符；最大的敲除损失几乎都来自这些头。每个随机种子有 4–6 个集中头，位置因种子而异。

**门控循环移位（附录 H）。** 把门控整体循环移动 $\delta$ 个偏移，准确率图样随之平移 $\delta$ 个相位，但窗口边界相位的准确率始终很低、不随之恢复，总体准确率还下降 3.3–18.4 pp。作者称这是重新指派弱相位，而不是修复。

## 六、理论直觉（§5）

论文在理想化模型中（不重叠块、查询揭晓前选定压缩系数、要求取回同块中的后继 token）给出两个结论，证明与充分条件见附录 A：

- **定理 1：最优压缩是集中的。** 即使压缩系数可以任意依赖上下文，全局最优仍是每头每块把键权重全放在某个位置 $r$、值权重全放在 $r+1$；嵌入几何精确时同一块内各头选的位置互不相同。直觉：一个头对目标的贡献约等于「它对正确块的注意力 × 值系数在答案位置的权重」，集中压缩同时加强这两个因子，代价是放弃其他位置的证据。但最优性只要求每块集中，不要求所选位置在各输入间固定。
- **定理 2：梯度流产生静态集中。** 若门控是跨上下文共享的参数，从零附近初始化的梯度流会让每个头选定一个固定位置 $r_h$ 并保持到所有输入；不同头可能选到同一位置。直觉：门控沿嵌入均值的分量起到与输入无关的位置偏置作用，初始的对称状态不稳定，每个头各自滑向一条「键 $r$、值 $r+1$」的路线。这为实验中相邻偏移偏好提供了理想化解释，但实测门控比极限情形更软。

作者明确不主张首创注意力硬化或头分工理论，贡献限于「查询前选定的压缩」这一设定（§6）。

## 七、评测含义与已测改动（§6–7、附录 F）

作者建议按相位测量可靠性：保持被查询信息不变、把输入平移几个 token；高平均准确率可以与系统性的位置失败共存。他们还提出，语义不变的平移是否会改变拒答或服从行为、这种变化是否跟随压缩相位，值得后续研究。

论文没有提出专门的缓解方法。所有测试过的改动都没有消除周期弱点，收窄差距的往往以平均准确率为代价：相对 W8/S8 参照（差距 75.3 pp、均值 50.6%），均匀平均把差距降到 19.2 pp，但均值跌到 12.5%；重叠窗口 W8/S4 差距 39.8 pp、均值 66.9%；增加 KV 头（4 / 8 个）差距没有明显缩小（78.0 / 71.1 pp）。

## 八、意义

这篇把长上下文评测中的位置偏置从「整体深度」细化到「压缩步长内的相位」，并在生产模型上实测到大幅差距。它的直接含义是：采用分块压缩的模型，用平均分与少数固定位置做长上下文评估是不够的；架构侧还留下一个开放问题——能否在不牺牲平均性能和压缩率的前提下，让各相位更均匀。

## 九、局限与待核实

1. **大模型证据的范围**：DeepSeek 实验中外层填充把目标与干扰记录一起平移，目标相位与干扰项相位没有分开；能分开两者的填充方式只在自训小模型上做过（附录 C.1）。
2. **代码补全对照不纯**：V3.1-Base 与 V4-Flash-Base 在架构、训练与推理后端上都不同；作者只称结果与分块压缩是来源相一致（附录 B.2）。
3. **敲除的解释边界**：均值替换作用在压缩与局部条目的合并读出上，不能单独切除压缩记忆；各头效应不能相加；挑最大损失属探索性，未在留出提示上检验（附录 E）。DeepSeek 上只到整层粒度。
4. **门控解释的适用面**：主要适用于不重叠窗口；重叠窗口（含 DeepSeek 式核）按相位折叠后门控近于均匀（附录 G.3）。
5. **理论的理想化**：嵌入与 Q/K/V 固定、只训门控、单层、总体梯度流；不解释边界相位，不覆盖重叠窗口与真实语言分布。
6. **规模**：自训模型为 0.6B 级、100B token、序列长 2,048，与 128K 级生产模型的差距论文未讨论。
7. **V4.1-Flash 步长的对应**：论文写「stride two」，[[DeepSeekV41Flash深读]] §3.2 记编码器 CSA2 $m=2$、解码器 $m=1$，周期 2 来自哪些层论文与库内均未给出。
8. 图 14–18 的逐头曲线与热图只引正文与图注描述；本篇依据 v1（即 arXiv 最新版）。
