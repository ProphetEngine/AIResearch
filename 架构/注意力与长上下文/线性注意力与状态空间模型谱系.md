# 线性注意力与状态空间模型谱系

> **主要来源**：[Mamba: Linear-Time Sequence Modeling with Selective State Spaces](https://arxiv.org/abs/2312.00752)；[Transformers are SSMs: Generalized Models and Efficient Algorithms Through Structured State Space Duality](https://arxiv.org/abs/2405.21060)；[Gated Delta Networks: Improving Mamba2 with Delta Rule](https://arxiv.org/abs/2412.06464)；[Kimi Linear: An Expressive, Efficient Attention Architecture](https://arxiv.org/abs/2510.26692)（截至 2026-10-08）。其余来源见第九节。

> **意义**：这条线把长上下文解码的显存与每步计算从随长度增长降为常数，是近一年 Qwen3.8-Next、Kimi K3 等旗舰采用混合架构的前置知识；它的召回短板也解释了为何工业界几乎都保留少量全注意力层。

**一句话**：softmax 注意力在解码时要读一份随长度线性增长的 KV 缓存，而线性注意力与状态空间模型（SSM）把全部历史压进一个固定大小的状态，使每个新 token 的计算与显存为常数。这条线从「去掉 softmax 后可写成 RNN」出发，经历了衰减与门控（RetNet、Mamba、GLA）、状态空间对偶（Mamba-2）和 Delta 规则（DeltaNet、Gated DeltaNet、KDA）三步，表达力与硬件效率不断提高；但固定状态在精确召回上存在根本短板，所以当代工业模型几乎都采用「多数线性层加少数全注意力层」的混合结构，也有厂商在评估后回到全注意力。

## 一、问题背景：KV 缓存与二次复杂度

1. **训练侧**：softmax 注意力对长度为 $N$ 的序列做 $O(N^2)$ 计算；FlashAttention 一类方法省的是显存搬运，不改变二次计算量。
2. **推理侧**：解码每步都要读完整 KV 缓存，缓存随上下文线性增长。长思维链、智能体多轮交互与百万级上下文让解码成为成本大头。
3. **三条降本路线**：压缩每个 token 的 KV（MQA、GQA、MLA，见 [[注意力效率族MQA到MLA]]）；只看一部分 token（稀疏注意力，见 [[原生稀疏注意力NSA]]）；以及本篇的路线——不再按 token 存历史，而是维护一个大小与长度无关的状态。

第三条路线的诱惑在于解码时显存与每步计算都是常数；代价是信息必须被压缩，而压缩会丢东西。整条谱系的演进都可以理解为「怎样在固定容量里记得更准」。

## 三、核心思想与关键机制

### 3.1 去掉 softmax，注意力就变成 RNN

因果 softmax 注意力的输出是 $o_t=\sum_{i\le t}\mathrm{softmax}(q_t^\top k_i)\,v_i$，每步都要回看全部历史。若把 softmax 换成可分解的相似度 $\phi(q)^\top\phi(k)$，求和可以先对 $i$ 累加：

$$S_t=S_{t-1}+v_t\,\phi(k_t)^\top,\qquad o_t=S_t\,\phi(q_t)$$

状态 $S_t$ 是一个 $d_v\times d_k$ 的矩阵（本篇按 Gated DeltaNet 论文的约定，[[Qwen38Next架构深读]] 用的是转置写法），大小与长度无关。这就是「线性注意力 = 以矩阵为隐状态的 RNN」。早期工作的问题有两个：质量明显不如 softmax，以及实现不够 IO 友好、实际并不快（GLA 摘要）。

### 3.2 三种计算形态：训练要并行，推理要递归

同一个层可以用三种方式计算（RetNet 摘要）：

| 形态 | 怎么算 | 用在哪 |
|---|---|---|
| 并行形式 | 像注意力一样写成 $N\times N$ 带掩码矩阵 | 短序列训练 |
| 递归形式 | 逐 token 更新状态，每步 $O(1)$ | 解码 |
| 分块形式 | 块内用并行形式（矩阵乘），块间传递状态 | 长序列训练与预填充 |

分块形式是这条线能落地的关键：块内计算能用上 Tensor Core，块间只传一个小状态。GLA 的 FlashLinearAttention 即这一思路，官方称作为独立层在 1K 长度上已快于 FlashAttention-2（GLA 摘要）。后续每种新的更新规则，都要配一套分块并行算法才算可用。

### 3.3 状态更新规则的演进：从只写不擦到先读后改

整条谱系的主要差别在于状态怎么更新。按 Gated DeltaNet 论文的约定（$S\in\mathbb{R}^{d_v\times d_k}$，输出 $o_t=S_tq_t$）：

| 规则 | 更新式 | 直觉 | 代表 |
|---|---|---|---|
| 加性 | $S_t=S_{t-1}+v_tk_t^\top$ | 只写不擦，状态很快被旧信息塞满 | 线性 Transformer |
| 衰减/门控 | $S_t=\alpha_tS_{t-1}+v_tk_t^\top$ | 按比例遗忘旧内容；$\alpha$ 固定为 RetNet（每头一个常数，RetNet §2.2），随输入变化为 Mamba-2（标量）、GLA（逐通道，GLA §4.1） | RetNet、Mamba-2、GLA |
| Delta 规则 | $S_t=S_{t-1}+\beta_t\,(v_t-S_{t-1}k_t)\,k_t^\top$ | 先用 $k_t$ 读出旧值，只把新旧之差写回，相当于定向覆盖 | DeltaNet |
| 门控 Delta | $S_t=\alpha_t\,S_{t-1}(I-\beta_tk_tk_t^\top)+\beta_tv_tk_t^\top$ | 门控负责整体清空，Delta 负责精确改写 | Gated DeltaNet |
| 细粒度门控 Delta | 把标量 $\alpha_t$ 换成逐通道的对角门控 | 不同通道以不同速度遗忘，更充分利用有限状态 | KDA（Kimi Linear） |

**在线学习视角**。把状态看成一组「快权重」，Delta 规则正好是对回归目标 $\tfrac12\lVert S_tk_t-v_t\rVert^2$ 做一步随机梯度下降，$\beta_t$ 就是学习率（Gated DeltaNet §3.1 对快权重与测试时训练视角的总结；线性注意力与快权重的等价性最早见 Schlag 等 2021）。这解释了 Delta 规则为何召回更好：加性写入只会累积，而梯度步会纠正已有的错误映射。同一视角下，把快权重换成 MLP、把一步梯度换成多步优化，就走到了测试时训练，见 [[测试时训练]]。

### 3.4 SSM 一支：S4 → Mamba → Mamba-2

- **S4**：从连续时间系统 $x'(t)=Ax(t)+Bu(t)$、$y(t)=Cx(t)+Du(t)$ 出发，参数与时间无关（LTI），整个层可以写成一个长卷积高效训练；关键是对 $A$ 做结构化参数化，使计算稳定高效（S4 摘要）。LTI 的弱点是对所有输入一视同仁，难以「看内容决定记什么」。
- **Mamba**：让 $B$、$C$ 与步长 $\Delta$ 随当前 token 变化（选择性），模型可以按内容选择传播或遗忘信息；代价是不能再用卷积，于是设计了硬件感知的并行扫描。官方称推理吞吐约为 Transformer 的 5 倍，Mamba-3B 与两倍规模的 Transformer 相当（Mamba 摘要）。
- **Mamba-2 与状态空间对偶**：把 $A$ 从对角进一步简化为「标量乘单位阵」，并把头维从 1 加大到 64 或 128（Mamba-2 §2.4）。此时整个 SSM 等于一个带衰减掩码的注意力矩阵 $(L\circ QK^\top)V$，其中 $L_{ij}=a_i\cdots a_{j+1}$（$i\ge j$）。同一个映射既可按递归线性计算，也可按二次的注意力形式计算，分块算法在两者间取长补短，能用上矩阵乘单元。官方称核心层比 Mamba 的选择性扫描快 2–8 倍，状态可大 8 倍以上而几乎不减速（Mamba-2 摘要、§1）。

对偶的意义在于：SSM 与线性注意力从此被看作同一个家族（Mamba-2 ≈ 带数据依赖标量衰减的线性注意力），后续的门控与 Delta 改进可以在两套语言之间互相翻译。

## 四、根本取舍：固定大小状态与 KV 缓存

| 维度 | softmax 注意力（KV 缓存） | 线性注意力 / SSM（固定状态） |
|---|---|---|
| 解码显存 | 随上下文线性增长 | 常数 |
| 每步解码计算 | 随上下文线性增长 | 常数 |
| 历史信息 | 原样保留，可精确回查任一 token | 有损压缩，容量由状态大小决定 |
| 擅长 | 精确召回、复制、多跳检索 | 长程平滑依赖、长度外推、吞吐 |

- **召回与状态大小的取舍**：Based 的实验与理论表明，H3、Mamba、RWKV 等维护固定大小循环状态的模型在召回上吃力，状态越大召回越好，形成一条「召回–显存」帕累托曲线（Based 摘要）。
- **复制的理论下界**：Jelassi 等证明两层 Transformer 可以复制指数长度的字符串，而固定状态模型受状态大小根本限制；预训练模型上 Transformer 在复制与上下文检索上也明显占优（Repeat After Me 摘要）。
- **更新规则能缓解、不能消除**：Mamba-2 的大状态在多查询联想召回（MQAR）上明显好于 Mamba（Mamba-2 图 8）；Kimi Linear 的合成任务中，只有乘性衰减、没有 Delta 规则的 Mamba-2 在其设置下全部失败（Kimi Linear §5.1）。这些改进提高的是同等状态下的利用效率，容量上限仍在。

因此「纯线性模型」在长上下文检索、精确引用类任务上始终有风险，这直接催生了混合架构：用大量线性层承担吞吐，用少量全注意力层保留精确检索。混合的比例与摆放规律见 [[混合Mamba与注意力架构设计菜谱]]。

## 五、混合架构与工业取舍

| 模型 | 线性/SSM 层 | 与全注意力的比例 | 官方称的收益 | 详见 |
|---|---|---|---|---|
| Jamba（2024-03） | Mamba | 注意力:Mamba = 1:7，另在部分层加 MoE | 52B 总参 / 12B 激活；int8 权重下单卡 80GB 可容纳超过 128K 上下文，长上下文评测至 256K | Jamba 摘要、§1、§3.1 |
| MiniMax-Text-01 / M1 | Lightning Attention（线性注意力的 IO 感知实现） | 每 7 个线性块接 1 个 softmax 块 | 训练 1M、推理外推至 4M 上下文 | [[MiniMaxM1技术报告深读]]；4M 见 MiniMax-01 摘要 |
| Nemotron-H（2025-04） | Mamba | 大多数自注意力层换成 Mamba | 推理最高快约 3 倍，精度相当 | Nemotron-H 摘要；[[Nemotron3Ultra技术报告深读]] |
| Qwen3.8-Next | Gated DeltaNet | 每 4 层 3 层 GDN、1 层全注意力（256K 继续预训练阶段该层换为 QSA） | 见该篇 | [[Qwen38Next架构深读]] |
| Kimi Linear（2025-10） | KDA | KDA:MLA = 3:1，MLA 层不用位置编码 | 1.4T token 公平对比下优于全 MLA；KV 缓存最多省 75%，1M 上下文解码吞吐最高约 6 倍 | Kimi Linear 摘要、§4 |
| Kimi K3 | KDA | 每块 3 层 KDA 加 1 层门控 MLA，骨干末另加一层门控 MLA，共 69 KDA + 24 MLA；MLA 层不用位置编码 | 见该篇 | [[KimiK3技术报告]] |

两个规律值得注意。其一，表中各家的比例集中在 3:1 到 7:1：Kimi Linear 的消融中 3:1 的训练与验证困惑度最低，7:1 验证困惑度变差，1:1 质量相近但推理开销更高，纯全注意力（0:1）最差（Kimi Linear §5.2）。其二，线性层可以承担位置信息：Kimi Linear 让全部 MLA 层不用位置编码，把位置与近因偏置完全交给 KDA，理由是门控 Delta 的状态转移可视为一种数据依赖、可学习的乘性位置编码（Kimi Linear §2、§4），Kimi K3 沿用了这一做法；Qwen3.8-Next 则因后训练中无尽生成明显增多而保留 RoPE（见 [[Qwen38Next架构深读]]），说明这一选择仍依赖具体配方。

**反方案例**。MiniMax-M2 系列报告称，在覆盖推理、代码、智能体的生产环境中，没有找到能稳定追平全注意力质量的高效注意力变体，因此放弃了 MiniMax-01 的混合设计；理由包括两点：一是混合模型在标准基准上看似持平，但难以可靠测出复杂任务上的质量损失；二是线性与稀疏注意力的基础设施不如全注意力成熟——许多线性结构在训练时就受访存限制，推理侧还面临低精度存储敏感、缺少原生前缀缓存、与投机解码集成不明等问题（MiniMax-M2 报告 §2.2.2；§2.1 与 §2.2.2 首句均写明全部层采用全注意力）。

需要注意两点：该节中系统开展的混合实验是滑动窗口注意力混合（Hybrid SWA，各变体在检索、多跳推理与上下文学习上均退化），对线性注意力的判断则来自 MiniMax-01 的开发经验；该节末的展望也写道，随上下文变长、GPU 算力扩展放缓，次二次注意力会越来越重要，他们正在长上下文数据、评测方法与基础设施上投入（同节）。这说明混合架构的取舍不仅是模型质量问题，也是整套训练与服务系统的成熟度问题。

## 七、意义

- **把长上下文的边际成本从线性降到常数**：对长思维链、智能体长轨迹和百万级上下文，混合模型的解码显存与延迟优势随长度扩大，这是近一年旗舰模型采用它的主要动机。
- **统一了三个看似不同的传统**：线性注意力、RNN、状态空间模型通过「矩阵状态 + 更新规则」和状态空间对偶被放进同一框架，设计空间变得可比较、可组合。
- **把「记忆」变成可设计的对象**：衰减、门控、Delta 规则分别对应遗忘、选择性写入和纠错式写入；在线学习视角又把它与测试时训练连起来。
- **推动系统层改造**：分块并行内核成为每种新层的必需品；上下文并行对线性层要传递的是固定大小的状态而非 K/V（Kimi K3 的做法见 [[KimiK3技术报告]]），与 Ring Attention 等按 K/V 设计的方案不同，后者的机制与取舍见 [[分布式训练并行策略]]。

## 八、局限与待核实

1. **「超过全注意力」的口径**：Kimi Linear 称在多种场景的公平对比下超过全注意力，依据是其 48B 总参、3B 激活规模与 1.4T token 的设置；MiniMax-M2 报告则在生产场景得出相反结论。两者的任务、规模与评测不同，本篇不作裁决。
2. **效率数字的条件**：Mamba 的 5 倍吞吐、Mamba-2 的 2–8 倍、Kimi Linear 的约 6 倍解码吞吐都绑定特定长度、硬件与实现；在短上下文下，线性层的优势很小。MiniMax 的博文 [Why Did M2 End Up as a Full Attention Model?](https://www.minimax.io/news/why-did-m2-end-up-as-a-full-attention-model)（2025-10-29）称理论交叉点在数千 token，但实际要解决访存与服务侧问题才能接近；本篇未逐一复核各论文的交叉点。
3. **混合比例**：3:1、7:1 等是各家在各自设置下的选择，并不互相可比；跨规模、跨任务的规律以 [[混合Mamba与注意力架构设计菜谱]] 的对照实验为准。
4. **未展开的分支**：RWKV 后续版本、Hyena 等长卷积模型、xLSTM、滑动窗口注意力与线性层的组合、线性层上的投机解码与前缀缓存实现，本篇未覆盖。
