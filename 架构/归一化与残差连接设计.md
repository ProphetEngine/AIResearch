# 归一化与残差连接设计

> **主要来源**：[On Layer Normalization in the Transformer Architecture](https://arxiv.org/abs/2002.04745)（简称 Xiong 等）；[Root Mean Square Layer Normalization](https://arxiv.org/abs/1910.07467)（简称 RMSNorm 论文）；[Peri-LN](https://arxiv.org/abs/2502.02732)（简称 Kim 等）；[Hyper-Connections](https://arxiv.org/abs/2409.19606)（简称 HC 论文）；[mHC: Manifold-Constrained Hyper-Connections](https://arxiv.org/abs/2512.24880)（简称 mHC 论文）；[Attention Residuals](https://arxiv.org/abs/2603.15031)（简称 AttnRes 论文）；[On the Design of Qwen3.8-Next Architecture](https://arxiv.org/abs/2608.30320)（简称 Qwen3.8-Next 报告）；[DeepSeek-V4.1-Flash](https://arxiv.org/abs/2609.19969)（简称 V4.1-Flash 报告）（截至 2026-09-17）。其余来源见第十二节。
> **研究线**：架构思想（归一化放在残差的哪个位置、用什么形式；残差从单条加和的通路扩展为多条流、带门控的读法或跨层注意力）· AI Infra（多流残差与跨层注意力带来的显存访问与流水线通信开销，以及相应的内核与缓存设计）
> **范围与相邻笔记**：
> - ≠ [[注意力与Transformer核心思想]]：本篇不写原始 Transformer 的整体结构，只从其后的归一化位置之争写起。
> - ≠ [[优化器与训练稳定性]]：本篇不写优化器、QK-Clip、软截断与权重衰减，只写 QK-Norm 这一结构本身。
> - ≠ [[DeepSeekV4技术报告深读]]：本篇不写该报告的完整架构表、MoE 与注意力变体，只写其中的 mHC 以及 query 与 KV 条目上的 RMSNorm。
> - ≠ [[KimiK3技术报告]]：本篇不写该报告的完整架构表、KDA 与 MoE，只写其中的 Block AttnRes。
> - ≠ [[Qwen38Next架构深读]]：本篇不写该报告的完整架构表、GDN 混合与注意力变体，只写其中的门控残差。
> - ≠ [[DeepSeekV41Flash深读]]：本篇不写 KV 缓存压缩，只写 Single-Pass mHC 与对应内核。
>
> **意义**：Transformer 每个子层都由「归一化加残差」包裹。来源把归一化的位置与残差的形式同训练是否稳定、能堆多深、每层贡献是否被稀释联系在一起。2020 年 Xiong 等从梯度角度比较 Post-LN 与 Pre-LN；此后 Pre-LN 加 RMSNorm 成为 LLaMA 等模型的写法，QK-Norm 用于抑制注意力 logit 过大。2024 年起，Hyper-Connections 把残差加宽为多条流，mHC 用双随机矩阵约束其混合以恢复稳定性；AttnRes 用对前面各层输出的注意力替代固定加和；Qwen3.8-Next 报告把加宽的流与逐元素门控结合。DeepSeek-V4、Kimi K3 与 Qwen3.8-Next 分别在产品模型中采用了 mHC、Block AttnRes 与门控残差，各报告也写明了为此付出的显存访问与通信开销及对应的工程设计。

## 一、问题背景

**残差与归一化的位置**：Xiong 等指出，原始 Transformer 把层归一化放在残差块之间（Post-LN）；在初始化时，输出层附近参数的期望梯度很大，直接用大学习率会让训练不稳定，因此需要学习率预热。把层归一化放进残差块内部（Pre-LN）时，初始化时的梯度表现良好，可以去掉预热阶段，以更少的训练时间与超参数调节取得相当的结果（Xiong 等摘要）。

**Pre-Norm 与 Post-Norm 的取舍**：HC 论文把两者概括为梯度消失与表征坍缩之间的「跷跷板」：Pre-Norm 在每个残差块之前做归一化，能缓解梯度消失，但会导致深层表征坍缩；Post-Norm 在残差块输出之后做归一化，能缓解表征坍缩，但又会重新引入梯度消失（HC 论文第 1 节）。

**Pre-LN 的稀释问题**：AttnRes 论文指出，带 PreNorm 的残差连接用固定的单位权重累加所有层的输出；这种均匀聚合使隐状态随深度不受控地增长，逐步稀释每一层的贡献（AttnRes 论文摘要）。Qwen3.8-Next 报告的说法相近：Pre-normalization 让大规模训练保持稳定，但削弱了每层收到的信号，每个块读的是同一条流，早期写入的特征要与之后写入的一切竞争（Qwen3.8-Next 报告第 2.2 节）。

**注意力 logit 过大**：ViT-22B 的作者报告，在约 8B 参数的模型上，训练几千步后损失发散，原因是注意力 logit 值极大，导致注意力权重接近 one-hot、熵接近零（ViT-22B 第 2 节）。

## 二、术语与位置谱系

本篇统一使用以下称呼。下表的「位置」均以一个子层（注意力或 MLP）及其残差加和为单位描述。

| 称呼 | 归一化放在哪里 | 来源中的描述 | 出处 |
|---|---|---|---|
| Post-LN | 子层输出与残差相加之后，即残差块之间 | 初始化时输出层附近期望梯度大，需要预热 | Xiong 等摘要、第 3 节 |
| Pre-LN（Pre-Norm、pre-normalization） | 子层输入处，在残差通路之内；另加一层最终归一化再做预测 | 初始化时梯度表现良好，可去掉预热 | Xiong 等摘要、第 3 节 |
| Peri-LN | 子层的输入与输出各做一次，并对输入嵌入与最终输出嵌入做归一化 | 多个开源模型已采用而未加解释，Kim 等为其命名 | Kim 等摘要、第 3.3 节 |
| DeepNorm | 仍是 Post-LN 的位置，但先把残差放大再归一化 | 兼取 Post-LN 的效果与 Pre-LN 的稳定 | DeepNet 摘要 |
| QK-Norm | 注意力内部，对 query 与 key 在点积之前归一化 | 抑制注意力 logit 过大 | Henry 等摘要；ViT-22B 第 2 节 |

Kim 等写道，Gemma 与 OLMo 两个模型家族都在模块输出处加了归一化（Output-LN），采用的就是同一种 peri-normalization 做法，但两条工作线都没有严格研究这一位置如何约束方差、缓解大的残差激活（Kim 等第 3.3 节）。Gemma 4 报告写作「pre-norm and post-norm with RMSNorm」（Gemma 4 报告第 2 节）。

## 四、归一化的形式

### 4.1 LayerNorm 与 RMSNorm

**LayerNorm**：在单个训练样本上，用一层神经元的全部加和输入计算均值与方差，先减去均值、再除以标准差，然后每个神经元各有一个自适应的偏置与增益。它在训练与测试时做完全相同的计算，也可直接用于循环网络（LayerNorm 论文摘要）。

**RMSNorm**：RMSNorm 论文假设 LayerNorm 中的「重新居中」（减去均值带来的平移不变性）并非必需，只保留「重新缩放」：不减均值，只用输入的均方根去除。论文称这带来重新缩放不变性与隐式的学习率自适应，计算更简单；在多种任务与网络上，效果与 LayerNorm 相当，运行时间缩短 7% 到 64%。论文还提出 pRMSNorm，只用部分（6.25%）加和输入估计均方根，效果与 RMSNorm 相当（RMSNorm 论文摘要、结论）。

两者的区别用文字概括：LayerNorm 先减均值再按标准差缩放，RMSNorm 跳过减均值、直接按均方根缩放；两者都保留逐通道的可学习增益。

### 4.2 QK-Norm

**QKNorm**：Henry 等对每个 query 与 key 沿头维度做 ℓ2 归一化，再乘一个可学习参数放大，而不是除以嵌入维度的平方根。论文报告在 TED Talks 与 IWSLT'15 的 5 个低资源翻译对上平均提高 0.928 BLEU（Henry 等摘要）。

**ViT-22B 的做法**：为解决第一节所述的发散，ViT-22B 沿用 Gilmer 等的做法，在点积之前对 query 与 key 施加 LayerNorm；论文图 1 展示了它对一个 8B 参数模型防止发散的效果（ViT-22B 第 2 节）。

**DeepSeek-V4 的变体**：DeepSeek-V4 在 CSA 与 HCA 两种注意力中，在核心注意力运算之前，对 query 的每个头以及压缩 KV 条目的唯一一个头再做一次 RMSNorm，报告称这能避免注意力 logit 爆炸、可能改善训练稳定性（DeepSeek-V4 报告第 2.3.3 节）；报告第 2.4 节称因此在 Muon 优化器中不使用 QK-Clip。QK-Clip 本身归 [[优化器与训练稳定性]]。

QK-Norm 作用在点积之前的 query 与 key 上；注意力输出上的门控与汇 token 是注意力内部的另一组设计，归 [[门控注意力与注意力汇]]。

### 4.3 nGPT：超球面上的归一化

nGPT 把构成网络的所有向量（嵌入、MLP、注意力矩阵与隐状态）都做单位范数归一化。输入 token 在超球面上移动，每一层在超球面上贡献一段朝向输出预测的位移，这些位移由 MLP 与注意力块给出，其向量分量也位于同一超球面上。论文称 nGPT 学得快得多，达到相同精度所需的训练步数减少 4 到 20 倍，取决于序列长度（nGPT 摘要）。

### 4.4 DyT：不用归一化

DyT 论文观察到，训练好的 Transformer 中 LayerNorm 的输入输出映射常呈类似 tanh 的 S 形曲线，据此提出 Dynamic Tanh：对输入逐元素乘一个可学习的标量 α 后取 tanh，作为归一化层的直接替换（DyT 第 3 节、第 4 节）。α 让网络按输入的取值范围做不同缩放，「Dynamic」由此得名；逐通道的可学习缩放与平移参数与归一化层相同，视为 DyT 层的一部分（DyT 第 4 节）。论文称使用 DyT 的 Transformer 在多数情况下无需调超参数即可达到或超过带归一化的模型（DyT 摘要）。

DyT 论文第 9 节列出的局限：实验集中在使用 LN 或 RMSNorm 的网络；初步实验显示 DyT 难以直接替换 ResNet 等经典网络中的 BN；在妥善编译优化后，DyT 相对带归一化层的模型没有速度提升。

## 五、归一化的位置

### 5.1 Post-LN 与 Pre-LN

见第一节与第二节：Xiong 等用初始化时的梯度分析解释了 Post-LN 需要预热、Pre-LN 可以去掉预热（Xiong 等摘要）。LLaMA 沿用 GPT-3 的 Pre-normalization：「为了提高训练稳定性，我们对每个 Transformer 子层的输入而不是输出做归一化」，并使用 RMSNorm（LLaMA 第 2.2 节）。Qwen3 的稠密模型使用带 pre-normalization 的 RMSNorm，去掉了 Qwen2 中的 QKV 偏置，并引入 QK-Norm 以保证训练稳定（Qwen3 报告第 2 节）。

### 5.2 Peri-LN

Kim 等把在子层周围（输入与输出两处）放归一化的做法命名为 Peri-LN，并在最大 3.2B 参数的 Transformer 上做实验（Kim 等摘要）。实验设定为 400M、1.5B 与 3.2B 三档参数，每个模型训练 30 billion token（原文「30 billion tokens」），每个设定用五个随机种子预训练（Kim 等第 4.1 节）。

论文的描述（Kim 等第 3.3 节、第 5.1 节）：

- Post-LN 的主通路上有归一化层，各层隐状态的幅度与方差保持稳定。
- Pre-LN 在每个注意力与 MLP 子层之后没有归一化，残差相加后隐状态的幅度与方差呈指数增长。
- Peri-LN 多出的输出归一化让这些统计量保持相对受控；论文称 Peri-LN 的方差增长更均衡、梯度流更平稳、收敛更稳定（摘要）。

### 5.3 DeepNorm

DeepNet 论文提出 DeepNorm：在 Post-LN 的位置做层归一化之前，先把残差放大（乘以常数 α）再与子层输出相加；同时在初始化时把参数缩小（DeepNet 第 2 节）。论文称这兼具 Post-LN 的良好效果与 Pre-LN 的训练稳定性，使 Transformer 可以扩展到 1,000 层（2,500 个注意力与前馈子层），比此前的深层 Transformer 深一个数量级。在覆盖 7,482 个翻译方向的多语言基准上，其 200 层、3.2B 参数的模型比 48 层、12B 参数的最佳模型高 5 BLEU（DeepNet 摘要）。

## 六、残差的扩展

### 6.1 Value Residual

Value Residual Learning 论文指出，标准的隐状态残差往往难以在深层保留初始的 token 级信息。ResFormer 在注意力的 value 上增加残差连接；SVFormer 让所有层共享第一层的 value 嵌入。论文称 ResFormer 用少 16.11% 的模型参数、少 20.3% 的训练数据达到与 Transformer 相同的验证损失，内存与计算开销相近；SVFormer 把 KV 缓存规模减少近一半，性能代价很小（Value Residual 摘要）。这两个比例的实验规模见论文第 4.2 节：在 20B token 上训练 82M、180M、320M 与 468M 参数的模型，16.11% 来自这组模型规模扩展的比较；20.3% 来自对 468M 模型每 2B token 的评估（Value Residual 第 4.2 节）。

### 6.2 Hyper-Connections

HC 论文把隐状态复制 n 份（n 为扩展率），组成一个超隐状态矩阵；宽度方向（不同流之间）与深度方向（层与层之间）的连接由一个矩阵表示。连接权重可以是可学习的常数（静态），也可以随输入变化（动态，DHC）；最后一层的超隐状态按行求和得到输出（HC 论文第 2 节、附录中的算法）。

结果（附模型规模）：

- 7B 稠密模型：n 为 4 的 OLMo-7B-DHC 在 V2 评测中损失改善 0.022、困惑度改善 0.293，下游平均分 0.710，基线为 0.701（HC 论文第 4.3 节）。
- MoE 模型：在 OLMoE-1B-7B 上，许多指标只需基线一半的训练 token 就能达到相同表现（HC 论文第 4.4 节）。

### 6.3 mHC：用双随机矩阵约束混合

**问题**：mHC 论文称 HC 破坏了残差连接固有的恒等映射性质，导致严重的训练不稳定、限制可扩展性，并带来显著的显存访问开销（mHC 论文摘要）。在 27B 模型上，以 mHC 为对照，HC 在约 12k 步出现意外的损失突增，与梯度范数的不稳定高度相关（mHC 论文第 3.1 节）。

**做法**：把残差混合矩阵投影到双随机矩阵（每行每列之和都为 1 的非负矩阵，即 Birkhoff 多胞形）上。投影用 Sinkhorn-Knopp 算法：先对矩阵各元素取指数使其为正，再交替把行与列重新缩放到和为 1；理论上迭代无穷次收敛，实验中取 20 次（mHC 论文第 4.2 节）。DeepSeek-V4 报告列出这一约束的性质：混合矩阵的谱范数不超过 1，残差变换不扩张；双随机矩阵集合对乘法封闭，深层堆叠时仍保持稳定；输入与输出变换用 Sigmoid 约束为非负且有界，避免信号相互抵消（DeepSeek-V4 报告第 2.2 节）。

**稳定性与规模**：

- HC 中复合映射的最大增益幅度接近 3000，mHC 把它降低了三个数量级（mHC 论文第 5.4 节）。
- 实验使用受 DeepSeek-V3 启发的 MoE 结构：主结果为 27B 模型，按参数量比例配数据；另有 3B 与 9B 模型考察算力扩展，以及一个在 1 万亿 token 上训练的 3B 模型考察 token 扩展（mHC 论文第 5.1 节）。随算力增加，性能优势基本保持，只有轻微衰减（第 5.3 节）。
- 开销：扩展率 n 为 4 时，额外时间开销只有 6.7%（mHC 论文摘要、第 1 节）。

### 6.4 Stream Collapse：多流是否真的被用上

Alimaskina 等用 n 为 4 的 mHC-lite nanoGPT 模型分析 HC（Stream Collapse 第 2.1 节）。他们发现，早期层的混合矩阵有大量非对角成分，较深层的混合矩阵接近恒等，残差混合在初期播种之后近似旁路（第 2.2 节）；训练后的模型把大部分信号、表征范数与可解释特征集中在单条主导流中（第 4 节）。论文提出 Learned Stream Scaling（LSS）在初始化时打破流之间的对称性，称它减少了这种坍缩，并在多个 mHC 变体上改善了困惑度（摘要、第 3.2 节）。

### 6.5 Attention Residuals

**Full AttnRes**：把 PreNorm 残差的固定累加替换为对前面各层输出的 softmax 注意力，使每层能以学到的、依赖输入的权重选择性地聚合更早的表征（AttnRes 论文摘要）。Kimi K3 报告的描述是：AttnRes 用可学习的伪查询，对嵌入与前面各块的输出计算注意力权重（K3 报告第 2 节图注、第 2.2 节）。

**Block AttnRes**：对全部前层输出做注意力，在大规模训练中会带来显存与通信开销。Block AttnRes 把各层分成若干块，块内求和，块间做注意力，在减少显存占用的同时保留 Full AttnRes 的大部分收益（AttnRes 论文摘要）。K3 报告写道，Block AttnRes 把显存与通信开销从与层数乘以隐维度同阶降为与块数乘以隐维度同阶，经验上约 8 个块就能在各种模型规模上恢复大部分收益（K3 报告第 2.2 节）。

**结果（附规模）**：

- 扩展律实验中，Block AttnRes 的损失与用 1.25 倍算力训练的基线相当（AttnRes 论文第 1 节、第 5.1 节，仅见 PDF）。
- 集成进 Kimi Linear 架构（总参数 48B、激活 3B）并预训练 1.4T token 后，论文称 AttnRes 缓解了 PreNorm 稀释，各层输出幅度与梯度分布更均匀，所有评测任务的下游表现都有提升（AttnRes 论文摘要）。

### 6.6 门控残差（Qwen3.8-Next）

**只加宽**：Qwen3.8-Next 报告先用一个适配 pre-norm 网络的简化 AltUp 变体考察「只加宽」带来多少收益：残差状态由 n_r 条分支组成，每个块用 n_r 个可学习标量加权读取，输出按深度轮流写回其中一条分支。这只增加 n_r 个参数、没有矩阵乘法，额外代价是搬运多条分支的显存流量；在一个训练 400B token 的 25B-A3B MoE 模型上，训练损失降低约 0.01（Qwen3.8-Next 报告第 2.2 节）。

**读写机制的取舍**：在加宽的流上，静态算子比 pre-norm 基线降低损失 0.021，改成随数据变化再降低 0.002；基准平均分则相反，从基线到静态提高 1.58 分，从静态到动态再提高 1.98 分。报告称这是损失与下游精度走势不一致的一个例子（Qwen3.8-Next 报告第 2.2 节、表 5）。

**Gated Residual（GR）**：报告此前发现，在 RMSNorm 之后加一个轻量的逐元素自门控（GatedNorm）能显著改善训练稳定性。GR 把读取改为：对每条分支分别做 RMSNorm（各有自己的增益），再由全部分支预测逐分支、逐通道的门控分数，加权平均后作为块的输入；块的输出通过每条分支一个随数据变化的标量写回每条分支。GR 取 n_r 为 4，注意力块与 MLP 块各有一个 GR 模块（报告第 2.2 节）。

报告说明 GR 与 HC、mHC 的区别：HC 与 mHC 保留混合矩阵，mHC 再把它约束为双随机；GR 把表达力花在读取上，门控是逐元素的，并完全去掉了混合矩阵。报告称消融显示去掉混合矩阵没有损失，还省去了每个块对整个残差状态的一次读取；由于读取已经做了归一化与门控，GR 直接替代块的 pre-normalization，而不是放在它前面（报告第 2.2 节）。

**与 AttnRes 的对照**：在 28 层（56 个子层）的模型上，Full AttnRes 与 GR 的最终训练损失同为 1.762；Block AttnRes 每块汇总 2 个子层时损失高 0.008，汇总 4 个时高 0.011。48 层时，汇总 4 个子层的 Block AttnRes 为 1.711，GR 为 1.707。GatedNorm 在各设定下都降低了损失，在 AttnRes 上降低 0.004 到 0.005，在普通 pre-norm 基线上降低 0.002（报告第 2.2 节、表 6）。

### 6.7 Dual AttnRes

Dual Attention Residuals（DAR）把跨层检索与多流两条路线结合：对每条目标流，用另一条流的归一化状态计算深度方向的权重，再作用于目标流自身历史中的 value；为控制开销，只在已完成的块历史上检索，块内维护两条临时流状态（DAR 摘要）。实验覆盖 0.1B 到 1B 的稠密模型与一个 7B 稀疏 MoE 模型，对照标准残差、AttnRes 与 mHC-4（DAR 实验设置）。在 7B 稀疏 MoE 上，DAR 的验证损失为 2.739，AttnRes 为 2.785，基线为 2.814（DAR「Sparse-MoE setting」小节）。

## 八、系统代价

### 8.1 mHC 的显存访问与通信

**DeepSeek-V4**：报告指出，与普通残差相比，mHC 增加了激活显存占用与流水线各阶段之间的通信量。对策包括为训练与推理设计融合内核、有选择地对中间张量做检查点重计算（重算大部分层间隐状态与全部归一化后的层输入，但避开计算密集的运算），以及其他优化；报告称这些优化合起来把 mHC 的墙钟时间开销限制在重叠的 1F1B 流水线阶段的 6.7%（DeepSeek-V4 报告第 3.4.2 节）。mHC 论文第 3.2 节也专门讨论了 HC 的显存访问开销，第 4.3 节给出内核融合、重计算与 DualPipe 中的通信重叠。

**V4.1-Flash 的 Single-Pass mHC**（V4.1-Flash 报告第 2.4.1 节）：

- 理想情况下，两个块之间的残差变换是一次映射，需要 n 加 1 份隐维度大小的读与同样多的写，这是激活显存流量的下界。
- 原先的多内核实现总流量是这一下界的两倍；即使改成两遍实现，也要多读一次残差状态，原因是输入混合系数要等对全部隐维度分块的归约完成后才能得到。
- Single-Pass mHC 把输入混合系数平移一个块：每个块使用上一个块算出的混合系数，依赖由此消失，残差的每个分块可以立即同时用于输入混合与系数预测。报告称这一平移带来的性能下降可以忽略。
- 预训练仍沿用原来的多内核实现；部署时把残差更新、输入混合与系数预测融合为单个内核 Mega-mHC，内核还包含输入的 pre-norm 与 FP8 转换。残差只读一次、写一次，达到理想映射的读写量，相对原先实现把激活显存流量减半（报告第 1 节称相对原先的四内核实现减半）。

### 8.2 AttnRes 的流水线通信与推理

- **训练**：AttnRes 论文给出跨阶段缓存，消除流水线并行下的重复传输（AttnRes 论文第 1 节）。K3 报告的做法是：块表示在块边界层生成一次，由后续所有层共享；AttnRes 的计算全部包在检查点中，每层为反向保存的激活与标准残差结构相同；流水线并行采用基于缓存的通信，只在阶段之间增量传输新生成的块，并在微批结束后立即释放，报告称达到显存占用的理论下界（K3 报告第 5.2.2 节「Memory-efficient Attention residual」小节）。
- **推理**：AttnRes 论文用两阶段推理策略，借助在线 softmax 摊薄跨块注意力的开销；论文称训练开销很小，典型推理负载下端到端推理延迟开销低于 2%（AttnRes 论文第 1 节、第 4.2 节，仅见 PDF）。

### 8.3 GR 的推理开销

Qwen3.8-Next 报告称 GR 的推理开销主要来自加宽残差状态的显存流量（报告第 2.2 节）：

- **稀疏读取未被采用**：训练后的模型中，每个 GR 层的写入通常由两条分支主导。报告尝试让每个块只读门控值最高的两条分支，预训练损失与基准几乎不受影响，但后训练后质量明显下降，因此没有采用。报告称这是只看预训练指标会做出错误决定的一个例子。
- **FP8 残差**：门控限制了写入流的幅度，残差值落在窄范围内，适合低精度格式。把分支存为 FP8，相对 BF16 把残差状态搬运的数据量减半，质量几乎无损。
- **内核融合**：读与写各融合为一个内核，分组 RMSNorm 并入读取，加宽的流在每个块中每个方向只遍历一次。

## 九、意义

- **位置之争**：Xiong 等的分析把 Pre-LN 的稳定性与去掉预热联系起来；HC 论文把 Pre-Norm 与 Post-Norm 概括为梯度消失与表征坍缩之间的跷跷板；Kim 等称已有多个开源模型在子层输入与输出两处都做归一化（第一节、第五节）。
- **残差的结构化**：HC 论文提出加宽残差；mHC 论文称其约束恢复了恒等映射性质并支持大规模训练；AttnRes 论文称用注意力替代固定累加缓解了 PreNorm 稀释；Qwen3.8-Next 报告称在加宽之上，把表达力放在逐元素门控的读取上（第六节）。
- **工程代价同步出现**：DeepSeek-V4、V4.1-Flash、K3 与 Qwen3.8-Next 的报告在采用这些残差设计的同时，都写明了显存访问或通信上的代价与对应的内核、缓存或精度设计（第八节）。

## 十、局限与待核实

1. **验证多在单一架构内**：mHC 论文的实验用受 DeepSeek-V3 启发的 MoE 结构；AttnRes 论文的大规模实验用 Kimi Linear 架构；GR 的消融在 Qwen3.8-Next 自身的设定下完成。来源没有给出这些设计在彼此架构上的交叉对照，Qwen3.8-Next 报告的表 6 是唯一在同一设定下同时比较 GR 与 AttnRes 的来源。
2. **规模与 token 数不全**：HC 论文 OLMo-7B 实验的训练 token 数、Qwen3.8-Next 报告表 6 的训练 token 数、DAR 7B 稀疏 MoE 的训练 token 数，本篇没有核对到，因此这些读数只附了已核对到的规模。
3. **多流可能退化为单流**：Stream Collapse 的分析基于 mHC-lite nanoGPT 模型，较大规模与产品模型中是否存在同样现象，来源没有给出。
4. **与优化器、精度的交互**：Qwen3.8-Next 报告称门控残差、GDN 混合与 Muon 都会改变更新与激活的缩放，需要在长时间训练下确认稳定（报告第 3.3 节）；DeepSeek-V4 用 query 与 KV 上的 RMSNorm 代替 QK-Clip。各来源的组合不同，结论不能直接互推。
5. **DyT 的适用范围**：DyT 论文自述实验集中在 LN 与 RMSNorm 网络，替换 BN 时效果下降，妥善编译后也没有速度提升（DyT 第 9 节）。
6. **AttnRes 的部分数字仅见 PDF**：AttnRes 论文 arXiv HTML 无法使用，「1.25 倍算力」「推理延迟开销低于 2%」「约 8 个块」等来自 PDF v1 正文；其中「约 8 个块」另有 K3 报告的 HTML 正文可对照。
7. **K3 的扩展效率**：「约 2.5 倍」是多项改动的合计，报告没有给出 AttnRes 单独的贡献。
8. **版本**：Xiong 等为 v2，HC 论文为 v3，nGPT 为 v2，Value Residual 为 v5，Kim 等为 v3，DyT 为 v2，mHC 论文为 v2，K3 报告为 v2，Gemma 4 报告为 v2，DAR 为 v2。本篇按 abs 页当前版本引用，早期版本的表述与数字可能不同。
