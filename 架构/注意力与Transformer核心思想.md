# 1　Attention / Transformer 核心思想转折

入口论文：Vaswani et al., *Attention Is All You Need* (2017)。辅读：Harvard NLP *The Annotated Transformer*（逐行实现与重排讲解）。本笔记以**架构思想**为主线、**数学直觉**为辅线；公式与结论均据论文原文，不编造未读到的实验数字。

---

## 一、问题背景与转折点

2017 年前后，序列转导（尤其机器翻译）的主流范式，是「复杂的循环或卷积网络 + Encoder–Decoder」，其中表现最好的系统还会在编码器与解码器之间接上注意力。RNN / LSTM / GRU 把计算沿符号位置展开：位置 $t$ 的隐状态依赖 $t-1$，这种**与时间步对齐的顺序计算**天然难以在单条样本内部并行；序列一长，批处理又受显存限制，训练成本迅速上升。

注意力机制当时已经常用，但论文指出：在几乎所有情形里，注意力仍是「挂在循环网络上的插件」，而不是整座大厦的骨架。与此同时，ByteNet、ConvS2S 等卷积路线试图用并行卷积减轻顺序瓶颈，但任意两位置之间的依赖路径长度仍随距离增长（ConvS2S 线性、ByteNet 对数），远距离依赖依旧难学。

**思想转折**在于一句话：提出名为 Transformer 的新架构——**完全基于注意力机制，彻底去掉 recurrence 与 convolutions**。全局依赖不再靠「一步步传隐状态」或「堆深卷积扩感受野」，而靠自注意力在常数条路径上直接连结任意位置。论文在 WMT 2014 英德 / 英法翻译上报告了质量与可并行性上的优势（摘要：英德 big 模型 28.4 BLEU，相对此前含 ensemble 的最佳结果提升超过 2 BLEU；英法 41.8 BLEU，在 8 块 GPU 上训练约 3.5 天）。转折的本质不是「多了一个模块」，而是**序列建模的计算图从「时间展开」换成了「全局可并行的注意力」**。

## 二、架构思想

### 2.1 仍沿用 Encoder–Decoder，但积木全换

Transformer **保留**经典 Encoder–Decoder 外壳：编码器把输入符号序列 $(x_1,\ldots,x_n)$ 映射为连续表示 $\mathbf{z}=(z_1,\ldots,z_n)$；解码器自回归地一次生成一个输出符号，并消费已生成符号。左右两半（论文 Figure 1）都是**堆叠的自注意力 + 逐位置全连接**，而不是 RNN 单元或卷积块。

- **Encoder**：$N=6$ 层相同结构；每层两个子层——多头自注意力，以及逐位置前馈网络（FFN）。每个子层外包残差，再接 LayerNorm：$\mathrm{LayerNorm}(x+\mathrm{Sublayer}(x))$。为方便残差，所有子层与嵌入输出维度统一为 $d_{\mathrm{model}}=512$。
- **Decoder**：同样 $N=6$ 层；在编码器的两个子层之外，再插入第三个子层——对编码器输出做多头注意力（encoder–decoder attention）。解码器自注意力加 **mask**，禁止位置 $i$ 看到后续位置，以保持自回归性质。

### 2.2 三种注意力用法（同一套多头算子，三种接线）

1. **Encoder 自注意力**：Q、K、V 同源（上一层编码器输出）；每个位置可关注上一层所有位置。
2. **Decoder 自注意力**：同样自注意力，但用 mask 挡住「未来」；保证预测只依赖小于 $i$ 的已知输出。
3. **Encoder–Decoder 注意力**：Q 来自解码器上一层，K/V 来自编码器输出；解码端每个位置可关注输入序列所有位置——这对应传统 seq2seq 里的「对齐注意力」。

### 2.3 位置编码：没有顺序偏置时，必须「注入」顺序

去掉 RNN / CNN 后，模型本身对置换不敏感，必须把相对或绝对位置信息加进输入。论文在编码器与解码器底部，把**正弦 / 余弦位置编码**加到词嵌入上（维度同为 $d_{\mathrm{model}}$，可相加）：

$$
PE_{(pos,2i)}=\sin(pos/10000^{2i/d_{\mathrm{model}}}),\quad
PE_{(pos,2i+1)}=\cos(pos/10000^{2i/d_{\mathrm{model}}})
$$

选择正弦的动机：对任意固定偏移 $k$，$PE_{pos+k}$ 可表示为 $PE_{pos}$ 的线性函数，便于学习相对位置；且可能外推到训练时未见过的更长序列。论文也试过可学习位置嵌入，开发集上几乎一样（Table 3 行 E），仍选正弦版本。

### 2.4 残差 + LayerNorm + FFN：深度堆叠的「公路」与「工位」

- **残差 + LayerNorm**：让六层堆叠可训练；信息可沿捷径流动。
- **Position-wise FFN**：对每个位置独立、相同地做两次线性变换，中间 ReLU：$\mathrm{FFN}(x)=\max(0,xW_1+b_1)W_2+b_2$。基线配置 $d_{\mathrm{model}}=512$，内层 $d_{ff}=2048$。可理解为「注意力负责混合位置，FFN 负责在每个位置上做非线性特征变换」。

### 2.5 相对 RNN / CNN 的归纳偏置与并行性取舍

论文 §4 用三张尺子比较（Table 1）：每层复杂度、最少顺序操作数、任意两位置的最大路径长度。

| 层类型 | 每层复杂度 | 顺序操作 | 最大路径长度 |
|--------|------------|----------|--------------|
| Self-Attention | $O(n^2\cdot d)$ | $O(1)$ | $O(1)$ |
| Recurrent | $O(n\cdot d^2)$ | $O(n)$ | $O(n)$ |
| Convolutional | $O(k\cdot n\cdot d^2)$ | $O(1)$ | $O(\log_k n)$（膨胀卷积等） |

**取舍可以读成：**

- **赢在并行与远距离路径**：自注意力一层内把所有位置连上，顺序步数为常数，长程依赖路径长度为常数——这是相对 RNN 最干净的优势。
- **代价是二次复杂度与「平均化」分辨率**：复杂度 $O(n^2 d)$；注意力对位置加权平均会降低有效分辨率，论文用 **Multi-Head** 来缓解。极长序列时，论文已想到可限制为邻域大小 $r$ 的受限自注意力（复杂度 $O(r n d)$，路径变 $O(n/r)$），并留作未来工作——说明原版**并不**自带「无限长上下文」工程解。
- **归纳偏置变弱**：RNN 自带「从左到右」的时间偏置与局部递推；卷积自带局部性与平移结构。Transformer 把顺序与局部性更多交给数据、位置编码与注意力模式去学，换来的是可扩展的并行训练与统一的依赖建模接口。

## 三、数学原理（直觉先、形式后）

### 3.1 Attention 在说什么

注意力把一个 **query** 与一组 **key–value** 映射到输出：输出是 values 的加权和，权重由 query 与对应 key 的兼容性给出。直觉上：query 问「我该看谁」，key 回答「我像不像你要的」，value 提供「被选中后带走的内容」。

### 3.2 Scaled Dot-Product Attention

形式（论文式 (1)）：

$$
\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^{T}}{\sqrt{d_k}}\right)V
$$

其中 queries、keys 维度为 $d_k$，values 为 $d_v$。实践中把一批 query 打成矩阵 $Q$，keys / values 打成 $K$、$V$，一次矩阵乘法算完。

**为何除以 $\sqrt{d_k}$?（论文给出的直觉，不是无关证明）**

- 点积注意力与加性注意力在理论复杂度上相近，但点积可用高度优化的矩阵乘，更快、更省空间。
- 当 $d_k$ 较小时两者差不多；$d_k$ 变大且**不缩放**时，加性往往更好。作者怀疑：$d_k$ 大时点积幅度变大，把 softmax 推进梯度极小的饱和区。
- 示意：若 $q,k$ 各分量独立、均值 0、方差 1，则 $q\cdot k=\sum_{i=1}^{d_k} q_i k_i$ 均值 0、**方差为 $d_k$**——维度升高，点积更容易「炸」。因此乘上 $1/\sqrt{d_k}$，把尺度拉回可训练区间。

### 3.3 多头：把「一个平均」拆成「多个子空间」

若只用一个头、在满维 $d_{\mathrm{model}}$ 上做注意力，不同关系会被**平均**在一起，互相抑制。多头做法：用 $h$ 组不同的学习到的线性投影，把 Q、K、V 投到 $d_k,d_k,d_v$，并行做注意力，再拼接并用 $W^O$ 投影回去：

$$
\mathrm{MultiHead}(Q,K,V)=\mathrm{Concat}(\mathrm{head}_1,\ldots,\mathrm{head}_h)W^{O},
$$
$$
\mathrm{head}_i=\mathrm{Attention}(QW_i^{Q},KW_i^{K},VW_i^{V}).
$$

论文配置：$h=8$，$d_k=d_v=d_{\mathrm{model}}/h=64$。单头维度变小，总算力与「满维单头」大致相当，但模型能**同时**从不同表示子空间、在不同位置上关注信息。消融（Table 3 行 A）显示：单头比最佳设置差约 0.9 BLEU；头数过多质量也会掉——多头是有用偏置，不是「头越多越好」。

### 3.4 跟读小结（数学线）

先记住三步：**算相似度（点积）→ 用 $\sqrt{d_k}$ 稳住 softmax → 加权汇聚 V**；再记住多头是「同一套点积注意力，复制到多个投影子空间再拼接」。Annotated Transformer 用同一公式实现 `attention()` 与 `MultiHeadedAttention`，并在解码端用上三角 mask 把非法位置打成极大负数，等价于论文中的 $-\infty$ mask。

## 四、常见误区

1. **「注意力 = 完全无偏置 / 无结构」**
 自注意力对位置置换近乎等变，顺序不来自递推，但仍有明确结构：缩放点积、多头投影、残差与 LayerNorm、FFN、以及**显式位置编码**。解码端还有因果 mask。说「无归纳偏置」过度；更准确的是：**弱化了 RNN/CNN 式的强局部与顺序偏置，换成另一套可学习接线方式**。

2. **「Transformer 天然擅长任意长上下文」**
 全连接自注意力复杂度 $O(n^2)$；论文自己讨论极长序列时要靠受限邻域注意力，并写明留待未来。正弦位置编码「可能」外推，但外推能力不等于无限上下文窗口。长上下文是后续工程与算法线（稀疏/线性注意力、更长训练、位置编码改进等）的课题，不是 2017 原版的免费礼物。

3. **「有了自注意力就可以不要位置信息」**
 论文 §3.5 开宗明义：没有 recurrence 与 convolution，**必须**注入位置信息，否则模型难以利用顺序。位置编码不是装饰，是架构闭环的一部分。

4. **「多头只是把宽度拆开、效果等价于单头」**
 论文明确：单头的平均会抑制「在不同子空间分别关注」的能力；消融也显示单头明显更差。多头的意义是**联合、分空间地**注意，而不只是算力均分。

5. **「Attention Is All You Need 等于以后所有模型都只要注意力」**（轻度延伸误读）
 原论文标题强调的是：在**该序列转导架构内部**，用注意力替换循环 / 卷积层。FFN、嵌入、位置编码、残差与规范化仍然在；后续 GPT/BERT 等是在此骨干上的目标与栈选择分叉，而非字面「只剩注意力一个算子」。

---

## 五、对后续史线的枢纽意义

Transformer 把「可并行的全局注意力编码器 / 解码器」立成新基建之后，史线迅速分叉为：**解码器栈 + 语言模型目标（GPT 一系）** 与 **编码器栈 + 双向掩码语言模型（BERT 一系）**——同骨异用，自此展开。
