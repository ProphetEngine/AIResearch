# 机制可解释性入门史：特征 → 电路 → 归因图

> **定位**：横切——立 **机制可解释性（MI）思想演进** 入门线：为何神经元不够用 → 如何用字典学习拆出特征 → 如何把特征连成电路 → 2025 归因图如何把「单条 prompt 上的计算」画成可验证因果图。
> **研究线**：**架构思想 / 可解释性纲领（主）**。
> **为何重要**：可解释性若停在「看单个神经元」就会被多义性卡住；特征 → 电路 → 归因图这条阶梯让研究者能在单条行为上画出可用干预验证的因果图，也是激活监控、safety case 中可解释性证据等安全用途的概念底座。
> **刻意不写**：SAE/CLT 训练配方、超参表、代码库教程、工具链操作手册；本篇只讲 **概念阶梯与代表论文的证据结构**。

## 二、纲领：MI 在问什么

### 2.1 综述的三对象（Rai et al. §4.1）

据综述 PDF（跟随 Olah et al., 2020）：

| 对象 | 定义（综述表述，压缩） | 本篇对应阶段 |
|---|---|---|
| **Features** | 编码在激活中的、对人可解释的输入性质 | §三–四：从神经元到字典特征 |
| **Circuits** | 连接特征（或组件）的、实现特定行为的计算子图 | §五：经典电路 → 稀疏特征电路 |
| **Universality** | 类似特征/电路是否跨模型、跨任务复现 | 两篇 Anthropic 文都当作「真实性」证据之一 |

综述强调：MI 取 **自底向上** 路径——先分解小部件与基本运算，再拼回整模型的行为理解（对照 Zou et al., 2023 等表述）。

### 2.2 与「事后解释」的划界（思想层）

| 路线 | 典型问题 | MI 的侧重点 |
|---|---|---|
| 事后归因 / saliency | 「这次预测看重输入哪几处？」 | 输入侧敏感度，不承诺内部算法 |
| 探针（probing） | 「某层是否线性可读出某属性？」 | 常验证 **已有假设**；开集发现力弱 |
| **Mechanistic** | 「模型用哪条内部计算路径做了这件事？」 | 部件 + 因果路径 +（理想上）可干预复现 |

本篇只讲这条 **部件→路径→验证** 的史线，不展开探针/可视化工具学。

## 三、起点：神经元为何不够用

### 3.1 Polysemanticity（多义性）

*Towards Monosemanticity* 开篇：机制解释希望把网络拆成比整体更好理解的组件；但最「自然」的单元——**神经元**——常常 **polysemantic**：对看似无关的输入混合物响应。文中举例：

- 视觉 Inception v1：同一神经元响应猫脸与车头；
- 文中小型 LM：同一神经元混合响应学术引用、英语对话、HTTP 请求、韩文等。

多义性使「用单个神经元活动推理整网行为」变得困难。

### 3.2 Superposition（叠加）假说

文中把一种重要成因指向 **superposition**：网络要表示的独立「特征」可能 **多于神经元数**，于是把每个特征分配成神经元上的线性组合——特征方向构成激活空间上的 **过完备基**。前置 *Toy Models of Superposition* 表明：当有用特征在数据中稀疏时，训练过程中自然出现叠加（类比压缩感知：稀疏性使激活可被消歧）。

**思想后果：** 若真特征藏在叠加里，解释的第一步就不是「盯神经元」，而是 **找回那套过完备、稀疏的特征字典**。

### 3.3 为何不优先「改架构消灭叠加」

同文回顾三类策略：（1）训练时鼓励稀疏、试图无叠加；（2）字典学习找回特征；（3）混合。作者称最终用反例说服自己：即便强制极稀疏甚至接近 one-hot，**仍可出现多义神经元**——因为在交叉熵下，模型常更偏好「用一个单元模糊表示多个特征」而非「干净表示少数真特征而丢掉其余」。因此对语言模型，**训练后分解（字典学习）** 成为主路径；SAE 用 MSE 重构激活，使稀疏惩罚在字典侧抑制「叠加套娃」。

## 四、阶段一：特征 = 字典学习拆出的 monosemantic 单元（2023）

### 4.1 线性分解式（思想，非实现手册）

激活向量近似写成：

$$
\mathbf{x}^j \approx \mathbf{b} + \sum_i f_i(\mathbf{x}^j)\,\mathbf{d}_i
$$

即：数据点 $j$ 的激活 ≈ 偏置 + 若干特征方向 $\mathbf{d}_i$ 的稀疏加权和。这正是经典 **稀疏字典学习 / 矩阵分解** 视角；SAE 用编码器给出 $f_i$，解码器列给出 $\mathbf{d}_i$。

**好分解的三条判据**（文中 Problem Setup）：能解释「何时激活」；能解释「下游效应」且与前者一致；能解释 MLP 层的相当一部分功能（相对 loss）。

### 4.2 实验骨架（只记规模，不记配方）

据 HTML：

| 项 | 文中设定 |
|---|---|
| 被分解对象 | **一层** transformer 的 **MLP 激活**（ReLU MLP，宽度 **512**） |
| SAE 字典宽度 | **512（1×）→ 131,072（256×）**；详细分析聚焦 **A/1 = 4,096** 特征 |
| SAE 训练数据 | 约 **80 亿** MLP 激活样本（基座语料 The Pile） |
| 平行模型 | 同设置不同种子的 A / B，用于 universality |

Anthropic 介绍页压缩说法：把 **512** 神经元的一层分解为 **4000+** 特征，分别对应 DNA、法律用语、HTTP、希伯来文、营养陈述等——其中多数性质在「只看单个神经元」时不可见。

### 4.3 证据结构（为何相信「特征」比神经元更可用）

文中并列多条证据线（Summary of Results）：

1. **个例深挖**：阿拉伯文字母、DNA、base64、希伯来文等——特异性 / 敏感性代理、下游 logit 效应、消融、pinned sampling 转向生成，并证明 **不对应单一神经元**。
2. **全局可解释性**：人工评分 + 基于 Claude 的自动解释（激活与 logit 两侧）——特征显著好于神经元。
3. **功能覆盖**：用 SAE 输出替换 MLP 激活时，A/1 恢复该层对数似然贡献的约 **79%**，最大字典约 **94.5%**（文中强调对「解释了多少」仍需谨慎）。
4. **可干预**：钉住某特征可驱动生成（如 base64 / 阿拉伯文）。
5. **Universal**：A 与 B 上字典学出的特征彼此更像，而非更像各自神经元。
6. **Feature splitting**：字典变宽时，粗特征拆成更细但仍可解释的家族（「分辨率」隐喻）。
7. **组合行为**：特征可连成类似有限状态机的系统（如协作生成合法 HTML）。

A/1 中另有数百个 dead 或极低密度特征，部分分析中排除——字典宽度 ≠ 「活」且行为正常的特征数。

### 4.4 这一阶段解决了什么、还没解决什么

| 已推进 | 仍敞开 |
|---|---|
| 给出比神经元更 monosemantic 的分析单元 | 「真特征」个数与正确字典宽度仍模糊；splitting 说明答案可能是光谱而非单点 |
| 证明至少部分特征是 **模型功能** 的一部分（下游效应非训练目标） | 多层、大规模模型上完整电路仍难 |
| 为「电路」准备了节点类型 | 特征如何经注意力 / 残差交互成完整算法，需要下一阶段 |

### 4.5 规模化之后：SAE 怎样评估

**规模化的背景**。Cunningham 等（2023-09）在开源语言模型上独立验证：SAE 学到的稀疏特征按自动解释打分比其他分解方向更可解释，并能更精细地定位间接宾语识别任务中起因果作用的特征。Anthropic 的 *Scaling Monosemanticity*（2024-05-21）把字典学习用到生产版 Claude 3 Sonnet。OpenAI 的 Gao 等（2024-06）改用 k-稀疏自编码器直接控制稀疏度，得到随字典规模与稀疏度变化的干净缩放律，并在 GPT-4 激活上训练了 1600 万隐变量的 SAE。同期还出现 Gated、JumpReLU、Matryoshka 等变体，分别针对 L1 惩罚造成的激活值低估、直接以 L0 控制稀疏度与特征被更细特征吸收的问题。

**评估的三个层次**：

| 层次 | 代表指标 | 要回答的问题 |
|---|---|---|
| 代理指标 | 重构误差、替换后的下游损失、L0 稀疏度、死特征比例 | 字典是否忠实且稀疏（4.3 第 3 条的对数似然恢复即属此类） |
| 可解释性与解耦 | 自动解释打分、稀疏探测、定向概念擦除 | 单个特征是否对应可读、可分离的概念 |
| 下游任务 | 引导、概念检测、有害意图探测等 | 字典能否在实际任务上胜过简单基线 |

Gao 等提出的新指标（假设特征的找回、激活模式的可解释性、下游效应的稀疏度）都随字典变大而总体改善。SAEBench（Karvonen 等，2025-03）用 8 类指标评估 8 种架构与训练方法下的 200 余个 SAE，结论是代理指标上的提升不能可靠转化为实际效果：Matryoshka SAE 在代理指标上略差，却在特征解耦指标上明显领先，且优势随规模扩大。

**下游任务上的负面结果**。AxBench（Wu 等，2025-01）在 Gemma-2-2B 与 9B 上比较引导与概念检测：引导上提示最好、微调次之，概念检测上差均值等表示方法最好，SAE 在两项上都不具竞争力。Google DeepMind 机制可解释性团队在 LessWrong / AI Alignment Forum 发帖（2025-03-26，论坛帖，非同行评审）报告：在跨越新越狱手法的有害意图检测上，SAE 探针不如稠密线性探针；团队据此及平行工作暂时调低 SAE 基础研究的优先级，同时说明并不认为 SAE 无用，仍把它留作工具箱中的一项。

**对「特征」本身的质疑**。Leask 等（2025-02）用 SAE 拼接显示小字典不完整，用元 SAE（在另一个 SAE 解码矩阵上训练的 SAE）显示大字典的隐变量常可分解为小字典隐变量的组合，即并非原子单元；作者建议按任务务实选择字典大小。这与 4.4「真特征个数仍模糊、splitting 说明答案可能是光谱」直接衔接。Korznikov 等（2026-02）报告：在已知真特征的合成设定中，SAE 解释方差达 71%，却只找回 9% 的真特征；在真实激活上，把特征方向或激活模式随机化的三种基线，在可解释性、稀疏探测与因果编辑上与训练好的 SAE 接近。

**评估工具本身的可靠性**。SynthSAEBench（Chanin 等，2026-02）用带相关、层级与叠加结构、且已知真特征的大规模合成数据作下限测试：在线性表示假说按构造成立时都失败的架构，在真实模型上希望不大；它复现了重构与隐变量质量脱节等现象，并发现 Matching Pursuit SAE 会利用叠加噪声提升重构而不学到真特征。Chanin 等（2026-05）对 SAEBench 的审计认为，TPP 与 SCR 两项指标在标准设定下不应再用于评估 SAE，其余指标的重采样噪声高于通常假设，sae-probes 是所测最可靠的指标，但仍难区分同一架构的不同变体。

上述正面结果（缩放律、Matryoshka 的解耦优势）与负面结果（下游比较、随机基线）分别依赖各自的模型、任务与指标设定，不能横比；SAE 的评估方法本身仍在建立之中。

### 4.6 开放字典：Gemma Scope、Llama Scope 与 Gemma Scope 2

训练一整套覆盖全部层的 SAE 成本高，曾使工业界以外的研究难以开展；开放字典把训练好的权重直接公开，减少重复训练。

| 字典 | 发布 | 覆盖 |
|---|---|---|
| Gemma Scope（Lieberum 等） | 2024-08 | Gemma 2 2B、9B 全部层与子层，27B 部分层的 JumpReLU SAE；以预训练模型为主，另附指令微调版 9B 的 SAE 供对比 |
| Llama Scope（He 等） | 2024-10 | Llama-3.1-8B-Base 每层每子层共 256 个 Top-K 类 SAE，特征数 32K 与 128K |
| Gemma Scope 2（Google DeepMind 博文） | 2025-12-19 | Gemma 3 从 270M 到 27B 全部尺寸，每层都有 SAE 与转码器，另含跳跃转码器与跨层转码器；采用 Matryoshka 训练；另有面向对话调优版的工具 |

博文称 Gemma Scope 2 是迄今 AI 实验室最大的开源可解释性工具发布，制作过程存储约 110PB 数据、训练参数总量超过 1 万亿。其中的跨层转码器即第六节归因图所用的 CLT 一类工具。这些现成字典也是下游审计与电路研究的直接输入，相关用法见 [[CircuitLasso与电路追踪]]、[[奖励黑客与涌现失对齐]]、[[对齐伪装与谄媚行为]]；博文列出的分析对象包括思维链忠实性，与 [[思维链可监控性]] 相接。

## 五、阶段二：电路 = 特征（或组件）之间的计算子图

### 5.1 经典「组件级」电路（谱系锚点）

在 SAE 之前，社区已在 **注意力头 / MLP 块** 粒度上找电路。综述 Figure 2 回顾 Elhage et al. (2021) 的 **induction circuit**：previous-token head 与 induction head 协作，完成「重复子序列续写」类行为。此类工作证明：**行为可对应稀疏子图**；但也受 polysemantic 组件拖累——子图节点本身难读。

### 5.2 特征就绪之后的自然下一步

*Circuit Tracing*（2025）导言把团队路径概括为两步：

1. 识别 **features**（可解释积木）；
2. 描述 features 交互产生输出的 **circuits**。

稀疏编码（SAE、transcoder、crosscoder 等）使「用特征当节点」变得可行；随后出现 sparse feature circuits、各类归因/路径方法（文中引用 Dunefsky、Marks 等方向）。**思想跃迁：** 电路的边不再只是「头 A→头 B」，而可以是「特征 $s$ 对特征 $t$ 的线性贡献」。

### 5.3 电路研究的两种问法（综述 §6.2 压缩）

| 问法 | 目标 |
|---|---|
| 解释 **特定行为** | 给定任务/输出，定位负责子图并说明机制 |
| 解释 **组件职能** | 某注意力头 / FF 层在分布上通常做什么 |

两者都依赖：选目标行为 → 定义计算图 → 定位重要部件 → 解释功能；评价常牵涉必要性/充分性与因果干预。本篇不展开具体定位算法名册。

## 六、阶段三：归因图 = 单条 prompt 上的可修剪因果计算图（2025）

### 6.1 为何还要「再发明」一层方法

特征字典解决「节点可读」，但落地时仍有设计空间爆炸：用 SAE 还是 transcoder？逐层还是跨层？如何定义特征间边？如何在百万级边上只看关键路径？*Circuit Tracing* 给出当时 Anthropic 的一套组合答案——核心产物是 **attribution graph（归因图）**。

### 6.2 Cross-layer transcoder（CLT）与 replacement model

**动机（思想）：** 相对只重构激活的 SAE，**transcoder** 族试图更直接逼近 **MLP 的输入→输出映射**，从而谈「特征写到下游」更干净；**cross-layer** 则让一层读入的特征可贡献到 **后续多层** MLP 输出重构，从而 **压缩路径长度**、简化图。

文中报告量级（验证用，非教你复现）：

- 在小型 **18 层** 模型上，CLT 总特征数约 **30 万–1000 万**；在 Claude 3.5 Haiku 上约 **30 万–3000 万**。
- 最大 18L CLT 作为 replacement model 时，在多样预训练风格 prompt 上，**下一 token 与原模型一致约 50%**（文中设定：原模型猜对且置信度 <80% 的样本等过滤条件下比较）。
- 评价上，CLT 相对 per-layer transcoder 与阈值化神经元，在重构误差 / 稀疏 / 自动可解释性等指标上呈 Pareto 改进（详见原文 Evaluations）。

**Local replacement model（关键思想）：** 对 **固定 prompt**，用 CLT 替换 MLP，同时 **冻结该 prompt 上的注意力模式与归一化分母**，并加入 **逐层误差修正**，使局部替换模型的激活与 logits **与原模型一致**。于是可把该 prompt 上的计算改写为：以活跃 CLT 特征为神经元、以残差/OV 线性路径为「虚权重」的大图——**非线性只剩特征阈值**。

> 类比文中自述：像函数在一点的 Taylor 局部一致；离该点远则机制可能分叉——故必须做 **扰动验证（mechanistic faithfulness）**。

### 6.3 Attribution graph：节点、边、修剪

| 元素 | 含义 |
|---|---|
| **节点** | 活跃特征（按 token 位置）、prompt token embedding、**error 节点**（CLT 未解释的 MLP 残差）、候选输出 logits |
| **边** | **线性归因**：源激活 × 虚权重；因冻结注意力模式与 LN，特征预激活可写成入边之和 |
| **未包含** | **QK 电路**（为何那样 attend）——只捕获 OV 搬运的信息流，不解释注意力本身如何形成 |
| **修剪** | 按对目标 logit 的影响保留关键子图；文称默认参数下节点约减一个数量级，而「被解释行为」约只降 20%（以文中 completeness 类度量叙述为准） |

案例直觉（文中 acronym / 事实回忆 / 加法）：图上可见并行启发式路径（如加法的个位路径 vs 量级路径）如何汇合到最终 token；再用 **constrained patching** 等干预检查「抑制上游特征是否按图预测抑制下游」。

### 6.4 Global weights：从单例图到跨上下文

归因图是 **prompt-local** 的。作者另讨论 **virtual weights / TWERA** 等，试图读出跨上下文的特征–特征连接，但强调 **interference**：虚权重会连上分布上几乎不同时激活的特征；需用共激活统计压制干扰。加法任务上，限制在相关特征子集后，全局连接与单例图的启发式分解更一致——说明「全局电路」仍早期、难。

### 6.5 局限清单（读文时应带着的滤镜）

原文 Limitations 直言（压缩）：

1. **Missing attention circuits**——induction、选择题等「故事在 QK」的例子上，归因图会显得无聊或跳过关键步骤；
2. **Reconstruction error / dark matter**——error 节点可淹没机制；
3. **Inactive / inhibitory circuits**——「没激活」本身可能是机制（如压制「无法回答」特征）；默认图只画活跃特征；
4. **图复杂、特征粒度错位**（splitting / absorption）；
5. **Mechanistic faithfulness**——替换模型与原模型对扰动的响应会随层累积偏离。

配套论文 *On the Biology of a Large Language Model* 把同一方法用到 Haiku 的多样行为（多跳、诗韵规划、多语、医疗追问、幻觉、拒答、越狱、CoT 忠实性等）——本篇只作指针，不摘要其生物学故事。

## 八、延伸阅读

1. 先读 Anthropic 介绍页建立直觉，再读 *Towards Monosemanticity* 的 **Problem Setup + Summary of Results + 一个个例特征**（如 Arabic / base64），浏览其特征可视化界面即可，不必复现训练。
2. 用综述 §4 + §6 把词汇表钉死：feature / circuit / universality；§5.3 只读 SAE **概念与动机**。
3. 读 *Circuit Tracing* 时按「CLT → local replacement → 图的边为何线性 → 为何要 prune → 为何必须 patch 验证 → Limitations」顺序，案例（acronym / Jordan / 加法）用来练习「读图」。
4. 对任何电路声称，默认追问：**缺了注意力 QK 吗？error 节点是否主导？抑制边是否被忽略？扰动是否与图一致？**
