## 二、问题立轴：为何不是「再训一遍」

### 2.1 标准设定（综述 §2.1）

| 符号 | 含义 |
|---|---|
| $\mathcal{D}$ / $M$ | 训练集与原模型（参数 $\theta$） |
| $\mathcal{D}_u$（forget / unlearn set） | 要移除影响的子集 |
| $\mathcal{D}_r = \mathcal{D}\setminus\mathcal{D}_u$（retain set） | 应保留的其余数据 |
| $\mathcal{U}$ → $M_u$ | 遗忘算法输出的 unlearned 模型 |
| $M_r$ | 理想：仅在 $\mathcal{D}_r$ 上重训的对照 |

**LLM 目标（综述原句压缩）：** unlearned 模型应**不再记忆 unlearn 集内容**，同时**保留其余内容**；并尽量低算力 / 时延开销。因全量 $M_r$ 对外部审计通常不可得，评测不能只靠「与 $M_r$ 逐参数比对」。

### 2.2 请求粒度：样本级 vs 实体级

- **样本级**：具体文本序列（PII、版权段落、有害片段等）——主流形态。
- **实体级**：某实体 / 抽象能力相关的**全部**知识（如某作者、某类危害能力）；通常先构造该实体的样本集再落到样本级，但要处理实体间关联，更难。

### 2.3 Retain 的再切分（评测用）

综述 §4.1：retain 可再分为
- **Neighbor set**：语义近但应保留（如 TOFU 预留 1%/5%/10%；或同领域人工/模型构造「难负例」）；
- **World set**：与 forget 基本独立的通用预训练知识（Wikidata / OpenWebText / FineWeb 等代理）。

### 2.4 与相邻议题的接口（勿展开）

| 相邻 | 本篇只取接口 | 不写什么 |
|---|---|---|
| **B5 红队** | 鲁棒性评测里「表面遗忘可被探测」这一**度量需求** | 众包剧本、universal jailbreak 成功判据全文、攻击复现 |
| **[[可扩展监督与弱到强]] oversight** | 都关心「模型是否仍持有不该暴露的信息」 | 弱监督引出强能力、metagaming / CoT monitorability 协议 |

## 三、方法族地图（综述 §3：按流水线阶段）

> 综述刻意按 **intervention 时机**分类（相对「按目标 / 意图」分类），便于按场景选型，并把「怎么改参数」与「改哪些参数」拆开、可正交组合。

`
预训练/续训 ──► 已训模型 ──► 推理服务
 │ │ │
 Training-time Post-training Inference-time
 （SISA 等） （SFT/RL±定位） （改输入/输出，不改主权重）
`

### 3.1 Training-time：可验证、但吃已训模型

- 代表思路：**SISA** 类——数据分片 + 存中间 checkpoint，遗忘时从**未接触 forget** 的状态重训受影响分片。
- 变体：只对新增可训模块做 SISA；FairSISA 等讨论公平性后处理。
- **利**：机制上 forget 样本从未进入最终路径 → 更易谈可验证性。
- **限**：不适用于**已经训完**的闭源 / 单次全量模型；存多份权重贵。

### 3.2 Post-training：主战场（改已训权重）

两大正交轴：**(Q1) 怎么改** × **(Q2) 改哪一段**。

#### 3.2.1 SFT 目标三类（综述 Fig.4）

| 族 | 在优化什么 | 代表思路（文中点名，非穷尽） |
|---|---|---|
| **Text-based** | 抬高/压低某文本的似然 | Gradient Ascent；NPO / SimNPO（偏好式约束）；替代表述（substitute responses）；只优化关键 token / 位置加权；外部 LLM 生成替代回答或选核心子集 |
| **Distribution-based** | 输出分布逼近「无敏感信息」的参考分布 | WHP / WPU（实体替换构造参考）；RKLD / Obliviate / PerMU（logits 差作参考）；KL / reverse KL / JS / f-divergence |
| **Activation-based** | 隐藏激活相对参考「无信息 / 拒答区」 | RMU（激活推向随机方向）；Adaptive RMU；LUNAR（导向拒绝区）；可解释性闭式更新等 |

实务上几乎总加 **retain 损失**；多目标时简单加权不够，有 NGDiff、MOLLM 等做动态权衡。

#### 3.2.2 RL 遗忘

- 奖励设计例：Quark（不良属性分位数 token）；DeMem（负 BERTScore）；RULE（拒答行为 + boundary set）。
- **相对 SFT**：文称对未见查询**泛化更好**，且可不改底层 loss、可挂进 RLHF / 推理 RL 流水线；代价是收敛慢、训练不稳。

#### 3.2.3 参数定位（改哪一层 / 哪些神经元）

| 大类 | 信号 | 例 |
|---|---|---|
| **Data-based · Gradient** | forget（±retain）上的梯度及组合 | DEPN、SURE、SSU、MemFlex、WAGLE、KLUE |
| **Data-based · Activation** | forget vs retain 激活统计 / 互信息 | Selective Pruning、REVS、FALCON |
| **Data-free · Heuristic** | 实验观察 + 搜层 | RMU / Adaptive RMU 的层选择惯例 |
| **Data-free · Mechanism** | 知识存储机制（如 MLP down-projection） | LUNAR、LaW |

要点：定位策略与 SFT/RL **正交可组合**（综述对 RMU 的拆法：损失在 SFT 节、层选择在定位节）。

#### 3.2.4 引入新结构（冻原参、训插件）

- 层间小模块：EUL、GRUN（可多任务 fusion）。
- **LoRA** 族：标准 LoRA 选择性遗忘常不够；FILA 初始化、正交正则 + OOD 门控等增强。
- **LOKA**：多 memory + 路由，缓冲突与顺序遗忘。
- **利**：顺序 / 多轮遗忘时参数彼此独立、可组合。
- **限**：下游适应性；**关掉插件即可绕过**——原模型仍含被「遗忘」内容（综述明确写出该风险）。

#### 3.2.5 复合：参数算术 / SAE

- Task-vector 式：训「坏模型」偏差再从原参减去（SKU 等）；PEFT 上做 negation；子空间正交化 / SVD 近似负向模型。
- SAE：识别 forget 强激活、retain 弱影响的特征，推理时钳制或删 codebook 向量——偏**可解释干预**，与纯黑盒微调对照。

### 3.3 Inference-time：不改主权重

| 位置 | 形态 | 例（综述 Table 2） |
|---|---|---|
| **输入 · Token** | 系统提示拒答；ICUL（标签翻转 in-context）；ICKU（`<UNL>` 包裹）；RAG 改检索库；量化 k-means 抽代表例 | 黑盒友好、可解释；提示护栏可被对抗绕过（文中一笔） |
| **输入 · Embedding** | ECO、SPUL（优化 soft prompt） | 把优化从权重挪到嵌入 |
| **输出 · Token** | 过滤；ALU 多 agent 消毒 | 更直接控可见输出 |
| **输出 · Logit** | $\delta$-UNLEARNING、ULD、DExperts | 解码期重加权 |

**利**：省算力、跨架构、少灾难性遗忘。**限**：不消除权重内记忆；累积遗忘请求时提示/过滤方案**难扩展**（OpenUnlearning §2 亦强调 prompting 不可规模化替代改权重）。

### 3.4 OpenUnlearning 对「改权重」方法的粗分（§2）

与综述互补的工程桶：**(1) 特制损失 (2) 优化步骤改造 (3) 局部参数更新 (4) 替代数据**——实现上落在统一 Trainer / Hydra 配置里，便于跨 TOFU/MUSE/WMDP 复用。

## 四、指标族：遗忘效用、残留与效用保留

> 综述 §4.2 四块：**knowledge memorization**、**model utility**、**robustness**、**efficiency**。
> OpenUnlearning 再把「指标本身可不可信」拆成 **Faithfulness / Robustness** 元评测。
> **本篇只记指标族与结论性数字；不写攻击复现步骤。**

### 4.1 知识记忆 / 遗忘效用（越「像已忘」越好——但方向依指标定义）

**Output-based（模型自由 / 模型辅助）**

| 子类 | 代表 | 适用直觉 |
|---|---|---|
| 字面 / 放宽字面 | Verbatim、关键词包含、ES、MA | 短答与可抽取续写 |
| n-gram / LCS | BLEU、ROUGE（→ EL、ECS） | 长生成重叠；ECS 只比关键实体 |
| 语义 | BertScore、NLI / BLEURT、人工 / 外部 LLM 评判 | 同义改写与知识一致性 |

**Logit-based**

| 子类 | 代表 | 要点 |
|---|---|---|
| 概率 | 下一 token 概率、困惑度、Truth Ratio（TOFU） | Truth Ratio：正确 vs 错误答案似然比；可用 KS 检验看分布；利检测 under-/over-unlearning |
| 排序 | Exposure、MRR、THR、PA | 用秩代替原始概率，分数更均匀 |

**成员资格代理（Privacy / MIA 谱系）**
LOSS、Zlib、Min-K%、Min-K%++、PrivLeak 等——传统 unlearning 常用；综述指出对 LLM **常需大量 shadow 模型**，算力与数据上难，适用性存疑。OpenUnlearning 元评测进一步显示：MIA 类 **Faithfulness 高但 Robustness 偏低**，不宜单独当「已遗忘」铁证。

### 4.2 模型效用（不该一起崩）

- 轻量：困惑度、distinct n-gram、unique token ratio、token entropy、Brunet / Honore 等。
- 综合榜：ARC、GSM8K、HellaSwag、PIQA、WinoGrande、MMLU、MT-Bench、TruthfulQA 等（综述 Table 5）；常经 LM Eval Harness。

### 4.3 「残留」与鲁棒性（只作评测维度）

综述观察：许多方法只压住**表面表达**，内部表征仍可能被后验干预恢复。评测上把下列当作 **stress 维度名称**（接口到 B5「对抗暴露面」，**不**展开手册）：

- **输入侧压力**（提示改写 / 自动提示搜索族等——仅作家谱标签）；
- **表示侧压力**（探针、logit lens、soft-prompt 类——仅作家谱标签）；
- **Relearning**：用少量 forget 相关数据再微调或 in-context 再暴露——文中反复报告遗忘质量快速回退；
- **部署变换**：如量化后知识「回弹」（综述引 Zhang et al.；OpenUnlearning 亦作 benign intervention）。

**读数纪律：** 报告「攻击成功率」却无协议与种子 → 不可比；本笔记不收录任何可复现攻击配置。

### 4.4 效率

墙钟时间、GPU-hours、理论 FLOPs / 梯度预算；跨文比较需同硬件，否则只作量级参考。

### 4.5 基准选型快照（综述 Table 3(b)，摘常用）

| 基准 | 内容 | FT？ | 任务形态 | 典型动机 |

## 五、OpenUnlearning：统一基准 + 指标元评测

### 5.1 框架要解决什么

领域碎片化例（文中）：UNDIAL 未落到三大基准；NPO 在 TOFU vs MUSE 公式不一致；RMU initially 绑 WMDP；MIA 在 MUSE 有、TOFU 无…… → 难横向比。

**OpenUnlearning 提供：** 模块化 pipeline（model loader / data worker / unlearning trainer / evaluator / stress-test）；Hydra YAML；社区可注册新方法与指标。文称集成 **13** 算法、**16** 评测、三大基准，并释放 **450+** checkpoint（代码：`github.com/locuslab/open-unlearning`）。

### 5.2 指标元评测：Faithfulness × Robustness

在 TOFU **forget10**（400 例）、Llama-3.2 1B、12 个指标缩放到 $[0,1]$ 上：

| 维度 | 定义（压缩） | 度量 |
|---|---|---|
| **Faithfulness** | 有目标知识的模型池 $P$ vs 无目标知识的 $N$，指标能否分开 | AUC-ROC |
| **Robustness · Quant.** | 良性变换（如 4-bit 量化）后，指标不应「翻转」成仍显示已遗忘 | $Q=\min(m_b/m_a,1)$ |
| **Robustness · Relearn** | 非良性再暴露时，unlearned 的指标回升不应快于 retain 对照 | 相对恢复率 $R$ |
| **聚合** | $HM(R,Q)$；总体 $HM(\text{Faithfulness}, \text{Robustness})$ | 表 2 |

**表 2 结论性排序（Agg.，文中数字）：**

| 指标 | Agg. | Faithful. | 备注（作者讨论） |
|---|---|---|---|
| **Extraction Strength (ES)** | **0.85** | 0.92 | 总体最可靠 |
| Exact Mem. | 0.80 | 0.90 | 次席 |
| Truth Ratio | 0.73 | **0.95** | 最忠实，鲁棒偏低 → 总第三 |
| Para. Prob. / Para. ROUGE / Prob. / ROUGE | ~0.70–0.73 | 中等 | 原始概率与 ROUGE 有限可靠 |
| MIA-ZLib / MinK / LOSS / MinK++ | 0.61–0.71 | 高忠实 | **鲁棒不足** → 慎作唯一合规证据 |

过滤现实约束：效用掉超 20%、或相对该指标阈值「未真正遗忘」的模型不进鲁棒分析——对齐从业者只关心「看起来已忘且仍能用」的情形。

### 5.3 方法横向（TOFU，8 法 × 10 指标；表 3）

聚合：**Mem.**（元评测前列：ES、EM、Truth Ratio、Para. Prob.；**高 = 更忘**）、**Priv.**（4×MIA）、**Utility**（Model Utility + fluency）；再谐波均值。每法 **27** 组超参见公平预算；选型不用需 oracle retain 的隐私指标。

| Method | Agg. ↑ | Mem. ↑ | Priv. ↑ | Utility ↑ |
|---|---|---|---|---|
| Init. finetuned | 0.00 | 0.00 | 0.10 | 1.00 |
| Retain（金标） | 0.58 | 0.31 | 1.00 | 0.99 |
| **SimNPO** | **0.53** | 0.32 | 0.63 | 1.00 |
| RMU | 0.52 | 0.47 | 0.50 | 0.61 |
| UNDIAL | 0.42 | 0.27 | 0.48 | 0.78 |
| AltPO / IdkNLL / NPO / IdkDPO | ~0.14–0.15 | 分化 | 低–中 | 高 |
| GradDiff | 9e-3 | **0.97** | 3e-3 | 0.79 |

**作者读法：** SimNPO 贴近 retain 的记忆水平（避免 over-unlearn）、效用满血、隐私尚可；RMU 遗忘/隐私强但效用伤。**Mem ↔ Priv 张力：** 遗忘不足（高似然）与遗忘过猛（似然异常低）都会在隐私轴上输给 retain——需要停在「默认不熟悉」行为，而非把 forget 概率打穿。

**排名敏感：** 换聚合方案名次会变（文指 Table 3 vs Appendix Table 6）；故他们开源全部 checkpoint，供社区改排序协议。

## 六、挑战与方向（综述 §5，只收架构层）

1. **定义分裂：** 「不生成」vs「明确 I don’t know」vs「行为像 $M_r$」→ 指标不可比；过弱 / 过强对抗探针都会扭曲审计（文中原则警告，不展开手法）。
2. **Unlearn 集边界：** 真实世界版权/隐私互联；合成集（TOFU）相对干净。
3. **跨语言 / 跨数据：** 单语遗忘不迁移；OOD vs ID 的效率–效用权衡；多跳知识、ripple / onion / transfer unlearning。
4. **现实差距：** 实验多 <10B 参数、forget <1B 实例；量化回弹；**顺序遗忘**尚未就绪。
5. **方向标签：** 专用结构（工具 LLM、MoE SEUF）；遗忘作分析工具；超越实例到抽象能力；可验证 / 可认证（SISA 式协议）；鲁棒遗忘（目标陈述层，非防御菜谱）。
