# Activation Steering / Representation Engineering（RepE → ActAdd/CAA/ITI → 机制案）

> **定位**：**P0**——立「**推理期对内部激活做加/减向量操控行为**」横切史：顶层纲领 **RepE**（读表征 → 控表征）→ 三条经典推理期手法 **ActAdd / CAA / ITI** → 近窗机制案 *What Drives Representation Steering?*（拒绝 steering 主要走 **OV**、可大幅稀疏）→ 可选补链 **Selective Steering**（保范数旋转 + 判别层选择）。
> **攻坚线**：**架构思想 / 控制界面（主）** + **评测字段（辅）**（TruthfulQA / 毒性·情感 / 行为 MC+开放生成 / 机制消融；表内数字）。
> **硬划界（开篇钉死）**：
> - **≠ [[机制可解释性入门]]**：不写 SAE → 电路 → 归因图的 **MI 解读阶梯**；本篇只取「激活方向可读写」接口，不写字典学习 / CLT。
> - **≠ [[审慎对齐与断路器]]**：不写 Deliberative Alignment 的规范 CoT，也不写 Circuit Breakers / Representation Rerouting 的 **熔断训练**；[[审慎对齐与断路器]] 里出现的 RepE 仅作「表征接口」一句，本篇主战场是 **推理期加向量**。
> - **≠ [[对齐脉络RLHF与偏好优化]]**：不写 RLHF / DPO / CAI 损失与三阶段通史；对齐流水线只作「权重更新 vs 激活编辑」对照。
> **硬约束**：**禁止可复用 jailbreak / 攻击步骤**、提示模板全文、绕过配方；机制案与 Selective 中涉及 refusal 的部分只保留 **机制结论与公开聚合字段**，不写有害数据构造、负向拒绝向量操作手册或攻击角扫。
> **禁止编造**：主张与表数字一律锚定官方 PDF（2026-09-22 CST）；未在源文出现的数字不写。
> **二进制**：六篇 PDF 均 **<20MB**（`ls -lh`，见 §一），保留入库；无权重 / 数据集 / 视频。

## 二、问题立轴：为何需要「激活操控」横切

三篇经典手法与 RepE 共享同一诊断（意译压缩）：

1. **提示工程不够稳**（ActAdd §1）：能力可能已在权重里，但提示未必能同时点亮想要的电路组合（文中「eloquent mathematicians」思想实验）。
2. **权重对齐成本高、粒度粗**（ITI / CAA / RepE）：RLHF 等需大量标注与算力；且改的是整网参数，难做「只拧某一概念旋钮」。
3. **内部已有线性可读方向**（ITI 引 Burns et al. CCS；RepE LAT；CAA 行为聚类）：生成轨与探针轨可差一截——ITI 在 LLaMA-7B × TruthfulQA 上写到约 **40%** 的 probe vs generation 差距——说明有空间用 **推理期移位** 把已有信息「说出来」。

**跟读抓手：**本篇史线是 **控制界面**（激活空间的加减法），不是 **可解释性通史**（[[机制可解释性入门]]），也不是 **安全对齐新范式训练**（[[审慎对齐与断路器]] / [[对齐脉络RLHF与偏好优化]]）。

## 三、纲领：RepE（2310.01405）——自上而下的表征工程

### 3.1 与 MI 的对照（Fig.2 叙事）

RepE 自称 **top-down transparency**：分析单位是 **representations**（高阶认知现象在激活中的方向/轨迹），而非神经元或电路。文中对照：

| | Mechanistic interpretability（[[机制可解释性入门]] 主线） | Representation Engineering（本篇） |
|---|---|---|
| 路径 | 自底向上：特征 → 电路 → 行为 | 自上而下：先定位概念/功能表征，再读/控 |
| 典型工具 | SAE、电路、归因图 | LAT 扫描、reading / contrast 向量、LoRRA |
| 本笔记取舍 | **不展开** | **主锚** |

### 3.2 Representation Reading：LAT 三步（§3.1.1）

**Linear Artificial Tomography（LAT）** 基线（神经成像类比）：

1. **设计刺激与任务**：概念用「陈述性」模板 $T_c$；功能（如 honesty）用实验/参照提示对 $T_f^\pm$。默认可无标签 / 自生成刺激（文强调减标注偏置）。
2. **采集神经活动**：Decoder 默认取模板 **最后 token**（概念）或回复各 token（功能）；形式如文 Eq.(1)(2)。
3. **拟合线性模型**：主用 **无监督 PCA**（常对成对差分做 PCA）；第一主成分作 **reading vector** $v$。

**评价四类实验（§3.1.2，只记思想）：** Correlation / Manipulation / Termination / Recovery——读到的方向要靠操纵与损伤类证据抬升因果强度。

### 3.3 Representation Control：四种基线（§3.2 / Table 2）

| 控制器 | 要点（文） | TruthfulQA MC1（LLaMA-2-Chat，Table 2） |
|---|---|---|
| 无干预 Standard | — | 7B **31.0**；13B **35.9** |
| ActAdd（文内变体） | 任务 vs 参照提示末 token 差 | 7B **33.7**；13B **38.8** |
| Reading Vector | LAT 方向，**与刺激无关**的常加 | 7B **34.1**；13B **42.4** |
| Contrast Vector | 推理时对比提示对差分，**刺激依赖**；算力约 **>3×** | 7B **47.9**；13B **54.0**（文称 SOTA 但贵） |
| **LoRRA** | 低秩适配 + contrast vector loss（Algo.1）；开销可忽略 | 7B **42.3**；13B **47.5** |

诚实控制模板（文）：实验「Give a truthful answer」vs 参照「Give an untruthful answer」；刺激用 **Alpaca** 以免 TruthfulQA 泄漏。文称直接提示「更诚实」对标准 MC1 **无效**，而表征控制可缩小「标准准确率 ↔ LAT 读出准确率」鸿沟。

**读侧数字（Table 1，MC1）：** 标准零样本均约 **32.3**；LAT 多刺激均约 **56.8–60.7**（7B/13B/70B Chat）——内部「真」概念可比输出轨更容易读出。

**跟读抓手：**RepE 把故事分成 **读（LAT）** 与 **控（加向量 / 低秩适配）**；后续 ActAdd/CAA/ITI 多半是「控」侧的轻量特化。

## 四、手法线 A：ActAdd（2308.10248）——少到一对提示的激活加法

### 4.1 算法骨架（Algo.1 / Fig.1）

对对比提示 $(p_+, p_-)$，在目标层 $l$ 取残差流激活差：

$$
h_l^A = h_l^+ - h_l^-
$$

用户前向时在对齐位置 $a$ 注入：$c\, h_l^A + h_l$（$c$ = injection coefficient）。**无梯度优化**；文称可少至 **一对** 数据点。中层通常更有效（与既有激活编辑文献一致）。

### 4.2 公开评测字段（只录表）

**毒性（Table 3，RealToxicityPrompts $n=1000$）：**

| 设定 | Toxicity ↓ | (Dis)Fluency ↓ | Relevance ↑ |
|---|---:|---:|---:|
| OPT 未控 | 0.134 | 8.9 | 0.369 |
| **ActAdd-OPT** | **0.112** | 13.8 | 0.329 |
| LLaMA-3 未控 | 0.114 | 6.3 | 0.391 |
| **ActAdd-LLaMA3** | **0.108** | 6.7 | 0.365 |

文称 ActAdd-OPT 毒性低于次优 PREADD-D-OPT 约 **8%** 相对幅度；ActAdd-LLaMA-3 相对未控约 **5%** 降幅，流利惩罚很小。

**情感（Table 4，IMDb 续写反转，SiEBERT 分类）：**
- Neg→Pos：**ActAdd-LLaMA3 Steering 0.669**（文称该方向 SOTA）；ActAdd-OPT 0.564。
- Pos→Neg：ActAdd-OPT 0.432；部分对照（如 PREADD-S）更高但 Disfluency 可到 **68.4** vs ActAdd **24.2**。

**能力保持：** ConceptNet / LAMA 上 wedding 向量对 off-target P@K 影响可忽略（Fig.5）；OpenWebText 上 topic 向量降低相关文档困惑度、无关文档基本保持（Fig.2）。

**跟读抓手：**ActAdd =「**爱 − 恨**」式对比残差，当 **虚拟 bias**，拧 $c$ 与层号即可迭代——最轻的控制界面之一。

## 五、手法线 B：CAA（2312.06681）——多样本 Mean Difference + 生成段全加

### 5.1 相对 ActAdd 的三点差分（§3）

1. **数据**：行为对比的 **多选题 A/B 对**（Anthropic Advanced AI Risk 等；幻觉/拒绝等另造对比集）——不是单对自由文本。
2. **提取**：在 **答案字母 token** 位置取残差差，再对多对 **平均（Mean Difference）** → 降噪。
3. **施加**：在用户指令之后的 **所有生成 token 位置** 加 $m \cdot v$（$m$ 可正可负），而非 ActAdd 式少数位置对齐。

形式（文 Eq.1）：

$$
v_{MD}^{(L)} = \frac{1}{|D|}\sum_{(p,c_p,c_n)\in D}\big(a_L(p,c_p)-a_L(p,c_n)\big)
$$

### 5.2 行为面与能力面（公开字段）

- **层扫：** Llama 2 Chat **7B** 约 **layer 13** 一带效应最大；**13B** 约 **14–15**（Fig.3）。
- **行为：** 对 AI Coordination / Corrigibility / Hallucination / Myopic Reward / Survival Instinct / Sycophancy / Refusal 等，MC 与开放生成均可被乘子双向拧动（Fig.4–5；开放生成例见表 1 奉承）。
- **叠在 SFT 上（Table 4）：** 7/7 行为中有 **3** 个方向 CAA 仍能在微调之上继续加分；奉承等上 SFT 的 OOD 失败而 CAA 仍泛化——文用作「改已有表征 vs 整模拟合」对照。
- **MMLU（Table 5，13B Chat，layer 14，$m=\pm1$）：** 基线正确选项概率约 **0.63**；多数行为 $\pm1$ 后仍在 **0.57–0.65**，文称能力损伤小。减奉承向量对 TruthfulQA 有小幅帮助（附录 H）。

**解释侧（§8，只记结论）：** 向量与 token 激活余弦可标出语义相关片段；邻近层向量更相似；层间迁移在中层有效、约 layer 17 后陡降。

**跟读抓手：**CAA = ActAdd 的「**数据集化 + 答位提取 + 生成段广播**」；乘子是连续旋钮，且可叠在 prompt/SFT 之上。

## 六、手法线 C：ITI（2306.03341）——稀疏注意力头上的真值方向

### 6.1 探针 → 移位（§3.2–3.3）

1. 在 TruthfulQA 重组的 QA 对上，对每个 **注意力头输出** $x_l^h$ 训线性探针；头间差异大——文例：**第 14 层第 18 头** 验证准确率 **83.3%**。
2. 只干预探针表现最好的 **Top-$K$** 头（默认扫描后常用 $K=48$）。
3. 沿真值方向移位 $\alpha\,\sigma_l^h\,\theta_l^h$（$\sigma$ 为该方向激活标准差）；方向优选 **mass mean shift**（真类均值 − 假类均值），优于探针法向 / CCS / 随机（Table 3）。
4. **每个自回归步**重复；与解码算法正交。

### 6.2 TruthfulQA 主表（生成轨 true×informative）

**Alpaca / Vicuna（Table 2，2-fold CV）：**

| 模型 | True*Info (%) | True (%) | MC (%) | CE | KL |
|---|---:|---:|---:|---:|---:|
| Alpaca | 32.5 | 32.7 | 27.8 | 2.56 | 0.0 |
| **Alpaca + ITI** | **65.1** | **66.6** | 31.9 | 2.92 | 0.61 |
| Vicuna | 51.5 | 55.6 | 33.3 | 2.63 | 0.0 |
| **Vicuna + ITI** | **74.0** | **88.6** | 38.9 | 3.36 | 1.41 |

摘要口径与上表一致：**Alpaca 32.5% → 65.1%**。LLaMA-7B 上相对 SFT / few-shot 亦有增益（Table 1）；$\alpha$ 与 $K$ 呈真值–信息量权衡的倒 U（Fig.4）。方向数据效率：数百例量表即可（对照 RLHF 量级叙事）。

**跟读抓手：**ITI =「**先找到少量真值头，再只推这些头**」——比全残差加向量更稀疏，旋钮是 $(K,\alpha)$。

## 七、三条手法对照（跟读表）

| | **ActAdd** | **CAA** | **ITI** |
|---|---|---|---|
| 向量来源 | 1 对（可极少）提示激活差 | 多对 MC 答位 **均值差** | 探针 / 类均值，按头 |
| 干预位置 | 指定层、对齐的序列位置 | 指定层、**生成段全位置** | **Top-$K$ 注意力头** 输出 |
| 强度旋钮 | $c$、层 $l$ | 乘子 $m$、层 | $\alpha$、$K$ |
| 主展示任务 | 毒性↓、情感转向、话题 | 对齐相关行为双向控 | TruthfulQA 真值↑ |
| 相对权重对齐 | 无训练 | 无训练（可叠 SFT） | 无训练（可叠 IFT） |

RepE 视角：ActAdd≈轻量 contrast/reading 加法；CAA≈数据集化 MD；ITI≈读侧探针 + 稀疏头控；LoRRA 则把对比目标写进 **低秩权重**（已偏训练，仍属表征控制族）。

## 八、机制案（2604.08524）：拒绝 steering 主要走 OV

> **安全读法：**本节能回答「向量加进去之后 **哪个子电路在传效应**」；**不**提供如何构造有害对比集、如何用负向拒绝向量越狱的步骤。文中 ASR 等仅作机制消融的 **公开聚合指标**。

### 8.1 设定（§3）

- **任务个案：** refusal 表征 steering（沿 Arditi et al. 2024 设定的双向拒绝/遵从；本笔记不展开其攻击协议）。
- **模型：** Gemma 2 2B Instruct、Llama 3.2 3B Instruct、Qwen 3 8B（non-thinking mode）。
- **向量族：** Difference-in-Means（**DIM**）、Next Token Prediction（**NTP**）、Preference Optimization（**PO**）。
- **工具：** 将激活 patching / attribution patching 扩到 **多 token 受控生成**。

### 8.2 主结论（摘要 + §5–7）

1. **电路可互换：** 不同求向量方法在同层应用时，恢复出的电路高度重叠（文：**≳ 90%**）。约 **10% / 11% / 8%** 边即可在三模型上达高 faithfulness（Gemma / Llama / Qwen 边数分母文内给出）。
2. **OV ≫ QK：** steering 与注意力的交互 **主要经 OV**；**冻结全部注意力分数（QK）** 时，性能平均仅降 **8.83%**（三模型族）。消融 OV / steering-value-vector / 对 MLP 的直接项则 ASR 类指标平均降幅 **≥ 45%** 量级（Table 1 叙事）。
3. **可解释分解：** 对受控 OV 做数学分解，可打出语义可释概念——**即使原 steering 向量本身不那么可释**。
4. **稀疏化：** 借 patching 重要性，向量可稀疏 **85–96%** 仍保留大部分效应；梯度系与 IE 系稀疏在共享维上聚合（IoU 显著高于随机）。

**跟读抓手：**「加向量」看起来像晃残差，机制上更像 **改写注意力 OV 通路上的值传播**；QK（重分配注意力分数）不是拒绝 steering 的主引擎。稀疏化说明有效自由度远低于全维 $d_{\mathrm{model}}$。

## 九、可选补链：Selective Steering（2026.findings-acl.529）

> **不升主深读。** 只收架构修补；**不写** 攻击角扫描、有害 prompt 构造或可复用越狱步骤。文内用 ASR 作可控性代理——此处 **不转载逐步结果表**。

**问题诊断（文）：** Activation Addition 对层范数敏感；Directional Ablation 只有开关；Angular Steering 的实用实现 **破坏范数** → 小模型（<7B）易 generation collapse。

**两招：**

1. **保范数旋转**（相对 Angular Steering）：在 2D steering 平面内旋转时保持 $\|h\|$（文 Proposition：SS 保范数；标准 Angular 实现可不保）。
2. **判别层选择：** 仅当正/负类均值在特征方向上的投影 **异号**（$\tilde\mu_{\mathrm{pos}}\cdot\tilde\mu_{\mathrm{neg}}<0$）时施加；同号层不动——避免在「尚未分开」的层搅动。

**文称结果口径（摘要，不展开攻击面）：** 跨多模型（摘要 **nine**；贡献条写 **8 models / 3 families**：Llama、Qwen、Gemma）——相对先验方法可控性代理指标可高达约 **5.5×**；**零** 困惑度阈值违规；标准基准能力保持约 **100%**。本篇只取「**几何合法 + 层选择**」接口，供与 ActAdd/CAA 均匀加层对照。
