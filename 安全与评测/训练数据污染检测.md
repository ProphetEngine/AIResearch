## 二、检测轴地图（本篇主轴）

> 下列「轴」是*工具族*，不是互相可替代的同一度量。[[评测与排行榜可靠性]] §2.4 已列 exact / n-gram / canary / 人工抽查为**引用时要问官方的问题**；本表补「测什么信号 / 谁能用 / 典型失效」。

| 轴 | 信号直觉 | 谁能用 | 本篇锚点 |
|---|---|---|---|
| **语料侧 n-gram / exact overlap** | 训练语料与评测题的高阶 n-gram / 精确重叠 | 主要是**有语料的开发者**；估近似比例而非「铁证」 | DCQ §5 Related Work：OpenAI / Llama / PaLM 等报告式做法 |
| **Canary 字符串** | 评测/公开数据嵌入可机读标记 → 预训练可排除 / 可检索证明混入 | 数据发布方 + 训练方 | [[评测与排行榜可靠性]]：Claude 4 Alignment Faking **machine-readable canary**；Opus 4.5 笔记 §2.4：**Canary**（Terminal-Bench BigBench/ARC 等）与 substring / 20-gram fuzzy 并列 |
| **Quiz（词级扰动选择题）** | 在原文与近义改写中认出「原词面」→ 当作 verbatim 记忆/污染代理 | 黑盒 I/O 即可 | **DCQ**（2311）；2409 称 **Word Perturbation Quiz (WPQ)** |
| **补全 / Token overlap** | 给数据集名+分段前缀，看后续是否 exact/near-exact 复现 | 黑盒；近匹配常靠另一模型裁判 | 2409：Token Completion Overlap（Golchin & Surdeanu 2024b）；DCQ 对照的 replication-based |
| **概率侧 Min-K% / Canonical order** | 最低概率 token 均值；规范序 vs 打乱序的似然差 | 需 **logits / 参数可及** | 2409：Shi et al. Min-K%；Oren et al. Canonical Order |
| **时间窗 / cutoff 纵向** | 截止前后同难度题 pass-rate 落差；或只报「发布晚于 cutoff」的题 | 需持续收题 + 可信 cutoff | DCQ Related Work：**Roberts et al. (2023)**；厂商表常把 **LiveCodeBench** 写成日期切片（如已入库 MiniMax M1：`24/8∼25/5`）——与 quiz 轴**互补一句**，协议以各家当期脚注为准 |

**与 [[评测与排行榜可靠性]] 概念三分的接口（不展开）：** 上表主攻 **训练集重叠 / contamination**；**runtime 检索泄漏**、**格式/分布污染**仍按 [[评测与排行榜可靠性]] §2.1 分列，勿把 quiz 高分直接等同「榜分造假机制已查明」。

## 三、Data Contamination Quiz（DCQ）要点

### 3.1 假设与题型

- **核心假设（§2）：** 若实例曾 **verbatim** 进入训练，模型应能在「原句 + 若干词级近义改写」中认出原词面。
- **五选一：** 1× 原文 + 3× GPT-4 生成的词级扰动（保意、保结构、彼此不同）+ **E) None**。
- **输出锁单字母 A–E：** 降采样噪声；并利于绕过「勿复述版权内容」类 **safety filter**（相对开放式复述/抽取）。

### 3.2 位置偏差补偿（BDQ → BCQ）

| 步骤 | 作用 |
|---|---|
| **BDQ**（Bias Detector Quiz） | 四选项全是扰动 + E；找「选得比随机还少」的 **non-preferred** 槽位 |
| **BCQ**（Bias Compensator Quiz） | 把原文放进 non-preferred 槽；多轮置换取**最高**表现 → 估污染 **区间 [min, max]**，兼顾过估/低估 |

作者强调：本方法以 **memorization** 为检测依据，文中对 memorization 与 contamination 在操作上互换使用（脚注）——读结论时要带着这层代理关系。

### 3.3 作者自承边界（DCQ Limitations）

- 只估 **verbatim**；**metadata / 非逐字**污染不在范围。
- 私有/半私有评测**不能**当作长期解（举 o3 在 ARC-AGI-1 vs 新发布 ARC-AGI-2 的纵向落差作污染担忧例；细节以原文 Limitations 为准）。

## 四、方法局限专线（2409.09927）

### 4.1 五方法一览（文 Fig.1 / §4）

1. Token Completion Overlap
2. Min-K% Prob
3. Word Perturbation Quiz（即 DCQ 族）
4. Instance Local Order Quiz（作者试点：问「原数据集中谁紧接在目标之后」）
5. Canonical Order Statistical Testing

### 4.2 文内点名的轴级局限（压缩）

| 方法 | 文中局限（意译压缩） |
|---|---|
| **Min-K%** | WikiMIA 式「发布前=污染」假设过强；实战缺阈值阈值；代码当时不可得 |
| **Canonical order** | 长实例 × shard × 置换成本高；依赖「网页规范序仍保留」等强假设（DCQ Related Work 亦批位置偏差） |
| **Token overlap** | 「near match」常委 GPT-4 裁判 → 歧义/偏见；前缀取哪一段影响 ROUGE/p 值 |
| **WPQ / DCQ 族** | 扰动常**不如原文流畅**；专名/数字/未扰动标签可成捷径 → **可能高估**污染；与「真记忆」纠缠 |
| **Local order quiz** | 既要见过局部序，又要语义检索成功；任务本身极难 |

### 4.3 三句总判（Abstract + §5–6）

1. **假设与落地均有非平凡限制**——传统基准/早期模型上「有效」≠ 难基准 + 当代模型上可信。
2. **指令微调 + CoT 答案增强** 的 oracle（LLaMA-2-70B 全参微调，按比例掺入难基准）上：五方法**都难稳健反映**已知污染比例；微调后 Min-K% 均值甚至**下降**（与「原题仍在」直觉相悖）。
3. 跨方法 **Spearman 相关弱**（Table 3）→「公认方法」**不能同时都对**；不可单点定谳某模型–某集「已污染百分之几」。

**跟读提醒：** Table 1 里 WPQ 准确率在多模型/多集上偏高，作者倾向解释为**识别扰动伪迹**而非稳妥污染检出——引用 WPQ/DCQ 数字时必须带上这句审慎。

## 六、跟读清单 / 开放问题

1. 黑盒估污染时：DCQ 给的是 **memorization 代理下的区间**，不是语料审计报告。
2. 有语料权时：n-gram / substring / canary 仍是工业主路径（见 Opus 4.5 笔记 §2.4），但 **fuzzy 阈值与假阳** 需各家原文。
3. IFT/合成解答污染：2409 oracle 表明「旧检测器」可能整体失灵——新基准涨分**不能**单靠某一 quiz 分数解释。
4. **待补材料（非本篇范围）：** LiveCodeBench 原论文时间窗定义；各家当期主榜 decontam 附录全文。

## 七、一句话收束

> **污染检测 = 多轴探针，不是单一仪表：** 语料侧 n-gram/canary 管「进没进库」，行为侧 quiz/补全/概率/规范序管「像不像背过」；DCQ 把后者做成可估区间的黑盒测验，而 2409 证明这些测验在难基准与指令微调污染上**互相打架**——写榜与写卡时，缺协议的「污染率」与缺轴说明的「已 decontaminate」同样不可信。
