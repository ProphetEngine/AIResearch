## 二、问题立轴：universal jailbreak × 部署可行性

### 2.1 为何不是「再训一遍 harmlessness」

CC §1–2：LLM 安全机制可被 jailbreak 绕过；随 **CBRN** 能力上升，风险更尖锐。作者聚焦 **universal jailbreak / universal jailbreak strategy**：在某一领域**绝大多数**目标查询上，可靠绕过护栏并抽出**高度细节、具体**有害信息——效果上把模型变成「无护栏变体」。动机与 Anthropic **Responsible Scaling Policy** 下的误用缓解承诺挂钩（脚注），但本篇写的是**分类器护栏工程**，不是 RSP 全文。

非专家 uplift 三条件（CC §2，意译压缩）：(i) 可靠拿到可核对的准确信息；(ii) 对复杂流程中绝大多数分步查询都能得到帮助；(iii) 信息足够细、够具体。故防御目标对准「跨查询、高细节」的通用攻击策略，而非单次偶发越狱。

### 2.2 三 desiderata（架构验收框）

| # | 要求 | 工程含义（原文） |
|---|---|---|
| **1 鲁棒** | 抗 universal jailbreak | 人类 RT + 自动评测；成功判据用 **rubric** 对 helpful-only 细节量 |
| **2 可部署** | 开销、延迟、误拒可控 | 保留 streaming / TTFT；生产流量拒答增量与相对推理成本可报 |
| **3 灵活** | 威胁面可变 | 改 constitution 类别即可重生成数据；也可把已知攻击模式写进训练 |

**与相邻笔记的接口（勿展开）：**

- **[[对齐脉络RLHF与偏好优化]] / CAI**：训练期用原则 + AI 反馈塑形策略；本篇是 **serving 路径上的旁路分类器**（swiss-cheese 多层）。
- **B5**：红队是「发现—度量—回流」流程；本篇只消费 RT **小时数 / 漏洞发现率 / 是否出现 universal**，不重写众包剧本。
- **[[可扩展监督与弱到强]]**：oversight 谈「谁监督谁」；本篇谈「上线后如何挡 jailbreak 流量」。

## 三、一代：Constitutional Classifiers（2501.18837）

### 3.1 总装：宪法 → 合成数据 → 双分类器

`
constitution（有害 / 无害类别自然语言规则）
 ↓
helpful-only 模型生成查询 + 有害/无害回复 → 过滤误拒绝
 ↓
数据增强（翻译、改写、系统提示变体、已知 jailbreak 技法、组合）
 + ART（自动红队模板，含长上下文 / 多轮）
 + 良性 pool（承包商数据；文称不用生产流量作 benign pool）
 ↓
input-only 分类器 + streaming output-only 分类器
 ↓
护住目标 LLM（瑞士奶酪多层，含被护模型自身）
`

**Constitution（§3.1 / Table 1）：** 同时写 **harmful** 与 **harmless** 类别（例：家用化学品讲解允许，受限化学品提纯/放大不允许）。无害侧对压低 over-refusal 必要（文指向 Appendix E.5）。自然语言规格 → 可快速改威胁模型；同一标注集也可训其他护栏形态（文点名 linear probes，++ 文展开）。

**为何双分类器（§3）：** output 流式分类挡住许多流行 universal 策略（文引 many-shot、GCG 等）；input 分类则拦截「专门绕过 output 分类器」的输入（含建立编码信道、使输出离开 input 则不可读的混淆）。

### 3.2 Output：按 token 流式预测「整段是否有害」

- 微调 LM + **linear value head**：用前缀 $t_{1:T'}$（$T'\le T$）预测全序列标签 $y$。
- 分数超阈值则**立即停流**——保安全与用户体验；可缓存中间激活。
- Fig.2：token（示意到词）级分数随有害内容上升而升高。

Input 侧则把整段输入包进分类任务模板，做成 next-token 式微调分类（Appendix E.7 模板；本篇不抄提示全文）。

### 3.3 人类红队（原型系统，§4）— 只记评测字段

| 字段 | 文中取值 |
|---|---|
| 受邀 / 激励 | 约 **800** 申请中邀 **405**；HackerOne bug bounty；单报告最高约 **$15K** |
| 目标 | **10** 条 CBRN infohazard 查询；要「universal」式跨查询细节 |
| 护栏底座 | 原型分类器从 **Claude 3.5 Sonnet** 微调，护同一代模型（偏鲁棒、拒答高） |
| 工作量 | 摘要写 **>3,000** 估计小时；脚注均值估计约 **4,720** 小时，90% CI **[3,242, 7,417]**（日志 + 自报校准 bootstrap） |
| 主结论 | **无**报告在「helpful-only 一半细节」阈值下答全 10 题；更严「相近细节」下单报告最多约 5、按人聚合最多 **6/10** |
| 基础设施教训 | 一则看似 universal 实为部署 bug：output 已 flag 后仍泄漏最多 **128** token → **分类器与部署管线都要红队** |

成功判据骨架（与 B5「怎么组织红队」无关，只记度量）：对每题用模型生成 **technical rubric**，候选输出与 helpful-only 对照打分；「一半细节 / 相近细节」两档。文指出高分报告常钻 **rubric / 良性改写 / 超长灌分**，而非经典 DAN / many-shot / God-Mode——攻击者打的是**评测最弱环**。

组件消融（§4.3 / Fig.5，红队提示随机子样、半细节阈值）：helpful-only ASR ~**16%** → HHH ~**14%** → +input ~**2%** → +input+output ~**0.5%**。说明：**仅 harmlessness 训练远不够**；分类器叠层贡献主降幅。

### 3.4 改进版部署可行性（§5 / Fig.6）— 化学武器 constitution

| 维度 | 数字（文 / 介绍页一致处） |
|---|---|
| 自动评测 ASR | 无分类器约 **86%**（仅拦 ~**14%**）→ Constitutional Classifiers 后约 **4.4%** / 「挡住 **95%**」（Fig.6A 叙述） |
| 生产拒答增量 | Claude.ai Free+Pro 随机 **5K** 对话：绝对 **+0.38%**（介绍页称该样本上相对基线不显著） |
| 相对推理开销 | **+23.7%**（相对被护模型；文称在对照基线中最低档） |
| 分类器底座 | 改进方法下 input/output 从 **Claude 3.5 Haiku** 微调，护 **Claude 3.5 Sonnet (New)** |
| 改进杠杆 | 扩大 harmless constitution、重校阈值、增强增广、更小分类器底座降开销 |

阈值校准约束（§5）：扫 input/output 阈值，最大化 jailbreak 集 TPR，同时约束相对 unguarded 的 FPR（WildChat 多轮增量 ≤**0.5%**、单轮 ≤**5%**、OR-Bench 增量 ≤**5%** 等）。

**一代局限（文自述）：** 原型拒答过高；仍发现局部脆弱；RT 人群≠全体对手；激励止于「半细节」可能低估更强攻击；rubric 难分「背景知识 vs 可 uplift 操作信息」；场景偏 chatbot + 预设题。介绍页另记 2025-02 live demo：约 **339** 有经验 jailbreaker、约 **3,700** 集体小时后出现至少一则被判定为 universal 的策略——强调**需互补防御与快速响应**；++ 文即针对上一代系统性漏洞与开销。

## 四、二代：Classifiers++（2601.04603）

### 4.1 上一代被打穿的两类洞（§2）

| 攻击族 | 机制（文） | 能力代价 |
|---|---|---|
| **Reconstruction** | 把有害请求拆进良性上下文（如代码库函数返回值），再令模型重组并答；可再叠输出混淆 | GPQA Diamond 上 Claude Opus 4：无混淆 **74.2%** → 两则示例攻击 **32.3%** / **49%**（能力掉但仍可观） |
| **Output obfuscation** | 隐喻、替换敏感词、谜语等；**离开 input 则难解** → 专打 **output-only** | 同上；文忧虑对手可找到**能力掉更少**的新变体 |

→ 架构响应：用 **exchange classifier** 替换「孤立看 input / 孤立看 output」的双塔主路径。

### 4.2 Exchange classifier（§3）

- 先像 input 一样看提示；再在生成中**按批**看输出，但始终带上**完整对话上下文**。
- Prompt caching 使持续复评可行。
- 实验：双塔（Haiku 3.5 input + 更小内部 LLM output）vs **exchange-only**（同用 Haiku 3.5；文称标准 input 分类器可直接当 exchange 用，无专门训法）。阈值对齐 WildChat **0.1%** 拒答。Exchange 相对上一代约 **+50%** 算力。
- 人类 RT：高风险漏洞 = 答对 **>5/8** 题且达「无护栏一半细节」。发现率：双塔 **0.01871** / 千查询（13 / 695K）→ exchange **0.00885** / 千查询（2 / 226K）≈ **2.2×** 更少；「答全题半细节」类 universal：双塔 4 则、均发现时约 **27** 自报小时 → exchange **1** 则、约 **100** 小时。

### 4.3 两阶段级联（§4）

- **Stage-1 轻量**筛全流量；flag **升级**而非直接拒绝 → 可容忍更高一阶假阳，从而用更弱/更便宜模型。
- Stage-2：Haiku **4.5** 级 exchange；Stage-1 ≈ Stage-2 成本的 **1/3**（内部模型）。护 Claude Opus 4。约 **10%** 流量进二阶；一阶约占系统总成本 **~77%**。
- 相对 §3 单 exchange：**5.4×** 降本（含管线/新模型）；仅换二阶模型约 **3×**。
- RT：高风险发现率 **0.00878** / 千查询（5 / 569K），与 exchange 相当；**无**单 jailbreak 达「全题、无护栏相当细节」。脚注：赏金外专家仍可用大量自动化找到 universal，但成本高。

### 4.4 线性探针（§5）— 复用被护模型激活

**设定：** 交换级标签 $y$，但要在采样过程中逐 token 决策。探针：

$$
p_{\mathrm{probe}}(y=1\mid x_{1:t})=\sigma(W^\top\psi_t(x_{1:t})+b)
$$

$\psi_t$ 可单层或多层拼接。关键训练改动：

1. **SWiM（滑动窗均值）logit 平滑**：训练时对最近 $M$ 个 logit 取均；推理用 **EMA**（只存一个标量）。避免单 token 尖峰误杀。
2. **Softmax 加权 BCE**：权重 $\propto\exp(\bar z_t/\tau)$，把梯度压到「最确信有害」的位置——允许公共无害前缀自信判无害，并严惩无害序列上的假阳（流式一旦 flag 后续全断）。

分析要点（静态 CBRN jailbreak 集、WildChat 0.1% 校准）：

- 全层探针 ASR 可逼近小外部分类器，优于 extra-small；全层约 **1.4%** ASR 优于抽层。
- 平滑 + softmax 组合最优（Fig.2b）。
- Probe 与外部分类器 **Spearman 相关更低** → 互补；**Probe–S ensemble** 优于纯外部 ensemble（Fig.3a）。
- 探针作一阶路由、二阶用 probe+小分类器平均 logit：文称在该集上可相对「全程小分类器」达约 **100×** 算力降，同时鲁棒不差甚至更好（Fig.3c）。探针本身相对小外部 LM 前向可视为近似零边际成本（文用 Gemma 3 量级 FLOPs 对照说明数量级）。

超参见文：$\tau=1$，$M=16$；训在 Claude Sonnet 4 全层激活；标签可用合成硬标或 Sonnet 4.5 Constitutional Classifier 软标蒸馏。

### 4.5 生产级系统（§6）与对照表

**架构：** 加权两阶段——全程 **线性探针**；超阈则升级到外部 Constitutional Classifier（Haiku 4.5）；升级路径最终分

$$
z_{\mathrm{final}}=0.55\,z_{\mathrm{probe}}+0.45\,z_{\mathrm{classifier}}
$$

护 **Claude Sonnet 4.5**（探针取该模型激活）。

**Shadow 部署：** 生产流量 **2025-12-01 → 2026-01-01**；**flag/拒答率 0.05%**（对比一代改进版报告的 **0.38%**）；约 **5.5%** 流量升级二阶；相对 §3 exchange 约 **40×** 降本，相对 §4 无探针级联约 **8×**。

**RT：** 估计累计 **1736** 小时、约 **198K** 次尝试；高风险漏洞 **1** 则 → **0.005** / 千查询（全文最低）；该攻击发现时 **30** 小时（文称「最高的最短发现时间」）；**无**答全 **8** 题且达无护栏一半细节的 universal。

## 五、架构思想压缩（可跟读清单）

1. **规格在 constitution，不在黑箱拒答表**：有害/无害类别显式 → 合成数据可再生、边界可解释、威胁面可改。
2. **护栏是 serving 多层，不是替代对齐训练**：HHH alone ASR 几乎不动；分类器叠层才把 RT 子样 ASR 打到亚百分点。
3. **流式是一等约束**：output / exchange / probe 都必须「前缀期」可停；训练目标（全交换标签）与推理（前缀决策）的错位，用平滑 + 非对称加权补。
4. **上下文绑定打败混淆**：reconstruction / 隐喻替换专杀「孤立 output」；exchange 把 input 绑回判决。
5. **级联把「假阳」改成「升级」**：一阶可激进召回；二阶才拒答 → 小模型扛得住生产。
6. **探针吃「已付费」表示**：几乎零边际成本的一阶 + 与外部分类器低相关 → ensemble/级联同时抬鲁棒、砍开销。
7. **评测要打基础设施**：128-token 泄漏说明 RT 必须覆盖部署接线，不只分类器权重。
8. **数字分系阅读**：一代「3k+ 小时 / 10 题 / +0.38% / +23.7%」vs 二代「1.7k 小时 / 8 题 / 0.05% / ~40×」——题目数、护栏代数、校准集不同，只比同文 Table 内相对序。
