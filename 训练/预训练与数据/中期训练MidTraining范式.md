# 中期训练（Mid-Training）范式总览

> **主要来源**：[Mid-Training of Large Language Models: A Survey](https://arxiv.org/abs/2510.06826)（Mo 等，v1，2025-10-08）（截至 2025-10-08）
> **研究线**：架构思想（主：数据分布退火、学习率调度、长上下文扩展三轴）；评测字段（辅：综述汇整的公开增益，不可横向硬比）
> **范围与相邻笔记**：
> - 相对 [[规模定律与预训练范式]]：那篇回答给定算力如何配参数与 token；本篇回答通用预训练之后剩余预算换什么分布、步长与窗口。
> - 相对 [[OLMo3全栈开放配方]]：那篇是单栈阶段表；本篇是横切 taxonomy。
> - 相对 [[分词器与数据配比]]、[[合成数据与教科书式数据]]、[[BeyondWeb合成预训练]]：高质量网页与合成数据在本篇只作 mid-training 数据源类型。
> - 相对 [[优化器与训练稳定性]]：LR 是本篇旋钮，优化器谱系在那篇。
> - 相对 [[持续学习]]：分布偏移与遗忘作风险提醒，终身学习 taxonomy 在那篇。
>
> **意义**：近几代配方不再把「预训练到后训练」写成两段硬切。在网页噪声语料上继续堆 token，推理、代码与长上下文常出现收益停滞；Mid-Training 用高质量数据退火、分段学习率与课程式拉长窗口，把剩余算力换成后期边际效用，而不是再堆一轮同质通用语料。

## 一、问题背景

仅靠网页级噪声语料继续堆 token，推理、代码与长上下文等能力常常收益停滞（综述开篇）。因而在通用预训练之后，额外插入若干 annealing 风格的中间阶段：提高数据质量、下调或分段学习率、按课程拉长上下文，以稳住收敛并抬高后期边际效用。规模定律回答「参数与 token 如何配」；Mid-Training 回答「已经吃过海量通用语料之后，剩余预算该换什么」。

综述还从三条理论视角概括「为何退火有效」（§II）：Gradient Noise Scale（更高质数据往往带来更大有用梯度方差）；Information Bottleneck（退火阶段压缩噪声特征）；Curriculum Learning（由多样噪声转向结构化推理）。三条是解释框架，非单一可证伪定理。

## 三、定义与阶段位置

Mid-Training 是介于大规模通用预训练与任务特定微调之间的中间阶段：模型已从海量网页等获得广覆盖表征后，再经历一轮或多轮 annealing——同时或交替地上采样高质 / 合成 / 推理向数据、降低或分段调整学习率、逐步扩展上下文窗口（综述摘要与引言）。

实践命名不统一（annealing / reasoning / long-context stage 等）。与持续预训练的差别：后者可在任意检查点换语料续训；mid-training 强调相对主预训练的刻意退火设计。与后训练对齐的差别：指令风格数据可提前注入，但最优插入位置仍有争议；偏好优化与 RL 本身不属于本篇。

## 四、三条配方轴

### 4.1 数据分布

综述 §III 常见类型：高质量过滤网页（FineWeb-Edu、DCLM 等）、代码与数学、指令 / QA、合成教科书、长文档、推理 / CoT、Fill-in-Middle。要点（§III-C）：更重质量；不同 HQ 源宜组合；指令数据插入时机未决；长上下文依赖数据来源而非仅序列长度；合成数据可补欠表示域；对高质子集适度重复与改写可部分替代堆量，但分布断裂会加剧遗忘（综述援引 OpenCoder：mid-training 仍保留约 84% 来自主预训练分布）；存在「灾难性过训练」警示，需停止准则。

### 4.2 学习率

主预训练常用 warmup + cosine / linear；显式 annealing 后多见多阶段、WSD、多步阶梯（§IV）。WSD 综述称末段可用约 10% token 完成大幅掉 loss。衰减形态与 batch、尺度、优化器强耦合，尚无统一理论。

### 4.3 长上下文

多数 RoPE 系扩展可理解为对基频的重映射，并可叠加 YaRN 类温度缩放与省显存手段（§V）。实践上窗口渐进拉长（例如 4k 到 32k 再到 128k），长/短样本混合（综述概括常见约 30%–60% 长样本区间），架构改动主要解锁 KV 预算。面向约不超过 128k 时，综述给出的经验默认是 ABF 将基频提到约 10^6 量级并配合 YaRN 类缩放。

三条轴应联合设计：无高质数据则难特化；无合适调度则浪费高质 token；无上下文扩展则长程任务受限。
