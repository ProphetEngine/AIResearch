## 一、问题背景

[[分词器与数据配比]] 已说明：同等 token 预算下，网页语料的抽取与过滤可改有效信息密度。本篇补另一条轴——数据是否由更强模型（或同一模型）合成，以及是否按「教科书 / 习题」形态组织。指令微调若只依赖人类写的任务，成本高且多样性常落在常见 NLP 任务附近（Self-Instruct §1）。代码侧 The Stack 等体量大，但对「学基础编程与算法推理」信号差；作者猜想模型同样受益于清晰、自洽、有教学性的数据（Textbooks §2）。

## 三、Self-Instruct：自生成指令对齐

主张：用预训练 LM 自身生成指令、输入与输出，过滤后微调同一模型；发布约 52K 合成指令（摘要）。对 vanilla GPT-3：Super-NaturalInstructions 未见任务上相对原 GPT-3 +33.1 绝对点（ROUGE-L 从 6.8 到 39.9），接近同设定 InstructGPT001（39.9 vs 40.8）（摘要 / Table 3）。数字按 ACL 2023 正式刊。

流水线（§2）：175 条人工种子，再 in-context 生成新指令，再判定是否分类任务，再用 Input-first 或 Output-first 生成实例，经 ROUGE-L≥0.7 等过滤后回填池。数据画像：52,445 条指令、82,439 实例；抽检三者皆有效约 54%（Table 1–2）。规模消融：人工 Rating-A 约在 16K 指令后接近平台；更好教师输出仍可再抬曲线（§4.5）。

## 四、教科书式数据：phi-1

phi-1：1.3B Transformer，约 8×A100 / 4 天；过滤「教科书质量」代码约 6B token + GPT-3.5 合成教科书与习题，合计 <7B token；HumanEval 50.6%、MBPP 55.5%（摘要 / Table 1）。CodeTextbook 预训练得 phi-1-base（HumanEval 已约 29%），再在 CodeExercises（约 180M token）上微调得 phi-1（§2）。过滤管用 GPT-4 小规模标注教育价值，再以随机森林筛全量；合成正文主要靠 GPT-3.5。多样性靠向 prompt 注入主题/受众/函数名等受控随机性（§2.2）。对 CodeExercises 大幅去污剪枝后重训，HumanEval 仍明显高于 StarCoder-Prompted（§5、Table 3）。作者省略部分合成细节（§1）。

## 五、近年衔接：合成预训练与网页策展

Self-Instruct / phi-1 之后，合成数据也出现在预训练与网页策展里。以下只取各文 abs 摘要可核句，细节见对端专文：

1. **BeyondWeb**（[arXiv:2508.10975](https://arxiv.org/abs/2508.10975)，v2，2025-08-19；专文 [[BeyondWeb合成预训练]]）：摘要称其为面向预训练的合成数据生成框架（synthetic data generation framework），用于推进预训练性能边界；并给出与 Cosmopedia、Nemotron-Synth 等对照的基准平均分差与训练加速叙述。与本篇 phi-1「小预算、教科书形态」同属合成监督，但问题从代码微调转到预训练配料。
2. **Nemotron-CC**（[arXiv:2412.02595](https://arxiv.org/abs/2412.02595)；正式刊 ACL 2025；专文 [[NemotronCC数据策展]]）：摘要称在 Common Crawl 英数据上，用分类器集成（classifier ensembling）、合成改写（synthetic data rephrasing）并减少对启发式过滤的依赖，以在精度与数据量之间取得更好折中。与本篇「造新教材 / 指令」划界，与 [[分词器与数据配比]] 的真实网页过滤互补。

## 六、与 R1 蒸馏的接口

两点对照：Self-Instruct 扩任务多样性（常自举）；Textbooks 抬单位 token 教学密度（更强教师写书/题）。用长推理轨迹做蒸馏的路线见 [[DeepSeekR1推理训练深读]]，本篇不写 GRPO 与阶段表。
