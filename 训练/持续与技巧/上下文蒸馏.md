# Context Distillation：从 Snell 到 OPCD / DiSC

> **定位**：上下文蒸馏 **P1**——立「**把上下文条件行为蒸馏进参数**」横切：经典框架 **Snell et al. (2022)**（教师富提示 + 学生贫提示，内化指令 / 示例 / scratch-pad）→ 近窗 **OPCD**（on-policy + reverse KL，经验知识与 system prompt 内化）→ **DiSC**（文档切分上下文、KL 主目标，持续知识适配且保留 post-training 能力）。
> **攻坚线**：**架构思想 / 蒸馏目标（主）**——谁当教师、损失方向（forward/reverse KL）、轨迹来源（off/on-policy）、上下文如何切；**评测字段（辅）**——任务内化分 vs OOD/能力保持（IF-Eval、IFEval/MATH/Code 等文内表）。
> **硬划界（开篇钉死）**：
> - **≠ 长上下文架构**：不写 RoPE/YaRN、滑动窗、稀疏注意、无限上下文系统设计；本卡只关心「**条件行为如何进权重**」，上下文窗口本身是约束而非主对象。
> - **≠ [[测试时训练]] TTT**：TTT 是**测试实例**上的 fast-weight / 临时适配；本卡是**训练期**把提示/文档蒸馏进持久参数，推理期可不带原上下文。
> - **≠ B8 教科书合成**：B8 写合成数据流水线（教材式语料）；本卡的「合成」仅指 Snell 式 raw task input / 教师补全，不写教科书数据工程。
> - **≠ [[合成对齐数据Magpie]] Magpie / ActiveUltraFeedback**：[[合成对齐数据Magpie]] 是对齐**偏好数据**流水线；本卡不写偏好对采集与 reward 模型，只写上下文→参数的蒸馏目标。
> **禁止编造**：准确率、KL 形式、页数、代码仓一律锚定官方 PDF（2026-09-22 CST）。Askell et al. 2021（Constitutional AI 语境下的 context distillation）仅作谱系交叉，**不升主文**。
> **入库体积**（`ls -lh`，均 **<20MB** → 二进制可入库）：Snell **1.3M**；OPCD **464K**；DiSC **629K**。禁止权重 / 数据集 / 视频。

## 三、Snell 2022：Context Distillation 经典框架（arXiv 2209.15189）

### 3.1 动机：上下文增益不内化

文观察：指令、ICL、scratch-pad 能显著提升表现行为，但**去掉上下文后增益消失**；长指令/草稿相对任务输入可长一个数量级，且总长易越窗。类比人类「练习 → 程序性记忆」。

### 3.2 四组件 + 形式化（§2）

开发者提供：

1. **Raw task input 分布** $\mathcal{D}$（规则生成 / 未标注池 / LM 条件采样）
2. **教师模板** $T_{\mathrm{teacher}}$（详指令、解释、示例）
3. **学生模板** $T_{\mathrm{student}}$（最小任务说明）
4. **答案提取器** $f$（从教师补全中抽出最终答案，剥掉中间推理）

单轮目标（文 Eq.1，记号略写）：教师在 $T_{\mathrm{teacher}}(x)$ 下采 $y$，学生在 $T_{\mathrm{student}}(x)$ 下最大化 $\log P_{\theta_{\mathrm{student}}}(f(y)\mid\cdot)$。**起步时** $\theta_{\mathrm{teacher}}=\theta_{\mathrm{student}}$，蒸馏驱动力来自 **$x,y$ 条件差异**，而非两套不同权重（对比经典 Hinton KD）。

**组合变体（§2.3）**：

- **Simultaneous**：多组 $(D_k,T_k,f_k)$ 损失求和 → 适合「多提示总长超窗」
- **Sequential**：逐轮用上一学生作初始化 → 可覆盖旧关联
- **Recursive**（引 Choi et al. 2022）：学生升格为下一轮教师

**实现（§2.4）**：硬标签浪费 logit；改 token-level KL；词表过大则用约 **100** 个 token sample 的经验软分布近似。

### 3.3 三类训练信号（§3，文内数字）

**A. 抽象指令与解释（Natural-Instructions-V2）**
- 可内化任务定义；解释相对无解释的教师可再抬学生；任务 id 关联后可用 **sequential** 覆盖旧映射（Table 1 / Table 6）。
- 解释蒸馏：margin 与蒸馏增益相关 $r=0.75$（$p=1\%$，Figure 5）。

**B. 具体示例（SPIDER → Incoder-6.7B，Table 2）**

| 设定 | 4 Examples | 8 Examples |
|---|---|---|
| Teacher | 27.7 | 28.2 |
| Pre-distill Student | 0.3 | 0.3 |
| **Post-distill Student** | **22.1** | **27.9** |
| Direct Gradient Descent | 13.4 | 18.9 |

摘要口径：相对直接 GD，**8-shot 约 +9%** exact set match（正文写 4-shot +8.6%，8-shot 再 +0.4%）。超窗：schema 很长时，simultaneous 从 8 例中随机抽 4 例作教师模板，学生 exact set match **14.22±0.8 → 16.2±0.6**。

**C. Scratch-pad 推理（8-digit addition，Table 3）**

| | Teach | Pre-Dist | Post-Dist | Sc→Dir | Sc+Dir |
|---|---|---|---|---|---|
| 8-digit Acc % | 93 | 0 | **95** | 72 | 61 |

T5-small：蒸馏后**无草稿直接加法** 0%→94.7%；相对 transfer / multitask 基线 **>20%**；评测相对教师约 **8.0×** 更少 token。TK-Instruct 上：直接加法 1%→17%，NI RougeL ≈57→58；合成「火鸡求和」应用题 17%→30%。

### 3.4 跟读要点

Snell 把「context distillation」立成**可组合的训练算子**：同一权重、不同模板差驱动内化。后续 OPCD/DiSC 分别在其 **off-policy / 生成后缀** 假设上动刀——但都承认同一问题陈述：「上下文行为 → 参数行为」。

## 四、OPCD：On-Policy + Reverse KL（arXiv 2602.12275）

### 4.1 诊断：经典 CD 的 off-policy + forward KL

文指既有 CD（Askell/Snell 线）多在**固定数据**上做 **forward KL**：
1. **Exposure bias**：训在教师/真值轨迹，推时自回归；
2. Forward KL **mode-covering** → 学生容量不足时易「糊分布 / 幻觉」。

### 4.2 方法（§3，Eq.1–2，Algorithm 1）

目标：压缩上下文 $c$ 进 $\theta$，使 $\pi_\theta(\cdot\mid x)\approx\pi_{\mathrm{teacher}}(\cdot\mid c,x)$。

$$
\mathcal{L}(\theta)=\mathbb{E}_{(x,c)\sim\mathcal{D},\,y\sim\pi_\theta(\cdot\mid x)}
\Bigg[\frac{1}{|y|}\sum_{t=1}^{|y|}
D_{\mathrm{KL}}\big(\pi_\theta(\cdot\mid x,y_{<t})\,\|\,\pi_{\mathrm{teacher}}(\cdot\mid c,x,y_{<t})\big)\Bigg]
$$

- **On-policy**：$y$ 由**学生无 $c$** 采样；
- **Reverse KL**：mode-seeking，压学生高概率但教师（有 $c$）低概率的 token；
- 实现：对词表求和限制在学生 **top-$k$**；
- 教师配置：**Teacher–Student**（默认可冻教师；可异尺寸）或 **Self-Distillation**（同权重、仅条件差，同步更新）。

### 4.3 两条应用

**① Experiential knowledge distillation（§4.1.1）**
三阶段：从解题轨迹（可不靠 GT 标签）抽出 `– EXPERIENCE ITEM:` → 拼接成长上下文 $c$（math 最长 16384 token；游戏 8192）→ OPCD 压进权重。数据：DAPO-Math-17K 英数；TextArena 的 Frozen Lake / Sokoban。设定含 **test-time**（从 300 条池随机抽，模拟无标签）与 **filtered**（用 val 打分选最优 $c$）。

**② System prompt distillation（§4.1.2）**
用 MetaSPO 优化的 medical / safety system prompt 作 $c$；MedMCQA 与 TweetEval+Hatecheck+Ethos（各留 500 test）。

模型：Qwen3-8B/4B/1.7B（math/游戏）；Qwen2.5-3B/7B-Ins、Llama-3.1-8B-Ins、Llama-3.2-3B-Ins（system prompt）。训练：50 steps，batch 128（文 §4.2）。

### 4.4 文内主表（照录）

**Table 1 — test-time experiential consolidation**

| Model / Task | Method | Acc | IF-Eval (OOD) |
|---|---|---|---|
| Qwen3-8B Math | Base / In-Context / CD / **OPCD** | 75.0 / 77.6±1.1 / 78.5±0.5 / **79.7±0.5** | 81.3 / — / 81.2±0.2 / **81.7±0.4** |
| Qwen3-1.7B Frozen Lake | Base / IC / CD / **OPCD** | 6.3 / 20.2±2.2 / 22.9±4.0 / **26.5±6.4** | 67.3 / — / 65.1±0.5 / **67.1±0.5** |

**Table 2 — filtered**（同结构）：Qwen3-8B Math OPCD **80.9**（CD 79.5）；Frozen Lake **38.3**（CD 35.2）；Qwen3-4B-Ins Sokoban **53.9**（CD 51.6）；OOD IF-Eval 均接近或优于 CD。

**Table 3/4 — system prompt（Medical / Safety）**：多数配置 OPCD > off-policy CD（例：Llama-3.1-8B Medical 76.7 vs CD 75.2；Safety 79.6 vs 77.2；Qwen2.5-7B Medical 62.3 vs 58.5）。Llama-3.2-3B Safety 上 CD 83.3 与 OPCD 83.1 接近（文写「most configurations」）。

**跨尺寸（Figure 2）**：Qwen3-8B 教师生成经验 → OPCD 训 1.7B/4B/8B 学生均升；**直接把教师经验塞进小模型上下文反而可能降分**——强调「经验要与消费模型 on-policy 对齐」。

**遗忘（§4.5）**：Frozen Lake 上 OPCD 相对 CD 约 **+2%** IF-Eval；safety prompt 蒸馏时 OOD medical 相对 off-policy 约 **+4** 分且贴近初始学生。

**Teacher–Student vs Self（§4.6）**：Sokoban 上 Self **18.8** vs Teacher-Student **53.9**（冻教师更稳）。

### 4.5 跟读要点

OPCD = **context distillation × on-policy distillation**：把「内化对象」从静态指令扩到**可累积的经验条**与**外部优化 system prompt**，并用 reverse KL 在学生自己的轨迹上纠错。与 [[测试时训练]] TTT 的分界：这里是**批量训练期巩固**，不是单测例临时权重。

## 五、DiSC：切分上下文更新参数知识（arXiv 2602.16093）

### 5.1 问题：post-trained LLM 的持续知识适配

设定（§2.1）：给定 $M_{\mathrm{post}}$ 与文档语料 $D$（多句/多段，**非** factoid 键值），求 $M_{\mathrm{new}}$：
- $\mathrm{Acc}(M_{\mathrm{new}};T_D)$ 升（新知识 QA）；
- $\mathrm{Acc}(M_{\mathrm{post}};T_{\mathrm{gen}})-\mathrm{Acc}(M_{\mathrm{new}};T_{\mathrm{gen}})$ 小（IFEval / MATH-Hard / HumanEval / BBH / GPQA / MuSR / MMLU-Pro）。

文强调：能力适配可用 RL（隐式偏小 KL）；**生文档无可靠奖励** → 主导仍是监督 FT，但 NTP 主目标 + KL/LoRA/replay 等辅助**不足以**保住 post-training 技能。

### 5.2 方法：Distillation via Split Contexts（§3）

直觉（类比带文档 QA）：若参数已含 $d$ 的知识，则 $P_M(y\mid d,q)\approx P_M(y\mid q)$；无 $(d,q)$ 对时，改为**文档内 prefix/suffix**：

1. 冻教师 $M_T\leftarrow M_{\mathrm{post}}$；可训学生 $M_S\leftarrow M_{\mathrm{post}}$。
2. 在句边界采 $k$ 个切点（含文末）；prefix $d^{\mathrm{pre}}_i=s_1\ldots s_{i-1}$，suffix $d^{\mathrm{suff}}_i=s_i$。
3. 主损失（Eq.3）：

$$
\mathcal{L}_{\mathrm{DiSC}}=\frac{1}{|I|}\sum_{i\in I}
\mathrm{KL}\big(P_{M_T}(d^{\mathrm{suff}}_i\mid d^{\mathrm{pre}}_i)\,\|\,P_{M_S}(d^{\mathrm{suff}}_i)\big)
$$

**效率**：教师一次前传抽全部 suffix 分布；学生把各 suffix 拼成一串并**切断跨 suffix 注意力**，亦一次前传 → **共 2 次 forward**，训练期**不必**再生成续写（相对 Padmanabhan et al. 2023 的 transfer-set 生成）。

**与前作对照（文 Table 1）**：Askell = 静态 $c$；Snell = 教师生成上下文与 $y$；Padmanabhan = 知识内化但需显式生成 suffix；**DiSC = 内化文档知识，suffix 来自文档自身**。

### 5.3 实验设定（§4）

- **适配语料**：KUP（5k 合成新闻式更新 + 500 MCQ）；BioASQ（3,226 docs / 209 cloze → GPT-5 造强干扰项变 MCQ）。
- **模型**：Qwen-2.5-7B/3B-Instruct；Llama-3.1-8B-Instruct；Qwen3-8B。FP32，1 epoch。
- **基线**：FT、+Rephrase、+TALR、+KL（$\beta=0.1$）、+LoRA（$r=16$）；**CD base**（Padmanabhan 2023 调参版）。
- **CP 选点（§5.2）**：在 LR 扫描中，要求 IFEval/Math/HumanEval 相对 $M_{\mathrm{post}}$ 掉幅约 **≤5** 分，再比较适配分。

### 5.4 文内主结果（照录口径）

**Finding 1 / Table 2（FT 病理）**：Qwen-2.5-7B-Ins on KUP：适配 **15.46→40.9**，但 IFEval **-14.9**、Math **-25.4**、Code **-9.15**。Llama-3.1-8B：KUP +15 分伴随 IFEval **-17.1**、Math **-6.2**、Code **-8.5**。摘要：适配文档级语料时，FT 可让 IF 掉近 **15**、math 掉 **>25**；DiSC 两域掉幅常 **<5**。

**Finding 2**：+KL / TALR / on-policy rephrase / LoRA **无**稳定「适配↑且遗忘↓」；LoRA 常减遗忘但伤域内分（同模型 KUP 例：35.6 vs FT 40.9）。

**Finding 3**：掉得最狠的是 **post-training 技能**（IF / math / code）；BBH/GPQA/MMLU/MuSR 等「预训练侧」相对稳；pre→post 增益与后续 FT 掉分相关约 **0.9**。

文结论：在 CP 约束下 DiSC **域适配最强**；八设定中有 **六** 次甚至超过无约束 FT 的域分；LR 扫描上相对 FT 更稳（Figure 2）。

### 5.5 跟读要点

DiSC 把 context distillation 从「提示行为内化」拉到「**文档知识持续写入**」，并用 **KL 主目标** 替代 NTP 主目标——这是与「FT + 正则」族的本质差别。与 OPCD 并列近窗：OPCD 强调 **轨迹 on-policy + reverse KL**（经验/系统提示）；DiSC 强调 **文档切分 + 无生成训练 + 能力保持**。二者都仍落在 Snell 开的「条件差驱动蒸馏」伞下。
