# Continual learning for LLMs：综述地图 + Lifelong-MoE

> **主要来源**：[Towards Lifelong Learning of Large Language Models: A Survey](https://arxiv.org/abs/2406.06391)；[Lifelong Language Pretraining with Distribution-Specialized Experts](https://arxiv.org/abs/2305.12281)；[MoRAL: MoE Augmented LoRA for LLMs' Lifelong Learning](https://arxiv.org/abs/2402.11260)（截至 2026-02-17）。三篇均只有 v1：综述为 Zheng、Qiu、Shi、Ma 所作（2024-06-10，投稿 ACM）；Lifelong-MoE 为 Chen 等的 ICML 2023 论文（2023-05-20）；MoRAL 为 Yang 等所作（2024-02-17）。
> **研究线**：架构思想（主）——参数内吸收与参数外挂两条路线、12 个场景与四类通用技法，以及「扩专家、冻旧专家、输出蒸馏」的 MoE 做法；数学原理（辅）——正则、KL 蒸馏与稀疏 top-2 专家扩展。
> **范围与相邻笔记**：
> - ≠ [[隐私与机器遗忘]]：本篇的「遗忘」指灾难性遗忘（学了新的、旧任务掉分），不写选择性抹除的机器遗忘方法。
> - ≠ [[优化器与训练稳定性]]：Lifelong-MoE 的 Adafactor 与学习率设置只作实验配置，不写优化器谱系。
> - ≠ [[混合专家架构]]：本篇只取「专家可扩展」这一接口，不写 MoE 通史与负载均衡。
> - ≠ [[检索增强与知识外挂]]：检索式终身学习只作「外部知识」一格。
>
> **意义**：一次性的静态预训练跟不上持续变化的数据、任务与偏好，而反复从头训练代价过高。这份综述把大模型的持续学习整理成「改参数吸收」与「外挂知识」两条路线、12 个场景和四类通用技法，给后续工作提供了统一的坐标；Lifelong-MoE 则表明在稀疏 MoE 上只加有限专家、激活算力不变，就能在分布变化的持续预训练中明显减轻遗忘。

**一句话**：持续学习的核心张力是可塑性与稳定性——学会新的、保住旧的；综述给出地图，Lifelong-MoE 用「扩容量加正则」在预训练层面给出一个可行解，MoRAL 在参数高效微调层面给出对照。

## 一、问题背景

- **为何需要**：世界知识会过时，用户需求与偏好会变化，静态预训练模型的知识停在截止日期；全量重训成本过高，部署方也常拿不到原始预训练数据（隐私或专有）。
- **核心张力**：可塑性与稳定性。综述开篇举例，持续的垂直领域预训练（如金融）能提升专科表现，但可能侵蚀通用能力；持续对齐中的对应现象称为对齐税（alignment tax）。
- **问题形式**（综述 §2.1）：从任务序列 $\{\mathcal{D}^{(1)},\ldots,\mathcal{D}^{(T)}\}$ 学习 $f_\theta:x\mapsto y$，$x$ 与 $y$ 都是自然语言（分类时 $y$ 为类名，自回归预训练时为下一 token 序列）。
- **评测三角度**（§2.2）：总体看平均准确率 $\mathrm{AA}_t$ 与平均增量准确率 AIA；稳定性看遗忘度 FGT（相对历史最好的掉分，越低越好）与后向迁移 BWT（相对初学时的变化，越高越好）；可塑性看前向迁移 FWD（相对只训该任务的随机初始化模型）。

## 二、脉络

| 阶段 | 代表 | 特点 |
|---|---|---|
| 前大模型时代（2016–2020） | LwF（2016-06）的蒸馏、EWC（2016-12）的权重正则、LAMOL 等生成式回放 | 主要在小模型与任务序列上做抗遗忘 |
| 大模型早期 | 持续预训练加回放、参数高效微调（Adapter、Prompt、LoRA） | 全量微调太贵，架构与参数高效方法成为主战场 |
| 数据级持续预训练（2023） | Lifelong-MoE | 面向语料分布流而非下游任务序列，扩专家容量 |
| PEFT × MoE（2024） | MoRAL | 冻结骨干上挂多组 LoRA 专家 |
| 综述（2024-06） | 12 场景、四类技法、内外两路 | 归纳三条趋势，见下段 |

综述归纳的三条趋势（§6）：任务从特定走向通用（指令调优、知识编辑）；微调从全量走向部分（Adapter、Prompt、LoRA）；知识从内部走向外部（RAG、工具）。

## 三、综述地图

### 3.1 两条路线、十二个场景（Fig.2）

| 路线 | 子类 | 场景 |
|---|---|---|
| 内部知识：更新参数 | 持续预训练（§3） | 垂直领域、语言领域、时间领域 |
| | 持续微调 · 任务特定（§4.1–4.4） | 文本分类、命名实体识别、关系抽取、机器翻译 |
| | 持续微调 · 任务无关（§4.5–4.7） | 指令调优、知识编辑、对齐（含 RLHF，强调对齐税） |
| 外部知识：不改或几乎不改参数（§5） | 检索 | DPR、IRCOT、TOC、FLARE、Self-RAG 等；动机是世界知识过时 |
| | 工具 | Chameleon、ToolAlpaca、Confucius、GPT4Tools；基准 APIBench、ToolBench；动机是超出纯文本生成 |

### 3.2 四类通用技法（§2.3，Fig.3）

| 类别 | 做法 | 代表 |
|---|---|---|
| 回放 | 重放旧数据或其压缩表征（经验回放）；用模型生成伪旧样本（生成式回放） | 持续预训练中的领域回放；指令调优中的 LAMOL、LFPT5、PCLL、SSR |
| 正则 | 保住对旧任务重要的权重（L2、EWC、MAS、RecAdam）或特征（IDBR、CPFD） | — |
| 架构 | 加参数高效模块（Prompt Tuning、Prefix Tuning、LoRA、Adapter）、加专家（MoE）或扩展模型；大模型全量微调太贵，架构与参数高效方法成为主战场 | C-LoRA、O-LoRA、MoRAL；DEMix、ModuleFormer、Lifelong-MoE；bert2BERT、LLaMA Pro、SOLAR、ELLE |
| 蒸馏 | 用新数据、旧数据或伪旧数据做蒸馏 | LwF；命名实体识别的 ExtendNER、CFNER；机器翻译的 COKD |

在垂直领域预训练中，综述把经验回放、参数高效微调、MoE、蒸馏、模型扩展、学习率重新预热（re-warming）、数据选择并列为手段，其中模型扩展与数据选择被摘要标为前大模型时代较少强调的新方向。

### 3.3 挑战与未来方向（§6）

- **挑战**：灾难性遗忘；可塑性与稳定性的权衡（含对齐税）；全量微调的算力；权重或预训练数据不可得。
- **未来方向**：多模态终身学习；高效策略（剪枝、合并、扩展、超长上下文的上下文学习）；与环境交互的通用终身学习（RL、智能体、具身），而不只是吃静态数据集。

## 四、Lifelong-MoE：扩专家、冻旧、输出蒸馏

### 4.1 设定：数据级而非任务级（§1–2）

多数终身学习文献做下游任务序列，而部署现实更接近在不断到来的语料分布流上持续预训练（新网页、维基、对话），下游可以少样本适配，因此论文研究**数据级终身预训练**。核心主张：对大模型，额外容量加合适的正则是关键；在 MoE 上加专家时，由于稀疏激活，算力保持恒定。骨架为 GLaM 式稀疏 MoE（每隔一层 FFN 换成 MoE，每个 token 选 top-2 专家）。

### 4.2 三个做法（§3，Fig.1–2）

1. **渐进扩专家**：只增加专家数与门控维度，深度与宽度不变，仍选 top-2，激活算力近似恒定；新专家从旧专家初始化（随机初始化效果差）；每阶段只部分扩展而非翻倍，避免指数膨胀。
2. **冻结旧专家与旧门控**：只训练新专家、新门控维度与共享的稠密层和注意力；消融显示只冻专家或只冻门控都不够，两者一起最好。嵌入、稠密层与注意力跨分布共享，不能整层冻结；旧专家绑定旧分布，可以冻结。
3. **输出正则（隐式蒸馏）**：$L=L_{\mathrm{Perp}}+\lambda L_{\mathrm{KL}}$，KL 项约束扩展后模型的输出贴近旧专家与旧门控的输出；$\lambda$ 过大（论文称大于 1）会使预训练不稳定。

### 4.3 实验设定（§4）

分布序列刻意拉大间隙：A 为维基百科与过滤网页（3B + 143B token），B 为非英语语料（366B），C 为公开社交对话（174B）。A 对应 TriviaQA，B 对应翻译，C 对应对话与多数 NLU，因此按 A→B→C 训练会伤 QA 与翻译。每个分布训 50 万步；下游评测 TriviaQA（F1）、WMT16（BLEU）、Ubuntu 与 19 项 NLU 的平均，主报 one-shot。规模上，小 MoE 激活约 145M，大 Lifelong-MoE 激活 1.878B，稠密 GShard 对照激活 1.7B；最大实验用 128 块 TPU-v4。回放基线在新分布训练时混入约 25% 历史数据。

### 4.4 结果（§5）

**消融**（Table 3，A→B→C 后的 TriviaQA F1）：不扩专家、不加 KL 为 5.93；只加 KL 为 6.96；4→8→16 翻倍扩展并冻结专家与门控为 6.98；4→7→10 部分扩展、冻结两者并加 KL 为 7.06，最好。

**主对比**（Table 4）：

| 方法 | TriviaQA F1 | WMT BLEU | Ubuntu | 19 项 NLU 平均 |
|---|---:|---:|---:|---:|
| 稠密 + 在线 L2 正则 | 12.99 | 5.66 | 27 | 48.65 |
| 稠密 + 记忆回放 | 14.18 | 7.54 | 26 | 48.65 |
| 稠密 Oracle（三分布联合训练） | 21.25 | 11.14 | 26 | 49.03 |
| GLaM | 21.76 | 6.97 | 26 | 50.9 |
| **Lifelong-MoE** | 20.22 | **19.16** | **27** | 50.26 |

相对稠密 Oracle，BLEU 与 NLU 更好或相当，TriviaQA 接近；相对 GLaM，翻译优势很大，GLaM 的 TriviaQA 略高是因为它在 A 阶段起始专家更多。大模型的扩展路径为每个专家层 16→28→32 个专家。

**阶段掉分**（Table 5，相对各自在 A 结束时的相对跌幅）：Lifelong-MoE 经 A→B→C 后 TriviaQA 跌 39.9%、WMT 跌 15.3%，低于在线 L2 的 48.5% / 72.7% 与记忆回放的 43.7% / 38.8%。Fig.3 中固定 10 个专家的基线在分布切换时旧分布表现陡降，4→7→10 路径明显减缓；部分阶段专家更少反而优于专家更多的固定 GLaM，说明容量怎样用比单纯堆专家更重要。

综述 §3.2 把 Lifelong-MoE 与 ModuleFormer 并列为语言领域持续预训练的 MoE 方法：前者动态加专家并正则预训练，强调少样本与多任务适应。

## 五、对照：MoRAL（PEFT × MoE）

- **做法**（§4）：把对预训练权重的更新写成 8 组低秩矩阵，作为 8 个 LoRA 专家，路由器 $G(x)=\mathrm{softmax}(W_g^\top x)$ 选 top-2，挂在冻结的 FFN 上。与 Lifelong-MoE 的区别是：后者在预训练分布流上扩真正的专家 FFN，MoRAL 在冻结骨干上挂 LoRA 专家，学习问答对而非事实三元组。
- **5L-bench**（§5）：从非结构化文本切块后由 GPT-3.5 出题、GPT-4 给参考答案；用 2023-12 的 arXiv 新论文减少泄漏，另用 HotpotQA-fullwiki 的 1500 行作保持集；分开卷（窗口内给检索块）、闭卷与交叉三种设定。
- **结果**：摘要称 Phi-2-2.7B 上 MoRAL 开卷的回答准确率相对闭卷最多提高约 30.15%（Table 1 中开卷 0.82、闭卷 0.63，比值与摘要一致）；相对只做预训练的基线，开卷回答准确率相对提高 TinyLlama 5.81%、Phi-2 12.32%、Llama-2-7B 9.75%；相对纯 LoRA，学新领域时保持集上的回答准确率掉得更少。综述 Table 3 的 LoRA 列也收录了 MoRAL。

## 六、意义

- **统一坐标**：综述把分散在持续预训练、持续微调、知识编辑、持续对齐、检索与工具等方向的工作放进同一张图，后续工作可以按「内部或外部」「哪类技法」定位自己。
- **容量加正则的可行性**：Lifelong-MoE 说明在稀疏架构上扩容量、冻结旧部分并加输出蒸馏，可以在激活算力不变的前提下明显减轻分布级遗忘。
- **重心外移的信号**：综述归纳的「从内部到外部」趋势，与后来检索、记忆、工具路线的兴起一致。

## 七、局限与待核实

- **综述时间较早**：截至 2024-06，没有覆盖此后的测试时训练、上下文蒸馏的新进展与 on-policy 蒸馏用于恢复行为等做法，相关内容见下节分工表各篇。
- **Lifelong-MoE 的范围**：实验在 GLaM 族与三段人为拉大间隙的分布上进行，下游以 one-shot 为主；TriviaQA 绝对分很低（消融表约 6–7 分），消融差距较小。
- **专家扩展的可解释性**：新专家是否按领域隐式分工、能否审计路由，论文没有回答。
- **内外两路的组合边界**：何时不该再改权重、改用检索或工具，综述未给出判据。
- **MoRAL 的评测**：5L-bench 由 GPT-3.5 与 GPT-4 构造，评测依赖模型生成的问题与参考答案。
