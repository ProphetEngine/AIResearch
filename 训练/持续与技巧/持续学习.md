# Continual learning for LLMs：终身学习综述 + Lifelong-MoE

> **定位**：持续学习 **P1**——相对 **[[规模定律与预训练范式]]**（规模定律 / 预训练）与 **机器遗忘**（unlearning / 遗忘删除），立 **持续预训练 / 任务序列下的抗遗忘与容量扩展**。主地图为综述 arXiv **2406.06391**；架构锚为 ICML 2023 **Lifelong-MoE**（**2305.12281**）；可选对照 **MoRAL**（**2402.11260**，综述 LoRA 族亦点名）。
> **攻坚线**：**架构思想（主）**——Internal / External 二分 + 12 场景 + 四类通用技法；Lifelong-MoE「扩专家 + 冻旧 + 输出蒸馏」；**数学原理（辅）**——正则 / KL 蒸馏 / 稀疏 top-2 专家扩展（不写优化器通史）。
> **硬划界**：
> - **禁止重写 `B4`**：Adafactor / AdamW / 学习率 schedule 仅作 Lifelong-MoE 文内实验配置**点名**，不展开优化器谱系或训练稳定性通史。
> - **禁止重写 `机器遗忘`**：本篇写 **学进去且不忘**；遗忘删除 / forget–retain / MIA 残留评测 → 只在接口表一句划界，不写 unlearning 方法族。
> - **禁止重写 `[[混合专家架构]]`**：GLaM / Switch / 稀疏 MoE 基座只取「专家可扩展」接口；不写 MoE 通史与负载均衡全书。
> - **禁止重写 `B6`**：检索式终身学习仅作 External Knowledge 一格；Self-RAG / CRAG 细节留给 Self-RAG / CRAG。
> - **禁止编造**：主张与表内数字一律锚定官方 PDF（2026-09-22 CST）；图版曲线未抽出的百分点标「待核实读图」。

### 2.2 跟读口诀（两条知识入口）

`
新知识如何进入 LLM？
 │
 ├─ Internal Knowledge ──► 全量或部分更新参数
 │ ├ Continual Pretraining（垂直域 / 语言域 / 时间域）
 │ └ Continual Finetuning（任务特定 × 任务无关）
 │
 └─ External Knowledge ──► 不改（或几乎不改）参数
 ├ Retrieval-Based（Wikipedia / 库 / RAG 族）

`

**关键语义：** 本篇主轴是 **plasticity–stability**（学会新的、保住旧的）；机器遗忘 主轴是 **选择性抹除**。二者都谈「遗忘」，方向相反。

## 三、综述地图（2406.06391）：12 场景 × 四类技法

### 3.1 问题形式化与评测三角度（§2.1–2.2）

形式：从任务序列 $\{\mathcal{D}^{(1)},\ldots,\mathcal{D}^{(T)}\}$ 学 $f_\theta: x\mapsto y$，$x,y$ 均为自然语言（分类时 $y$ 为类名；自回归预训练时 $y$ 为下一 token 序列）。

| 角度 | 指标（文内定义） | 方向 |
|---|---|---|
| **总体** | Average Accuracy $\mathrm{AA}_t=\frac1t\sum_i a_{t,i}$；Average Incremental Accuracy $\mathrm{AIA}=\frac1T\sum_t\mathrm{AA}_t$ | 越高越好 |
| **稳定性** | Forgetting $\mathrm{FGT}_t$（相对历史最好的掉分）；Backward Transfer $\mathrm{BWT}_t$（相对初学时的变化） | FGT↓；BWT↑ |
| **可塑性** | Forward Transfer $\mathrm{FWD}_t$（相对「只训该任务的随机初始化模型」） | 越高越好 |

### 3.2 十二场景（Figure 2 taxonomy）

**Continual Pretraining（§3）**

1. Continual **Vertical Domain** Pretraining
2. Continual **Language Domain** Pretraining
3. Continual **Temporal Domain** Pretraining

**Continual Finetuning · Task-Specific（§4.1–4.4）**

4. Continual Text Classification
5. Continual Named Entity Recognition
6. Continual Relation Extraction
7. Continual Machine Translation

**Continual Finetuning · Task-Agnostic（§4.5–4.7）**

8. Continual Instruction-Tuning
9. Continual Knowledge Editing
10. Continual Alignment（含 RLHF；文强调 **alignment tax**）

**External Knowledge（§5）**

11. Retrieval-Based Lifelong Learning
12. Tool-Based Lifelong Learning

开篇产业例子：持续垂直域预训练（如金融）可抬专科表现，但可能侵蚀通用能力——正是 Internal 路线的核心张力。

### 3.3 四类通用技法（§2.3，Figure 3）

| 类别 | 子型 / 抓手 | 代表点名（文内，非穷尽） |
|---|---|---|
| **Replay** | Experience Replay（重放旧数据或压缩表征）；Generative Replay（模型生成伪旧样本） | 持续预训练中的域重放 [47,78,…]；指令调谐 LAMOL / LFPT5 / PCLL / SSR |
| **Regularization** | Weight（L2 / **EWC** / MAS / RecAdam）；Feature（IDBR / CPFD） | 保住对旧任务重要的权重或激活模式 |
| **Architecture** | 见下节六子类 | 大模型全量微调贵 → 架构 / PEFT 成主战场 |
| **Distillation** | 来自新数据 / 旧数据 / 伪旧数据 | LwF；NER 的 ExtendNER / CFNER；MT 的 COKD 等 |

### 3.4 架构子法六类（§2.3.3，Figure 4）——跟读重点

1. **Prompt Tuning**（仅输入侧可训提示）
2. **Prefix Tuning**（各层前缀）
3. **LoRA**（低秩旁路；文列 C-LoRA、O-LoRA、**MoRAL** 等）
4. **Adapters**（瓶颈 FFN 插入层间）
5. **Mixture of Experts**（门控选专家；文举 DEMix、ModuleFormer；§3.2 另述 **Lifelong-MoE**）
6. **Model Expansion**（加层 / 扩模块；bert2BERT、LLaMA Pro、SOLAR、ELLE 等）

综述在垂直域预训练技法枚举中，把 **experience replay、PEFT、MoE、蒸馏、model expansion、re-warming、data selection** 并列为演进手段——其中 **model expansion** 与 **data selection** 被摘要标为「pre-LLM 时代较少被强调」的新兴向。

### 3.5 External：参数不动如何「终身」（§5，接口级）

- **检索**：动机 = 世界知识过时；机制族点名 DPR、IRCOT、TOC、FLARE、**Self-RAG**（细节不展开，→ Self-RAG / CRAG）。
- **工具**：动机 = 超出纯文本生成；框架点名 Chameleon、ToolAlpaca、Confucius、GPT4Tools；基准 APIBench / ToolBench。

### 3.6 挑战 · 趋势 · 未来（§6）

**挑战：** 灾难性遗忘；plasticity–stability（含 alignment tax）；全量微调算力；权重 / 预训练数据不可得（隐私 / 专有）。

**趋势：** 任务从特定 → 通用（指令调谐 / 知识编辑）；微调从全量 → 部分（Adapter / Prompt / LoRA）；知识从 Internal → External（RAG / 工具）。

**未来向：** 多模态终身学习；高效策略（剪枝 / 合并 / 扩展 / 超长上下文 in-context）；**General** lifelong（与环境交互、RL / agent / embodied，而非只吃静态集）。

## 四、架构锚：Lifelong-MoE（2305.12281）

> 核心主张（摘要 / §1）：对大 LM，**额外容量 + 合适正则** 是数据级终身预训练的关键；在 MoE 上「加专家、算力因稀疏激活保持恒定」，可比经典 LLL 在 **19** 个下游 NLP 任务上取得更好 few-shot。

### 4.1 设定：data-level 而非 task-level（§1–2）

文区分：多数 NLP 终身学习文献做 **下游任务序列**；部署现实更接近 **语料分布流上持续预训练**（新网页 / wiki / 对话不断进入）。后者称 **data-level lifelong pretraining**，且下游可少样本适配，故任务级 LLL「对已部署大模型参数几乎不动」的收益有限。

基座：以 **GLaM** 族稀疏 MoE 为骨架（GShard Transformer：每隔一层 FFN 换成 MoE；每 token **top-2** 专家）。

### 4.2 三板斧（§3，Figure 1–2）

`
分布流 x^{(t)} 到达
 │
 ├─ 1. Progressive Expert Expansion
 │ 只扩专家数与门控维 E^{(t-1)}→E^{(t)}
 │ 深度/宽度不变；仍 top-2 → 激活算力近似恒定
 │ 新专家：从旧专家「Net2Wider」式初始化（随机初始化差）
 │ 部分扩展（非翻倍），避免指数膨胀
 │
 ├─ 2. Freeze old experts + gatings
 │ 只优化 θ_t（新专家/门控维）与共享 θ_d（dense/attention）
 │ 消融：冻专家或冻门控单独不够；二者一起最好
 │
 └─ 3. Output regularization（隐式蒸馏）
 L = L_Perp + λ L_KL
 L_KL：旧专家/门控（θ_{0:t-1},θ_d）输出 vs 扩后模型输出
 λ 过大（文称 >1）会导致预训练不稳定
`

Embedding / dense / attention **跨分布共享**；旧专家显式绑定旧分布故可冻；共享层不能简单整层冻结。

### 4.3 实验构造（§4）

**分布序列 A → B → C**（刻意拉大分布间隙以暴露遗忘）：

| 分布 | 语料 | Tokens (B) |
|---|---|---|
| **A** | Wikipedia 19% + Filtered Webpages 81% | 3 + 143 |
| **B** | i18n（非英语） | 366 |
| **C** | Conversations（公开社交对话） | 174 |

动机：A↔TriviaQA；B↔翻译；C↔对话 / 多数 NLU；顺序使 A 后训 B/C 伤 QA，B 后训 C 伤翻译。

**规模（Table 2）：** 小 MoE 激活约 **145M**（E=4～16）；大 Lifelong-MoE 激活 **1.878B**（E=16～32，总参 11～22B 量级）；dense GShard 对照激活 **1.7B**。最大实验：**128** Cloud TPU-v4；vocab **256K** SentencePiece；batch 打包至约 **1M** tokens；优化器 **Adafactor**（β1=0, β2=0.99 等——**仅配置，不展开 B4**）。

每分布 **500K** steps；监控各分布 next-token acc / perplexity；下游：TriviaQA（F1）、WMT16（BLEU）、Ubuntu、以及 **19** NLU 平均分；主报 one-shot（Brown 等协议）。

### 4.4 关键结果（§5，表内数字）

**抗遗忘曲线（Figure 3）：** A→B→C 切换时，基线（固定 10 专家）在旧分布上 next-token / PPL 陡降；Lifelong-MoE（示例路径 **4→7→10**）明显减缓掉分。文强调：在部分阶段**更少专家**仍可优于更多专家的固定 GLaM——容量用法比裸堆专家更重要。

**消融（Table 3，TriviaQA F1，训完 A→B→C）：**

| # | 扩展 | Freeze | λ | F1 |
|---|---|---|---|---|
| 1 | 4→4→4 | — | 0 | 5.93 |
| 3 | 4→4→4 | — | 1 | 6.96 |
| 7 | 4→8→16 | Experts+Gatings | 0 | 6.98 |
| 9 | **4→7→10** | **Experts+Gatings** | **1** | **7.06** |

要点：只加 KL 有帮助；扩专家时须 **专家+门控一起冻**；部分扩展 **4→7→10** 优于朴素翻倍且略优。

**主对比（Table 4）：**

| 方法 | TriviaQA F1 | WMT BLEU | Ubuntu | Avg. 19 NLU |
|---|---|---|---|---|
| Dense + Online L2 Reg. | 12.99 | 5.66 | 27 | 48.65 |
| Dense + Memory Replay | 14.18 | 7.54 | 26 | 48.65 |
| Dense Oracle（三分布联合） | 21.25 | 11.14 | 26 | 49.03 |
| GLaM | 21.76 | 6.97 | 26 | 50.9 |
| **Lifelong-MoE** | **20.22** | **19.16** | **27** | **50.26** |

解读（文内）：相对 Dense Oracle，BLEU / NLU 更好或可竞争，TriviaQA 接近；相对 GLaM，翻译优势大（GLaM 在 A 上起始专家更多故 TriviaQA 略高）。大模型扩展路径：**16→28→32** 专家（每 expert-layer）。

**阶段掉分（Table 5，括号为相对该法在 A 结束时的相对跌幅）：** Lifelong-MoE 在 A→B→C 后 TriviaQA **−39.9%**、WMT **−15.3%**，低于 Online L2（−48.5% / −72.7%）与 Memory Replay（−43.7% / −38.8%）的对应跌幅；绝对值亦最高保住翻译（BLEU **19.16**）。

Replay 基线设定：新分布训练时保留约 **25%** 历史数据混合（文称对齐 Lin et al. 2022 竞争设定）。

### 4.5 综述如何安放 Lifelong-MoE

2406.06391 §3.2（语言域预训练）将 **ModuleFormer** 与 **Lifelong-MoE [23]** 并列为 MoE 架构法：前者按输入激活模块；后者 **动态加专家 + 正则预训练**，强调 few-shot / 多任务适应。垂直域技法列表亦含 MoE 指针——与本篇「架构锚」一致。

## 五、可选对照：MoRAL（2402.11260）——PEFT × MoE

> 定位：Lifelong-MoE = **预训练分布流 + 扩真正专家 FFN**；MoRAL = **冻结骨干 FFN 上挂多组 LoRA 专家 + router**，吃 **问答对**（非事实三元组），并给 **5L-bench**。

### 5.1 方法要点（§4）

- 将预训练权重的更新写成多组低秩矩阵，当作 **n 个 LoRA 专家**；router $G(x)=\mathrm{softmax}(W_g^\top x)$；输出 $y=\sum_i s_i E_i(x)$。
- 文设 **n=8**，**top-k=2**；MoRAL 加在 **冻结 FFN** 上；Adam lr=1e-4，batch 16，2 epochs；A100 80G。

### 5.2 5L-bench（§5）

- 数据：非结构化文本 → chunk → GPT-3.5 出题、GPT-4 出 Gt；Arxiv **2023-12** 新文减泄漏；另用 HotpotQA-fullwiki **1500** 行作 **hold-out 保持**。
- 设定：open-book（上下文窗内检索块）/ closed-book / cross（QR、FL）。
- Open-book 子指标：Faith / Filter / RR / RA 等（0–1）。

### 5.3 数字抓手（摘要 + Table 1，Arxiv）

- 摘要：Phi-2-2.7B 上，MoRAL 的 open-book **RA** 相对同模型 closed-book **RA** 可有至多约 **30.15%** 提升（跟读：Table 1 中 Phi-2+MoRAL 为 open **0.82** vs closed **0.63**，$(0.82-0.63)/0.63\approx30\%$，与摘要口径一致）。
- 相对「仅预训练」基线，文称 open-book RA 相对提升：TinyLlama **5.81%**、Phi-2 **12.32%**、Llama-2-7B **9.75%**。
- 文主张：相对纯 LoRA 等，MoRAL 在学新域时对 hold-out（HotpotQA）**RA** 掉得更少——抗遗忘叙事与 Lifelong-MoE 同族，但尺度在 PEFT / 指令侧。

综述 Table 3（continual instruction tuning 比较表）LoRA 列将 **MoRAL [234]** 标为 2024、评测 Arxiv+HotpotQA——与可选对照吻合。
