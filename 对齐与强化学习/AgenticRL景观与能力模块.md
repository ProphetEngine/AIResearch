# Agentic RL 景观与能力模块

> **主要来源**：[The Landscape of Agentic Reinforcement Learning for LLMs: A Survey](https://arxiv.org/abs/2509.02547)（Zhang、Geng、Yu 等，简称综述，v5，TMLR 01/2026，[OpenReview](https://openreview.net/forum?id=RY19y2RI1O)）；[xhyumiracle/Awesome-AgenticLLM-RL-Papers README](https://github.com/xhyumiracle/Awesome-AgenticLLM-RL-Papers)（论文与开源环境索引，不作数字来源）（截至 2026-09-22）。
> **研究线**：架构思想（把智能体的各项能力当作可由 RL 优化的策略切片）
> **范围与相邻笔记**：
> - ≠ [[GRPO与DAPO算法族]]：本篇不写组相对优势、解耦裁剪、去偏目标等算法细节，算法在此只是「优化器槽位」。
> - ≠ [[RL算力缩放与环境扩展]]：本篇不写 RL 算力曲线与训练环境的批量构建；能力地图中「环境与训练算力」一格在该篇展开。
> - ≠ [[ToRL工具集成强化学习]]、[[MemoryR1强化学习记忆维护]]：本篇只在「工具」「记忆」两格点名，不写解释器沙箱或记忆操作的训练细节。
> - ≠ [[MiMoV26智能体强化学习短报]]：本篇不写生产规模下 batch、环境与评分器的扩算力配方。
> - 综述另有感知能力与按任务域（搜索、代码、数学、GUI、具身、多智能体）的分类，本篇只取规划、工具、记忆、推理、自改进五个能力模块。
>
> **意义**：综述把「Agentic RL」从零散的工具 RL、搜索 RL、记忆 RL 中抽象出来，用「单步 MDP 对多步 POMDP」一组形式化划清它与偏好式后训练的界线，并主张 RL 是把规划、工具、记忆等能力从固定流水线变成可适应行为的关键机制。综述把 RL 训练算力与训练环境的扩展列为开放方向（§6.2–§6.3）。

**一句话**：Agentic RL 把大模型当作嵌在序贯决策环中的可学习策略，在长程、部分可观测的环境里用 RL 联合优化它的各项能力，而不是只给单轮回答打分。

---

## 一、问题背景

早期的大模型 RL 是**偏好式后训练**：RLHF 用人类反馈训练奖励模型再做策略优化，DPO 直接在偏好数据上优化，目标都是让单轮回答更符合偏好（[[对齐脉络RLHF与偏好优化]]）。综述称之为偏好式强化微调，并把它形式化为一个退化的 MDP：每个回合从一个提示开始，模型输出一条回复即结束，视界 $T=1$，状态转移是确定的，奖励是一个标量（综述 §2.1–§2.5）。

o1 与 DeepSeek-R1 之后，规则可判对错的奖励配合大规模 RL 让推理能力显著提升（[[DeepSeekR1推理训练深读]]）；o3 一类模型又把推理和工具调用结合起来（综述 §2）。研究者开始让模型在 RL 中真正与环境交互：调用搜索与代码解释器、读写记忆、在网页或操作系统中执行动作。另一方面，提示式智能体虽然已有规划、工具、记忆模块，但多是静态启发式，不会从经验中改进。综述认为这两条线缺少统一处理：现有工作各自研究孤立能力、领域或自建环境，术语与评测协议不一致，难以横向比较（综述 §1）。

## 二、形式化：从单步 MDP 到 POMDP（综述 §2）

| 要素 | 偏好式后训练 | Agentic RL |
|---|---|---|
| 状态 | 单个提示，回复后即结束 | 环境状态 $s_t$，模型只看到观测 $o_t=O(s_t)$，视界 $T>1$ |
| 动作 | 纯文本序列 | 文本动作 ∪ 环境动作（调用工具、修改环境），后者可递归组合 |
| 转移 | 确定性，一步到终态 | $s_{t+1}\sim P(s_{t+1}\mid s_t,a_t)$，带不确定性 |
| 奖励 | 单个标量 $r(a)$ | 逐步奖励，稀疏的任务奖励与稠密的子奖励结合 |
| 目标 | $\mathbb E_{a\sim\pi_\theta}[r(a)]$ | $\mathbb E_{\tau\sim\pi_\theta}[\sum_t\gamma^t R(s_t,a_t)]$ |

这张表是全篇的骨架：Agentic RL 的难点几乎都来自右列，即部分可观测、长视界和稀疏奖励带来的信用分配问题，以及动作会改变外部世界带来的环境构建问题。优化器本身沿用 REINFORCE、PPO、GRPO、DPO 及其变体（综述 §2.7），算法细节见 [[GRPO与DAPO算法族]]。

## 四、能力模块地图（综述 §3）

| 模块 | 要点 | 代表方向（综述点名） |
|---|---|---|
| 规划 | 把目标拆成多步动作。RL 有两种用法：**外挂**，不改或少改模型本身，训练价值或启发函数去引导 MCTS 等搜索；**内化**，把模型直接当规划策略，用环境成败轨迹更新。远景是两者结合：既能快速出计划，也学会何时深思、何时剪枝 | 外挂：RAP、LATS、Planning without Search；内化：ETO、VOYAGER、AdaPlan / PilotRL、Planner-R1、RLTR |
| 工具 | 从模仿示例调用，推进到为结果自主决定何时用、用哪个工具。早期 ReAct 与 SFT 轨迹容易锁死调用模式；工具集成 RL 把代码执行、检索等嵌进同一次推理 rollout，用结果或过程奖励学策略。长程瓶颈是哪一次调用该记功或记过 | ToolRL、ReTool、AutoTIR、ToRL、ARTIST、OTC-PO、ASPO；长程信用分配：GiGPO、SpaRL |
| 记忆 | 记忆从外挂只读库变成 RL 可控的子系统：存什么、取什么、何时忘。路径大致是先用 RL 决定何时检索，再管理增、改、删，再到显式或隐式的 token 级读写；结构化图谱记忆仍多靠启发式 | RAG 式：Memory-R1、Mem-α、Memory-as-action；token 级：MemAgent、MEM1、ReSum、Context Folding、MemGen；结构化（前瞻）：Zep、A-MEM、G-Memory、Mem0 |
| 推理 | 借用快慢双过程：快推理是直觉式短链路，慢推理产生显式中间步骤、可多步校验，常与 RL 和推理时扩展绑定。智能体场景的难点是环境多样导致训练不稳，以及慢推理的过度思考 | 慢推理 RL：o1、o3、DeepSeek-R1、DAPO 等；快慢混合与自适应推理时算力 |
| 自改进 | 让智能体从自己的错误中持续改进，分三层：口头反思（同一次推理内生成、批评、改写，不更新权重）；内化反思（用 DPO 或 RL 把纠错写进参数）；迭代自训练（自博弈、按执行反馈出题、集体轨迹库），减少对人工标注的依赖 | 口头：Reflexion、Self-Refine、CRITIC、Chain-of-Verification；内化：KnowSelf、Reflection-DPO、DuPo；自训练：R-Zero、Absolute Zero、TTRL、SiriuS、Self-Evolving Curriculum |

五个模块不是互斥的产品名，而是可以分别或联合优化的策略切片；真实系统通常几格同时在动，例如慢推理加工具加记忆。综述 §3.6–§3.7 另述感知与长程信用分配等，本篇不展开。

## 五、综述提出的开放问题（综述 §6）

下文「机制之争」一条的完整展开（度量口径、收缩与扩展两方证据、熵机制）见 [[RLVR能力边界与熵机制]]。

- **可信**：智能体的攻击面比纯语言模型大（工具、记忆、规划模块都可能被注入）。RL 会放大这一风险：若某个不安全工具或绕过安全规程能带来高奖励，RL 会主动强化这种行为，让智能体从被动受害者变成主动利用漏洞的一方（§6.1）。这与奖励黑客的泛化问题同源（[[奖励黑客与涌现失对齐]]）。
- **训练规模化**：延长 RL 训练能提升工具使用频率、推理深度与任务准确率；模型变大时更易出现熵塌缩；多领域 RL 数据之间既有互补也有干扰，需要配比（§6.2）。
- **环境规模化**：ALFWorld、ScienceWorld 等常用环境不足以训练通用智能体，研究正从「只调策略」转向让环境本身可学习、可演化，例如自动设计奖励函数（§6.3）。这两点在 [[RL算力缩放与环境扩展]] 中有展开。
- **机制之争**：RL 是「放大器」（把概率集中到基座已能采到的正确路径，提升 pass@1 而不扩大解的支撑集）还是能装入新能力，尚无定论。综述统计其引用的数学与代码推理研究，约 2/3 主要报告 pass@1 提升，约 1/3 明确报告 pass@k 前沿扩大；「新能力」类现象多出现在奖励高保真且可执行或可形式化核验、任务多步可分段评分、基座处在中等水平的条件下（§6.4）。

## 六、意义

这份综述的价值在于给一个快速膨胀的方向提供了共同语言。POMDP 框定说明了 Agentic RL 与偏好式后训练的本质差别不在优化器，而在环境：多步交互、部分可观测、动作改变外部状态。能力模块地图则把散落在各任务域的方法按「优化的是哪项能力」重新归类，方便判断一项新工作补的是哪一格。它也把讨论引向几处共同瓶颈：长程信用分配、可信与奖励黑客、训练环境的规模与质量，以及 RL 到底教会了什么。

## 七、局限与待核实

- 本篇只依据一篇综述；各模块中代表方法的归类与命名照综述原样，方法本身的效果数字未逐一核对。
- 脉络表的日期取 arXiv 首版，只列各模块的少数代表节点，不代表完整时间线；完整时序见 [[对齐与强化学习发展时间线]]。
- 综述 §6.4 的「约 2/3 对 1/3」是作者对其所引数学与代码研究的粗略统计，不是独立的元分析。
- 综述发表后（2025-10 起），RL 算力缩放与环境扩展方向进展很快，本篇不跟踪，见 [[RL算力缩放与环境扩展]]。
- 感知、多智能体与各任务域专章未展开，需要时回读综述 §3.6 与 §4。
