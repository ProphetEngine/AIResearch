## 二、问题立轴：为何还要「新范式」

两文对传统栈的诊断互补（意译压缩，非通史）：

1. **输出级监督的局限（两文共有）**
 - Deliberative §1：SFT + RLHF 仍易被绕过、易 overrefuse；模型须**即时**作答、固定算力，且只能从标注样本**间接**推断规范 → 数据效率与 OOD/对抗泛化差。
 - Circuit Breakers §1 / Fig.1：refusal 训练在表征里形成「拒绝态」，但**绕过拒绝态后有害态仍可达**；针对具体攻击的 adversarial training 难泛化到未见攻击，且常付能力代价。

2. **两条正交出路**
 - **A**：把完整（或按类裁剪的）**safety specification** 直接教给推理模型，让其在 CoT 里「先查政策再答」——**scalable、可解释、可吃 test-time compute**。
 - **B**：不盯攻击面，而盯「产生有害输出的内部过程」——把相关表征重路由到与原有害方向正交（或无信息）的空间，**攻击无关**地打断有害生成链。

本篇只立这两条范式；系统级过滤、CAI 全文、safety case 论证树见划界笔记。

## 三、范式 A：Deliberative Alignment（2412.16339）

### 3.1 核心主张（架构）

摘要 / §2：在具备 CoT 的推理模型上——

1. **直接教规范文本**（内容政策 + 应答风格：硬拒 / safe completion / 合规）；
2. **训练模型在回答前显式召回并准确推理规范**；
3. **无需人工写 CoT 或答案**——用 helpfulness-only 的 o 型基座 + context distillation 合成数据；
4. 用于对齐 OpenAI **o 系列**（文：o1-preview、o1、o3-mini）。

与「部署时把全量 spec 塞进 system prompt」对照（§2 开篇 / §4.1）：全量塞入有延迟与漏读风险；deliberative 目标是把「何时相关、如何推理」**嵌进权重**。

### 3.2 两阶段流水线（Fig.3）

`
prompts + safety category
 ↓ 拼 category-specific spec(category)（全量过长；按类给细规 + 其它类摘要）
G_base（仅 helpfulness、无安全相关数据训过）+ 指令「引用并讨论相关政策」
 ↓ 生成 (CoT, output)；CoT 引用政策
G_RM（同样被喂 spec）过滤高质量 completion；再**去掉** prompt 中的 spec
 ↓
SFT：在无 spec 的原始 prompt 上拟合 (CoT, output) → 学会「无上下文也能召回政策」
 ↓
RL：安全相关 prompt 上，G_RM（持有政策）给 outcome 奖励；
 RL 时对 G_RM **隐藏 CoT**（避免直接压 CoT → 降低「欺骗性 CoT」压力）
 ↓
G_spec（政策对齐的推理模型）
`

**规范结构（§2.2，只记范式字段）：**
- 内容类例：erotic、extremism、harassment、illicit、regulated advice、self-harm、violence 等；每类定义 **allowed / disallowed / requires safe completion**。
- 风格指南：硬拒（短道歉 + 不能协助）、self-harm / 受监管建议的 **safe completion** 细则。
- 文称规范部分基于 OpenAI 公开 **Model Spec** [14]。
- **人工标签**：可不写完整 completion；文脚注称可用「宽安全类」标签辅助 context-distillation，但非本质。

**阶段覆盖（§2.4）：** SFT 段用于全部 o 系列；文述「该 RL 安全奖励信号」加在 **o1** 与 **o3-mini** 训练中。

### 3.3 公开评测字段（只录表内数字）

- o 系列在 disallowed / jailbreak 上整体优于 GPT-4o；**o1** 的 StrongREJECT `goodness@0.1` = **0.88**。

#### 3.3.3 Test-time compute（§3.3 / Fig.13）

增大 CoT 算力：StrongREJECT 与 **regulated advice safe-completion style** 明显上升；其它内部 overrefusal / 部分 style 评测相对平坦。文假设：难任务（组合式 jailbreak、复杂 style）更吃推理时间——安全失败可来自「想不够久」。

#### 3.3.4 消融与机制（§4，用减配 o1-mini 变体）

| 实验 | 公开结论（聚合） |
|---|---|
| SFT / RL 去安全数据四组合（Fig.14） | **SFT+RL 全开**最好；单开 SFT 或单开 RL 居中 → SFT 给安全推理 prior，RL refining CoT 用法 |
| 无安全训、推理时塞**全类摘要 spec** | 弱于 deliberative，且 style 尤差；细规每类约 **5–10K** token，全塞会爆上下文 → **训期嵌入 > 部署全塞** |

**Related Work 定位（§5，一句）：** 文自称首个「直接教规范全文 + 推理时对所学规范做 deliberative CoT」的对齐法；相对经典 SFT+RLHF / DPO 等「从示例间接推断规范」——本篇不展开对照图全表。

## 四、范式 B：Circuit Breakers / Representation Rerouting（2406.04313）

### 4.1 核心主张（架构）

摘要 / §3：受 **representation engineering (RepE)** 启发，引入 **circuit-breaking**：

- **不**以「识别某类攻击」或「加固拒绝态」为主；
- **直接**控制「通向有害输出」的内部表征，将其连到熔断器（重路由到无信息 / 拒绝相关方向）；
- 有害生成是多步过程 → 每一步都可打断，且表征相对攻击路径更稳定 → **attack-agnostic**；
- 可叠在已有 refusal 训练之上；文主张推理期无额外外部 guard 模型负担；可与监控并存。

**与 RMU 等关系（§2 末）：** 扩展表示层控制族；主实验方法为 **Representation Rerouting (RR)** + LoRRA（低秩适配）。

### 4.2 RR 方法骨架（§3 / Algorithm 1）——只记目标，不记攻击配方

**数据两集：**

| 集 | 作用 |
|---|---|
| **Circuit Breaker Set $D_s$** | 引出「通向有害行为」的内部表征，用于触发熔断 |
| **Retain Set $D_r$** | 不应触发熔断的样本，用于保持良性表征与能力（文：UltraChat、XSTest；Llama-3 另加 refusal 点） |

对已有强拒绝机制的模型：文称需精心策展——Retain 含 refusal；Breaker 侧用能引出有害过程的文本（含「去掉有害用户请求、保留有害助手回复」一类策展原则，**本篇不写可复用构造细节**）。

**损失（文给多种，主推正交化）：**

- **RR loss $L_s$**：使熔断后表征与原模型有害表征的 **cosine similarity** 经 ReLU 压向 ≤0（正交，不过度优化到负相似）。
- **Retain loss $L_r$**：熔断模型与原模型在 retain 样本上表征的 $\ell_2$ 距离。
- 系数调度示例：$c_s=\alpha(1-\frac{t}{2T}),\ c_r=\alpha\frac{t}{2T}$。
- 备选：推到大范数随机方向（近 RMU）等；文称正交+ReLU 在稳健性与能力间更直觉有效。
- 也可映射到「拒绝方向 / EOS 嵌入」等，文留待未来。

训练对象：冻结原模型 $M$ + 带 LoRA 的 $M_{cb}$；超参用 HarmBench **验证集静态用例**选定（§4.1）。

### 4.3 公开评测字段（聚合；禁止展开攻击步骤）

#### 4.3.1 文本 LLM · Table 1（HarmBench 合规率 / ASR ↓；能力 ↑）

| | Mistral-7B-Instruct-v2 | | | Llama-3-8B-Instruct | | |
|---|---:|---:|---:|---:|---:|---:|
| | Refusal | Adv Trained (R2D2) | **+ RR** | Refusal | **+ RR** | **Cygnet** |
| MT-Bench ↑ | 7.60 | 6.00 | **7.53** | 8.05 | **8.00** | **8.21** |
| Open LLM ↑ | 65.4 | 61.2 | **65.4** | 68.8 | **68.3** | **71.9** |

表内分列攻击族（Direct / Manual / AutoDAN / TAP-T / PAIR / GCG / Multilingual / Prefilling / Input Embed / RepE Attack）——**本篇只保留族名与平均**，不写优化过程或提示构造。

自建 **100** 条有害函数调用请求（类别覆盖网络犯罪、虚假信息、欺诈、骚扰等——**不写请求内容**）。

| 维度 | Deliberative Alignment | Circuit Breakers (RR) |

## 六、局限与文内自述（压缩）

**Deliberative：** 依赖可用 CoT 的推理模型；消融设置下安全训可能抬高 overrefusal（Fig.14）；政策检索准确率对「本应合规」类低于拒答/safe-complete；StrongREJECT 组合攻击偶发干扰自动评分，文用人审复核（Appendix A）。

**Circuit Breakers：** 稳健性依赖 Breaker 集与目标危害分布对齐（Fig.5）；极端白盒（如 input embedding）上 ASR 非零（Llama-3+RR **9.6**，Cygnet **7.9**）；standalone 图像识别对抗鲁棒仍是开放问题——文强调的是**多模态大系统**对「图像劫持出有害文本」的抑制。
