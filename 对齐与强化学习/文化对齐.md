# 文化对齐：CoCoA + Aligned but Flattened（≠ 激活操控）

> **定位**：[[文化对齐]] **P1**——补仓库对齐轴上缺的双锚：
> - **CoCoA**（*Context-Conditional Cultural Alignment*）：实体级文化偏好应**随语境条件切换**——有文化线索时偏好本地实体，无线索时保持近中性；用双语境训练 + 对比/校准/漂移正则 + goal-aware PCGrad，对抗「一律中和」导致的 **cultural homogenization**。
> - **Aligned but Flattened**：文化微调若只追 **alignment 分数**，会系统性牺牲 **diversity**，造成 **cultural flattening**（多数锚定、选项池塌缩）；在 WVS-7 上把对齐与多样性写成同一 Soft Accuracy 度量下的互补轴，并给低秩压缩式机制解读。
> **攻坚线**：**架构思想 / 评测字段（主）**——语境条件目标、CBS/CS、Align–Div 双轴、多数锚定诊断；禁止把本卡写成激活加向量手册或 RLHF 通史。
> **硬划界（开篇钉死）**：
> - **≠ [[激活操控与表征工程]]**：禁止主写 ActAdd / CAA / ITI / CuE 等 **推理期激活加向量**。CoCoA Related Work 把 *steering* 与数据/偏好优化并列一句 → **仅交叉索引**，不展开向量构造与注入层。Flattened 的 FFN 神经元探测是**评测/机制诊断**，不是 steering 方法篇。
> - **≠ [[StatutoryAI法律规范对齐]]**：禁止重写 Statutory / 法律规范宪法式对齐；本卡对象是**文化偏好与多样性**，不是成文法规。
> - **≠ [[对齐脉络RLHF与偏好优化]]**：禁止重写 RLHF / DPO / CAI 三阶段通史；两文用到的 SFT / LoRA /（文内提及的）偏好优化仅作**接口槽**，不抄损失族。
> - **≠ B9**：禁止重写 XLM-R / BLOOM / 旗舰语种配比通史；十语设置与 WVS 多国只作**评测床**，不是跨语种迁移史。
> **禁止编造**：机制、表数字、消融一律锚定官方 PDF（2026-09-22 CST）。图内未抽出的精确曲线点标 **待核实读图**。

## 三、主文 A：CoCoA（2608.29492）——语境条件文化对齐

### 3.1 问题立轴：西方默认 vs 一律中和

Abstract / Fig.1 / §1 的双病：

1. **Cultural Bias**：语境已点明「韩国甜点饮品」，vanilla 仍常把 espresso 等西方实体排在 sikhye 等本地实体之上。
2. **Cultural Homogenization**：把社会偏见式「全语境中和」搬过来，会在**所有**语境上抹平偏好——合法文化联想与不当偏好一起被压掉。

社会偏见缓解（StereoSet / CrowS-Pairs 一系）的目标是**跨语境均等**；文化实体偏好的目标是**有线索则偏本地、无线索则近中性**——二者目标函数错位。CoCoA Related Work 亦点名：多数文化对齐工作停在价值观 / 回复 / 词汇联想，**实体级且依赖语境**的缓解仍少；文中并列提到 culture-specific data、self-pluralising、**steering**、偏好优化、CALM、LRPO 等 → **本卡对 steering 只记「路线名存在」，不升主。**

### 3.2 问题形式化与打分（§3）

- **Grounded 语境 $c_g$**：显式国家/地区/传统线索 → 应偏好 **local** 实体 $e_l$ 而非 **other-culture** $e_o$。
- **Neutral 语境 $c_n$**：无线索（如 “Alone at home, drinking ___”）→ $e_l$ 与 $e_o$ 应近平衡。
- 冻结 vanilla 权重 $W$，只训 attention 投影上的 **LoRA** $\phi$（$r{=}16$，$\alpha_{\mathrm{LoRA}}{=}32$；App. A.1）。
- 实体续写对数似然 $\ell_\theta(e|c)=\sum_t\log P_\theta(e_t|c,e_{<t})$（**序列求和**，非长度均值——文称均长归一不能保证生成概率可比）。
- **先验校正（PMI 风格）**：$s_{\theta,\alpha}(e|c)=\ell_\theta(e|c)-\alpha\cdot\ell_{\mathrm{vanilla}}(e)$；训练 $\alpha_g{=}1.0$、$\alpha_n{=}0.3$；评测两端均 $\alpha{=}1.0$。

**Cultural Bias Score（CBS）**（沿 CAMeL/Camellia）：在语境 $c$ 上，other 实体得分高于 local 的 pair 比例（×100）。分别报 **CBSg**（grounded，越低越好）与 **CBSn**（neutral，越近 **50** 越好）。辅助 **CS = |CBSn − CBSg|**（语境敏感度），须与 CBSn 同读——CBSn 远离 50 时大 CS 无意义。

### 3.3 三损失 + goal-aware PCGrad（Fig.2）

同一实体对在 $c_g,c_n$ 上各打一对分，形成不可「全局抬/压某一实体」偷懒的配对：

| 符号 | 目标 | 形式（文内） |
|---|---|---|
| $\mathcal{L}_g$ | grounded：$e_l$ 压过 $e_o$ | $-\log\sigma\big((s(e_l|c_g)-s(e_o|c_g))/\tau\big)$，$\tau{=}1.0$ |
| $\mathcal{L}_n$ | neutral：分差 → 0 | $\big(\Delta_\theta(c_n)/\kappa\big)^2$，$\Delta=s(e_l)-s(e_o)$ |
| $\mathcal{L}_d$ | 防 grounded 梯度拖垮 neutral | $\big((\Delta_\theta(c_n)-\Delta_{\mathrm{vanilla}}(c_n))/\lambda\big)^2$ |

方向分组：$v_g=\nabla_\phi(w_g\mathcal{L}_g)$，$v_n=\nabla_\phi(w_n\mathcal{L}_n+w_d\mathcal{L}_d)$。冲突时用 **goal-aware PCGrad**（Yu et al., 2020 变体）：投影强度 $\beta_{i\leftarrow j}=d_j/(d_i+d_j)$，其中 $d$ 为相对目标（grounded→0，neutral→50）的 batch CBS 距离 EMA——**离目标更远的目标保留更多原方向**。文强调：PCGrad 是干扰防护；换成同权加权和时 CBSg/CBSn **基本不变**（App. D.2）→ 主增益来自**双语境目标本身**，不是梯度手术魔术。

默认权重 $w_g{=}1.0,w_n{=}2.0,w_d{=}1.0$；15 epoch / 语种，AdamW $1{\times}10^{-5}$，cosine+10% warmup；40 个 model–setting 中 33 个用默认，7 个仅在验证集 CBSn 远离 50 时调 $w_d$（偶调 $w_n$）（Table 4）。

### 3.4 评测床与基线（§4）

### 3.6 Limitations（文内必留）

- 文化线索按 **二元** 有无处理，不含隐式/强度分级线索。
- 基准固定 **本地 vs 西方** 配对，未证多非西方文化同时对齐。
- 评测停在实体填空，**不含**开放生成 / 下游文化推理。
- 部分语种需手调 $w_d$；文称希望未来 culture-adaptive 减手动。

## 四、主文 B：Aligned but Flattened（2609.00565）——对齐分数 vs 多样性塌缩

### 4.1 问题立轴：Align 高了，是否还「像多种文化」？

Abstract / §1：文化微调已成「文化感知 LLM」的默认配方，但只优化 **aggregate alignment** 时，模型可靠追踪**多数回答模式**抬分，同时毁掉组内/跨文化异质。中心问题：**追求文化对齐是否以牺牲文化多样性为代价？** 文称六模型上 fine-tuning **一致**抬 Align、**锐减**行为多样性（Fig.1 trade-off 曲线；精确点 **待核实读图**）。

与「事后审计出厂模型多样性」（Wu / Murthy 等）不同：本文盯 **文化微调过程本身**——trade-off 出现并可被机制分析的阶段。

### 4.2 双轴形式化（§3）

Persona 条件：文化语境 $c$ + 细粒度人口属性 persona $p$（国/地区/性别/年龄/阶层/教育/婚姻等；英文统一提示以隔离多语能力混淆）→ 答问卷 $q$。

$$
A(M)=\mathbb{E}_{q,c,p}\big[S(M(q|p,c),\,H(q|p,c))\big]
$$

$$
D(M)=\mathbb{E}_{q,p_i,p_j}\big[1-S(M(q|p_i,c_i),\,M(q|p_j,c_j))\big]\quad(c_i\neq c_j)
$$

同一相似度 $S$：**Soft Accuracy（SA）**——序数题给部分分 $1-|y_i-y_j|/(|q|-1)$，类别题 exact-match 指示。$A$ 越高越好；$D$ 过高未必「更真」，过低则标 **cultural flattening**。Human reference（Table 1 注）：Align=**100**，Div=**37.9**。

### 4.3 实验设置（§4.1）

| 项 | 文内设定 |
|---|---|
| 数据 | **WVS-7**；14 国：NGA, MAR, TUN, USA, BOL, URY, CHN, TJK, JOR, RUS, SRB, CYP, AUS, NZL；每国 80 答卷人 × 31 题 × 3 复述 |
| 训练 | 每国抽样 20 答卷人构 SFT 语料（显式保回答多样）；**SFT** = 全量；**SFT-E** = 去掉美/澳以测主流文化影响；单 epoch、同超参 |
| 模型 | Llama-3-8B-Instruct、Llama-3.1-8B-Instruct、Qwen2.5-7B-Instruct、Qwen3-4B、gemma-2-9B-it、Mistral-7b-Instruct-v0.3 |

### 4.4 主结果：Align↑、Div 塌（Table 1）

| 模型 | Align W/O → SFT → SFT-E | Div W/O → SFT → SFT-E |
|---|---|---|
| Gemma-2 | 67.22 → 68.93 → 69.42 | 17.52 → 5.68 → **0.52** |
| Llama-3 | 63.32 → 69.79 → 68.04 | 21.58 → 9.95 → 10.58 |
| Llama-3.1 | 62.69 → 70.23 → 68.72 | 24.48 → 3.91 → 5.22 |
| Qwen-2.5 | 61.29 → 69.67 → 69.67 | 31.18 → 5.08 → 3.39 |

文述：Align 增益约 **1.7（Gemma-2）～11.9（Mistral）**；所有微调后 Div **&lt;11.0**，低于全部 W/O 下界（均 **&gt;17.5**），相对人类 37.9 缺口巨大——文称这在统计上意味「即便文化语境差很多，微调后仍有 **&gt;90%** 概率吐相同答」。Gemma-2：Align 仅 +2.2 量级，Div 可掉约 **17** 点至近零（SFT-E **0.52**）。跨架构静态相关不显著（$p{>}0.05$）；trade-off 主要表现在**同模型微调前后位移**（App. F）。

### 4.5 行为机制：多数锚定 + 序数题「保守中间」（§4.3–4.4）

**类别题例**（宗教活动频率，七档）：人类分布宽；微调后大量塌向多数档 Option G（人类约 **39%** 份额）。Qwen-3×SFT-E 甚至把人类仅 **6%** 的 Option A 推成主导——「对齐」≠「贴真分布」。

**Table 2 诊断：**

| 模型 | Majority Choice Rate % W/O / SFT / SFT-E | Choice Pool Size W/O / SFT / SFT-E |
|---|---|---|
| Gemma-2-9B-it | 40.93 / 47.59 / 47.50 | 2.48 / **1.07** / 1.09 |
| Qwen2.5-7B-Instruct | 40.59 / 55.59 / 52.14 | 2.66 / **1.06** / 1.23 |
| Qwen3-4B | 38.53 / 52.29 / 45.78 | 2.39 / 1.42 / 1.45 |
| Mistral-7b-Instruct-v0.3 | 40.16 / 54.80 / 51.51 | 2.64 / 1.19 / 1.31 |
| Llama-3.1-8B-Instruct | 41.57 / 56.50 / 50.92 | 2.31 / 1.65 / 1.71 |
| Llama-3-8B-Instruct | 40.76 / **57.74** / 51.49 | 2.06 / 1.51 / 1.41 |

微调后多数率常**超过**人类 49.98%；选项池逼近 **1**——「用同质化模拟共识」。

**序数题**：不一定贴绝对多数，而常退到「保守中间」覆盖邻域。例：「对他国国籍者信任度」人类多数 “Trust somewhat”(**53.8%**)；微调模型可 **100%** 塌到 “Do not trust very much”，该选项邻域覆盖 53.8% / 26.9% / 15.4%（Fig.3 文述）。

**边缘化风险**：尼日利亚某 persona 上，微调可**破坏**预训练对齐；Qwen 系 Align **51.52→37.59**（相对约 **−27.04%**，App. G）——抬全局 Align 的同时系统性伤少数队列。

### 4.6 机制解读：低秩简约偏置 + FFN 激活重叠（§5）

假设（Huh / Súkeník / Galanti 等低秩简约文献）：文化微调在**表征瓶颈**下把多样文化压进窄激活子空间，而非扩展容量。操作：对每题取 FFN 激活 top-$K{=}100$ 神经元得 $N_q$，再并成 $N_M$；比较 W/O 与 SFT(-E) 的重叠率 $|N_{W/O}\cap N_{SFT}|/|N_{W/O}|$。

文述：多数设定下共享激活集 **&lt;10%** of W/O（Fig.4 右栏摘录：Gemma-2 SFT **1.9%** / SFT-E **1.5%**；Qwen-2.5 **2.0% / 1.3%**；Qwen-3 **9.4% / 10.2%**；Mistral **6.1% / 6.2%**；Llama-3 **5.0% / 12.2%**；Llama-3.1 **11.3% / 21.8%**）。左栏 MDS 投影示 W/O 与 SFT 几何分离。**文内自限**：机制节是「解释透镜」，**非**严格因果证明，亦非把论文主轴改成网络理论。

### 4.7 Limitations（文内）

- 经验分析**限于 SFT**；DPO/PPO/GRPO 等未系统评（文化偏好标注/奖励难造）。
- 静态问卷 ≠ 开放交互中文化演化。
- **未提出**缓解 flattening 的具体训练法（结论呼吁保留多元的对齐目标；类比多模态表征塌缩的蒸馏缓解仅作未来方向）。
