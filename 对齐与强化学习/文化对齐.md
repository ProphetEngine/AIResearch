# 文化对齐：CoCoA + Aligned but Flattened

> **主要来源**：[CoCoA: Context-Conditional Cultural Alignment for Large Language Models](https://arxiv.org/abs/2608.29492)（Lee 等，SKKU / Georgia Tech / USC，简称 CoCoA，v1，EMNLP 2026 Findings）；[Aligned but Flattened: Analyzing the Trade-off between Cultural Alignment and Diversity in LLMs](https://arxiv.org/abs/2609.00565)（Zhang 等，天津大学 / SUTD，简称 Flattened，v1，EMNLP 2026 Findings）（截至 2026-09-18）。
> **研究线**：架构思想 / 评测字段——语境条件化的训练目标、文化偏差分数（CBS）、对齐—多样性双轴与多数锚定诊断。
> **范围与相邻笔记**：
> - ≠ [[激活操控与表征工程]]：不写推理期激活加向量方法；Flattened 的神经元重叠只是机制诊断。
> - ≠ [[StatutoryAI法律规范对齐]]：本篇对象是文化偏好与多样性，不是成文法规。
> - ≠ [[对齐脉络RLHF与偏好优化]]：不写 RLHF、DPO、CAI 通史；两文的 SFT 与 LoRA 只作训练接口。
> - ≠ [[多语言与跨语种]]：十语设置与 WVS 多国只作评测床，不写语种配比与跨语种迁移。
>
> **意义**：通用偏好对齐默认存在一套「好回答」，文化对齐要回答两个被它掩盖的问题：什么时候应该带有文化偏好，以及把模型对齐到人群时会不会把人群的分歧抹平。CoCoA 给出「有文化线索才偏本地、无线索保持中性」的可训练目标；Flattened 发现文化微调在抬高对齐分数的同时普遍明显降低多样性。两者合起来说明，文化对齐的评测至少要同时看「该偏时是否偏」和「分歧是否保留」，单一对齐分数会掩盖同质化。

**一句话**：CoCoA 修的是「何时允许文化偏好」；Flattened 警告的是「追对齐分数可能把多种文化压成一张脸」。

## 一、问题背景

两文针对两类不同的「压扁」，不可混称：

- **文化同质化（cultural homogenization，CoCoA §1）**：模型本有西方默认偏差。语境已点明「韩国甜点饮品」，原模型仍常把 espresso 排在 sikhye 之前。若照搬社会偏见缓解的做法（如 StereoSet、CrowS-Pairs 一系追求跨语境均等）把所有语境的偏好一律中和，合法的文化联想也会被一并抹掉。论文指出，多数文化对齐工作停在价值观、回复或词汇联想层面，实体级且依赖语境的缓解仍少。
- **文化扁平化（cultural flattening，Flattened §1）**：文化微调已是「文化感知模型」的常见做法，但只优化总体对齐分数时，模型会追踪多数回答模式来抬分，同时破坏组内与跨文化的异质性。论文的中心问题是：追求文化对齐是否以牺牲文化多样性为代价？与事后审计出厂模型多样性的工作不同，Flattened 关注微调过程本身。

## 三、CoCoA：语境条件文化对齐

### 3.1 形式化与打分（§3）

- **有线索语境 $c_g$**：含国家、地区或传统线索，应偏好本地实体 $e_l$ 而非他文化实体 $e_o$。
- **中性语境 $c_n$**：无线索（如 “Alone at home, drinking ___”），$e_l$ 与 $e_o$ 应接近平衡。
- 冻结原模型，只在注意力投影上训练 LoRA（$r=16$、$\alpha=32$，附录 A.1）。
- 实体打分用续写对数似然的序列求和（论文称长度均值不能保证生成概率可比），再做 PMI 式先验校正：$s_{\theta,\alpha}(e|c)=\ell_\theta(e|c)-\alpha\cdot\ell_{\mathrm{vanilla}}(e)$；训练时 $\alpha_g=1.0$、$\alpha_n=0.3$，评测两端均取 1.0。

**文化偏差分数 CBS**（沿用 CAMeL / Camellia）：在给定语境上，他文化实体得分高于本地实体的配对比例（×100）。分别报告 **CBSg**（有线索，越低越好）与 **CBSn**（中性，越接近 50 越好）；辅助指标 **CS = |CBSn − CBSg|** 衡量语境敏感度，需与 CBSn 同读，CBSn 远离 50 时 CS 大并无意义。

### 3.2 三项损失与目标感知 PCGrad（§3、Figure 2）

同一实体对在 $c_g$、$c_n$ 上各打一对分，模型无法靠整体抬高或压低某个实体取巧：

| 损失 | 目标 | 形式 |
|---|---|---|
| $\mathcal{L}_g$ | 有线索时本地实体胜出 | $-\log\sigma\big((s(e_l\mid c_g)-s(e_o\mid c_g))/\tau\big)$，$\tau=1.0$ |
| $\mathcal{L}_n$ | 中性时分差趋于 0 | $(\Delta_\theta(c_n)/\kappa)^2$，$\Delta=s(e_l)-s(e_o)$ |
| $\mathcal{L}_d$ | 防止有线索目标拖动中性语境 | $\big((\Delta_\theta(c_n)-\Delta_{\mathrm{vanilla}}(c_n))/\lambda\big)^2$ |

两组梯度冲突时用目标感知的 PCGrad（Yu 等 2020 的变体）：离目标越远的一方保留越多原方向。论文强调这只是干扰防护，换成等权相加时 CBSg、CBSn 基本不变（附录 D.2），主要增益来自双语境目标本身。默认权重 $w_g=1.0$、$w_n=2.0$、$w_d=1.0$；40 个模型—语种设定中 33 个用默认值，其余 7 个只在验证集 CBSn 偏离 50 时调整 $w_d$（偶尔调 $w_n$）。

### 3.3 评测设置（§4）

- 基准：CAMeL（阿拉伯语）+ Camellia（九种亚洲语言），合计七个文化组、十种语言设定（KO、JA、ZH、VI、UR、HI、ML、MR、GU、AR），grounded 与 neutral 由母语者标注。
- 骨干：Llama-3.1-8B、Qwen3-8B（指令版）、Mistral-7B-v0.3、Gemma-3-12B-pt。
- 协议：5 折交叉验证，语境与实体先切分再配对，评测实体不在训练中出现；每个语境最多 30×30 对；报告均值 ± 标准误。
- 基线：把社会偏见方法 BiasEdit、BiasUnlearn 改编到中性语境上做平衡训练。

### 3.4 主要结果

四骨干十语平均（摘要）：CBSg 从 43 降到 24，CBSn 保持在 50.2。各骨干在 Table 1 五种代表语种设定（韩、日、越、印地、阿拉伯）上的平均（§4.3；另五种见 Table 15）：

| 骨干 | CBSg：原模型 → CoCoA | CBSn：原模型 → CoCoA |
|---|---|---|
| Llama-3.1-8B | 33.1 → 9.0 | 38.9 → 48.2 |
| Qwen3-8B | 39.1 → 17.7 | 42.4 → 50.6 |
| Gemma-3-12B-pt | 45.3 → 31.7 | 44.7 → 45.6 |
| Mistral-7B-v0.3 | 42.6 → 10.1 | 46.0 → 53.2 |

- **基线对照**（Table 1）：BiasUnlearn 多半不降 CBSg；BiasEdit 常把 CBSn 一起拉低，例如 Llama-3.1-8B 韩语上 CBSg 47.0 → 20.8，CBSn 也从 49.4 掉到 21.8，正是「一律中和」式的同质化。
- **消融**（Table 2，Llama-3.1-8B）：去掉 $\mathcal{L}_g$ 后 CBSg 升到 54.6；去掉 $\mathcal{L}_n$ 后 CBSg 仍低（13.4），但 CBSn 掉到 37.0；去掉 $\mathcal{L}_d$ 后 CBSn 漂到 58.8，CBSg 为 15.2。三项损失分工清楚。
- **行为**（Figure 3）：有线索语境上 79% 的配对分差向本地方向移动；中性语境上 54% 的配对绝对分差缩小。
- **通用能力**（Table 3，Llama-3.1-8B）：MMLU 65.34 → 65.22、HellaSwag 82.24 → 82.04、ARC-C 58.19 → 57.81、WinoGrande 78.37 → 78.06、TruthfulQA 44.16 → 44.14，最大降幅 0.38 个百分点（ARC-C）。

## 四、Aligned but Flattened：对齐分数与多样性

### 4.1 双轴形式化（§3）

在文化语境 $c$ 与细粒度人口属性人设 $p$（国家、性别、年龄、阶层、教育等；统一用英文提示以排除多语能力差异）下回答问卷题 $q$：

- 对齐：$A(M)=\mathbb{E}_{q,c,p}\big[S(M(q|p,c),\,H(q|p,c))\big]$
- 多样性：$D(M)=\mathbb{E}_{q,p_i,p_j}\big[1-S(M(q|p_i,c_i),\,M(q|p_j,c_j))\big]$，$c_i\neq c_j$

两者用同一相似度 $S$，即软准确率（序数题按距离给部分分 $1-|y_i-y_j|/(|q|-1)$，类别题按完全匹配）。人类参照为 Align 100、Div 37.9。

### 4.2 设置（§4.1）

WVS-7 的 14 国（NGA、MAR、TUN、USA、BOL、URY、CHN、TJK、JOR、RUS、SRB、CYP、AUS、NZL），每国 80 名答卷人 × 31 题 × 3 种改写。每国抽 20 名答卷人构建 SFT 语料：SFT 用全部国家，SFT-E 去掉美国与澳大利亚，以检验主流文化的影响；均训练 1 个 epoch。六个模型：Llama-3-8B-Instruct、Llama-3.1-8B-Instruct、Qwen2.5-7B-Instruct、Qwen3-4B、gemma-2-9B-it、Mistral-7B-Instruct-v0.3。

### 4.3 主要结果：对齐升、多样性塌（Table 1）

| 模型 | Align：原模型 → SFT → SFT-E | Div：原模型 → SFT → SFT-E |
|---|---|---|
| Gemma-2 | 67.22 → 68.93 → 69.42 | 17.52 → 5.68 → 0.52 |
| Llama-3 | 63.32 → 69.79 → 68.04 | 21.58 → 9.95 → 10.58 |
| Llama-3.1 | 62.69 → 70.23 → 68.72 | 24.48 → 3.91 → 5.22 |
| Qwen-2.5 | 61.29 → 69.67 → 69.67 | 31.18 → 5.08 → 3.39 |
| Qwen-3 | 63.48 → 66.67 → 65.39 | 21.26 → 9.98 → 7.15 |
| Mistral | 58.11 → 69.99 → 69.89 | 26.92 → 5.70 → 4.96 |

论文称（§4.2）：对齐增益从 1.7（Gemma-2）到 11.9（Mistral）；微调后 Div 全部低于 11.0，而原模型均高于 17.5，与人类 37.9 差距很大，统计上意味着即使文化语境差别很大，微调后的模型仍有超过 90% 的概率给出相同答案。跨架构的静态相关不显著（$p>0.05$），权衡主要体现在同一模型微调前后的位移。

### 4.4 行为机制：多数锚定与「保守中间」（§4.3–§4.4）

- **类别题**：以宗教活动频率题为例，人类多数选项占 39%，微调后回答大量塌向该选项；Qwen-3 的 SFT-E 甚至把人类只占 6% 的选项推成主导。
- **多数选择率与选项池**（Table 2）：

| 模型 | 多数选择率 %（原模型 / SFT / SFT-E） | 选项池大小（原模型 / SFT / SFT-E） |
|---|---|---|
| Gemma-2-9B-it | 40.93 / 47.59 / 47.50 | 2.48 / 1.07 / 1.09 |
| Qwen2.5-7B-Instruct | 40.59 / 55.59 / 52.14 | 2.66 / 1.06 / 1.23 |
| Qwen3-4B | 38.53 / 52.29 / 45.78 | 2.39 / 1.42 / 1.45 |
| Mistral-7B-Instruct-v0.3 | 40.16 / 54.80 / 51.51 | 2.64 / 1.19 / 1.31 |
| Llama-3.1-8B-Instruct | 41.57 / 56.50 / 50.92 | 2.31 / 1.65 / 1.71 |
| Llama-3-8B-Instruct | 40.76 / 57.74 / 51.49 | 2.06 / 1.51 / 1.41 |
| 人类参照 | 49.98 | 3.61 |

  微调后多数选择率多次超过人类的 49.98%，选项池接近 1，论文称这是「用同质化模拟共识」。
- **序数题**：模型不一定贴绝对多数，而是退到保守的中间选项。「对他国国籍者的信任度」题中，人类多数选 “Trust somewhat”（53.8%），几乎所有微调模型都 100% 选 “Do not trust very much”，该选项的邻域覆盖 53.8%、26.9%、15.4% 的人类回答（Figure 3）。
- **边缘化风险**：在尼日利亚的某一人设上，微调反而破坏了原有对齐，Qwen2.5-7B-Instruct 的 Align 从 51.52 降到 37.59（相对 −27.04%，附录 G）。

### 4.5 机制解读：FFN 激活重叠（§5）

作者引用低秩简约偏置文献，假设文化微调在表征瓶颈下把多样文化压进狭窄的激活子空间。做法：对每题取 FFN 激活最强的 $K=100$ 个神经元并取并集，比较原模型与微调后的重叠率。论文称多数设定下共享激活不足原模型集合的 10%（Figure 4）：Gemma-2 SFT 1.9% / SFT-E 1.5%，Qwen-2.5 2.0% / 1.3%，Qwen-3 9.4% / 10.2%，Mistral 6.1% / 6.2%，Llama-3 5.0% / 12.2%，Llama-3.1 11.3% / 21.8%。论文自述这一节是解释视角，不是严格的因果证明。

## 五、两项工作对照

| 维度 | CoCoA | Flattened |
|---|---|---|
| 问题 | 实体偏好：有线索该偏本地，无线索该中性 | 价值观模拟：追对齐分数导致多样性塌缩 |
| 方法 | LoRA + 三项损失 + 目标感知 PCGrad | 对齐—多样性评测框架 + 微调轨迹审计 + 神经元重叠 |
| 数据 | CAMeL / Camellia 实体填空（十语） | WVS-7 人设问卷（十四国） |
| 主指标 | CBSg 下降、CBSn 接近 50、CS | Align 与 Div；多数选择率、选项池、神经元重叠 |
| 对「对齐」的态度 | 要条件化的对齐 | 警告单一对齐分数掩盖同质化 |

两文任务空间不同，「CBSg 24」与「Align 70」不能直接比较优劣。

## 六、意义

CoCoA 把「文化偏好是否恰当」从全局开关变成语境条件，并显示可以用少量 LoRA 参数做到，通用能力几乎不受影响；它也说明直接搬用社会偏见缓解的「一律中和」会伤害合法的文化联想。Flattened 把多样性提升为与对齐并列的评测轴，用六个模型的一致结果说明，常见的文化 SFT 在抬分的同时把跨文化回答压成多数模板，并且会伤及少数人群。对部署而言，两文给出的共同要求是：文化适配需要同时报告条件化偏好与多样性两类指标。

## 七、局限与待核实

- **CoCoA 自述**（Limitations）：文化线索按有或无二元处理，不含隐式或强弱分级的线索；基准固定为「本地对西方」配对，未验证多种非西方文化同时对齐；评测停在实体填空，不含开放生成与下游文化推理；部分语种需手动调 $w_d$。
- **Flattened 自述**（Limitations）：分析限于 SFT，DPO、PPO、GRPO 等未系统评测；静态问卷不等于开放交互；论文没有提出缓解扁平化的训练方法，只把保留多元性的对齐目标列为未来方向。
- Flattened Figure 1、Figure 3 的散点精确坐标未读出，本篇只保留文内叙述和表格数字。
- 已删去的明细（需要时回读原文）：CoCoA 的学习率与 warmup 等训练超参、逐语种 Table 1 与 Table 15、实体类型热图；Flattened 的提示模板与训练语料统计。
