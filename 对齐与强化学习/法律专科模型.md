# Legal specialty models：SaulLM + Legal-R1 + Unilaw-R1

> **定位**：[[法律专科模型]] **P1** 专科短线——相对 **[[MedGemma医学专科]] MedGemma**（医学高监管多模态），本卡写 **法律高监管文本/推理专科**：从 **法律语料继续预训练（SaulLM）** 到 **测试时缩放评测 + 拒绝采样蒸馏（Legal-R1）** 再到 **SFT + GRPO + 迭代推理（Unilaw-R1）**。
> **攻坚线**：**架构思想（主）**——域适应管线差异；**评测字段（辅）**——LegalBench-Instruct / LawBench / LexEval / Unilaw-R1-Eval 与错误类型。
> **硬划界**：
> - **相对 [[MedGemma医学专科]]**：一句对照即可——同属高监管专科，但本卡是 **文本法律推理**，不写医学影像 / MedSigLIP / clinical-grade 边界。
> - **禁止**写「替代律师 / 自动出具法律意见 / 诉讼策略操作指南」；笔记只记录论文主张、评测与风险字段。
> - **禁止重写** `[[推理时扩展TestTimeScaling]]` TTS 通史、[[DeepSeekR1推理训练深读]] 四阶段管线全文、`[[GRPO与DAPO算法族]]` GRPO 算法族；本篇只取「蒸馏 / GRPO 奖励槽位」。
> - **禁止编造**：司法辖区、数据量、分数一律锚定官方 PDF（2026-09-22 CST）；图内未抽出可读点标 **待核实读图**。

### 2.2 幻觉与可靠性风险（Hallucination / Reliability）

| 风险类型 | SaulLM（文内） | Legal-R1（错误分析 §5.3） | Unilaw-R1（文内） |
|---|---|---|---|
| **过时 / 废止法条** | 未专章错误类型学；域继续预训练依赖收集截止时的公开文本 | **明确**：数据未及时更新 → 引用 **outdated or repealed** 条款；AR 有 **outdated references** | 动机段引用法律幻觉文献；**未**做与 Legal-R1 同粒度分型；Limitations 承认 **逐步 CoT 未充分评** |
| **法条 / 引用捏造** | 未量化 | AR：**content fabrication**（Legal-R1 错误中约 **70%** 为捏造类；R1 则以条文错配为主约 73%）；CPC：**citation factual inaccuracies** | 管线：Answer Check + DeepSeek-V3 选链，意图降低错误迹入 SFT；**不保证**部署无捏造 |
| **事实幻觉累积** | 未量化 | LJP 量刑：**early misjudgment propagates**；NYSJE：R1 会 **编造题干未给的情境** | 三奖励含 **legal validity**（附录规则）；仍是自动奖励，非律师复核 |
| **法域混淆** | 多辖区英语言混训 → 潜在风险（文内未做跨法域混淆消融） | R1 在 AR 上 **条文错配** 被归因于中英/两大法系混训；Legal-R1 更易 **捏造** | 单辖区中国法，混淆风险相对低；**跨辖区迁移未主张** |

## 四、SaulLM-7B：英文法律继续预训练 + 指令微调

### 4.1 管线（Figure 1 / §2）

`
Mistral-7B
 → Legal continued pretraining（法律语料 + ~2% replay 通用数据 + 部分指令数据）
 → SaulLM-7B（base）
 → Legal-enhanced instruction finetuning（通用 IFT + 合成法律对话）
 → SaulLM-7B-Instruct
`

- **骨干**：Mistral 7B。
- **法律预训练**：多来源英文法律文本，过滤+去重后 **约 30B tokens**。
- **Replay**：Wikipedia / StackExchange / GitHub（SlimPajama 采样）约 **2%**，减轻灾难性遗忘。
- **对齐**：早期实验 **DPO 无显著收益** → 本版未做（§2 Remark）。
- **许可**：模型与评测代码 **MIT**；权重入口 HF `Equall`。

### 4.2 LegalBench-Instruct 与 Legal-MMLU（§4–6）

- 原版 LegalBench 提示过复杂、开源 7B **格式遵循差** → 整理为 **LegalBench-Instruct**（短指令，要求只输出 Yes/No 等）。
- **主结果（文内，balanced accuracy）**：
 - SaulLM-7B-Instruct 在 LegalBench-Instruct **平均约 0.61**，相对最佳开源 Mistral-Instruct 约 **+6 绝对点**（Figure 5；相对提升约 **11%**）。
 - 仅通用 IFT 的 Saul 基座亦约 **0.59**，相对 Mistral-Instruct 约 **+4**（Figure 4）。
 - Legal-MMLU 三子集相对 Mistral-Instruct-v0.1 平均约 **+5 绝对点**（Figure 6）。
- **能力切片**：Issue / Rule / Interpretation / Understanding 强于非法律 Instruct；偏 **纯演绎 Conclusion** 弱于 Mistral-Instruct（Figure 7）——作者推测需补数学等演绎数据。

### 4.3 跟读抓手

**先用大量英语言法律 token「洗」基座，再用合成法律多轮对话教它听指令**；评测要改提示格式，否则 7B 会因格式挂掉——**不是**「上线即律师助手」。

## 五、Legal-R1：TTS 法律评测 + 拒绝采样蒸馏

### 5.1 评测设计（§3 / Figure 1）

- **12 个模型**：通用（GPT-4o、Llama-3.1-405B、Qwen2.5-72B-Instruct、DeepSeek-V3、Claude-Sonnet-4、Gemini 2.5 Pro 等）+ TTS（DeepSeek-R1、o1-preview/mini、GLM-zero-preview、QwQ-32B-Preview、R1-Distill-Qwen-14B）+ **Legal-R1-14B**。
- **17 任务**：**10 中文（civil law）+ 7 英文（common law）**。
- **总判断（Abstract）**：DeepSeek-R1 在中文法律推理上优势明显；o1 在英文任务上可与之相当；**即使最强模型**仍在司法伦理、复杂计税等任务上吃力。

### 5.2 Legal-R1 训练（§4）

1. **拒绝采样**：DeepSeek-R1 对每题最多 **3** 次生成；答对才保留推理迹 → **96,533** 条、覆盖 **8** 类任务的四元组 $(i,x,c,y)$。
2. **Progressive SFT**：
 - 阶段 1：在 **法律判决预测（LJP：罪名 / 法条 / 刑期）** 上微调 → $M_{core}$。
 - 阶段 2：并入其余中英法律推理数据 → **Legal-R1**。
3. **骨干**：DeepSeek-R1-Distill-Qwen-**14B**。

### 5.3 主表数字（closed-book，照录）

**中文 Table 2（节选，Legal-R1 vs 蒸馏基座）：**

| 模型 | LC↑ | LMHR↑ | CAIL2018↑ | MultiLJP↑ | MUD↑ | IAPE↑ | AR↑ | JE↑ |
|---|---|---|---|---|---|---|---|---|
| R1-Distill-Qwen-14B | 91.03% | 39.00% | 72.03% | 56.50% | 87.19% | 57.00% | 20.49% | 48.67% |
| **Legal-R1** | **91.38%** | **48.98%** | **77.60%** | **61.70%** | **90.02%** | **58.50%** | **20.95%** | **51.05%** |

文内强调相对基座在 LMHR（**+9.98%**）、CAIL2018（**+5.57%**）、MultiLJP（**+5.2%**）等增益；部分任务仍落后完整 DeepSeek-R1。

**英文 Table 5（节选）：** Legal-R1 相对同尺寸蒸馏基座多数小幅上升（如 LRC 90.91%→**92.73%**，NYSJE 56.51%→**58.00%**），整体仍低于 o1-preview / 完整 R1 顶尖格。

**消融 Table 6：** Progressive SFT 中文任务平均 **61.64%**，相对 Single-Stage **60.19%**（**+1.45%**）、相对 Base **58.75%**（**+2.89%**）。

### 5.4 错误分析 → 幻觉风险字段（本卡核心）

| 任务 | 主要失效模式（文内） |
|---|---|
| **IAPE** | 不一致反驳 / 间接或弱反驳；复杂背景干扰 |
| **CFE** | 争议焦点偏离（R1 完全偏离约 **67%**；Legal-R1 约 **60%**）——缺法律知识时「会推但推偏」 |
| **LJP 量刑** | ① 早期幻觉累积；② **过时/废止法条**；③ 过度类案类比忽略关键差异 |
| **AR** | 条文错配 / **内容捏造** / 遗漏 / **过时引用**；Legal-R1 捏造占比更高（约 **70%**） |
| **NYSJE** | R1：**虚构题干外情境**；Legal-R1：域数据覆盖不足 |
| **CPC** | **引用内容事实幻觉**；对判例理解偏移 |

跟读：**加长思考 ≠ 法律正确**；蒸馏可以把分数拉上来，也可能把「编法条」的习惯一起学进来。

## 六、Unilaw-R1：中国法 SFT + GRPO + 迭代推理

### 6.1 数据（§3.2）

- 源：**JEC-QA**（26,365 多选）+ 国考 PDF 抽取（2015–2021，约 1,700；人工校对）；其中 **800** → **Unilaw-R1-Eval**。
- 蒸馏教师：**DeepSeek-R1**；过滤：**Answer Check（精确匹配）** → 部分 **Chain Rewriting / Explanation Generation** → **DeepSeek-V3** 做 Reasoning Selection。
- **Unilaw-R1-Data**（Table 1）：单选 **9534** + 多选 **7001**；思维链平均约 **723** tokens。
- RL 另采 **8,000** QA（半数来自未入选池、半数来自 Data）。

### 6.2 训练（§3.3）

- 骨干：**Qwen2.5-7B-Instruct** + **LoRA**。
- **Stage 1 SFT**：`<think>…</think>` + `<answer>…</answer>`。
- **Stage 2 GRPO**：三奖励——**accuracy**（规则匹配）+ **format** + **legal validity**（附录法律规则约束）。
- **推理时**：Assessor–Reviser **多轮迭代**；按 ORM 保留 top-$k$，末轮 **self-consistency**。

### 6.3 主结果 Table 2（照录）

| 模型 | Params | LawBench | LexEval | Unilaw-R1-Eval | Avg.(%) |
|---|---|---|---|---|---|
| DeepSeek-R1 | 671B | 61.8 | 67.2 | 55.2 | 61.4 |
| R1-Distill-Qwen-32B | 32B | 57.0 | 65.2 | 42.6 | **54.9** |
| Qwen-2.5-7B-Instruct | 7B | 52.3 | 57.8 | 29.9 | **46.6** |
| Unilaw-R1-SFT | 7B | 52.2 | 58.6 | 33.3 | 48.0 |
| Unilaw-R1-RL | 7B | 54.2 | 60.6 | 35.6 | 50.4 |
| **Unilaw-R1** | **7B** | **56.6** | **63.5** | **39.5** | **53.2** |

Abstract / §4.3：相对同尺寸 Qwen-2.5-7B-Instruct（46.6%）平均约 **+6.6**；与更大 **R1-Distill-32B（54.9%）**「on par」量级（**53.2%**）。迭代推理相对零样本 / 多数票有增益（Table 3）。

### 6.4 Limitations（文内三点）

1. 训练数据仍偏 **客观多选题**，覆盖不足。
2. **纯文本**，难处理含图表的法律文档。
3. 评测偏终答匹配，**缺乏逐步法律推理（如三段论）质量评估**。

## 七、三模型对照（架构思想）

| 维度 | SaulLM-7B | Legal-R1-14B | Unilaw-R1-7B |
|---|---|---|---|
| **时间锚** | 2024-03 | 2025-03 投稿轴 / v2 2025-11 | EMNLP 2025 |
| **核心手段** | 域 **继续预训练** + 法律 IFT | **TTS 评测** + R1 **拒绝采样蒸馏** + Progressive SFT | 数据蒸馏过滤 + **SFT+GRPO** + **迭代多智能体推理** |
| **基座** | Mistral-7B | R1-Distill-Qwen-14B | Qwen2.5-7B-Instruct |
| **司法辖区** | 英语言多辖区语料 | 中 + 美任务显式分列 | 中国法（司考 / JEC-QA） |
| **主榜** | LegalBench-Instruct / Legal-MMLU | 自建 17 任务 + LegalBench 子集 | LawBench / LexEval / Unilaw-R1-Eval |
| **幻觉叙事** | 弱（未做错误类型学） | **强**（过时法条、捏造、事实累积） | 中（奖励与过滤意图减幻觉；Limitations 承认 CoT 未充分评） |
| **开源** | MIT；HF Equall | GitHub YinghaoHu/Legal-R1-14B | GitHub Hanscal/Unilaw-R1 |

跟读三条线：

`
SaulLM：把「法律分布」写进权重（预训练期）
Legal-R1：把「长思考法律迹」蒸馏进 14B，并量测错法条/幻觉
Unilaw-R1：在中国法选择题上用奖励+迭代推理抠正确率与可解释格式
`
