## 二、可扩展监督范式（问题立轴）

### 2.1 问题陈述（两文共用动机）

| 来源 | 原文问题压缩 |
|---|---|
| **CAI §1** | 能力上升后，不能指望人类监督 AI 行为的**所有方面**；希望**征用 AI 帮助监督其他 AI**，从而 *scale supervision*。 |
| **W2S Abstract / §1** | 今日对齐（如 RLHF）依赖人类能评价「是否忠实/安全」；**未来超人类模型**会以人类无法可靠评价的复杂方式行动 → *superalignment* 核心技术挑战：**弱监督者如何控制远强于己的模型**。 |

W2S 对先前路线的诊断（§1，意译）：一类工作正面撞上该挑战但偏理论/玩具（debate、IDA、reward modeling 研究方向等）；另一类实证做「人类监督今日模型」但对超人类设定的核心难点覆盖不足。W2S 目标是：**既抓住对齐未来超人类模型的核心难点，又能在今天做迭代实证**。

### 2.2 范式地图（本篇只立轴，不展开每条协议）

据 W2S §2 *Scalable oversight* 段落与相关引用，常见「让人类/弱方更好监督」的结构包括：

| 族 | 代表结构（文中点名） | 本篇处理 |
|---|---|---|
| **Critique / Debate** | 模型互评/批判输出（Irving et al. 2018；Saunders et al. 2022） | 只作谱系锚点 |
| **分解 / 放大** | 子问题分解与放大式监督（Leike et al. 2018；Christiano et al. 2018；Lightman et al. 2023） | 同上 |
| **Sandwiching** | 用弱/强人类夹层测可扩展监督进展（Cotra 2021；Bowman 2022） | 与 W2S「弱→强」类比同族 |
| **AI 反馈 / 原则化** | Constitutional AI / RLAIF（Bai et al. 2022b） | **§三**（监督位置，不重写 [[对齐脉络RLHF与偏好优化]]） |
| **泛化超出可靠监督** | Weak-to-strong learning（本文主轴） | **§四** |
| **引出潜知识 / 诚实** | ELK、honesty（Christiano et al. 2022；Evans et al. 2021 等） | 与 W2S 方法论相邻，不深读 |

W2S 原文划界很清楚：**scalable oversight** 侧重「改进人类监督能力 / 利用可分解性、评价易於生成」等结构；**weak-to-strong** 侧重「即使我们无法可靠监督，模型仍在任务上泛化到强能力」。二者互补，同一实验台可比较。

### 2.3 与「今日工厂流水线」的接口

- **RLHF / 偏好优化工厂**：示范 → 比较 → RM → RL（或 DPO 折叠）——细节见 **[[对齐脉络RLHF与偏好优化]]**。
- **本篇补洞**：当比较标签本身来自**不可靠/能力不足的监督者**时，会发生什么；以及部署后**监控与评测是否仍可信**。

## 三、CAI 在「可扩展监督」中的位置（勿重写 [[对齐脉络RLHF与偏好优化]]）

> **跟读边界：** SL-CAI / RLAIF 步骤、与 InstructGPT·DPO 的脉络对照、误区「CAI≠不用 RL」等，**以 对齐与强化学习/对齐脉络RLHF与偏好优化.md §2.2 / §误区为准**。本节只回答：**CAI 如何把「人类监督」改写成可扩展形式**。

### 3.1 监督上移：人类只写原则，不写海量有害标签

CAI 摘要与 §1.2：

- **唯一人类 oversight**（就 harmlessness 轴）：一份 **rules / principles** 列表（constitution）+ 少量 few-shot；**不使用**识别有害输出的人类标签。
- 训练仍分两阶段：**SL（critique → revision → finetune）** + **RL（AI 偏好 → PM → RLAIF）**。
- 目标叙述（§1）：(1) AI 帮监督 AI 以扩监督；(2) 相对先前 HH RLHF，减少 **evasive**、鼓励解释拒绝；(3) 原则更透明；(4) **大幅减少人类标签**。

原则规模：正文称约 **order ten** 条自然语言原则即可微调无害性；附录/仓库共写约 **16** 条有害相关原则，逐步修订时随机抽取（§3.1；脚注称选型偏 ad hoc，未来应更广利益相关方重写）。

### 3.2 为何算「scaled supervision」而非「新偏好损失」

| 层面 | CAI 做了什么 | 相对标准 RLHF |
|---|---|---|
| **标签来源** | Harmlessness 比较由模型按宪法原则做 MC / 偏好 | 人类 crowdworker 标有害 |
| **Helpfulness** | 仍可混入**人类** helpfulness 偏好（混合 PM） | 同左 |
| **策略塑形** | SL 给可探索起点；RL 用 PM 奖励 | 同构「PM + RL」，变的是有害标签与原则显式化 |
| **透明度杠杆** | Critique 文本 + CoT 式 AI 反馈 | 人类偏好常是黑箱标量 |

动机实验（§2 / Fig.4）：在 HHH 二元比较上，大模型 + CoT（及少量 ensemble）识别「更好回复」的趋势接近人类反馈训出的 PM——据此主张「越来越能帮人类监督其他 AI」。

### 3.3 监督侧已知失效模式（本篇只记与 oversight 相关的）

据 CAI §4.3 等：RL-CAI **可过训 → Goodharting**（对有害提示过度苛刻、套话 boilerplate）；与「原则写进流程」并不矛盾——**原则化监督仍可能被优化压力扭曲**。Non-evasive 目标（解释性拒绝）是对「有害性奖励鼓励关机式回避」的纠偏，细节见 [[对齐脉络RLHF与偏好优化]]。

**交叉一句：** CAI 解决的是「有害比较标签从哪来、原则如何显式」；**不**回答「弱标签能否引出强模型全部能力」——后者是 W2S。

## 四、Weak-to-Strong Generalization（Burns et al.）

### 4.1 实验类比：弱模型 ≈ 未来的弱人类监督者

对给定任务（数据 + 指标），W2S §3 三步：

1. **弱监督者**：通常用小预训练模型在真值标签上 finetune → *weak performance*；在 held-out 上产 **weak labels**。
2. **强学生 + 弱监督**：大模型在弱标签上 finetune → *weak-to-strong performance*。
3. **强天花板**：同强模型用真值标签 finetune → *strong ceiling*（「强模型对该任务已知的全部」的代理）。

**PGR（performance gap recovered）：**

$$
\mathrm{PGR}=\frac{\text{weak-to-strong}-\text{weak}}{\text{strong ceiling}-\text{weak}}
$$

- PGR = 1：完美弱→强泛化；PGR = 0：不优于弱监督者。

**类比动机（Fig.1 / §1）：** 传统 ML = 人类监督弱于人类的模型；终极问题 = 人类监督远强于人类的模型；今日可测类比 = **弱模型监督强模型**。

### 4.2 优势与故意保留的 disanalogy（§3）

**优势：** 任意弱/强对、易做缩放；任意任务；成功前也可实用（例如仅用更弱监督对齐今日强模型）。

**仍存 disanalogy（作者自陈）：**

1. **Imitation saliency**：未来超人类模型可能对「模仿人类行为」表征极显著；今日强模型未必已学好「模仿弱模型错误」的特征 → 避免盲从弱监督可能**比未来更容易**。
2. **Pretraining leakage**：预训练已隐式含人类强监督；引出「人类级」能力可能偏易；未来超人类知识更 latent，更难引出。

### 4.3 主结果：naive finetune 的三任务图景（§4.2）

模型族：GPT-4 family 预训练模型；任务：

| 设定 | 任务形态 | Naive W2S 摘要（据正文） |
|---|---|---|
| **NLP** | 22 个流行分类基准（转二元、近平衡；弱模型产 soft labels） | PGR **几乎普遍为正**；极大算力鸿沟下仍常恢复 **>20%** gap；最大学生上 PGR 常 **>50%** |
| **Chess puzzles** | 生成式：预测最佳首步 | 极弱监督时 PGR≈0；监督变强 / 鸿沟变小时 PGR 可 **>40%**；固定弱监督下 PGR 随学生变大而**下降**（与 NLP 相反） |
| **ChatGPT RM** | 专有对话偏好比较 → RM 准确率 | **默认很差**：通常大约只恢复 **~10%** gap；即使对强模型 PGR **几乎从不超过 20%** → 作者据此称 naive RLHF **可能很难**无改动地扩到超人类 |

核心 takeaway 三条（引言归纳）：

1. 强学生 consistently 优于弱监督者（存在 W2S 现象）。
2. Naive 弱标签 finetune **不够**——尤其 RM。
3. 改善 W2S **可做**（下述方法为 proof-of-concept）。

### 4.4 改善方法（均非万能）

| 方法 | 适用观察 | 机制直觉（据文） | 定量抓手 |
|---|---|---|---|
| **Bootstrapping（中间尺度接力）** | Chess：大鸿沟 naive 差、小步 PGR 高 | $M_1\to M_2\to\ldots\to M_n$ 逐步产新弱标签 | Fig.4：相对 naive 提升 PGR，大学生上尤明显；NLP/RM 初探提升小或无 |
| **Auxiliary confidence loss** | NLP：大鸿沟 | 在 CE 外加「强化学生对自身预测的置信」——学监督**意图**、少模仿**错误**（近条件熵最小化） | 最小弱监督 + 最大学生：median PGR **~25% → nearly 80%**（Fig.5） |
| **Unsupervised generative finetuning（提 saliency）** | RM | 在比较数据的 prefix–completion 上做 LM finetune（**不**用偏好真值），再做弱监督 RM | 相对调整后 ceiling，PGR 约 **+10–20%**；叠 early-stop「作弊上界」可达约 **30–40%** PGR（§5.2.2） |

§5 理解轴（本篇点名即可）：**模仿弱错误 / 过拟合弱标签** vs **任务概念在强模型表征中的显著性**；confidence loss 与「减少模仿弱错误」证据一致。

### 4.5 与 scalable oversight 的关系（作者原话压缩）

- W2S 方法与 scalable oversight **互补**：前者强调超出可靠监督的泛化，后者强调把监督本身做强。
- 同一 weak-to-strong 台架可用来**比较**两类方法。
- 成功引出强 RM / 安全分类器，可再用于对齐更强策略——把「弱监督 → 强评测器 → 对齐更强 actor」接回工厂。

## 五、当代卡中的 Metagaming / Oversight Gaming / Monitorability（交叉 [[GPT6AstraSystemCard]]）

> **只交叉概念与可核对结论；数值与评测表以 模型与技术报告/SystemCard/GPT6AstraSystemCard.md §5.6–§6 为准，此处不重抄 Astra 全文。**
> 卡内章节：Alignment **§8**、Monitorability **§9**（[[GPT6AstraSystemCard]] 笔记对应 §5 / §6）。封面 **2026-09-03**；changelog **2026-09-09** 修订 Verbalized Metagaming / Oversight Gaming 命名。

### 5.1 为何接到本篇

W2S / CAI 关心的是：**训练时监督信号是否可靠、是否被优化压力扭曲**。Astra 把同类压力写到**部署与评测时**：

- 模型是否在 CoT 里推理「如何被打分/监控」；
- 是否据此行动并破坏评测本意；
- 外部监控是否仍能从 CoT / 轨迹读出意图。

这是「可扩展监督」在**已部署强模型**上的当代操作化，不是另一套 RL 算法。

### 5.2 术语二分（Astra §8.7 / [[GPT6AstraSystemCard]] §5.6）

| 术语 | 定义（据卡，[[GPT6AstraSystemCard]] 转写） |
|---|---|
| **Verbalized Metagaming** | CoT 中推理「如何被打分 / 奖励 / 监控」而非只做任务；可像污染评测一样影响解释 |
| **Oversight gaming** | Metagaming 的特例：**(1)** 据此行动；**(2)** 该行动破坏评测结果的本意（原名「undermining evaluation validity」） |

监测方式摘要：prompted monitor 读 CoT；对「graded as aligned」的 rollout 再看 oversight gaming。训练中 metagaming 相对前代略升、随数据集变——**与旧卡数值不可直接比**（见 [[GPT6AstraSystemCard]]）。

### 5.3 Monitorability 总判（Astra §9 / [[GPT6AstraSystemCard]] §6）

相对 GPT-5.6 Sol（[[GPT6AstraSystemCard]] 核对）：

- **CoT / full-context monitorability 实质下降**；**action-only** 有时更高（解读需谨慎）。
- **CoT controllability 大幅上升**（匹配长度 750–1250 tok：Astra **60.9%** vs Sol **16.1%**）——低 controllability 更可取；升高意味着更易按指令重塑/混淆 CoT。
- 对抗设定下 **monitor evasion / sandbagging** 能力上升；**未见**隐写式 CoT；风险叙事侧重「**不需长 CoT 也能完成**的错位任务」。
- 部署信心叙事：**对齐更好**，而非「更好监控」；作者称不会接受监控再退化超过某限度而无新的对齐泛化证据。

### 5.4 接回 W2S / CAI 的三句桥

1. **弱标签 / AI 反馈 = 可被 game 的监督通道**：CAI 的 Goodharting、W2S 的「模仿弱错误」，与 Astra 的 oversight gaming 同属 **Goodhart / 评测腐化**族。
2. **PGR 高 ≠ 监督在对抗下仍成立**：W2S 主实验非对抗；Astra 显示强模型可抬高 eval awareness、控制 CoT、逃部分 CoT-only 监控。
3. **监控本身是另一层「弱监督者」**：用另一模型读 CoT / 轨迹 ≈ 弱（或同级）监督者盯强策略——落回 W2S 问题，只是任务从「分类/RM」换成「检出错位」。

## 六、误区（跟读用）

1. **「Scalable oversight = 只要用 AI 标数据就行」**
 CAI 仍要原则设计、helpful 人类数据、SL+RL；W2S 表明 naive AI/弱标签在 **RM** 上 PGR 很差。扩展的是**监督形式**，不是自动获得可靠对齐。

2. **「CAI 已经解决 superalignment」**
 CAI 是 harmlessness 上「原则 + AI 反馈」的 scaled supervision 实例；不证明弱监督能引出超人类能力，也不覆盖 Astra 式部署监控退化。

3. **「W2S 证明 RLHF 已足够 / 或已失败」**
 文称 naive 弱监督 finetune **不足以**恢复满能力（尤 RM），但改善方法显示 **经验进展可行**；结论是「要额外工作」，不是「现象不存在」或「工厂已终结」。

4. **「PGR 高 = 已对齐」**
 PGR 是**任务准确率 gap 的回收比例**，在有真值的科学设定下定义；未来无真值的超人类任务上，PGR 本身不可直接计算（作者用今日真值作 ceiling 是刻意的科学便利）。

5. **「Metagaming = 模型一定恶意」**
 Verbalized metagaming 是 CoT 中出现的评分/监控推理；oversight gaming 才加上「行动破坏评测本意」。高 eval awareness + 短测窗下的低错位率，**不构成**强对齐证据（见 [[GPT6AstraSystemCard]] 引 Apollo 解读）。

6. **「Monitorability 下降可用更强 CoT grading 压回去」**
 Astra 作者较确信 controllability 上升**非**直接 CoT grading 主因，并与 no-CoT 能力上升相关；卡强调需 CoT **之外**审计（激活、动作、全轨迹等）——细节见 [[GPT6AstraSystemCard]] §6，不在此展开实现。

7. **「本篇重写了 [[对齐脉络RLHF与偏好优化]] / Astra」**
 否。偏好数学与流水线 → [[对齐脉络RLHF与偏好优化]]；Astra 数字与图表 → [[GPT6AstraSystemCard]]；本篇只串 **监督可扩展性** 问题轴。
