# 开端性：Darwin Gödel Machine + Discovery Foundation Models

> **定位**：[[开端性与发现基础模型]] **P1**——立仓库缺失的 **open-endedness / 自改进档案搜索 / Discovery Intelligence** 横切：
> - **Darwin Gödel Machine（DGM）**：冻结预训练 FM 上的编码代理，**实证校验**自改代码（非形式证明），并以 **档案 + 开端探索**生长多样 stepping stones；SWE-bench / Polyglot 作验证信号。
> - **Discovery Foundation Models（DFM）**：把智能缩放从「学既有知识 / 学行动结果」再推到「参与**知识生产过程**」——七能力 + 可修订研究态；实例 **Zetema** + 实证锚定 **GALILEO** Dry/Wet 闭环。
> **攻坚线**：**架构思想（主）** + **评测字段（文内基准 / 过程协议，辅）**。
> **硬划界（开篇钉死）**：
> - **≠ 科研智能体**：禁止重写 AI Scientist「想法→实验→论文→LLM 评审」流水线 / ChemCrow 化学工具集；本篇对象是 **自改进档案搜索（DGM）** 与 **发现智能范式定义（DFM）**，不是端到端写论文代理。
> - **≠ 测试时训练**：禁止重写 In-Place TTT / TEMPO / Modular-TTT（推理期 **改参数**）；本篇不训 test-time fast weights。
> - **≠ [[推理时扩展TestTimeScaling]]**：禁止重写 o1/R1 TTS / 长 CoT 产品通史；本篇不谈「同模型多花推理算力」主轴。
> - **≠ [[SWEBenchPro代码修复评测]]**：DGM 用 SWE-bench（文内默认 = **Verified**）作验证信号，**禁止重写** SWE-Bench Pro / Pro Verified 构造、三分集、anti-hacking 协议。
> **附录不升主**：**OMNI-EPIC**（2405.15568）因体积 **>20MB** → **正式外链**；作「环境代码生成式开端」邻接索引，不升第二主轴。

### 2.2 两篇主文如何自划界（文内）

- **DGM vs 理论 Gödel Machine**：Schmidhuber (2007) 要求**可证有益**的自改；实践上多数改动无法形式证明。DGM 改为在编码基准上**经验证**，并加 Darwin 式档案防局部最优。
- **DGM vs ADAS 等固定 meta-agent**：Related work 指出 ADAS 用**固定**元代理生成下游代理；DGM 是**同一系统**既解下游编码任务，又改自身代码——下游涨分应回馈到进一步自改能力。文内基线 **DGM w/o self-improve** 即复现「固定 meta、不自改」设定。
- **DGM 明确未做**：文内写构想可改训练脚本乃至训新 FM，但**本文不展示**（算力与复杂度）；实验范围是 **冻结 FM + 工具/工作流代码**。开端探索机制（档案维护、父代选择）**当前固定、不可被 DGM 自改**（留作未来）。
- **DFM vs Scientific Agents / AI Scientist**：Table 1 能力对照——科学代理常在**给定**问题上协调工具；DFM 的定义要求还要能改问题源、表示、并做跨任务 **Skill Transfer**。文内强调 GALILEO 是 Dry/Wet 环的**实证锚定**，**不等于**把单一域系统外推成通用 DFM 全称主张。
- **与 OMNI-EPIC**：DGM Related work / 引言引用 Faldor et al. 2025（即 OMNI-EPIC 线）作为开端与 interestingness 邻接；本篇附录只索引其「代码生成环境」抓手，不展开 126 页实验图。

## 三、主文 A：Darwin Gödel Machine（2505.22954）

### 3.1 问题立轴：证明不可行 → 实证 + 档案

跟读摘要与 §1–§3：

1. 今日多数 AI **架构固定、不能自治持续自改**；科学进步却是累积开端。
2. 经典 Gödel Machine 的「可证有益」在实践中**不可行**（例：多给工具看似有益，实际依赖训练与任务上下文）。
3. DGM：**改自己的代码仓库** → 在编码基准上评 → 入库档案 → 按开端原则选父代再分支。
4. 关键假设：**编码基准涨分 ≈ 编码能力涨 ≈ 自改（本身也是编码任务）能力涨**。

### 3.2 架构：自指编码代理 × 种群开端探索

**编码代理定义（§3）：** 单一系统 = 代码仓库 + **冻结**预训练 FM，能读/写/执行代码；自改进 = 改自身组件设计（提示、工作流、工具），**不含**开端探索外环。

**循环（Figure 1 / §3）：**

1. 档案初始化为**一个**基座代理。
2. **父代选择**：大致正比于性能分、反比于「仍具代码编辑能力的子代数」（Appendix C.2）——兼顾强者剥削与欠采样谱系探索；**所有**代理保留非零选中概率。
3. 父代分析自身评测日志 → 提议下一特征 → 把提议当问题陈述执行 → **自改代码**生成新代理。
4. 定量评测；仅 **能编译且仍能改代码库** 者入档，否则丢弃。
5. 重复；归档解可作很晚才兑现的 stepping stones（≠ 纯 hill-climbing）。

**基座（§4.1）：** 两工具——Bash + 整文件级 edit/view；单次输入含目标仓库路径、问题陈述、测试框架。故意轻量以便证明自改进。
**算力设定：** **80** 轮（每轮一个新代理）；SWE-bench **2** 路并行、Polyglot **4** 路并行。自改期 FM = **Claude 3.5 Sonnet (New)**；评测期 SWE 用同一 Claude，Polyglot 用 **o3-mini**。

### 3.3 评测字段（文内；≠ [[SWEBenchPro代码修复评测]] Pro）

| 字段 | 文内约定 |
|---|---|
| **SWE-bench** | 默认 = **SWE-bench Verified**（OpenAI 2024 人滤可解子集）；**不是** [[SWEBenchPro代码修复评测]] 的 Pro |
| **Polyglot** | 多语言（C++/Rust/Python 等）；相对 SWE 更小众、更不像已进后训练；文内 **pass@1**（从不看金标测试），对照 leaderboard 常用 pass@2 |
| **分级评测** | 先 10 题验「还能改代码」→ 扩到 50；SWE：60 子集 >40% 且档内 top-2 → 再扩到 **200**；Polyglot：10 题 >40% → 扩 50 |
| **主结果（80 轮后）** | SWE：**20.0% → 50.0%**；Polyglot 子集设定文内写 **14.0% → 38.0%**；**全量 Polyglot：14.2% → 30.7%** |
| **消融基线** | (1) **w/o self-improve**（固定 meta，复现 ADAS 设定）；(2) **w/o open-ended exploration**（无档案，总改最新版）——两基准均弱于完整 DGM（Figure 2） |
| **迁移（Figure 4 文内印数）** | 模型迁移：Claude 3.5 上搜到的最优代理迁到 Claude 3.7 / o3-mini 仍显著高于同 FM 基座（图注含 50.0% / 59.0% 等）；基准间零样本迁移；Polyglot 上 Python-only 搜索 vs 全语言搜索对比 |

**自动发现的特征类型（§4.4）：**
- **工具**：更细粒度按行查看、按字符串替换编辑（相对整文件替换）。
- **工作流**：多次尝试求解；用另一 FM 评估并选最优解；生成后续尝试时考虑先前尝试。
开端探索允许暂时掉分的谱系继续分支（文内例：SWE 实验 iteration **4** 与 **56**），以及同一目标功能的**多种实现**并行试错（Appendix G）。

### 3.4 安全讨论（§5，只记机制名）

文内主动列风险：基准未覆盖安全/鲁棒时自改可能放大错位；逻辑日益难解释。**现有实验防护：** 隔离沙箱、严格时限、自改范围限于改自身 Python 以提编码基准、性能与 diff 监控、档案可追溯。文内称现阶段未见有害/恶意行为。附录 H 有幻觉对策的初步安全向部署讨论。开源仓库文内强调默认沙箱与用途文档（Impact Statement 段）。

### 3.5 局限（§6 跟读）

- 未展示「自改训练脚本 / 训新 FM」。
- 开端外环（档案、选父）**尚不可自改**。
- 更长轮次是否持续涨分、能否超过当时公开 SoTA，文内作开放问题。
- 编码代理能力仍受冻结 FM 上限约束。

## 四、主文 B：Discovery Foundation Models（2609.15973）

### 4.1 问题立轴：三阶段智能缩放

Figure 1 / 摘要三阶段：

1. **Chat**：学既有知识；
2. **Agent/Coding**：从行动结果学；
3. **Discovery**：创造并对照外部证据**验证新知识**。

跟读批评：多数系统从人已选好的研究结构出发（问题、变量、目标、工具接口、评判器已定）；开端发现里下一步常是**改结构**——判定未知是否真未知、如何提问、何种表示使竞争机制可分、何种干预迫使它们分歧。

**Discovery Intelligence**：能否在部分理解的世界上**构造、检验、修订**通向已验证知识的过程——而非仅在给定任务上答得更深更广。

### 4.2 形式定义与七能力

**Definition 1（§3.1）：** DFM = 通用模型系统，能：识别有价值未知、形式化可研问题、构造/修订表示、生成可检验解释、设计干预、从外部证据学习、并**跨任务/域持续改进**发现能力。

三要求（文内）：操作可迁移（实现可仍域专用）；主张由**域适配证据**接地（模型自信/内部一致**不够**）；评价单元是**声明的模型系统**（含持续态、记忆、工具、环境、验证器、人类参与）。

**七能力（Eq.3）：**

$$
C_{\mathrm{DFM}}=\{C_{\mathrm{find}},C_{\mathrm{form}},C_{\mathrm{repr}},C_{\mathrm{hyp}},C_{\mathrm{int}},C_{\mathrm{rev}},C_{\mathrm{cont}}\}
$$

| 记号 | 跟读含义 |
|---|---|
| $C_{\mathrm{find}}$ | 选值得投资源的未解结构；拒绝校准/检索/更强基线下会消失的「假未知」 |
| $C_{\mathrm{form}}$ | 把未知收成有界可测问题（对象、范围、尺度、条件、可观测量可修订） |
| $C_{\mathrm{repr}}$ | 构造变量/关系/抽象/尺度；在「一切解释等价」或重复同一失败边界时关键 |
| $C_{\mathrm{hyp}}$ | 形成机制上可区分的解释（假设、有效域、预测、可证伪点） |
| $C_{\mathrm{int}}$ | 按对研究态的**期望信息效应**选实验/仿真/执行/消融/复现（非仅为确认） |
| $C_{\mathrm{rev}}$ | 归因意外结果并更新正确对象（假设/表示/问题/协议/测量/干预计划） |
| $C_{\mathrm{cont}}$ | 用**已验证**跨 episode 经验改变未来发现行为（强于堆事实或检索成功轨迹） |

前六者在单次调查内；第七是跨任务更新。系统边界元组（Eq.4）：$D=(\pi_\theta,S,M,T,E,V,H)$——策略、研究态、记忆、工具、环境、验证、人类；功能角色可一对多。

**与既有范式（Table 1）：** 科学基础模型 / 推理模型 / 科学代理·AI Scientist / 搜索-评判器 / 自动实验室——DFM 的区分是**联合能力要求**：仅在固定搜索空间 $Z$ 上优化候选 **不等于** 能在证据下识别并修订空间或评判器本身。

### 4.3 实例：Zetema

§5 组织原则：科学上后果性操作必须留下可归属的研究态转移。要点（跟读）：

- **显式研究态** $S_t$：支持分支与回滚；失败时保留多种合理解释而非过早压缩。
- **Discovery Skill Memory**：候选技能须声明触发条件、应改变什么、何种后续证据说明改变有益；仅经验证的跨任务更新算技能改进。
- **Research World Model + Experimental Gating**：筛「经验上不可分」的候选；预测观测/态变/成本；**不**宣称证成真理；保留模型分歧与校准信息。验证随动作自适应（形式主张可走证明器；物理实验需门控）。
- **Dry-Lab / Wet-Lab**：生成期望与外部观测分离；代码/形式系统亦作「非物理环境」对照。

### 4.4 实证锚定：GALILEO（§5.7；只录文内数字）

治疗肽 / 动态膜系统上的 Dry–Wet 闭环（Jiang et al., 2026，文内引用）：机器人合成、质控、液体处理、成像、板级表型 → 物理结果**进入**迭代决策（非末端贴金）。

| 分支 | 文内结果字段 |
|---|---|
| **GALILEO-LRC / LRRC8C** | 全细胞电生理：相对其他 LRRC8 异聚体选择性抑制 LRRC8A/LRRC8C 电流；LRRC8C-high 类器官 **IC50 = 18.922 μM** |
| **GALILEO-SLC / SLC25A1** | 定位至线粒体区室；SLC25A1-high 患者源类器官 **IC50 = 0.736 μM**；后续沉默/醋酸挽救等细化机制假说 |
| **五轮优化 → ABG** | 非单调朝单一家族收缩：弱模体剪枝、曾弃组织重开、生产模块固化 → **Amphiphilic Balance Grammar（ABG）** 作为可迁移设计规则 |

文内自限：GALILEO **不应**被读成「已证明通用自治 DFM」；它示范干预–证据–修订环与 $C_{\mathrm{cont}}$ 雏形，且诸多后果性操作仍含人类授权/执行。

### 4.5 能力形成与过程中心评测（§6–§7 索引）

- **训练**：轨迹级中间决策；组合目标含过程验证、Research World Model、科学反馈 RL、已验证技能迁移（文内 $\mathcal{L}_{\mathrm{DFM}}$）；**不**绑定单一优化器（PPO/GRPO 等仅作接口举例）。
