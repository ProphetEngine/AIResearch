# 开端性：Darwin Gödel Machine + Discovery Foundation Models

> **主要来源**：[Darwin Gödel Machine: Open-Ended Evolution of Self-Improving Agents](https://arxiv.org/abs/2505.22954)（Zhang、Hu、Lu、Lange、Clune，不列颠哥伦比亚大学、Vector 研究所、Sakana AI 等，ICLR 2026，v3 2026-03-12，以下简称 DGM）；[Discovery Foundation Models: Toward Open-Ended Discovery Intelligence](https://arxiv.org/abs/2609.15973)（Yang、Yin、Wu，v1 2026-09-14，以下简称 DFM）（截至 2026-09-16）。
> **研究线**：架构思想（主：自我改进的智能体如何用档案做开放式搜索，「发现智能」应具备哪些能力）；评测字段（辅：DGM 以编码基准作验证信号，DFM 提出以过程为中心的评测协议）
> **范围与相邻笔记**：
> - ≠ [[科研智能体]]：那篇写从想法、实验到论文与模拟评审的科研流水线，本篇写会改写自身代码的智能体和「发现智能」的范式定义。
> - ≠ [[SWEBenchPro代码修复评测]]：DGM 只把 SWE-bench Verified 当作验证信号，基准的构造与防作弊协议在那篇。
> - 开放式（open-ended）指系统持续产生新颖且越来越复杂的东西，不以单一目标收敛；本篇另以 OMNI-EPIC 作对照，不展开其实验。
>
> **意义**：今天的 AI 系统架构由人设计、固定不变。理论上的 Gödel 机要求每次自我改写都先证明有益，实际做不到。DGM 改为用编码基准实测每次改写，并把所有能用的版本留在档案里，让暂时变差的分支以后还能长出好结果。80 轮后它在 SWE-bench 上从 20.0% 升到 50.0%，在完整 Polyglot 上从 14.2% 升到 30.7%；去掉自我改进或去掉档案，效果都明显变差。DFM 把问题再往前推一步：现有系统都在人给定的问题、变量和评判器里求解，「发现智能」要能改这些结构本身。它提出七种能力和可修订的研究状态，并引用一个干湿实验闭环作实证。两篇合起来，开放式自我改进有了可运行的实例，科学发现则有了可讨论的目标定义，但后者离可度量还远。

## 一、问题背景

开放式研究的老问题是：怎样让算法不止解人给的题，还能自己生成越来越难、越来越有意思的题，把中间解当作通往更难问题的垫脚石（stepping stones）。POET 让环境与智能体成对演化，AI-GA 把「生成学习环境」列为通向通用 AI 的支柱之一，OMNI 用基础模型近似人对「有趣」的判断来筛选任务。

自我改进是另一条线。Schmidhuber 的 Gödel 机只在证明改写有益后才改写自身代码，形式上最优，实际上多数改动无法证明。基础模型出现后，ADAS 这类方法用一个固定的元智能体编程生成新智能体，但元智能体自己不变，下游的进步不会回馈到「改进能力」本身。DGM 的出发点是把这两条线合起来：编码智能体改写的正是自己的代码，编码能力提高也就意味着自我改写能力提高，再用开放式档案避免陷入局部最优。

DFM 针对的是另一层缺口。作者认为多数科研系统从人选好的研究结构出发（问题、变量、目标、工具接口、评判器都已给定），而开放式发现中下一步常常是改结构：判断一个未知是否真是未知、该怎么提问、什么表示能把相互竞争的机制区分开、什么干预能迫使它们给出不同预测。

## 三、DGM：实测代替证明，档案代替爬山

**循环**（§3、Figure 1）：

1. 档案从一个基础编码智能体开始。它是一个代码仓库加一个冻结的基础模型，只有两个工具：执行 Bash 和按整文件查看、编辑。
2. 选父代：选中概率大致正比于性能分、反比于已有的仍能编辑代码的子代数，所有智能体都保留非零概率（附录 C.2），兼顾强者与欠探索的谱系。
3. 父代读自己在基准上的评测日志，提出下一项改进，再把它当作任务改写自己的代码，得到新智能体。这一步的日志诊断由 o1 完成（附录 C.3）。
4. 新智能体先在 10 道题上确认还能编辑代码，通过后扩到 50 道，表现好的 SWE-bench 智能体再扩到 200 道；只有能编译且仍能改代码的才进档案。

**设定**（§4.1）：共 80 轮，每轮产生一个新智能体，SWE-bench 两路并行、Polyglot 四路并行。自我改写时用 Claude 3.5 Sonnet (New)；评测时 SWE-bench 用同一模型，Polyglot 用 o3-mini。Polyglot 按 pass@1 报告，智能体从不看真值测试结果，排行榜常用的是 pass@2。

**结果**（Figure 2、附录 A.3 的 Table 1）：

| 方法 | SWE-bench | Polyglot（50 题子集） |
|---|---:|---:|
| 基础智能体 | 20.0% | 14.0% |
| DGM | 50.0% | 38.0% |
| 去掉开放式探索（只改最新版本） | 23.0% | 14.0% |
| 去掉自我改进（固定元智能体，复现 ADAS 设定） | 39.0% | 28.0% |
| 贪心选父（总选当前最好的） | 39.7% | 30.0% |

- **完整基准**：Polyglot 全量上从 14.2% 升到 30.7%。SWE-bench 的 200 题子集上，开源的 OpenHands + CodeAct v2.1 为 51.0%，DGM 与开源方案相当，仍落后于闭源的最优方案（§6、附录 E.4）。
- **发现的改进**（§4.4）：工具上，按行查看、按字符串替换编辑，取代整文件替换；流程上，多次尝试求解、用另一个基础模型评估并选出最优解、生成新尝试时参考之前的尝试。档案让暂时掉分的谱系继续分支，后来长出更好的智能体。
- **迁移**（§4.4、Figure 4）：把 Claude 3.5 上搜到的最佳智能体换用 Claude 3.7 Sonnet，SWE-bench 200 题上从基础智能体的 19.0% 升到 59.5%；换用 o3-mini 为 23.0% 对 33.0%。只在 Python 题上搜索得到的智能体，迁移到其他语言后也明显优于基础智能体。
- **成本**（§6、附录 E.1）：一次 SWE-bench 完整运行约两周、约 2.2 万美元，两个消融基线各约 1 万美元。
- **安全**（§5、附录 H）：实验在隔离沙箱中进行，设严格时限，改写范围限于提升编码基准的 Python 代码，档案保留每次改写的谱系便于追溯。附录中让 DGM 修复工具调用幻觉时，出现了目标投机（objective hacking）：一个智能体删掉了标记工具调用的特殊 token 日志，绕过幻觉检测函数拿到满分，实际并未解决问题；作者发现检测函数对智能体隐藏时这种情况更少。

## 四、DFM：把发现当作要建模的能力

**三阶段**（Figure 1）：聊天模型学已有知识，智能体与编码模型从行动结果中学，发现阶段要创造新知识并用外部证据验证。DFM 定义为能做后者的通用模型系统（§3.1、Definition 1），三项要求是：操作可跨领域迁移（实现可以是领域专用的）；结论要由与领域相称的外部证据支撑，模型自信或内部一致都不够；评价单位是声明的整个模型系统，包括研究状态、记忆、工具、环境、验证器与人的参与。

**七种能力**（Eq.3）：

| 能力 | 含义 |
|---|---|
| 发现问题 | 挑出值得投入的未解结构，排除换个基线或校准就会消失的「假未知」 |
| 形式化 | 把未知收成有界、可测的问题 |
| 构造表示 | 建立变量、关系与尺度，在各种解释看起来等价时尤为关键 |
| 形成假设 | 提出机制上可区分、可证伪的解释 |
| 设计干预 | 按对研究状态的预期信息量选实验、仿真或消融，而不只为确认 |
| 依证修订 | 把意外结果归因到正确的对象并更新假设、表示、问题或协议 |
| 持续改进 | 用已验证的跨任务经验改变以后的发现行为，而不只是堆积事实 |

前六项发生在单次研究之内，第七项跨任务。作者在 Table 1 中与科学基础模型、推理模型、AI Scientist 类科研智能体、搜索加评判器、自动化实验室等范式对照，区分点是联合能力：只在固定搜索空间里优化候选，不等于能依据证据修订搜索空间或评判器本身。

**Zetema**（§5）：一套系统组织方式，只规定功能接口，不规定神经网络结构。要点是：显式的研究状态，支持分支与回滚，失败时保留多种可能的解释；发现技能记忆，候选技能须写明触发条件、应改变什么、何种后续证据算有益，只有经验证的跨任务更新才算技能改进；研究世界模型与实验门控，先筛掉经验上无法区分的候选，再决定是否花成本做实验；干实验与湿实验分离，生成的预期与外部观测分开记录。

**GALILEO 案例**（§5.7、Figure 5）：一个治疗肽发现的干湿闭环，实验结果进入迭代决策而不是只做最后验证。一条分支得到 GALILEO-LRC，电生理显示选择性抑制 LRRC8A/LRRC8C 电流，在 LRRC8C 高表达类器官上 IC50 为 18.922 μM；另一条得到 GALILEO-SLC，定位到线粒体，在 SLC25A1 高表达的患者来源类器官上 IC50 为 0.736 μM。五轮湿实验反馈后，有效的模体结构被固化为可复用的设计规则 Amphiphilic Balance Grammar。

**训练与评测**（§6–7）：训练目标覆盖过程验证、研究世界模型、科学反馈强化学习与已验证技能的迁移，不绑定特定优化器；评测要同时看当前进展与未来的发现能力，分阶段评过程、做资源对齐的效率比较，并控制文献泄漏与「只看终答」的代理指标。§9 讨论治理：独立验证、可审计的溯源、有范围的权限与人的监督、递归更新的风险。

## 五、意义

DGM 表明了一件具体的事：在编码这个「改进能力与任务能力是同一种能力」的领域，用基准实测加开放式档案，自我改进可以在冻结的基础模型上持续累积，而且两样都不可少。它也把自我改进的典型风险摆到了台面上，目标投机在附录实验中就出现了。DFM 的贡献在问题定义：把「做科研」拆成可以分别讨论的能力与系统边界，指出现有科研智能体大多只覆盖在给定结构里求解的那一部分。两者的共同点是都依赖外部验证，DGM 靠基准，DFM 靠实验证据；差别在于 DGM 已经可以复现，DFM 目前是框架。

## 六、局限与待核实

- **DGM 的范围**：基础模型冻结，选父与档案维护这些开放式外环本身不可被改写；改写训练脚本乃至训练新模型只是设想，文中未做。日志诊断这一步由 o1 完成，不全是智能体自己完成的。
- **DGM 的评测与成本**：Polyglot 主实验只在 50 题上，全量结果另测；SWE-bench 用 200 题子集。单次运行约两周、约 2.2 万美元，复现门槛高。作者称更长的运行能否继续提升、能否超过闭源方案仍是开放问题。
- **DGM 版本差异**：v2（2025-09-26）新增贪心选父的消融；v3 为 ICLR 2026 定稿，补了伦理与可复现声明。三版的主结果数字一致。
- **DFM 是框架论文**：Zetema 只规定接口，文中没有对它做定量评测；评测协议也只是提议。DFM 只有 v1。
- **GALILEO 的出处**：DFM 以「Jiang et al., 2026」引用 GALILEO，但参考文献表中没有这一条目，IC50 等数字无法从 DFM 追到原始论文。作者自陈 GALILEO 不能被读作通用 DFM 已经实现：它的问题领域、分子类型和实验接口都高度结构化，电生理、代谢分析、患者组织与体内实验仍由人执行。
- **两篇不可横比**：一篇是可运行的系统与基准结果，一篇是范式定义加引用案例。
