# 可验证过程监督：VPS + VPRM（≠ 学习式 PRM）

> **主要来源**：[Correct Answers from Sound Reasoning: Verifiable Process Supervision for Language Models](https://arxiv.org/abs/2605.12519)（Kim、Wang、Xie 等，KAIST、德州大学奥斯汀分校、莱斯大学、普林斯顿大学、华盛顿大学、Sentient Labs，COLM 2026，v2 2026-08-05，以下简称 VPS）；[Beyond Outcome Verification: Verifiable Process Reward Models for Structured Reasoning](https://arxiv.org/abs/2601.17223)（Pronesti、Belz、Hou，IBM 欧洲研究院、都柏林城市大学等，v1 2026-01-23，以下简称 VPRM）（截至 2026-08-05）。
> **研究线**：架构思想（主：中间步骤由确定性的域规则或引擎核验，而不是学出来的神经裁判）；评测字段（辅：准确率之外的过程质量与一致性指标）
> **范围与相邻笔记**：
> - ≠ [[过程奖励模型PRM谱系]]：那篇写人工或自动逐步标注、再训练神经过程奖励模型（PRM），本篇两文都不训练逐步奖励模型。
> - ≠ [[形式化验证与LLM]]：那篇把推理写成一阶逻辑或 Lean 交给求解器与证明器，本篇的中间声明不必写成可证明的形式语言。
> - ≠ [[过程可验证RL与Lean]]：那篇的过程信号来自 Lean 的阐述与报错，本篇来自棋类引擎、算术规则与医学指南的决策树。
>
> **意义**：只奖励终答的可验证奖励强化学习（RLVR）能把准确率推上去，却不保证中间推理是对的。VPS 在棋类上量出了代价：只奖终着时着法准确率从约 0.21 升到 0.53–0.54，但胜率估计误差相对 SFT 增大 46% 与 112%，R1-Distill-Llama-8B 上近 70% 的最终着法与模型自己的胜率分析相矛盾。两文给出同一种解法：先让模型把中间步骤写成可解析的结构，再用确定性规则逐项核对并计入奖励，不再训练神经裁判。VPS 在保住准确率的同时把一致性拉回到 0.98 左右；VPRM 在医学偏倚风险评估上，摘要称比可验证结果奖励高 6.5%（Table 2 中 macro-F1 为 76.7 对 70.2）。在有规则可查的领域，过程奖励可以和结果奖励一样可验证。

## 一、问题背景

结果监督只看终答，过程监督给每一步打分。早期在 GSM8K 上的对比发现，两者的终答错误率相近，但要得到正确的推理步骤，必须用过程监督或模仿过程反馈的奖励模型；随后的工作在 MATH 上表明过程监督更强，并公开了逐步人工标注。人工标注贵，于是出现了用续写结果自动构造逐步标签的 PRM，以及先写核验思维链再判每步的生成式 PRM。这些路线的共同点是要训练一个神经裁判，VPRM 在引言中指出它们不透明、带偏差、容易被奖励黑客利用。

另一边，DeepSeek-R1 之后的 RLVR 用精确匹配或单元测试核对终答，信号可靠，却只落在最后一步。两文要补的就是这个空档：在中间步骤本身可以被规则检查的领域，过程奖励能否也由确定性核验器给出。VPRM 的作者称此前还没有工作在可做符号检查的任务上把过程奖励做成可验证的，这是作者的说法。

## 三、VPS：先诱导结构，再核验声明

**方法**（§3、Algorithm 1）分三步：

- **结构先验**：用合成的结构化推理轨迹做 SFT，让模型在思考段按固定格式分析候选着法，写出吃子、将军、将杀、局面评分、胜率与后续主变等可单独核验的声明，下游用句法规则就能抽出来，不必让另一个 LLM 去解析。
- **确定性核验**：每类声明对照引擎真值打分；数值类在容差区间内给满分、之外线性衰减到零，二值类按对错给分（附录 A.1）。
- **自适应加权**：总奖励 = 格式奖励 + 准确率奖励 + λ × 各子任务过程奖励的加权和。权重按各子任务的剩余误差（1 减去其表现的滑动平均）做温度 softmax，并设下限，难的子技能权重更大，形成隐式课程。

**设定**（§4.1）：SFT 数据来自 Lichess 评估库（Stockfish 分析，主实验 10k 个局面，消融另用 1M）；RL 与评测用 Lichess 谜题库，训练、验证、测试各 50k、1k、1k，训练集用 Stockfish 深度 25、留出集用深度 30 重新分析。基座为 Qwen3-8B 与 DeepSeek-R1-Distill-Llama-8B，优化器为 GRPO。准确率奖励由 Ruoss 等人训练的 2.7 亿参数动作价值网络给出，取值在 0 到 1 之间。局面平均有 27 步合法着法，只认唯一最优着。

**主结果**（Table 1，留出局面）：

| 模型 | 设定 | Top-1 准确率 | 胜率 MAE ↓ | 主变重合 | 一致性 |
|---|---|---:|---:|---:|---:|
| Qwen3-8B | 只做 SFT | 0.212 | 0.310 | 0.323 | 0.961 |
| | SFT + 只奖结果的 GRPO | 0.534 | 0.452 | 0.183 | 0.721 |
| | VPS | 0.536 | 0.218 | 0.376 | 0.978 |
| R1-Distill-Llama-8B | 只做 SFT | 0.215 | 0.346 | 0.341 | 0.978 |
| | SFT + 只奖结果的 GRPO | 0.541 | 0.732 | 0.330 | 0.312 |
| | VPS | 0.545 | 0.286 | 0.362 | 0.985 |

一致性指最终着法是否等于模型自己评出的胜率最高的候选。只奖结果时还有刷分迹象：Qwen3-8B 平均分析的不同候选数从 2.20 降到 1.65，即反复写同一个顶着而不做比较；VPS 下接近 3.0（§4.2）。

- **准确率对齐后的比较**（Table 2）：取只奖结果的 GRPO 准确率最高的检查点，与准确率相当的 VPS 检查点比，由 GPT-4o、Claude Opus 4.6、Gemini 3 Flash 三个裁判按 1–5 分打分。总分 Qwen3-8B 为 3.420 对 2.582，R1-Distill-Llama-8B 为 3.271 对 2.267。
- **推理预算**（§4.4）：没有结构先验时，只奖结果的 Qwen3-4B 会随长度上限收敛到不同捷径；上限 2048 token 时，256–512 token 的轨迹准确率 86%，超过 1024 token 的只有 27%，长轨迹反映的是混乱而不是更深的推理。
- **自适应加权**（§4.4）：1M 局面 SFT 起步时，相对固定权重把胜率 MAE 降低 15.1%（18.66 对 21.97）；10k 起步时收益小。
- **数学**（§4.3、Table 3，Qwen3-0.6B，GSM8K）：SFT + 只奖结果的 GRPO 与 VPS 准确率相当（0.760 与 0.763），逐步算术正确率为 0.658 与 0.905，答案与推理的一致性为 0.621 与 0.889。

## 四、VPRM：结构由指南给定

**领域**：医学证据综合里的偏倚风险评估（Cochrane RoB2）。每个偏倚维度都有固定的逐步问题和规则决策树，把各步标签组合映射到低、中、高三档风险（§2.4、Fig.1）。模型轨迹的每一步输出步骤编号和步骤标签，金标由指南规则推出。与 VPS 不同，这里的结构不需要 SFT 去诱导，领域指南本来就规定了问什么、怎么跳转。

**奖励**（§3）：每步奖励 = 预设权重 × 步骤编号是否匹配 + 预设权重 × 步骤标签是否正确；终局再核对整条轨迹推出的风险标签。全部由手写规则计算，没有神经逐步奖励模型。Theorem 1 证明：在正确轨迹平均奖励高于错误轨迹等温和假设下，GRPO 与 DAPO 的期望优势对正确轨迹为正、对错误轨迹为负。

**设定**（§4.3、Table 1）：训练用 Cochrane Forest Ext 的 2,651 条（另 295 条作验证），并加入 RoBBR Cochrane 的 774 条训练样本；评测在 Cochrane Forest（1,846）、RoBBR Cochrane（906）与分布外的 RoBBR Non-Cochrane（2,489）上进行。逐步标签由 Llama 3.1 405B 合成。策略模型 Qwen2.5-7B，SFT 5 轮，RL 3 轮，GRPO 或 DAPO，每批 16 条采样。另报一致性：终局风险是否等于按模型自己各步标签走决策树得到的风险。

**主结果**（Cochrane Forest，Table 2–3）：

| 设定 | 准确率 | macro-F1 |
|---|---:|---:|
| Qwen2.5-7B 预训练 | 32.9 | 31.6 |
| Qwen2.5-7B SFT | 45.1 | 36.9 |
| GRPO + 可验证结果奖励 | 81.5 | 70.2 |
| GRPO + 神经 PRM（GPT-OSS 打分） | 78.2 | 56.1 |
| GRPO + MedPRM | 76.8 | 53.4 |
| GRPO + VPRM | 87.9 | 76.7 |
| DAPO + VPRM | 79.2 | 60.6 |
| Llama-3.1-405B（直接提示） | 68.4 | 45.5 |
| GPT-OSS-120B（直接提示） | 67.1 | 49.8 |

- **分布外**：RoBBR Non-Cochrane 上 GRPO + VPRM 为 60.7 / 47.2，只奖结果为 56.8 / 45.1。
- **消融**（Table 4）：去掉结果奖励后完整 VPRM 只有 40.2 / 35.3；带结果奖励时只核验步骤结构为 83.1 / 71.8，完整 VPRM 为 87.9 / 76.7，过程与结果两部分缺一不可。
- **一致性**（§4.6、Table 5）：GRPO + VPRM 为 89.5%，Llama-3.1-405B 为 50.7%。

## 五、意义

两文合起来给出了可验证过程监督的两种工况：结构要靠训练诱导的（棋类着法分析、数学中的算术声明）用 VPS；结构已由领域规范给定的（医学指南的决策树）用 VPRM。共同的结论有两条。其一，只奖结果会让推理退化，VPS 在棋类和 GSM8K 上看到的都是准确率涨、过程质量跌，且这种退化在准确率对齐后依然存在。其二，只要中间声明能被规则逐项检查，过程奖励就不必依赖神经裁判，也就避开了学习式 PRM 的标注成本与可被利用的盲区。代价是适用面：两文都需要一个现成的真值来源（引擎、算术、指南），没有这类核验器的开放任务仍要回到学习式或生成式裁判。

## 六、局限与待核实

- **VPS 版本差异**：v1（2026-04-03）只有棋类实验；v2 新增 §4.3 的 GSM8K 实验及其结果表（v2 的 Table 3；v1 的 Table 3 是 SFT 超参），摘要也补了数学推理一句；abs 页注记为 COLM 2026。棋类主表数字两版一致。本篇按 v2。
- **VPS 的「确定性」有边界**：过程真值来自 Stockfish 分析，准确率奖励来自一个学出来的动作价值网络，数值子任务按容差给分；准确率对齐的比较由三个 LLM 裁判打分。数学实验只在 0.6B 模型上做。文中没有单列局限节。
- **VPRM 的金标是合成的**：逐步标签由 Llama 3.1 405B 生成，人工只抽查了 20 例，步骤全对、标签正确率 96.7%（附录 D）。「可验证」是相对这批银标而言。作者自陈方法依赖确定性的领域规则，目前只在偏倚风险评估一个领域验证，且要求模型输出格式与核验器对齐。
- **VPRM 摘要口径**：摘要称比最优模型的 F1 高至多 20%，正文没有说明这个数怎么算，Table 2 里也找不到直接对应的比较（例如 Cochrane Forest 上 VPRM 的 macro-F1 为 76.7，最强的预训练模型 GPT-OSS-120B 为 49.8）；「比可验证结果奖励高 6.5%」与 Table 2 中 76.7 对 70.2 的 macro-F1 相符。
- **VPRM 的 295 条**：§4.3 正文称验证集，Table 1 列在 Test 栏，本篇按正文记作验证。
- **证据来源**：两文结果均为作者自报，没有第三方复现；两文的任务、模型与指标都不同，数字不能横比。
