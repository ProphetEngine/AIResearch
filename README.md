# AIResearch

面向人类阅读的 AI 研究知识库（Obsidian 友好）。这里只放研究成果与内容地图，不放论文附件或工作流水账。

## 怎么开始读

1. 打开 [`Moc/MOC_阅读入口.md`](Moc/MOC_阅读入口.md)。
2. 按阅读目的进入其它宏观 MOC（发展时间线、架构类型、数学原理、研究方向等），全部在 [`Moc/`](Moc/) 下，文件名以 `MOC_` 开头。
3. 再进入各**主题目录**中的原子笔记深读。

## 阅读约定

- 单篇笔记尽量一事一题；用 MOC 串联，而不是靠各目录 README。
- 文中引用为外链，仓库内不存放 PDF 等附件。
