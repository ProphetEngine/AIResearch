# 长程规划记忆：CHIME

> **主要来源**：[CHIME: Credit-Aware Hierarchical Memory Evolution for Long-Horizon Agentic Planning](https://arxiv.org/abs/2609.02074)（Ye 等，厦大 / 浙大 / 阿里，简称 CHIME，v1 2026-09-02）；对照：[MEM1](https://arxiv.org/abs/2506.15841)（Zhou、Qu 等，v2 2025-07-17）、[ReSum](https://arxiv.org/abs/2509.13313)（Wu、Li 等，v3 2026-03-26）（截至 2026-09-02）。
> **研究线**：架构思想（计划库与执行库分层、信用归因门、按信用演化记忆，主）· 评测字段（四个长程工具任务基准的 Avg@3、消融与六个分析问题，辅）
> **范围与相邻笔记**：
> - ≠ [[智能体长程记忆]]：本篇不写 MemGPT 分页与 A-Mem 卡片网络，只写「终局信号如何归到计划还是执行」。
> - ≠ [[MemoryR1强化学习记忆维护]]：本篇不写用 RL 学记忆增删改；CHIME 冻结模型参数，归因靠模型自省。
> - ≠ [[Mem0与Zep生产级记忆]]：本篇不写生产对话记忆层的 API 与时序图。
>
> **意义**：自演化记忆让冻结参数的智能体从任务流中积累经验，但现有方法直接拿任务成败当记忆的监督信号，把计划失误、执行失误和环境噪声混在一起写入。CHIME 先归因再写入，把经验分到计划库与执行库并按信用更新价值，两种骨干上的四基准平均都高于最强基线，τ²-Bench 上只留 129 条记忆（最近基线 3,585 条）；作者据此认为，自演化记忆的效果取决于所存经验的质量，而不是数量。

**一句话**：每局结束后先让模型判断成败该归功或归咎于计划、执行、两者还是都不是，再只更新对应的那一层记忆库，检索时按相似度召回、按信用价值重排。

## 一、问题背景

长程智能体规划有三条改进路径（CHIME §1–2）：测试时搜索多个候选计划（如 WebAnchor），推理开销大，也不跨任务保留经验；训练专门的规划模型（如 TodoEvolve），数据与持续更新代价高；自演化记忆冻结参数，从交互中提炼经验写入外部记忆库，不需训练、可以持续。CHIME 指出第三条路的缺陷：现有方法把终局成败 $s_t\in\{0,1\}$ 直接当记忆的监督，而同一个结果可能来自好计划、执行挽救了坏计划、坏计划、执行出错或环境噪声。后果有两层：偏差经验被写入后反复检索，系统性规划错误累积；执行层或环境层的细节被误当成规划经验，污染高层分解。

## 二、脉络

| 时间 | 工作 | 关键一步 |
|---|---|---|
| 2023-03 | [Reflexion](https://arxiv.org/abs/2303.11366) | 不更新权重，把对任务反馈的语言反思存入情节记忆，指导后续尝试 |
| 2023-08 | [ExpeL](https://arxiv.org/abs/2308.10144) | 跨任务收集经验、提炼洞见，不更新参数 |
| 2025-09 | [ReasoningBank](https://arxiv.org/abs/2509.25140) | 从模型自判的成功与失败轨迹中提炼可泛化的推理策略，检索后再把新经验写回 |
| 2026 | A-MapReduce（CHIME 的最近基线） | 从轨迹提炼提示，但直接用终局结果更新记忆 |
| 2026-09 | CHIME | 先归因再写入，计划与执行分库 |

## 三、方法（§3）

### 3.1 设定

任务以流的形式到来，策略参数冻结，适应全部由外部记忆库 $M_t$ 承担。训练段上边做边更新记忆，评测段冻结记忆库、只检索，因此评测成绩只反映此前累积的经验。

### 3.2 分层记忆库

$M_t=(M_{\mathrm{plan},t}, M_{\mathrm{exec},t})$。计划库存子任务分解、依赖与约束等策略性经验，执行库存工具选择与调用等操作性经验。每条记忆 $m_i=(c_i,e_i,v_i,n_i)$：适用场景、可复用经验、价值 $v_i\in[-1,1]$、被复用次数 $n_i$。检索分两步：先按相似度召回候选，再按校准价值 $\tilde v_i=v_i\cdot n_i/(n_i+\lambda)$ 重排取前 $K$ 条，复用少的记忆价值被打折，相似度仍占主导。

### 3.3 信用归因门

一局结束后，由同一冻结模型做结构化自省：审视任务、计划、轨迹、结果与本局检索到的记忆，输出归因标签 $a_t\in\{$planning, execution, both, none$\}$（成功时表示归功于哪一阶段）、为相应阶段生成的新经验、归因置信度 $\gamma_t\in[0,1]$，以及被判为误导的已检索记忆。

### 3.4 按信用演化

- **价值**：只更新标签指向的那一层。被判误导的记忆得 $-\gamma_t$，成功且所在阶段被归功的记忆得 $+\gamma_t$，其余为 0，以在线平均累积；复用次数够多而价值过低的记忆被剪枝。
- **内容**：新经验与已有条目足够相似则合并，否则插入；置信度不足或内容不可执行则丢弃。

## 四、实验（§4–5）

**设置**：τ²-Bench（多轮客服）、VitaBench（多轮生活服务、意图漂移、大工具空间）、BrowseComp-ZH（长程中文信息检索）、BFCL-v4（Live 与长程智能体函数调用）。每个基准按任务流 7:3 分训练与评测，三种随机顺序取 Avg@3。骨干为 Qwen3.5-Flash（35B 总参 / 3B 激活）与 DeepSeek-V4-Flash（284B / 13B），计划、执行与归因用同一骨干。基线由远及近：不做规划、WebAnchor（测试时计划搜索）、TodoEvolve（训练元规划器）、A-MapReduce（从轨迹提炼提示，直接用终局更新记忆）。

**主结果（Table 1，评测段平均）**：Qwen3.5-Flash 上 CHIME 34.87，比最强基线高 2.96；DeepSeek-V4-Flash 上 39.01，高 3.68。单个基准有例外：DeepSeek 骨干的 BFCL-v4 上 A-MapReduce 69.98 高于 CHIME 67.15。

**消融（Table 2，Qwen3.5-Flash 评测段，完整 CHIME 34.87）**：

| 去掉 | 评测平均 |
|---|---:|
| 执行库 | 30.06 |
| 分层（并成一个共享库） | 31.27 |
| 计划库 | 31.61 |
| 记忆演化 | 31.83 |
| 归因门（退回终局直接写入） | 32.43 |
| 信用重排 | 32.83 |

作者的解读是，增益来自阶段专用的经验与显式分库，而不是「多记一点」。

## 五、分析（§6）

- **记忆质量（Table 3）**：外部模型评训练段记忆库，CHIME 综合分 81.04，A-MapReduce 36.08，去掉归因门后 21.38。
- **演化效率**：τ²-Bench 任务流结束时 CHIME 只留 129 条记忆，A-MapReduce 留 3,585 条，CHIME 准确率仍最高；两组对照在 75% 检查点后准确率下滑，作者归因于无归因写入的误导记忆不断累积。
- **价值是否有用**：按价值分低、中、高三组，计划记忆的准确率从 21.7% 升到 50.8%，执行记忆从 23.7% 升到 35.4%，计划层的高价值记忆作用更大。
- **归因门可靠性（Table 4）**：三次重采样与原标签一致 87.8–97.9%；只带新生成记忆重跑失败任务，56.3–67.6% 的归因失败得到纠正。
- **更强的归因模型（Table 5）**：归因门换成 Qwen3.7-Flash 后，τ²、Vita、BFCL 评测段分别再高 3.12、2.50、2.25（单次运行）。
- **跨骨干迁移（Table 6）**：把一个骨干积累的记忆库冻结后给另一骨干用，CHIME 比 A-MapReduce 高 2.25–4.68 个百分点。

## 六、对照：MEM1 与 ReSum

- **MEM1**：长程多轮任务若把全部思考、动作与观察拼进上下文，成本与长度外推都会恶化；MEM1 每步更新一个紧凑的内部状态，丢弃冗余，以端到端 RL 训练，实现常量大小的记忆。它压缩的是上下文，CHIME 管的是外部记忆写入前的信用。
- **ReSum**：网页智能体周期性调用外部摘要工具压缩交互历史，再从摘要续探；不训练即比 ReAct 平均高 4.5%，再做 ReSum-GRPO 训练又高 8.2%（摘要）。它管理单条搜索轨迹的上下文，不跨任务积累经验。

## 七、意义

CHIME 把强化学习中的信用分配问题搬到了不训练参数的记忆系统里：同样是「从经验中学」，写入什么、写到哪一层，比写入多少更重要。计划与执行分库、先归因再写入，使记忆库更小、更干净，也更容易跨骨干复用；归因门换成更强模型还能继续提升，说明这一机制的上限随模型自省能力上升。

## 八、局限与待核实

- **受限于骨干能力**（附录 B）：记忆只提供指导，不改变骨干；即便归因正确，重跑也只纠正了 56.3–67.6% 的失败。
- **跨基准迁移弱**（附录 B）：同一基准内跨骨干可以迁移，换基准后工具、动作与成功标准不同，语义相似不保证经验适用。
- **归因依赖自省**：归因门用的是同一冻结骨干，Table 5 的更强归因模型结果只跑了一次，不是 Avg@3。
- **代码未发布**：论文写明代码将在 ATH-MaaS/Marco-DeepResearch 发布；该仓库 README 的新闻栏只列出 CHIME 论文链接，`Marco-DeepResearch-Family` 目录下尚无 CHIME 代码。
