# Multi-Agent Debate（MAD）：多样性·置信度·反共识机制

> **定位**：多智能体辩论主题轴——仓库无 MAD 专篇；近窗 ACL Findings 与 arXiv 把「vanilla MAD ≈ 多数票且更贵」写成可核共识，新工作转向 **多样性初始化、置信度调制、去共识决策、动态路径/过程审计、分歧分层测量**。
> **攻坚线**：**架构思想（主）**——辩论协议与失败模式；**评测字段（辅）**——相对 majority vote / SoM 的增益、轮次与 token、分歧是否「真」。

### 2.2 失败模式口诀（跟读）

`
同质初始化 → 共享错误路径 → 辩论退化成多数票（更贵）
从众/谄媚 → 正确少数被说服 → Silent Agreement / 错误传播
末轮投票 → 忽略中间轨迹 → 僵局随机破、正确曾出现却丢
表演性分歧 → 语气指令改「说什么」→ 不改持久立场 / 终答质量
`

诊断锚点（Demystifying 引 Choi et al. 2025）：同质 + 未加权更新 ⇒ $E[p_{i,t}\mid\mathcal{F}_{t-1}]=p_{i,t-1}$（信念正确率过程为鞅）⇒ **期望上不能系统超过多数票**。

## 三、主文 A · Demystifying：多样性管「谈什么」，置信度管「怎么聚」

### 3.1 Vanilla MAD 形式（§3）

- $N$ 个同质 agent；$t=1$ 独立采样；$t>1$ 见上轮全集 $R_t$ 后用提示修订算子 $D$ 更新。
- 终答 = 对 $\{y_{i,T}\}$ 做 **majority vote**。
- 对照：无交互的 majority vote（式 2）。

### 3.2 干预 1：多样性感知初始化（§4.1）

- 多样性 $\mathrm{div}(S)=|\mathrm{unique}(S)|$。
- 先采 $N_{\mathrm{cand}}\ge N$（实验 **$N_{\mathrm{cand}}=10$**），再贪心选 size-$N$ 子集最大化 div（训练免费）。
- **命题 1**：若成功概率对初始相异假设数非减，且多样性初始化在 $S$ 上随机采样一阶随机占优，则 $P(A_T\mid\mathrm{diverse})\ge P(A_T\mid\mathrm{random})$——**只抬先验，不改后续鞅动力学**。

### 3.3 干预 2：置信度调制辩论（§4.2–4.3）

- 输出扩成 $(y_{i,t}, w_{i,t})$，$w\in\{0,\ldots,10\}$。
- 挑战：口头置信常 **过自信**；且「说了」≠「会用」。
- **校准表达**：二值交叉熵风格 log-reward（式 10），用 RL 训口头数值置信。
- **感知与使用**：对辩论更新算子再加正确性 + 校准奖励（式 11），使更新 **显式条件于他人置信**。
- 训练：GRPO + LoRA；推理 temp **1.0**、nucleus $p=0.9$；设置 **5 agents × 5 turns**。

### 3.4 理论：置信加权 ⇒ 严格下鞅（§5.2 Theorem 1）

在 DCM + 置信与正确性正相关假设下，$E[p_{i,t}\mid\mathcal{F}_{t-1}]\ge p_{i,t-1}$（正概率严格）——**打破鞅对称，期望向正确答案漂移**。多样性与置信度被作者写成 **互补**：一个改初始支撑，一个改聚合动力学。

### 3.5 实证要点（Table 1 / Table 2）

设置：Qwen-2.5-7B-Instruct、Llama-3.1-8B-Instruct；域内 GSM8K / CSQA / HellaSwag / MMLU（含 FL、PM）；OOD GPQA、ARC-C。

| 观察（文内） | 数字锚 |
|---|---|
| Vanilla Debate **5×5** 常 ≤ Majority Vote | 例：Qwen GSM8K Debate **0.847** vs MV **0.908**；CSQA **0.727** vs **0.808** |
| 初始多样性 vs 辩论增益相关（弱但显著） | Table 2：Qwen $r=0.070$ $p<0.001$；Llama $r=0.019$ $p=0.002$（$n=26624$） |
| HD + Confidence 常领先同组 | 例：Qwen GSM8K **0.932**、CSQA **0.828**、GPQA **0.361**；Llama MMLU-PM **0.842**、GPQA **0.352** |
| Sankey（Fig.2）：置信调制后「改对」流更明显 | 文述；细分数 **待核实读图** |

**跟读：** 钱砸在多轮交互上，若不开多样性、不教置信加权，协议结构上就在「重演多数票」；两刀是轻量、可分阶段加的。

## 四、主文 B · FREE-MAD：共识不是目标，全轨迹打分才是

### 4.1 两阶段分解（§3.1）

$$
\{r_i^R\}_{i=1}^N \leftarrow \mathrm{Debate}(\{a_i\}, q, p, R),\quad
r_{\mathrm{final}} \leftarrow \mathrm{Decide}(\{r_i^R\}).
$$
作者把生成写成独立推理 $P_{\mathrm{in}}$ × 从众项 $\exp(\beta(p)\,S_{\mathrm{con}})$（式 4）：中性提示下 $\beta_{\mathrm{default}}>0$（倾向从众）；批判性提示可使 $\beta<0$（反从众正则）。

### 4.2 共识型 MAD 的三类伤（§3.2 + Fig.1）

1. **准确率**：决策只看末轮 $N$ 条，丢掉 $R\times N$ 中间答案；过早共识锁死错误；甚至初答多数票优于辩后。
2. **可扩展性**：共识常要 2–3 轮；token 复杂度文引 $O(NR^2 V + N^2 RV + NR|q|)$。
3. **安全/公平**：通信打断拖垮共识；角色辩论加剧偏见；LLM-as-Judge 易塌成变相多数票。

### 4.3 协议重构（§4）

**共识自由辩论（Anti-conformity）：** 在「他人回答如下」前缀后附加 CoT 场景——假设有对抗性同伴；仅在清晰证据表明自己错时才改信念，**不以共识为目标**。
**分数决策（Algorithm 1）：** 矩阵 $A\in\mathbb{R}^{N\times(R+1)}$ 记全轨迹；字典 $S$ 对候选答案计分：

- 初轮：$S[\hat r]\mathrel{+}=w_1 f$，$f=(k+1)^{-1}$（越后轮越打折，抑制晚期从众）。
- 改口：旧答案 $-\,w_2 f$，新答案 $+\,w_3 f$（弃旧≈更可能错，采纳≈更可能对）。
- 坚持：$+\,w_4 f$。
- 实验权重初始化 $W=\{20,25,30,20\}$。
- $\arg\max S$；并列则随机（理论稳健性）。

**双方案：** FREE-MAD-**N**（反从众辩论 + 分数）与 FREE-MAD-**C**（从众辩论 + 分数）——从众是双刃剑，简单任务过度反从众会「固执」。

相对 SoM 基线实现，以减混淆；Table 1 宣称在 Decision / Anti-Conformity / Fairness / Security 维优于 Sparse MAD、Liang Judge、ReConcile、ChatEval、DMAD、SoM 等（作者对照表，非独立复现声明）。

### 4.4 实证（R=1 主结果 + 安全 + 消融）

- **8 基准**：GSM-Ranges L4/L6、AIME2024/2025、MATH500、StrategyQA、MMLU Logical Fallacies、AICrypto；AIME 用 N=3（Qwen1.5-7B-Chat + DeepSeek-V3），其余 N=4（+ Qwen2.5-72B-Instruct）。
- **R=1 平均准确率（Table 3）：** FREE-MAD-N **64.43%**（相对两基线 ↑16%/↑19%）；FREE-MAD-C **61.41%**（↑10%/↑14%）；Baseline1 **55.73%**、Baseline2(SoM) **54.06%**。文述平均改进约 **13.0% / 16.5%**。
- **R=2（Table 4，子集 AVG）：** N **70.42** / C **69.17** vs B1 **62.50** / B2 **62.71**。
- **难度**：数学题越难，去从众优势越明显；知识薄弱时 **C 优于 N**（反从众乱换思路）。
- **安全（Fig.4）：** 通信攻击下分数机制仍可用；退出者主要触发「坚持」分支，决策在 LLM 外确定性执行。细格数字 **待核实读图**。
- **可扩展（Fig.5）：** 宣称少轮即可达更高准确–token 前沿；相对单模仍贵（Limitations）。

**跟读：** FREE-MAD 把「要不要共识」从协议默认里拿掉——辩论负责生产可审计轨迹，决策负责 **跨轮计分**；反从众是可开关旋钮，不是道德口号。

## 五、可选对照 C · DynaDebate：用「路径」而不是「答案集合」破同质

### 5.1 三阶段（§3）

1. **Dynamic Path Generation & Allocation：** Path Generation Agent $\Phi_{\mathrm{gen}}$ 产 $K\le N$ 条 **逻辑合理且互独立** 的解题路径；Round-Robin 分配（$K\approx N$ 探索；$K<N$ 同路径冗余做一致性检查）。
2. **Process-Centric Debate：** 首轮严格沿路径展开原子步骤；后续轮做 **First-Principles Audit**（查计算/事实错 + 步骤迁移有效性），而非看流畅度或只比终答。
3. **Trigger-Based Verification：** 仅当终答分歧时激活 Verification Agent，调代码执行/搜索等外部工具注入参考意见；全员一致则提前停。

> 划界提醒：工具调用细节 → 不展开为 [[智能体工具与长程任务]]；此处只记「死锁时外部证据」协议位。

### 5.2 主结果与消融（Table 1 / 2；3 agents × 2 rounds；mean±std over 3 runs）

**Qwen3-8B 上 DynaDebate 全面领跑该块：** MATH500 **82.17**、AIME24 **35.56**、AIME25 **27.78**、MMLU **82.44**、GPQA **46.38**（对比 SoM 28.89/26.67/…、MAD 更弱）。
**GPT-4o-mini / Llama-3.3-70B：** 多数列最优或次优；例外：Llama MMLU 上 Self-Contrast **87.78** > Dyna **86.96**；GPT-4o-mini AIME25 Self-Contrast **16.67** > Dyna **13.33**（作者称落在「难度–多样性」假说靶心外）。
**消融（Qwen3-8B）：** 去路径生成在 AIME 上掉最狠（24：**35.56→28.89**；25：**27.78→21.11**）；去过程审计各集普降；去验证在最难集代价最大（AIME24 **−6.67**），且验证触发在 AIME 约 **80–90%**（Appendix I，文述）。

**跟读：** 与 Demystifying「答案集合多样性」同族但更硬——**先分配异构推理路径**，再辩「步骤对不对」，最后才必要时请外部裁判。

## 六、可选对照 D · 分层分歧：表面吵 ≠ 答案好

开放题 GlobalOpinionQA 上 **750** 场三模委员会辩论；语气三档：**friendly / neutral / hostile**。四层仪器：

| 层 | 测什么 | 主结果（文内） |
|---|---|---|
| **A** | 自报同意度 | friendly→hostile 全同意率差 **50.4pp**（**74.8%→24.4%**）；1 轮后已有 **45.0pp** 缺口 |
| **B** | 条件盲文本法官：回复是否真在 push back | 同模式；标签与文本大致 1:1；「只声称反对、文本没有」极少 |
| **C** | 删掉 eliciting 指令后再问：立场是否持久 | 首轮 turn-weighted：删敌意指令后向同意回退比保留指令对照高 **23.1pp**；题加权 $p=0.0625$（方向在、未定论）；并全部轮次 $p=0.016$；首轮回退中仅 **11/28** 也出现在新文本 |
| **D** | 开源模型 logprob 立场边距 | 对手论证更常 **削弱边距** 而非稳定改方向 |
| **产物** | 辩 vs 不辩终答质量 | 顺序互换一致的陪审团：**299/299 平局**（只能排除大差距）；无偏置检查时曾误报辩论赢 **66%**（读序伪影）；可验证控制任务准确率不变；235 题 web-research 上「可见同伴草稿」相对独立修订 **+0.9pp**（预注册等价界内） |

## 八、误区与交叉

1. **「多开几个 agent 辩论就会更好」** → 同质 + 未加权更新下期望是鞅；先比 majority vote / token。
2. **「共识 = 正确」** → FREE-MAD：共识可锁错；Silent Agreement；末轮票丢中间正确轨迹。
3. **「让模型报置信就够了」** → Demystifying：要校准 **且** 要学会读他人置信；过自信是默认。
4. **「persona / 敌意语气 = 真多样性」** → Layered：语气猛改 A/B，持久立场与终答证据弱；路径/答案支撑多样性更靠近 Demystifying/DynaDebate。
5. **「外部工具一加就赢」** → DynaDebate 附录称同工具单代理仍弱于完整框架（文述）；工具是死锁触发器，不是本篇主轴（≠ [[智能体工具与长程任务]]）。

**交叉：** 测试时缩放谱系见 [[推理时扩展TestTimeScaling]]；异构聚合 MoA/TUMIX → [[MixtureOfAgents与TUMIX]]；工具环产品面 → [[智能体工具与长程任务]]；合成评测用户 → [[合成用户仿真]]。
