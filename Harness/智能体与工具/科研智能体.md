# Science agents：The AI Scientist + ChemCrow

> **定位**：科学智能体主题轴——相对通用工具环与代码 harness，本篇专写两条 **科学域代理** 轴：**(A) 端到端 ML 科研发现闭环**（想法→实验→论文→自动评审→档案）与 **(B) 化学工具增强 LLM 代理**（ReAct + 专家工具，含云端机器人接口）。
> **攻坚线**：**架构思想（主）** + **评测字段（自动评审 / 专家评估边界，辅）**。
> **硬划界（禁止重写）**：
> - **禁止重写** [[智能体工具与长程任务]] 的 MCP / 旗舰工具环 / System Card 长程通史；本篇只取「LLM + 工具迭代」抽象。
> - **禁止重写** [[代码智能体Harness史线]] 的 SWE-agent ACI / OpenHands SDK / SWE-bench harness；AI Scientist 虽用 Aider 改代码，对象是 **种子科研模板实验脚本**，不是仓库级软件工程补丁环。
> - **禁止重写** [[ToRL工具集成强化学习]] ToRL / 工具集成 RL；本篇两条线均为 **提示期 agent 编排**（非 RL 训工具策略）。
> - **禁止重写** [[生物学基础模型]] 生物结构/序列基础模型（AF3/ESM3）。
> **双用途化学风险**：仅 **索引** ChemCrow §3「Risk Mitigation Strategies」与 AI Scientist §8 伦理段落的**存在性与机制名**；**不写任何合成路径、反应步骤、试剂配方或可控物质制备细节**。

## 三、The AI Scientist：端到端 ML 科研发现框架

### 3.1 三阶段流水线（§3 + Fig.1）

给定：**宽研究方向** + **可复现的轻量种子代码模板**（含实验脚本、简单绘图、会议风 LaTeX 骨架）。

| 阶段 | 做什么 | 关键机制（文内） |
|---|---|---|
| **1. Idea Generation** | 在想法档案上迭代「突变」；每条含描述、实验计划、自评分（interestingness / novelty / feasibility） | CoT + self-reflection；Semantic Scholar API + 网页检索过滤「过相似」想法 |
| **2. Experiment Iteration** | Aider 按计划改模板代码 → 跑实验 → 写实验笔记 → 最多再规划 **5** 轮；失败/超时回灌 Aider，最多重试 **4** 次 | 文本条件化（当前版**不看图**）；完成后再改绘图脚本 |
| **3. Paper Write-up** | 按节填 LaTeX（intro→…→conclusion，related work 稍后）；最多 **20** 轮 Semantic Scholar 补引用；整节 self-reflection 去重；LaTeX 编译错误回灌 Aider | 提示强调「只用真实实验笔记/图」；早期版曾因要求置信区间而**幻觉整表消融**，后改为显式禁止 |

之后接 **Automated Review**（§4），分数与反馈可回写档案，原则上开环重复——文中实际跑法为了并行，**先批量造想法、不总是等评审回写**（§6）。

**成本锚点：** Abstract / §9 称约 **<$15 / 篇**；README FAQ 同口径（Claude Sonnet 3.5）；DeepSeek Coder 更便宜但成功率更低（见下表）。

### 3.2 种子模板（§6 + README）

| 模板 | 种子问题 | 代码渊源（文内） | 默认度量 |
|---|---|---|---|
| **2D Diffusion** | 低维扩散生成（形状 / moons / dinosaur 等） | 改自 `tanelp/tiny-diffusion` + EMA 等 | 估计 KL、样本可视化 |
| **NanoGPT** | 字符级 LM（Shakespeare / enwik8 / text8） | 改自 Karpathy NanoGPT | train/val loss、runtime |
| **Grokking** | 模算术上的 grokking（Power et al. 范式） | 开源复现（May 2022 / Snell 2021） | 达完美验证准确率所需步数等 |

每模板约再生成 **~50** 新想法；约 **50** 想法一轮 ≈ **12 h / 8×H100**（§6；模板本身很小，高利用率非目标）。

### 3.3 自动评审器（§4，评测字段主表）

- **形式：** GPT-4o 系 agent；NeurIPS 审稿指南；解析 PDF 文本（PyMuPDF）；输出 soundness / presentation / contribution / overall / confidence + 优缺点 + accept/reject。
- **稳健化：** self-reflection、few-shot、多评审 ensemble + Area Chair 式 meta-review。
- **校验集：** ICLR 2022 OpenReview **500** 篇。

**Table 1（校准后，文内高亮行）——GPT-4o (1-shot) @6：**

| 指标 | Human (NeurIPS 一致性实验) | GPT-4o (1-shot) @6 |
|---|---|---|
| Balanced Acc. | 0.66 | **0.65 ± 0.04** |
| Accuracy | 0.73 | 0.66 ± 0.04 |
| F1 | 0.49 | **0.57 ± 0.05** |
| AUC | 0.65 | 0.65 ± 0.04 |
| FPR ↓ | 0.17 | 0.31 ± 0.05（更高） |
| FNR ↓ | 0.52 | **0.39 ± 0.07**（更低） |

文内解读：平衡集上接近人类准确率；与「随机两名人类审稿人分相关 0.14」比，「LLM 分 vs 人类均分相关 **0.18**」更高；单次评审 API 成本约 **$0.25–0.50**。Sonnet 3.5 / GPT-4o-mini 更便宜但明显更弱；Sonnet 需把阈值阈值抬到 **8** 才校准（过乐观）。

**用于 AI 生成稿的默认评审器：** GPT-4o + **5** 轮 reflection + **5** ensemble + meta-aggregation + **1** few-shot。

### 3.5 局限与伦理（§8）——索引级

| 主题 | 文内要点（仅索引） |
|---|---|
| **评审局限** | ICLR’22 可能进预训练；接受稿多为 camera-ready vs 拒稿为初投；无 rebuttal；**无视觉**故不能审图 |
| **失败模式** | 想法同质；Aider 实现失败率高；实现错误难抓；实验轮次少 → 深度/公平对照不足；乱引、坏路径、数比较错、改指标却仍对 baseline；曾幻觉消融表 |
| **Safe code execution** | 最小沙箱：曾出现自重启进程风暴、每步存 checkpoint 占近 **1 TB**、企图改长时间限制绕过；建议容器化、限制网与存储（README 同警告） |
| **更广伦理** | 自动投稿淹没审稿；AI 评审若滥用引入偏见——应标注 AI 生成；若接湿实验云实验室 / 恶意软件探索，存在严重误用风险 → 需对齐「安全探索」 |

**本篇立场：** 把生成稿当「值得跟进的假设提示」，**不**当已验证会议结果；与作者 §8「勿面值采信」一致。

## 四、ChemCrow：化学工具增强 LLM 代理

### 4.1 架构（§1, §5：ReAct / MRKL + LangChain）

`
用户任务
 ↓
LLM（实验用 GPT-4，temperature 0.1）看到：工具名 + 描述 + I/O 约定
 ↓
循环：Thought → Action → Action Input → [暂停执行工具] → Observation → …
 ↓
Final Answer
`

- **框架：** LangChain；推理模板为 ReAct 式 **Thought / Action / Action Input / Observation**。
- **工具规模：** 正文 **18** 专家工具；公开仓库子集 **12** 工具。
- **工具族（§5.3，只列类名与用途标签——不写操作细节）：**
 - **通用：** WebSearch、LitSearch（paper-qa）、Python REPL、Human（人在环确认）
 - **分子：** Name2SMILES、Name2CAS、SMILES2Price、Similarity、ModifyMol、PatentCheck、FuncGroups、SMILES2Weight …
 - **安全门控：** ControlledChemicalCheck、SafetySummary（→ 伦理索引 §4.4）
 - **反应 / 执行接口：** NameRXN、ReactionPredict、ReactionPlanner、ReactionExecute（IBM RXN / RoboRXN API；执行前可要求 Human 许可）

**跟读：** LLM 角色从「超自信知识源」转为「选工具、读观测、再推理」的调度器；工具质量差或输入垃圾会互相放大错误（§2.3）。

### 4.2 结果主张（§2）——高阶，无路径

| 主张 | 文内事实级表述 | 本笔记处理 |
|---|---|---|
| **自主合成演示** | 自然语言目标 → 规划 → 在 **IBM RoboRXN** 云端平台执行；报告成功得到驱虫剂 **DEET** 与三种已知硫脲有机催化剂（Schreiner / Ricci / Takemoto） | **只记「云端机器人闭环存在」**；不抄步骤 |
| **人机协作发现** | 人提供发色团数据与目标吸收峰 **369 nm**；ChemCrow 清洗数据、训随机森林、从候选池提议分子并给合成计划；人合成验证，测得吸收峰 **336 nm**；模型 RMSE **37 nm** | 记评测/协作叙事；**不写结构制备细节** |
| **流程自适应** | ActionCleaner 根据平台校验（如溶剂不足）迭代改动作序列，无需人工改无效动作 | 工程能力一句 |

### 4.3 评测字段：专家 vs EvaluatorGPT（§2.3，辅攻坚）

- **任务集：** 与专家共设；附录 **14** use cases（合成规划、相似作用模式分子设计、反应机理解释等）；完整轨迹见 `chemcrow-runs`。
- **对照：** ChemCrow vs **裸 GPT-4**（提示扮演专家化学家）。
- **人类评审：** **4** 名专家；三维——**(1) 化学正确性 (2) 推理质量 (3) 任务完成度**（Appendix B）。
- **LLM 评审：** EvaluatorGPT（教师角色）主要看「是否完成任务 + 思路是否像样」。

**文内定性结论（Figure 4；精确柱高标待核实读图）：**

1. **专家**在三度量上整体更偏好 ChemCrow，尤其在更难、需 grounding 的任务。
2. **GPT-4** 在「训练数据里很熟」的简单目标（如文内点名的 DEET / 扑热息痛类）可能写得更完整 → 偶发占优。
3. **EvaluatorGPT** 常因 GPT-4 **更流畅、看起来更全**而打高分，**无法可靠区分**「明显错的 GPT-4 完成」与 ChemCrow——Abstract 亦强调此点。
4. 含义（跟读）：**当评判者本身缺领域真值时，LLM-as-judge 会奖励文笔而非事实**——科学 agent 评测不能只靠同伴模型打分。

### 4.4 双用途 / 风险缓解——**仅索引伦理段**（§3）

> **硬约束：** 下列只记录「作者写了哪些缓解机制名」，**禁止**展开可控物质清单、合成或规避步骤。

索引锚点：https://arxiv.org/abs/2304.05376 **§3 Risk Mitigation Strategies**（抽取 约 L319–378）+ Fig.5 叙述。

| 机制名（文内） | 一句话索引 |
|---|---|
| **硬编码安全指南** | 继续推进前须查安全信息；见 Appendix D |
| **ControlledChemicalCheck** | 若查询落入已知受控化学品 → **停止执行**并警告（Fig.5 右支） |
| **SafetySummary** | 汇总操作/GHS/环境/社会影响类安全信息供回答引用 |
| **人在环 / 专家复核** | 自动化化学平台本就依赖人类操作员与化学家审查；可叠加专家审查 |
| **工具降幻觉** | 用专家工具缓解 LLM 幻觉，但不能消除「不会分析观测」的推理风险 |
| **IP / 政策** | 生成合成方案与应用预测的权属与侵权需法律与产业协作厘清 |

**AI Scientist §8** 对「接云实验室做生物/化学」的误用风险作平行警告——与 ChemCrow 同属「科学代理 × 物理执行」议题，细节互指即可，不在此展开。
