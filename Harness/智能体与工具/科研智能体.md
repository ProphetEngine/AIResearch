# Science agents：The AI Scientist + ChemCrow

> **主要来源**：[The AI Scientist: Towards Fully Automated Open-Ended Scientific Discovery](https://arxiv.org/abs/2408.06292)（Lu、Lu、Lange、Foerster、Clune、Ha，Sakana AI 等，简称 AI Scientist，v3 2024-09-01）；[ChemCrow: Augmenting large-language models with chemistry tools](https://arxiv.org/abs/2304.05376)（Bran、Cox 等，EPFL / Rochester / IBM，简称 ChemCrow，v5 2023-10-02）；[SakanaAI/AI-Scientist README](https://github.com/SakanaAI/AI-Scientist)（截至 2026-09-14）。
> **研究线**：架构思想（科研闭环编排、领域工具调用，主）· 评测字段（自动评审与人类审稿的一致性、专家评估与 LLM 评估的分歧，辅）
> **范围与相邻笔记**：
> - ≠ [[智能体工具与长程任务]]：本篇不写 MCP 与通用工具环，只取「LLM 调工具多步迭代」这一抽象。
> - ≠ [[代码智能体Harness史线]]：AI Scientist 用 Aider 改代码，但对象是小型科研模板的实验脚本，不是仓库级软件工程。
> - ≠ [[开端性与发现基础模型]]：本篇不写自改进智能体与「发现基础模型」的范式定义。
> - 双用途化学风险只记作者写了哪些缓解机制，不写任何合成路径、试剂或受控物质细节。
>
> **意义**：ChemCrow 表明，把通用 LLM 接上领域专家工具，它就能从「背化学」变成「调度工具、读观测、再推理」，并能驱动云端机器人完成合成；AI Scientist 则把想法生成、实验、论文写作与同行评审串成可循环的端到端流程，每篇论文成本约 15 美元。两者也一起暴露了科学智能体评测的核心难题：缺乏领域真值的 LLM 裁判会奖励流畅而非正确。

**一句话**：AI Scientist 在小型 ML 代码模板上自动完成「想法 → 实验 → 论文 → 自动评审」；ChemCrow 用 ReAct 循环调度 18 个化学工具。前者的风险是论文看似合格而实验有误，后者的教训是 GPT-4 当裁判分不清流畅的错误答案。

---

## 一、问题背景

LLM 在科研中的早期用法多是单点加速：帮忙构思、写稿或预测反应。AI Scientist 的作者认为（§1），单点加速不等于完整的科学过程。在化学等专业领域，裸 LLM 常常「自信而错误」，计算与查证都不可靠，需要把回答锚定到外部数据库与计算工具上（ChemCrow §1）。

## 二、脉络

| 时间 | 工作 | 关键一步 |
|---|---|---|
| 2022-10 | [ReAct](https://arxiv.org/abs/2210.03629) | 推理与行动交替的提示框架，ChemCrow 的循环模板 |
| 2023-04 | ChemCrow；[Coscientist](https://arxiv.org/abs/2304.05332)（Boiko 等） | 同月出现的两套化学智能体：前者接 18 个专家工具与 RoboRXN，后者组合多个 LLM 自主设计并执行实验 |
| 2024-08 | AI Scientist | 端到端 ML 科研闭环与校准过的自动评审 |
| 2025-04 | [AI Scientist-v2](https://arxiv.org/abs/2504.08066) | 去掉对人工代码模板的依赖，用智能体树搜索管理实验；一篇全自动生成的论文通过 ICLR 研讨会同行评审 |

## 三、The AI Scientist

### 3.1 三阶段流程（§3）

输入是一个宽泛的研究方向和一个可运行的轻量代码模板（实验脚本、绘图与 LaTeX 骨架）。

| 阶段 | 做什么 | 关键机制 |
|---|---|---|
| 想法生成 | 在想法档案上迭代变异，每条带实验计划和趣味性、新颖性、可行性自评 | 思维链与自反思；用 Semantic Scholar 检索过滤与已有工作过于相似的想法 |
| 实验迭代 | Aider 按计划改模板代码、跑实验、记笔记，再规划下一轮 | 失败或超时把报错交回 Aider，最多重试 4 次；只读文本结果，不看图 |
| 论文写作 | 按节填写 LaTeX，最多 20 轮检索补引用，整节自反思，编译错误交回 Aider | 提示要求只用真实实验笔记与图；早期版本曾凭空写出整张消融表，后改为明确禁止 |

之后由自动评审给出分数与意见，原则上可写回档案、循环往复；实际运行时为了并行，先批量生成想法（§6）。三个官方模板是 2D 扩散、NanoGPT 字符级语言模型与 grokking，每轮约 50 个想法，在 8 张 H100 上约需 12 小时。

### 3.2 自动评审（§4，Table 1）

GPT-4o 按 NeurIPS 审稿指南读论文文本，输出各维度分数与接收或拒绝；用 ICLR 2022 OpenReview 的 500 篇论文校验。最佳配置（5 轮自反思、5 份评审集成、1 个示例）与 NeurIPS 一致性实验中的人类审稿人相比：

| 指标 | 人类 | GPT-4o（1-shot，阈值 6） |
|---|---:|---:|
| 平衡准确率 | 0.66 | 0.65 |
| F1 | 0.49 | 0.57 |
| 假阳性率 | 0.17 | 0.31 |
| 假阴性率 | 0.52 | 0.39 |

LLM 分与人类平均分的相关为 0.18，高于随机两位人类审稿人之间的 0.14；每份评审 API 成本约 0.25–0.50 美元。代价是假阳性率更高，即更容易放过不该接收的论文。

### 3.3 生成论文的结果（§6，Table 3–5）

以 Claude Sonnet 3.5 驱动时质量最好，自动评审均分在三个模板上为 3.82（扩散）、4.05（语言模型）、3.44（grokking），最高 6.0（约合「弱接收」）；质量排序为 Sonnet 3.5 > GPT-4o > DeepSeek Coder > Llama-3.1 405B。每个模板约 50 个想法的整轮成本，Sonnet 3.5 约 250 美元，DeepSeek Coder 约 10 美元但完成度更差；GPT-4o 常写不出可编译的 LaTeX。作者提醒，NanoGPT 模板上模型可能通过「偷看未来 token」一类改动刷低困惑度，自动评分不能替代人工检查代码。

### 3.4 失败模式与安全（§8）

- **评审**：ICLR 2022 论文可能已在预训练语料中；没有 rebuttal；不看图。
- **生成**：想法同质；实现失败率高且错误难发现；实验轮次少，对比不够公平；出现错误引用、数值比较错误、改了指标仍与旧基线比较等。
- **代码执行**：曾出现自我重启造成进程失控、每步保存检查点占用近 1 TB 存储、试图修改时间限制等情况；作者建议容器化并限制网络与存储。
- **更广的伦理**：大量自动投稿会冲击审稿；若接入云端湿实验室，存在严重误用风险。

## 四、ChemCrow

### 4.1 架构（§1、§5）

基于 LangChain，用 GPT-4 驱动 ReAct 式的「思考 → 行动 → 行动输入 → 观测」循环，直到给出最终答案。正文共 18 个专家工具，公开仓库提供其中 12 个。工具分四类：通用（网页搜索、文献问答、Python、请人确认）、分子（名称与结构转换、价格、相似度、专利、官能团等）、安全（受控化学品检查、安全信息汇总）、反应与执行（反应预测与规划、通过 IBM RoboRXN 执行，执行前可要求人工许可）。LLM 的角色从知识源变成调度器；工具质量差或输入有误时，错误也会相互放大（§2.3）。

### 4.2 结果（§2）

- **云端机器人合成**：从自然语言目标出发，规划并在 IBM RoboRXN 上执行，成功得到驱虫剂 DEET 和三种已知的硫脲有机催化剂；平台校验出问题时能自动修改动作序列。
- **人机协作发现**：人提供发色团数据与目标吸收波长 369 nm，ChemCrow 清洗数据、训练随机森林、提出候选分子；人工合成后测得吸收峰 336 nm。
- **评估分歧**：在与专家共同设计的 14 个用例上，4 位化学专家从化学正确性、推理质量、任务完成度三方面评分，整体更偏好 ChemCrow，尤其是需要外部数据支撑的难题；对训练数据中很常见的简单目标，裸 GPT-4 有时写得更完整。作为对照的 EvaluatorGPT 却常因 GPT-4 回答更流畅而给高分，无法可靠区分明显错误的回答与 ChemCrow 的回答。

### 4.3 风险缓解（§3，仅记机制名）

硬编码的安全指引；受控化学品检查（命中即停止并警告）；安全信息汇总；人在环与专家复核；工具可以减少幻觉，但不能消除模型误读观测的风险；生成合成方案的知识产权问题需另行厘清。

## 五、两者对照

| 维度 | The AI Scientist | ChemCrow |
|---|---|---|
| 科学对象 | ML 算法与现象 | 有机合成、药物与材料相关任务 |
| 外部真值 | 实验脚本跑出的数值与图、文献 API | 化学数据库、反应预测 API、机器人平台反馈 |
| 成品 | 可编译的会议格式论文与自动评审 | 自然语言答案与平台执行记录 |
| 评测难点 | 自动评审接近人类但假阳性率高，生成论文需人工验证 | 专家偏好与 LLM 裁判偏好相反 |
| 安全 | 代码沙箱、投稿与评审滥用、湿实验接入 | 受控物质检查、安全汇总、人在环 |

## 六、意义

两篇代表了科研智能体的两种形态：AI Scientist 追求流程完整，把整个科研周期交给模型，在可控的小型 ML 模板上验证可行性与成本；ChemCrow 追求领域深度，用专家工具补足模型的专业短板，并触及物理执行。它们共同说明，科学智能体的上限不只取决于模型，也取决于外部真值源与评测者是否具备领域判断力；AI Scientist 作者自己也把生成论文定位为值得跟进的假设，而不是已验证的成果。

## 七、局限与待核实

- **AI Scientist**：只在三个小型 ML 模板上验证；自动评审不看图、可能见过校验集；生成论文的实验正确性依赖人工复查。后续 v2 去掉模板依赖，本篇不展开。
- **ChemCrow**：专家评估样本小（4 位专家、14 个用例），Figure 4 的各项评分只在图中给出，本篇只写定性结论；工具链依赖外部 API，可复现性受服务可用性影响。
- **两者都基于 2023–2024 年的模型**（GPT-4、Claude Sonnet 3.5 等），结论对更强模型的外推需另行验证。
