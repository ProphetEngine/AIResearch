# A.X K2 Technical Report 深读

> **主要来源**：[A.X K2 Technical Report](https://arxiv.org/abs/2608.30181)；[skt/A.X-K2 模型页](https://huggingface.co/skt/A.X-K2)（仅用于核对型号名）（截至 2026-08-31）。报告只有 arXiv v1；模型页不引事实，不计入截至。
> **研究线**：架构思想（主：Sparse Gated Attention、Gated Norm、稀疏预热）；评测字段（辅：对照表、长上下文与韩语评测、部署吞吐）
> **范围与相邻笔记**：
> - ≠ [[DeepSeekV32技术报告深读]]：稀疏注意力 indexer 的原始设计在那篇，本篇只写 A.X K2 的稀疏预热改法。
> - ≠ [[DeepSeekV3训练与MoE基建]]、[[KimiK2技术报告深读]]：超大 MoE 的训练配方在那两篇，本篇不重写。
> - ≠ [[MiniMaxM1技术报告深读]]：CISPO 算法在那篇，本篇只记 A.X K2 的用法。
>
> **意义**：A.X K2 是 SK Telecom 在固定算力与约 70 天工期下从零训练的 688B 总参、33B 激活 MoE，训练数据约 8.5T token，少于前代 A.X K1 却全面超过它。它的增量集中在三处：把 DeepSeek 的稀疏 indexer 与门控注意力合成 SGA，并让 indexer 一开始就在自身稀疏选择上预热，比先对齐稠密注意力更省；用 Gated Norm 压制激活离群值，替代 K1 的双重归一化并利于 NVFP4 部署；用配对数据的 Think-Fusion 让单一模型可切换思考模式。

## 一、问题背景

开源大模型的前沿越来越由智能体能力定义，即多步推理、工具调用与长程任务。把这些能力变成可部署系统还需要高效服务、可控的推理计算量，以及在现实数据与硬件预算下可训练（§1）。A.X K2 是 A.X K1 的后继，定位为韩国的主权 AI 基座：在 512 张 NVIDIA B200、约 70 天的固定预算下，按 MoE 的规模定律选取模型规模与训练 token 的取舍（§2.1）。

长思维链会推高延迟与服务成本，在简单问题上也是浪费，因此报告让用户按请求选择思考或不思考模式（§1）。

## 三、核心机制

### 3.1 规模与取舍（§2.1，Table 1）

61 层（第 1 层为稠密 FFN，其余 60 层 MoE），隐层 7168，64 个注意力头，256 个路由专家激活 8 个，另有 1 个共享专家；词表 163,840 沿用 K1；原生上下文 128K，用 YaRN 扩到 256K。相对 K1，专家数由 192 增至 256，激活参数保持 33B。64 头加共享稠密专家的设定参考 Kimi K2 的观察，优先降低注意力的推理开销。

### 3.2 Sparse Gated Attention（§2.2）

SGA 由两部分组成：

1. **门控注意力**：在 MLA 之上对注意力输出加头特异门控，贯穿整个预训练，引入非线性、抑制 attention sink、改善收敛。
2. **稀疏注意力**：沿用 DeepSeek-V3.2 的轻量 indexer，每个 query 只选 top-k（k = 2048）个位置。预算固定，128K 时每个 query 只看 1.6% 的位置，256K 时 0.8%，注意力项近似线性增长。

两者互相增强：indexer 的训练目标是复现注意力分布，门控把 sink 上的注意力质量压下去，分布更干净，indexer 的有限预算就更多花在真正相关的位置。引入稀疏后 LongBench 从 62.80 变为 62.99（Table 9），质量基本不变。报告脚注说明，这里的 SGA 与 Du et al. (2025) 的同名方法无关。

### 3.3 Gated Norm（§2.2）

GN 在 RMSNorm 之后立即做门控，抑制隐状态的离群值（massive activations），使损失收敛更平滑，激活分布也更适合 FP8、FP4 这类低比特格式。代价是训练吞吐约降 5%。有了 GN，训练无需 K1 的双重归一化也足够稳定。

### 3.4 预训练与稀疏预热（§3）

预训练约 8.2T token，分三阶段：Stage 1 通识、Stage 2 高质量推理数据，均为 4K 长度；Stage 3 先原生扩到 32K（Stage 3A，约 0.22T），再到 128K（Stage 3B），最后做稀疏适配（Stage 3C），3B 与 3C 合计约 0.14T。RoPE base 在 Stage 1–2 保持 10⁴，Stage 3A 起升到 10⁶ 并保持，按 ABF 方法原生学满 128K。数据候选池约 16.2 trillion token，在预算内按难度递增筛选；相对 K1 显著加大了智能体、软件工程、工具轨迹与仓库级代码数据。

**稀疏预热**：DeepSeek-V3.2 与 GLM-5 先让 indexer 对齐稠密的全注意力分布，再开启稀疏选择；A.X K2 从一开始就在 indexer 自身的稀疏 top-k 选择上计算 KL 损失。先冻结骨干只训 indexer，再全模型续训并调低 indexer 损失权重。因为预热在稀疏注意力下进行，比稠密预热快得多，下游表现差异可忽略（§3.4）。Stage 3C 与 3B 共用数据配比，做法取自 GLM-5。

### 3.5 Think-Fusion 与多阶段 RL（§4）

混合训练思考与非思考数据时，思考样本更长，模型容易出现模式混淆，即用户要求不思考时仍输出思维链。K1 用双轨训练缓解，也有工作把推理与非推理数据的 token 比调到 1.5:1。A.X K2 改为单轨：构造配对数据集，每个 prompt 同时有思考与非思考两种回答，思考与非思考的 token 比约 13:1，让模型依赖显式控制 token 而非数据分布的表面差异（§4.1）。

RL 分多阶段，每阶段联合优化指令遵循、人类偏好与智能体工具调用，后期加入安全；工具奖励对单步调用做可验证比对，对长程任务用门控评审。算法用 CISPO 加 GDPO（各奖励分别归一化再合并），不加 KL 惩罚，每个 prompt 采 16 条 rollout，全程约 100K 个 prompt；按 MiniMax-M1 的发现，把 AdamW 的 epsilon 从 10⁻⁸ 降到 10⁻¹⁵（§4.3）。

## 五、意义

A.X K2 展示了中等算力团队的一条路线：骨干沿用 MLA 与细粒度 MoE，把增量放在训练稳定性、长上下文成本与部署精度上。稀疏预热把 DeepSeek-V3.2 的「先稠密后稀疏」简化为一步，成本更低；门控注意力与 GN 同时服务训练稳定与低比特部署，使 688B 模型以 NVFP4 服务时几乎不掉点。Think-Fusion 则说明，模式切换可以靠配对数据实现，不必双轨训练。

## 六、局限与待核实

1. **报告自述的局限**（§7）：专家并行限制在单节点 8 卡 NVLink 内（EP = 8），未探索多节点细粒度专家并行；固定时间与 GPU 预算导致相对更大算力训练的同规模模型有小幅差距；只支持文本，原生多模态留待后续。
2. **A.X K1 数字只有转述**：K1 的 519B 参数、约 10T token、192 个专家与双重归一化都来自本报告。
3. **对照分数来源**：Table 6 中标星号的分数取自 Artificial Analysis，开源对照模型经 OpenRouter 评测，均非本团队在同一框架下复现。
4. **LongBench v2 的集合**：去掉 87 道含汉字题会改变排名，完整 503 题与 416 题的分数须分别标明。
5. **超长检索**：512K 的 NIAH 只是检索探测，不是支持的服务长度。
6. **思考模式的安全性**：韩语红队测试中，切换到思考模式使 A.X K2 的攻击成功率上升 21.8 个点，延长推理不一定更安全（§5.4）。
7. **图中数字**：GN 消融曲线、吞吐曲线等只在图中给出，本篇不录。
