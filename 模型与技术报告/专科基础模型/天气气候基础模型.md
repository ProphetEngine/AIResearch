# Weather / climate foundation models：Aurora（及 Earth-system 对照）

> **定位**：天气与地球系统基础模型主题轴——相对 **[[生物学基础模型]]**（biology FM）、**[[表格与时序基础模型]]**（表格/时序 FM），再立一条 **天气 / 地球系统 foundation** 叙事；主锚为 Microsoft Research AI for Science 的 **Aurora**，Nature 刊发版与 arXiv 为**同一工作**的审稿定稿，博文 **Aurora 1.5** 作开放增量入口。
> **攻坚线**：**架构思想（主）**——异构地球场如何收进统一 3D latent、预训练→多域微调、相对「只打 0.25° 中期天气」的 AIWP 谱系差在哪。
> **硬划界**：
> - **禁止做成数值天气预报工程手册**（不写同化作业流、业务 SLA、特征清单、部署 playbook、业务订正规程）。
> - **禁止**把 IFS / GraphCast / Pangu 做成通史排行；基线只在文内主结果出现时点名。
> - **禁止编造**：参数量、%、加速倍数、微调周数一律锚定官方 PDF（2026-09-22 CST）与 MSR 博文抽取；图版柱高未抽出的百分点标「待核实读图」。
> - 博文数字 **不**回写覆盖 Nature/arXiv 主结果；1.5 增量单独成节。

## 二、议题边界：何谓「天气 / 气候 foundation」

### 2.1 相对 LLM 与其它科学 FM 的平行轴

| 轴 | 典型对象 | 「Foundation」在本卡的含义 | 下游默认形态 |
|---|---|---|---|
| **文本 LLM**（对照） | token | 大规模预训练 → 多任务适配 | 生成 / 指令 |
| **[[生物学基础模型]] biology** | 原子坐标 / 蛋白 token | 结构预测扩散 vs 多轨道生成 LM | 预测或生成分子 |
| **[[表格与时序基础模型]] 表/时序** | 表细胞 / 一维实值序列 | in-context 或零样本预报 | 分类回归 / 预报 |
| **本卡 Aurora** | 全球格点 **表面+气压层** 地球场（可扩变量集） | **异构分辨率/变量/气压层 → 统一 3D latent**；预训练动力学表示 → **多域微调** | 自回归 rollout 预报 |

跟读：**对象几何是「球面上的多通道 3D 场」**，不是自然语言，也不是蛋白质或表格行。

### 2.2 相对 2023 波 AIWP（文内自述谱系）

文内将 Pangu-Weather 等突破定位为：神经网络替换数值求解器，但**大多停在全球中期天气、0.25°**，在海洋动力学、波浪、大气化学与「超越人类综合多模式的极端天气系统」上留白。Aurora 的主张是：**同一预训练骨干 + 微调**填这些空白，并在运算成本上相对业务数值系统有数量级优势（具体倍数按任务引用，见 §五）。

### 2.3 刻意不写什么

- 业务同化循环、观测算子、后处理订正、产品化 SLA。
- IFS/CAMS/HRES-WAM 的内部物理模块手册。
- 完整 AI 天气模型族谱与 WeatherBench 全榜史。
- 「如何用 Aurora 做交易/能源调度」操作步骤（博文企业叙事仅作**存在性**一句）。

## 三、架构思想：异构场 → 统一 3D latent → 时间演化

> 核心问题：**不同分辨率、变量数、气压层的地球数据，如何变成同一个可训、可微调的模拟器？**

`
(X_{t-1}, X_t) ──► 3D Perceiver 编码器 ──► 固定 L=3 潜气压层的 3D latent
 │
 ▼
 3D Swin Transformer U-Net（处理器；可插 LoRA）
 │
 ▼
 3D Perceiver 解码器 ──► 任意目标变量 / 气压层 / 分辨率的 X̂_{t+1}
 │
 └── 自回归喂回，得到更长 lead time
`

### 3.1 三件套（Nature Fig. 1b / Methods；arXiv §2 + Methods）

| 组件 | 文内事实 | 跟读 |
|---|---|---|
| **3D Perceiver 编码器** | 各变量当 $H\times W$ 图像；切 $P\times P$ patch；变量专用线性嵌入；表面与各气压层嵌入求和并加气压/表面标记；**Perceiver 把可变物理气压层数 $C$ 压到固定 $L=3$ 潜层**；再加 patch 位置/面积/绝对时间的 Fourier 编码 | **面积编码** → 同一骨干可吃多分辨率；潜层固定 → 骨干深度可做大 |
| **3D Swin U-Net 骨干** | Vision Transformer 族；**窗内局部自注意力** + 对称上/下采样三阶段；**48 层 / 三阶段**（文对比 Pangu 线：**16 层 / 两阶段**）；球拓扑下每隔一层做邻域信息传播；res-post-norm；无死绑单一分辨率的位置偏置 | 局部窗 ≈ 数值积分的局部模板；U-Net 多尺度 |
| **3D Perceiver 解码器** | 潜气压层再展开到任意物理气压层集合；变量专用线性层解 patch | 下游换变量集时主要动编解码，而非重做整个动力学骨干 |
| **静态场** | 地形、海陆掩膜、土壤类型掩膜当额外表面变量 | 地理先验进同一通道逻辑 |
| **规模** | Fig. 1：**1.3 billion** parameters | 缩放实验：约每 **10×** 参数，验证损失降约 **6%**（Extended Data / Supp. G） |

### 3.2 训练三阶段（Methods）

| 阶段 | 做什么 | 关键旋钮（文内） |
|---|---|---|
| **1. 预训练** | 学大气/海洋流及相关二阶过程的通用表示；目标 **下一步（6-h）MAE** | **150,000** steps × **32×A100**（每 GPU batch 1）；约 **2.5 周**；AdamW；drop path **0.2**；bf16；激活检查点 |
| **2. 短 lead 微调** | 按任务微调**整网**，1–2 步 rollout（视显存） | 换数据分布与变量集 |
| **3. 长 rollout 微调** | **LoRA** 只适配骨干自注意力中的线性层；**pushforward**（梯度只过最后一步）；**内存回放缓冲**采初值→预测→写回 | 大模型 + 高分辨率长时程可训的关键工程思想（仍属架构/训练形态，不是业务手册） |

损失：全程 **MAE**，表面与大气项加权，并有**数据集权重** $\gamma$（公式见 Nature Methods eq. (1)；细节 Supp. D.1）。

### 3.3 「Foundation」证据链（文内缩放，不另开通史）

- **数据多样**：分析 / 再分析 / 预报 / 再预报 / **CMIP6 气候模拟** 等混训；点名 ERA5、HRES、IFS-ENS、GFS、GEFS、MERRA-2、CAMS 等（完整清单 Supp. C）。
- **更多异构数据 → 更好验证**，极端值尤甚（Extended Data Fig. 1）。
- **对照实验**：0.25° 中期天气微调上，相对 **IFS** 与 **GraphCast**，文称在 **>91%** targets 上更好（Supp. H）——用作「预训练是否值钱」的标尺，不是本卡主秀。
- **0.1° 场景**：预训练相对从头训平均约 **+25%**（Supp. I.4）。

## 四、四域微调：Earth-system 对照的实体内容

> 议程「Earth-system 对照」在材料层 = Nature 刊名与多域叙事；在内容层 = 下表四域相对「单天气任务」的扩维。数字均为文内摘要句，**禁止**当业务保证。

| 域 | 分辨率 / 时程 | 文内主主张（targets 比例） | 速度/成本口径（文内） | 预训练增益（文内） |
|---|---|---|---|---|
| **大气成分 / 空气质量** | **0.4°**，约 **5** 天；对标 CAMS | 与 CAMS 比：RMSE 竞争（±20%）覆盖 **95%** targets；**持平或更好 74%**；3 日时 **89%** 变量持平或更好 | ~**1.1 s / 小时 lead**（单 A100）→ 文称相对 CAMS 约 **×50,000** | 相对从头训平均约 **54%** |
| **海浪** | **0.25°**，约 **10** 天；对标 HRES-WAM | **86%** 波浪变量；3 日 **91%** | 「数量级更小算力」（摘要口径） | 文强调预训练相对从头有大增益（细节 Supp.） |
| **热带气旋路径** | **0.25°** 场 + 简易中心追踪（MSLP 最小）；约 **5** 天 | 相对 **7** 家业务官方路径：**100%** 文内比较格子上更好；NA/EP 平均约 **20%**、西太约 **18%**、澳区约 **24%** | — | — |
| **高分辨率天气** | **0.1°**，约 **10** 天；对标 IFS HRES | RMSE 更低覆盖 **92%** targets；>12 h 增益更明显（RMSE 降幅文称可达 **24%**）；WeatherReal-ISD 台站风/温全 lead 优于 HRES | 摘要「orders of magnitude」 | 见上 **+25%** vs scratch |

**污染物变量（空气质量）：** CO、NO、NO₂、SO₂、O₃（多层 + 总柱）与 PM1 / PM2.5 / PM10；CAMS analysis 作真值；因 analysis 时段短，微调还并入较低分辨率的 CAMS 再分析（EAC4，2003–2021）。

**海浪变量族（跟读即可）：** 风浪/涌浪相关波高、周期、方向等 + 密度通道处理海冰等造成的空间缺失（Supp. B.8）。

**飓风追踪方法边界：** 文明确用 **启发式**（连续预报里取 MSLP 最小为涡旋中心），**不是**另训专用追踪网；高光个例含 **Doksuri（2023）** 登陆菲律宾判断优于部分官方中心。

**Storm Ciarán（2023-10）个例：** 在比较的 AIWP 中，文称 Aurora **唯一**准确抓住最大 10 m 风速陡升并贴近 IFS analysis；为利极端事件，该次 **关闭 LoRA** 跑（Fig. 5 注）。

**微调工期（Discussion）：** 每个微调实验约 **4–8 周**、小团队——相对数值业务模式「多年」；文立刻补刀：这只因传统数值方法积攒了**几十年数据资产**才可能。

## 六、局限与开放轴（论文自述）

摘自 Nature / arXiv **Discussion**（压缩，不扩写工程对策）：

1. **集合预报**：原文承认可扩展 ensemble（**1.5 博文已部分落地**）。
2. **缩放未触顶**：更多样预训练数据 + 更大模型仍可能抬微调上限。
3. **初值依赖**：业务实验仍吃**传统同化**初值；文指向端到端观测驱动（引 Vaughan et al. 2024 一类工作）为未来。
4. **可解释性**（Nature 多一句）：是否可把内部模式连回物理过程——**提出即止**。
5. **潜在下游清单**（文内举例，非结果）：海洋环流、局地/季节天气、植被物候、洪水野火、农业与可再生、海冰等——**本卡不展开、不编造性能**。

## 九、可跟读摘要

1. **同一模型、两层文献**：arXiv 2405.13063 ≈ Nature s41586-025-09005-y；引用优先 Nature；长附录以 arXiv PDF 为准。
