# Biology foundation models（AlphaFold 3 + ESM3）

> **主要来源**：[Accurate structure prediction of biomolecular interactions with AlphaFold 3](https://doi.org/10.1038/s41586-024-07487-w)（Abramson 等，Nature 第 630 卷第 8016 期，2024-05-08 在线发表，2024-06-13 刊期）；[Simulating 500 million years of evolution with a language model](https://doi.org/10.1101/2024.07.01.600583)（Hayes 等，bioRxiv，所据版本 posted 2024-12-31；*Science* 2025-01-16 在线发表，DOI [10.1126/science.ads0018](https://doi.org/10.1126/science.ads0018)；数字以 bioRxiv 版本为准）（截至 2025-01-16）
> **研究线**：架构思想（主：结构预测扩散 vs 序列–结构–功能生成式掩码 LM）
> **范围与相邻笔记**：
> - ≠ [[扩散生成式视觉与LLM]]、[[扩散语言模型]]：同词「扩散」但状态空间不同——AF3 是连续原子坐标扩散；ESM3 刻意不用三维扩散而用结构离散 token，目标更近掩码 LM。
> - ≠ [[MedGemma医学专科]]：医学影像/临床文本专科 ≠ 分子结构与序列基础模型。
> - ≠ [[表格与时序基础模型]]、[[天气气候基础模型]]：同属科学 foundation 横切，对象几何不同。
>
> **意义**：AF3 把几乎 PDB 全类复合物结构预测收进 Pairformer + 原子坐标扩散；ESM3 把序列、结构、功能收进同一套离散 token 的生成式掩码 LM，并用缩放与偏好对齐做可控生成。两条线共享「生物学基础模型」标签，但生成对象与噪声定义不可混抄——一个回答「这个复合物长什么样」，一个回答「按约束写一条新序列」。

## 一、问题背景

AF2 推动了蛋白结构与相互作用建模；问题升维为：能否在同一深度学习框架内预测含配体、离子、核酸、修饰残基等更广复合物（AF3 开篇）。另一条正交问题是：在进化规模数据上，能否用语言模型联合推理序列、结构与功能，并按跨模态提示生成新蛋白（ESM3 开篇）。二者都叫 foundation，但一个是条件结构求解器，一个是多轨道 masked LM。

## 三、站 1：AlphaFold 3 — 复合物结构预测扩散

| 组件 | AF2 习惯 | AF3 决策 |
|---|---|---|
| 主干 | Evoformer（重 MSA） | Pairformer（48 blocks）：主要在 pair + single 上运算；MSA 表示不保留，信息经 pair 传递 |
| 结构模块 | 氨基酸帧 + 侧链扭转角 | Diffusion module：直接预测原始原子坐标；无旋转帧 / 等变强制 |
| 损失侧 | 需立体化学 violation 等 | 多尺度扩散去噪：低噪声管局部立体化学，高噪声管大尺度排布 |
| 训练 crop | — | 初始 384 tokens → fine-tune 640 → 768；PoseBusters 专用模型训练截止 2019-09-30 |
| 扩散批 | — | 初始每优化步 256×48 = 12,288 diffusion samples；fine-tune 256×32 = 8,192 |

扩散训练：接收加噪原子坐标，预测真实坐标；推理从随机噪声迭代去噪。置信度头用 diffusion mini-rollout（约 20 iterations）得到预测结构，再训 pLDDT、PAE 与距离误差矩阵 PDE（Supplementary Methods 4.3）。幻觉对策：用 AlphaFold-Multimer v.2.3 预测结构做 cross-distillation，减轻无序区虚假紧凑结构（Extended Data Fig. 1）。

**推理：** 默认 5 个随机种子 × 每种子 5 个 diffusion samples，按置信度取 top；抗体–抗原扩到 1,000 seeds（Fig. 1 注）。AlphaFold Server 供非商业用途；原文发表时写明不提供代码（伪代码在 Supplementary），Nature 的 [Addendum](https://doi.org/10.1038/s41586-024-08416-7)（Nature 第 636 卷第 8042 期，2024-11-27 在线发表，2024-12-12 刊期）称推理代码已发布（google-deepmind/alphafold3）。

**评测主张（文内可核句）：** 配体相对 Vina 大幅优于且不用结构输入（Fisher exact P=2.27×10^-13）；相对 RoseTTAFold All-Atom 亦大幅优于；蛋白–蛋白相对 AF-Multimer v.2.3 在 DockQ>0.23 成功率上提升（paired Wilcoxon P=1.8×10^-18）；抗体–蛋白 P=6.5×10^-5；蛋白单体 LDDT P=1.7×10^-34。PoseBusters：428 个 2021 及以后蛋白–配体结构。训练动态：链内局部指标在前 20,000 步内即达最大值的 97%；蛋白–蛋白界面 LDDT 要到 60,000 步后才过同一 97% 门槛。

**局限（论文自述）：** PoseBusters 手性违例率 4.4%；原子 clash，极端时同源多聚体整链重叠；无序区可出现虚假结构秩序；CASP15 RNA 平均高于部分 ML 基线，但未达最佳有人类专家介入的系统。

## 四、站 2：ESM3 — 序列–结构–功能生成式 LM

为何不用 3D 扩散：引言明确对照近期模型的三维扩散，改用离散 token 表示结构，便于 all-to-all 与缩放——这是与 AF3 路线对照的关键句。

| 决策 | 论文事实 |
|---|---|
| 结构 token | 离散自编码器压缩局部原子邻域 → 每氨基酸一 token；CAMEO 上重建 <0.5 Å RMSD |
| 功能 / 粗结构 | SS8、SASA；InterPro / GO 衍生关键词 → token |
| 骨干 | 双向 Transformer；首块几何注意力可吃原子坐标条件；输出分轨道 logits |
| 目标 | 生成式 masked LM：掩码率按噪声日程变化；任意掩码组合 → 任意阶生成 |
| 最大模型 | 98B 参数（另训 1.4B、7B）；训练 FLOPs 1.07×10²⁴；2.78 billion 蛋白；771 billion 唯一 token；216 transformer blocks |

表示学习：单序列结构预测上 ESM3 98B 平均 LDDT 0.880 vs ESMFold 0.861（CAMEO）。无条件生成平均 pLDDT 0.84。

**提示遵循与偏好对齐：** 各轨道可独立提示。用提示生成构造正负偏好对，做 preference optimization。Pass@128（46 个配体结合基序）：对齐前→后，1.4B 为 9.5%→18.8%，7B 为 19.0%→37.4%，98B 为 26.8%→65.5%。

**esmGFP 实验锚点（科学事实，非操作手册）：** 以天然 GFP 核心少量残基结构等为提示迭代生成。第一轮 88 个设计（96 孔板）得到微弱荧光的 B8（相对天然 GFP 约 50× 暗）。从 B8 继续，第二块 96 孔板得到 esmGFP（C10）：亮度落入常见 GFP 分布；相对最近已知荧光蛋白 58% 同一（相对 tagRFP 有 96 处突变）；相对 *Aequorea victoria* GFP 36% 同一。「5 亿年」是用自然 GFP 家族序列同一–时间关系外推的估计量（Fig. 4H）。

**开放权重（仅存在性）：** 博文称 ESM3 1.4B 权重与代码 MIT 开源；更大模型经 API。原文附录 A.6 述负责任开发评测——本篇不转述过滤词表或评测协议步骤。

## 五、双站对照

| 维度 | AlphaFold 3 | ESM3 |
|---|---|---|
| 任务 | 预测给定输入的复合物结构 | 生成满足提示的蛋白 |
| 机理 | 连续坐标空间扩散去噪 | 离散 token 掩码–反掩码 |
| 结构表示 | 直接原子坐标 | 结构离散 AE token → 解码器 |
| 开源形态（文内） | Server；推理代码随 2024-11 Addendum 发布 | 1.4B MIT + 更大模型 API（博文） |

接口一句：若问题是「这个复合物长什么样」→ AF3；若问题是「按结构/功能约束写一条新序列」→ ESM3。可流水线串联，但不是同一损失函数的两种写法。

## 六、局限与待核实

1. **AF3：** 手性与 clash；无序区幻觉；核酸相对专家系统的差距。
2. **ESM3：** 「进化年」估计的统计假设敏感性；98B 与开源 1.4B 的能力鸿沟。
3. **Chem 专用基础模型：** 本篇未找到 Chem 专用基础模型的一手技术报告，因此不写其架构数字。
4. **Science 版：** Science 正式版正文未能核对。ESM3 正文数字出自 bioRxiv 2024-12-31 版；其中 58% 序列同一与「5 亿年」估计已在 Science 摘要中核到，与本篇一致。
5. **版本：** AF3 以 Nature 刊发版为准；ESM3 数字以 bioRxiv 2024-12-31 版本为准。
