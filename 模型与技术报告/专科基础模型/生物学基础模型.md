# Biology foundation models（AlphaFold 3 + ESM3）

> **定位**：生物学基础模型主题轴——与 LLM 主轴**平行**的生物学基础模型双站：**结构预测扩散（AF3）** vs **序列–结构–功能生成式语言模型（ESM3）**。
> **攻坚线**：**架构思想（主）**。
> **硬划界**：
> - **科学综述口径**：只写问题设定、架构选择、训练/生成形态、公开评测与论文自述局限。
> - **禁止**写操作层增强、双用途生物设计的可复现步骤、筛选规避、病原体/毒素相关能力评测细节（→ 仅在开放模型附录作**存在性**一句，不展开）。
> - **Chem 专用基础模型**：本检索窗**无**独立一手长 PDF → **附录「待核实」**，不升正文。
> - 与 **[[扩散语言模型]]**（离散文本 MDM）/ **B10**（图像 LDM/DiT）：同词「扩散」但状态空间不同——**AF3 = 连续原子坐标扩散**；ESM3 **刻意不用**三维扩散而用结构离散 token。
> **禁止编造**：数字、p 值、参数量、FLOPs、序列同一律锚定官方 PDF（2026-09-22 CST）与 EvolutionaryScale 博文抽取；图/Extended Data 表内未抽出的百分点标「待核实读图」。

## 二、问题立轴：为何双站并立

### 2.1 两条正交问题

| 轴 | **AlphaFold 3** | **ESM3** |
|---|---|---|
| 核心问题 | 给定组分（聚合物序列、配体等），**预测**联合三维结构 | 在进化规模数据上学分布，**生成**满足提示的新蛋白（可跨模态） |
| 输出 | 原子坐标（及置信度） | 序列 / 结构 token / 功能关键词（可解码为结构） |
| 「基础」含义 | 单一网络覆盖蛋白–配体、核酸、修饰、离子等 | 单一 LM 覆盖序列–结构–功能联合推理与生成 |
| 与 LLM 类比（跟读） | 更像 **条件结构求解器**（扩散采样多解） | 更像 **多轨道 masked LLM**（任意阶生成） |

### 2.2 与仓库相邻笔记的三维划界

| 轴 | B10（图像） | [[扩散语言模型]]（文本 MDM） | **AF3** | **ESM3** |
|---|---|---|---|---|
| 状态 | 连续像素/潜变量 | 离散词表 + [MASK] | **连续原子坐标** | **离散**序列/结构/功能 token |
| 噪声 | 高斯等 | 吸收态掩码 | 坐标加噪 → 预测干净坐标 | 可变掩码率 MLM |
| 骨干直觉 | U-Net / DiT | 双向 Transformer mask predictor | Pairformer + Diffusion module | 多轨道 Transformer + 几何注意力（首块） |
| 本篇覆盖 | ✗ | ✗（仅对照「扩散」一词） | ✓ | ✓ |

跟读：**不要把 AF3 的扩散步当成 ESM3 的 unmask 步；也不要把 ESM3 的结构 token 解码当成 AF3 的原子扩散。**

## 三、站 1：AlphaFold 3 — 生物分子复合物的结构预测扩散

### 3.1 动机与主张（Abstract / §开篇）

- AF2 推动蛋白结构与相互作用建模；问题升维为：能否在**同一深度学习框架**内预测含配体、离子、核酸、修饰残基等更广复合物。
- 既有专用预测器准确度参差，且多数高度特化；文称并发有另一通才方法（文内 ref.29），但 AF3 主张在**几乎所有**类别上显著高于强专项基线（Fig. 1c；Extended Data Table 1——**表为图版，百分点待核实读图**）。
- 主张句（压缩）：统一框架内的高精度建模横跨生物分子空间是可能的。

### 3.2 架构思想：Pairformer + 原子扩散（相对 AF2）

据正文「Network architecture and training」与 Fig. 1d / Fig. 2：

| 组件 | AF2 习惯 | **AF3 决策** | 跟读 |
|---|---|---|---|
| 主干 pairwise | Evoformer（重 MSA） | **Pairformer**（**48** blocks）：主要在 **pair + single** 上运算；MSA 表示**不保留**，信息经 pair 传递 | MSA **大幅降权**：更小 MSA embedding；pair-weighted averaging；后续几乎只用 pair |
| 结构模块 | 氨基酸帧 + 侧链扭转角 | **Diffusion module**：直接预测 **原始原子坐标**；粗粒度 token 表示；**无**旋转帧 / 等变强制 | 为任意化学图（配体等）减特判 |
| 损失侧 | 需立体化学 violation 等 | 多尺度扩散去噪：低噪声→局部立体化学，高噪声→大尺度排布 → **可去掉**多数扭转参数化与 violation 损失 | 「化学合理性」更多交给扩散局部任务 |
| 训练阶段 | — | 三阶段：初始 crop **384** tokens → fine-tune crop **640** → **768**；cutoff **2021-09-30**（PoseBusters 专用模型 **2019-09-30**） | Methods |
| 扩散批 | — | 初始训练每优化步：mini-batch **256**×**48** = **12,288** diffusion samples；fine-tune **256**×**32** = **8,192** | Methods |

**扩散训练图像（文述）：** 接收加噪原子坐标，预测真实坐标；推理时从随机噪声迭代去噪得终结构；**生成式** → 每个样本局部几何可锐利，即使全局不确定。文称相对标准扩散做法（ref.33），且**不要求**全局旋转/平移等变以简化架构。

**置信度头（相对 AF2 的适配）：** 扩散只训单步，无法直接像 AF2 那样用完整结构模块误差回归。解决：从 trunk 末端做 **diffusion mini-rollout**（约 **20** iterations，Fig. 2c）得到预测结构，再训 confidence head → **pLDDT**、**PAE**，以及距离误差矩阵 **PDE**（Supplementary Methods 4.3）。

**幻觉对策：** 生成模型易在无序区「编造」结构。对策：用 AlphaFold-Multimer v.2.3 预测结构做 **cross-distillation** 丰富训练数据（无序区多为伸展环而非紧凑假结构），显著减轻幻觉（Extended Data Fig. 1）。

### 3.3 推理与排序（公开口径）

- 默认：同一训练模型 **5** 个随机种子 × 每种子 **5** 个 diffusion samples → 按置信度取 top（抗体–抗原：扩到 **1,000** seeds 再排序，Fig. 1 注）。
- PoseBusters：排名分基于 ipTM 聚合；配体手性错误或与蛋白 clash 时分数再除以 100（Methods）。
- **AlphaFold Server**（文内 Code availability）：https://www.alphafoldserver.com ，非商业用途，配体/共价修饰有限制；**Nature 文明确：Code is not provided**（伪代码在 Supplementary）。

### 3.4 评测主张（只录文内可核句；忌读图编造）

评测轴（Fig. 1c 注）：配体/共价修饰 → pocket-aligned ligand RMSD **< 2 Å** 成功率；蛋白–核酸 → interface LDDT；核酸/单体 → LDDT；蛋白–蛋白/抗体 → DockQ **> 0.23** 成功率。

文内可核统计主张（非编造读图 %）：

| 对比 | 文内主张 | 检验 |
|---|---|---|
| 配体 vs 经典对接 Vina | AF3 **大幅优于** Vina，且**不使用**结构输入（盲对接设定） | Fisher exact $P=2.27\times10^{-13}$ |
| 配体 vs RoseTTAFold All-Atom | 大幅优于 | $P=4.45\times10^{-25}$ |
| 蛋白–蛋白 vs AF-Multimer v.2.3 | DockQ>0.23 成功率提升 | paired Wilcoxon $P=1.8\times10^{-18}$ |
| 抗体–蛋白 | 显著提升（1,000 seeds 排序） | $P=6.5\times10^{-5}$ |
| 蛋白单体 LDDT | 显著提升 | $P=1.7\times10^{-34}$ |
| MSA 深度 | 与 AF-M 2.3 **类似**：浅 MSA 仍更难 | Extended Data Fig. 7a |

PoseBusters：**428** 个 2021 及以后蛋白–配体结构；为公平用 **2019-09-30** cutoff 模型，确保未训到该集。**精确成功率柱高以 Fig. 1c / Extended Data Table 1 为准（待核实读图）**。

训练动态（Fig. 2d 文述）：局部（链内）指标约 **20,000** 步达最大性能约 **97%**；蛋白–蛋白界面 LDDT 约 **60,000** 步才过同一 **97%** 门槛——界面难于局部。

### 3.5 局限（论文自述，跟读）

1. **立体化学：** 手性仍可违（PoseBusters 基准手性违例率 **4.4%**，尽管排名已罚手性）；原子重叠/clash，极端时同源多聚体整链重叠；罚 clash 可降但不能消。剩余 clash 几乎都在「>100 nt 核酸且总残基 >2000」的大体系。
2. **幻觉：** 扩散相对非生成 AF2，无序区可出现虚假结构秩序；通常低置信，但外观可不像 AF2 的飘带。
3. **动力学 / 特定靶标：** 文列 dynamics 与某些靶标精度为局限轴（细节见正文 Model limitations）。
4. **CASP15 RNA：** 平均高于 RoseTTAFold2NA 等 ML 基线，但**未达**最佳有人类专家介入的 AIchemy_RNA2。

## 四、站 2：ESM3 — 序列–结构–功能生成式语言模型

### 4.1 动机与主张（Abstract / Introduction）

- 自然蛋白是数十亿年进化筛选的结果；大规模序列/结构库使「蛋白生物学有一种可用 LM 理解的语言」成为共识。
- **ESM3**：前沿**多模态生成** LM，对序列、结构、功能联合推理；可跟随跨模态复杂提示；对**生物对齐（alignment）**高度响应。
- 实验叙事锚点：提示生成荧光蛋白；合成验证中得到明亮 GFP——与已知荧光蛋白最近邻 **58%** 序列同一；作者估计与自然 GFP 家族类似分化幅度对应 **>5 亿年** 进化距离（文题/摘要口径；博文同述）。

### 4.2 架构思想：离散化一切，然后做可缩放 Transformer

| 决策 | 论文事实 | 跟读 |
|---|---|---|
| 为何不用 3D 扩散 | 引言明确对照近期预测/生成模型的复杂架构与**三维扩散**；改用**离散 token** 表示结构，便于 all-to-all 与缩放 | **与 AF3 路线对照的关键句** |
| 结构 token | 离散自编码器压缩局部原子邻域 → 每氨基酸一 token；不变几何注意力（局部键几何参考系 + 全局帧交互，Appendix A.1.6）；解码重建全原子；CAMEO 上重建 **<0.5 Å** RMSD（文述） | 结构变成「另一种字母表」 |
| 功能 / 粗结构 | SS8、SASA token；InterPro / GO 衍生关键词 → token（TF-IDF + LSH 等，附录） | 语义级提示 |
| 骨干 | 双向 Transformer；输入端融合多轨道嵌入；首块几何注意力可吃原子坐标条件；输出分轨道 logits | 「多轨道、单潜空间」 |
| 目标 | 生成式 **masked LM**：掩码率按噪声日程变化（非经典固定 15%）；监督在被掩码位；任意掩码组合 → **任意阶**生成因子分解 | 与 [[扩散语言模型]] MDM 同族直觉，域在蛋白 |
| 采样 | 从全/部分掩码上下文迭代采样 unmask，直至填满（Fig. 1A） | 可控：任意模态组合作 prompt |

**规模（最大模型，引言/§训练）：**

| 量 | 数值（PDF） |
|---|---|
| 参数 | **98B**（另训 **1.4B**、**7B**） |
| 训练 FLOPs | **1.07×10²⁴** |
| 蛋白数 | **2.78B**（自然 + 合成增强；结构/功能注释有限 → 数亿合成结构/功能点） |
| 唯一 token | **771B** |
| 深度 | **216** transformer blocks（相对宽，偏深；超参实验称深度响应更大） |

表示学习：单序列结构预测上，ESM3 **98B** 平均 LDDT **0.880** vs ESMFold **0.861**（CAMEO；Table S9）。无条件生成：平均 pLDDT **0.84**（文述）。

### 4.3 提示遵循与对齐（架构思想辅线）

- **各轨道独立提示**（Fig. 2A）：cRMSD / SS3 / SASA Spearman ρ / keyword recovery；**7B** 即可找到「跟提示且 ESMFold pTM>0.8」的解（文述；存在 mode switching）。
- **三级原子协调（tertiary coordination）+ 偏好对齐：** 用提示生成构造正负偏好对（高 pTM、低 cRMSD vs 差样本）；**preference optimization** 损失（文引 Rafailov 等；Appendix A.4）。
- **Pass@128**（46 个配体结合基序，1024 提示估计）：对齐前 → 后
 - 1.4B：**9.5% → 18.8%**
 - 7B：**19.0% → 37.4%**
 - 98B：**26.8% → 65.5%**
 文称对齐后成功簇数（TM>0.8）等亦升；相对监督微调基线，偏好调优提升更大（Appendix A.4.6）。
- 跟读：缩放把「难提示」的**潜在能力**做大；对齐把能力**表现出来**——与 LLM 偏好对齐叙事同构，但奖励来自结构一致性/置信度等自动度量，而非人类聊天偏好。

### 4.4 esmGFP：生成式能力的实验锚点（科学事实，非操作手册）

据正文 GFP 节与 Fig. 4（及博文同叙事）：

1. 以天然 GFP 核心少量残基结构等为提示，链式思维式迭代生成候选。
2. 第一轮测 **96** 个：得遥远但微弱荧光的 **B8**（相对天然 GFP 约 **50×** 暗；生色团成熟约一周）。
3. 从 B8 序列继续生成第二轮 **96** 个：得 **esmGFP（C10）**——亮度落入常见 GFP 分布；相对最近已知荧光蛋白 **58%** 同一（**96/229** 位点突变）；相对 *Aequorea victoria* GFP **36%** 同一。
4. 光谱：文述与 EGFP 比较（发射峰 **512 nm** 等；细节以 Fig. 4D 为准）。
5. 「5 亿年」：**估计量**——用自然 GFP 家族序列同一–时间关系外推（Fig. 4H）；作者强调模型并未显式在进化约束内行走，但是预测掩码 token 迫使模型学习进化如何穿越序列空间 → 「进化模拟器」隐喻。

博文另给**科学示例**（非双用途操作）：多模态提示为 PETase 活性位点搭脚手架（活性位点结构+氨基酸 + α/β hydrolase 功能词）——本笔记只保留「跨模态可控生成」存在性，不写工程配方。

### 4.5 开放权重与负责任开发（仅存在性；禁止操作细节）

- 博文：ESM3 **1.4B** 权重与代码 **MIT** 开源；API（Forge）公开预览（博文 Jan 2025 Update）。

## 五、双站对照卡（跟读）

| 维度 | **AlphaFold 3** | **ESM3** |
|---|---|---|
| 机构叙事 | Google DeepMind + Isomorphic Labs | EvolutionaryScale, PBC |
| 任务 | **预测**给定输入的复合物结构 | **生成**满足提示的蛋白（可预测结构为副产品） |
| 生成机理 | 连续坐标空间**扩散去噪** | 离散 token **掩码–反掩码** |
| 结构表示 | 直接原子坐标（+ pair/single） | 结构 **VQ/离散 AE token** → 解码器 |
| 条件信息 | MSA（弱化）、模板、化学组分等 | 任意轨道部分提示（序列/结构/功能） |
| 缩放叙事 | 数据效率与化学通才（相对 AF2） | 参数/数据/FLOPs 前沿；能力随规模与对齐涌现 |
| 实验高光 | 盲配体对接级精度；抗体界面；统一模态 | esmGFP 远距离功能蛋白；三级协调 Pass@128 |
| 开源形态（文内） | Server；**代码未随 Nature 文提供** | 1.4B MIT + 更大模型 API（博文） |
| 典型失效 | 手性/clash/无序幻觉 | 提示 mode switching；难配体仍可能双失败（文：9/46） |

**接口一句：** 若问题是「这个复合物长什么样」→ AF3 轴；若问题是「按结构/功能约束写一条新序列」→ ESM3 轴。二者可流水线串联（生成后再预测/验证），但**不是同一损失函数的两种写法**。
