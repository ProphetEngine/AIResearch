## 一、如何读谱系（开闭源、代际、thinking/路由、多模态）

读「前沿谱系」时，建议固定四条坐标轴，避免被聚合站型号名冲散：

### 1.1 开源 / 开放权重 vs 闭源 API

| 类型 | 跟读含义 | 本稿代表 |
|---|---|---|
| **闭源产品栈** | 公开的是能力叙事、产品路由与评测；**参数量 / 层数 / 训练配方多数未公开** | OpenAI GPT-5 系、Anthropic Claude 4、Google Gemini 2.5 |
| **开放权重 / 开源报告** | 至少可下载权重或有完整技术报告；架构与训练数字可跟读复述 | DeepSeek-V3、Llama 4（Scout/Maverick）、Qwen3 |

> 注意：Meta 文案写 *open-weight* / *openly available*；Qwen3 报告写明 **Apache 2.0**。二者许可与可商用边界不同，勿混称为「同一类开源」。具体许可证全文未在本稿逐条粘贴处展开者标 **待核实**。

### 1.2 代际：不是「数字越大越新」一条线

- **OpenAI**：2024-09 起出现 **o 系列 reasoning**（见 [[推理时扩展TestTimeScaling]]）；2025-08-07 发布 **GPT-5** 把「快答 + 深思」合成统一系统；此后 *Model Release Notes* 显示 **GPT-5.x Instant / Thinking / Codex / Sol** 等产品线继续迭代（至 2026 年中仍有发布）。
- **Anthropic**：Claude 3.x → **Claude 4（Opus 4 / Sonnet 4，2025-05-22）**，强调 hybrid（即时 / extended thinking）。
- **Google**：Gemini 2.0 Flash Thinking → **Gemini 2.5 thinking models（2025-03-25）**。
- **开放权重**：DeepSeek-V3（2024-12）→（官方新闻列表另有 V3.1/V3.2/V4…，架构细节见第五节待核实清单）；Llama 3 → **Llama 4 MoE 多模态 herd（2025-04-05）**；Qwen2.5 → **Qwen3 统一 thinking/non-thinking（arXiv 2025-05）**。

### 1.3 Thinking / 路由：三种产品化形态（架构思想主轴）

`
A. 独立 reasoning 型号（历史：o1/o3、部分 R1 形态）
B. 统一模型内嵌「可开关 / 可预算」thinking（Claude 4 hybrid；Qwen3 think/no_think；Gemini 2.5 thinking）
C. 系统级实时路由：轻量快答子模型 + 深思子模型 + router（OpenAI GPT-5 官方表述）
`

跟读要点：**「会不会想」已从提示词技巧，变成训练目标 + 产品默认行为 +（可选）路由/预算旋钮。** 与 [[推理时扩展TestTimeScaling]] test-time scaling 同一叙事轴。

### 1.4 多模态

- **原生早期融合**：Llama 4 官方明确 *early fusion* 把 text / image / video token 纳入统一骨干。
- **原生多模态 + 长上下文**：Gemini 2.5 Pro 官方强调 text/audio/images/video/codebase，上下文 **1M tokens（2M coming soon）**。
- **GPT-5 / Claude 4**：官方强调视觉 / 多模态评测或能力，但**骨干是否「从零原生融合」的层设计未公开** → 表中填「未公开」。
- **DeepSeek-V3 技术报告**：语言 MoE 报告为主；官方 V3 新闻写展望 multimodal → **V3 本体多模态细节待核实**（以报告正文为准，勿臆造）。
- **Qwen3 技术报告**：系列以 LLM 为主叙述；视觉等姊妹型号不在本稿入口 PDF 主线内展开。

## 三、开源 / 开放权重：DeepSeek / Llama 4 / Qwen3

### 3.1 DeepSeek-V3：MLA + DeepSeekMoE + 无辅助损失负载均衡 + MTP + FP8

| 字段 | 核实值 |
|---|---|
| 官方新闻日 | **2024-12-26**（https://api-docs.deepseek.com/news/news1226） |
| 技术报告 | arXiv:**2412.19437**（Submitted **2024-12-27**，last revised **2025-02-18** v2） |
| 官方 PDF | `https://arxiv.org/abs/2412.19437` |

**代际定位（报告摘要）：** 671B 总参数 MoE，**每 token 激活 37B**；称在多项评测上优于其他开源并可比肩领先闭源（以报告图表/表格为准）。

**架构思想（主，已核实）：**

1. **MLA（Multi-head Latent Attention）**：KV 低秩压缩，降推理 KV cache。
2. **DeepSeekMoE**：细粒度专家 + **共享专家**；路由用 sigmoid + top-K 归一化。
3. **Auxiliary-loss-free load balancing**：专家 bias 动态调节，减少传统 aux loss 伤效果；辅以极小序列级 balance loss。
4. **Node-limited routing**：每 token 最多到 **M=4** 节点，利于通算重叠。
5. **Multi-Token Prediction（MTP）**：深度 D（配置为 1）额外预测未来 token；可弃用模块或改用于 speculative decoding。
6. **规模配置（报告 §4.2）**：61 层、hidden 7168、128 heads、MLA 压缩维等；MoE：**1 shared + 256 routed**，每 token **8** routed；词表 128K；上下文经两阶段扩到 **128K**。

**AI Infra（辅，已核实）：**

- 集群：**2048×H800**；节点内 NVLink，跨节点 IB。
- 并行：PP16 + EP64（跨 8 节点）+ ZeRO-1 DP；**DualPipe** 双向流水线重叠 compute/通信。
- **FP8 混合精度**训练（细粒度 tile/block 量化 + 提高累加精度）。
- 数据：**14.8T** tokens；全流程约 **2.788M** H800 GPU hours（预训练 2664K + 上下文扩展 119K + 后训练 5K）。
- 后训练：SFT + **GRPO**；并从 DeepSeek-R1 系列蒸馏推理模式。

**谱系提醒（官方新闻列表，仅日期/名称，架构细节待核实）：**
同一文档站新闻索引在 as_of 时尚列有 DeepSeek-V3-0324（2025-03-25）、V3.1（2025-08-21）、V3.2-Exp / V3.2（2025-09 / 2025-12）、V4 Preview（2026-04-24）、V4-Pro GA（2026-08-13）等。**本稿架构深挖以 V3 报告为准**；后续代际结构勿用聚合站二手描述填表。

### 3.2 Meta Llama 4：首个开放权重原生多模态 MoE「herd」

- **发布日**：**2025-04-05**
- **URL**：https://ai.meta.com/blog/llama-4-multimodal-intelligence/（WebFetch 400，已用 curl 拉取 200 核实）

**产品族（官方）：**

| 型号 | 激活参数 | 专家结构 | 总参数 | 备注 |
|---|---|---|---|---|
| **Llama 4 Scout** | 17B | 16 experts | **109B** | 单卡 H100（Int4）；上下文 **10M** |
| **Llama 4 Maverick** | 17B | 128 experts | **400B** | 可单 H100 DGX host；含 shared expert 路由描述 |
| **Llama 4 Behemoth** | 288B active | 16 experts | **待核实（未给总参）** | 作教师蒸馏；**仍在训练**，未发布权重 |

**架构思想（已核实）：**

- 首用 **MoE**；Maverick：**交替 dense 与 MoE 层**；MoE 层 **128 routed + 1 shared**，每 token → shared + **1** 个 routed。
- **原生多模态 early fusion**（text / image / video）；视觉编码器基于 MetaCLIP 思路并与冻结 Llama 联合适配。
- **Scout 长上下文**：iRoPE（交错无位置编码注意力层 + 多数层 RoPE；推理期 attention temperature scaling）；中期训练做长文扩展。
- 后训练管线：**轻量 SFT → 在线 RL → 轻量 DPO**；强调去掉过多「简单」SFT 以免限制 RL 探索。

**AI Infra（已核实片段）：**

- 预训练混合 **>30T** tokens（相对 Llama 3 称 10× 多语 token 等）；**FP8**；Behemoth 预训练称 **32K GPUs**、约 **390 TFLOPs/GPU**。
- 多语：预训练覆盖 **200** 语言等（以博文为准）。
- 权重获取：博文指向 llama.com 与 Hugging Face；**许可证全文条款 → 待核实（勿默认 Apache）**。

### 3.3 Qwen3：稠密 + MoE 全家桶，thinking / non-thinking 统一

| 字段 | 核实值 |
|---|---|
| arXiv | **2505.09388**（Submitted **2025-05-14**） |
| PDF | 已下载 `https://arxiv.org/abs/2505.09388`（pdfTeX CreationDate 2025-05-15 CST） |
| 许可（报告摘要） | **Apache 2.0** |

**型号谱（报告 §2）：**

- Dense：0.6B / 1.7B / 4B / 8B / 14B / **32B**
- MoE：**30B-A3B**（128 experts / 8 activated）、旗舰 **235B-A22B**（总 235B，激活 22B；128/8 experts）
- MoE：**无 shared experts**（相对 Qwen2.5-MoE）；global-batch load balancing loss。

**架构组件（稠密，报告）：** GQA、SwiGLU、RoPE、RMSNorm pre-norm；去掉 Qwen2 的 QKV-bias，引入 **QK-Norm**；词表 **151,669**。

**架构思想——Thinking Control（主）：**

1. **同一权重**支持 thinking / non-thinking（`/think`、`/no_think` 或 chat template；默认 thinking）。
2. **Thinking budget**：达用户阈值可截断思维并插入固定 stop 指令再给最终答——报告称该能力由 mode fusion **涌现**，非单独专项训练。
3. 旗舰四阶段后训练：Long-CoT cold start → Reasoning RL（**GRPO**）→ Thinking Mode Fusion → General RL；小模型 **Strong-to-Weak Distillation**（off-policy + on-policy logits KL）。

**预训练 Infra 要点：**

- 约 **36T** tokens，**119** 语言/方言；三阶段：通用 ~30T @4K → 推理增强 ~5T → 长文至 **32K** 训练（推理可用 YARN/DCA 扩至更长，报告另有 RULER 评测）。
- 长文：RoPE base 提到 **1,000,000**（ABF）等。

## 五、常见误区与引用表

### 5.1 常见误区

1. **把聚合站「GPT-5.0-turbo-moe-1.2T」一类名称当官方型号**
 以 OpenAI 介绍页与 *Model Release Notes* 为准：公开产品名是 GPT-5 / thinking / pro，以及后续 **5.3 / 5.4 / 5.5 / 5.6 Sol**、Codex 变体等。未见官方披露「GPT-5 总参数 = xxx」——见则标谣言直至有官方 URL。

2. **把「Claude 4」当成单一权重名**
 官方是 **Opus 4 + Sonnet 4** 一对 hybrid 型号，不是只有一个「Claude-4」。

3. **把 Gemini 2.5 的自定义 agent SWE 分数与他厂「官方 scaffold」横比而不读脚注**
 Google 页写明 SWE-Bench Verified **63.8% with a custom agent setup**；Anthropic / OpenAI 亦各有子集与脚手架差异。

4. **Llama 4 Behemoth 当已可下载旗舰**
 官方明确 **still training**，发布的是 Scout / Maverick；Behemoth 作教师。

5. **DeepSeek-V3「671B」当成每 token 算力**
 总参 671B，**激活 37B**；谈推理成本必须用激活参。

6. **Qwen3 = 只会「慢思考」**
 官方卖点恰恰是 **同一模型** 可 fast path（non-thinking）与 deep path（thinking）+ budget，不必像过去在「聊天模型 / 推理模型」间换权重。

7. **开源 = 可任意商用**
 以各许可证为准：Qwen3 报告写 Apache 2.0；Llama 开放权重条款 **待核实原文**；DeepSeek 权重许可以 GitHub/模型卡为准 **待核实**。

8. **用 2026 年中的 ChatGPT 默认名倒推 2025-08 的 GPT-5 论文级架构**
 Release Notes 显示默认与路由在变；**架构白皮书级披露仍然缺位**。
