# Protein design 增量：BindCraft + RFdiffusion（相对 13）

> **定位**：蛋白质设计增量——相对 **[[生物学基础模型]]**（AF3 结构预测扩散 + ESM3 序列–结构–功能 LM）的 **de novo binder / 骨干生成设计流水线**增量。主锚 **RFdiffusion**（Watson et al., *Nature* 2023）与 **BindCraft**（Pacesa et al., bioRxiv v3 → *Nature* 2025 定稿）。
> **攻坚线**：**架构思想（主）**——扩散骨干生成 vs AF2 反传幻觉；**评测字段（辅）**——文内 in silico success 定义、实验命中率、亲和力与结构验证口径。
> **硬划界（禁止重写）**：
> - **≠ [[生物学基础模型]] AF3 / ESM3 全文**：不重写 Pairformer+原子坐标扩散、ESM3 多轨道掩码 LM、Forge API；本篇只取「AF2/RF 作**过滤器或幻觉骨干**」的接口句。
> - **≠ [[扩散语言模型]] / `B10`**：离散文本 MDM / 图像 LDM 通史不写；此处噪声在 **残基帧（Cα+刚体取向）** 或 **序列 logits→结构**，不是像素/词表。
> - **≠ [[MatterSim材料基础模型]] MatterSim**：材料原子势，非蛋白 binder。
> **安全硬约束**：只写**公开方法与评测字段**；**禁止**生物武器化、增益功能（GOF）、病原体增强、筛选规避的可复现操作层。病毒/核酸酶靶标仅作论文自报评测对象的**存在性/结果字段**，不展开合成/投递/逃逸配方。
> **禁止编造**：命中率、Kd、r.m.s.d.、滤镜阈值一律锚定官方 PDF（2026-09-22 CST）；Fig. 柱高未抽出的精确百分点标「待核实读图」。

**一句话抓手：**
- **RFdiffusion** = 把 **RoseTTAFold** 微调成 **残基帧去噪网络**，从噪声迭代生成骨干 → **ProteinMPNN** 填序列 → **AF2** 过滤；一条模型覆盖无条件单体、对称寡聚、motif scaffolding 与 **site-conditioned binder**。
- **BindCraft** = **不做骨干扩散**，直接对 **AF2 multimer** 做 **序列幻觉反传**（ColabDesign），再 **MPNNsol** 优化非界面残基，用 **AF2 monomer + Rosetta** 滤镜筛「少样本可实验」的 binder。

**跟读口诀：**

`
[[生物学基础模型]] AF3：给定组分 → 预测复合物坐标（结构求解）
[[生物学基础模型]] ESM3：掩码 LM → 生成序列/结构/功能 token
 ↓（本篇）
RFdiffusion：噪声帧 → 扩散去噪骨干 → MPNN 序列 → AF2 过滤 → binder/装配
BindCraft：随机序列 → AF2 反传幻觉（结构+序列+界面同迭代）→ MPNNsol → 滤镜 → binder
`

## 二、相对 [[生物学基础模型]] 的问题立轴

### 2.1 为何需要「设计流水线」增量

| 轴 | [[生物学基础模型]] **AF3** | [[生物学基础模型]] **ESM3** | 本篇 **RFdiffusion** | 本篇 **BindCraft** |
|---|---|---|---|---|
| 核心问题 | 预测已有/给定组分的结构 | 进化规模生成式 LM | **生成**满足规格的新骨干/界面 | **少样本**生成可结合靶标的 binder |
| AF2/RF 角色 | AF3 自身是预测器 | 结构 token 解码旁路 | RF = **去噪网络**；AF2 = **验证/过滤** | AF2 = **生成器（反传）+ 过滤器** |
| 典型输出 | 坐标 + 置信度 | 序列/结构/功能 token | 骨干坐标 → 序列设计 | 已含序列的 binder–靶标复合物假说 |
| 实验叙事重心 | 结构精度基准 | 生成与功能提示 | 数百装配/金属结合/binder；cryo-EM | 12 靶标、平均实验命中率 **46.3%**（文自报） |

跟读：**AF3「预测你给的东西长什么样」≠ RFdiffusion「从噪声造一个该长成什么样的骨架」≠ BindCraft「用 AF2 梯度把序列拧成能贴上靶标的 binder」。**

### 2.2 两条设计哲学对照

| | **RFdiffusion** | **BindCraft** |
|---|---|---|
| 生成原语 | **DDPM 去噪**（帧空间） | **Hallucination / 反传**（序列空间） |
| 靶标处理 | 设计时常 **固定靶标**；hotspot 条件化 | **每步重预测复合物**；靶标可柔顺（文报靶标 Cα RMSD **0.5–5.5 Å**） |
| 序列从哪来 | 默认后置 **ProteinMPNN**（常每骨干 **8** 条） | 幻觉阶段已出序列；再 **MPNNsol** 只改核心/表面、**保留界面** |
| 宣称优势 | 通用骨干生成器；binder 实验命中相对旧 Rosetta 流水线 **约两个数量级**（文归因：扩散 ≈1 阶 + AF2 过滤 ≈1 阶） | 「one-shot / 少筛选」：实验成功 **10–100%**，平均 **46.3%**；不必筛成百上千 |

## 三、站 1：RFdiffusion — RoseTTAFold 作蛋白骨干扩散

### 3.1 架构思想（主文开篇–Fig.1）

1. **动机**：先前蛋白 DDPM 难出可设计骨干；结构预测网络（AF2/RF）已隐含丰富结构先验。
2. **表示**：每个残基 = **Cα 坐标 + N–Cα–C 刚体取向**（RF frame）。
3. **前向加噪（至多约 200 步）**：平移 = Cα 上 3D 高斯；取向 = 旋转流形上 Brownian（文引 Riemannian / SO(3) 扩散文献）。
4. **训练损失**：**m.s.e.**（预测帧 vs 真结构，**不对齐**全局坐标）——相对 RF 结构预测常用的 **FAPE**，m.s.e. **不**对全局参考系不变，以保持时间步间坐标连续。
5. **推理**：随机帧初始化 → 每步预测干净结构 $\hat{X}_0$ → 向预测方向迈步并加噪 → 匹配前向分布；轨迹常 **~200** 步。
6. **Self-conditioning**：下一步可条件于上一步预测（类比 AF2 recycling）；文称显著提升 in silico 表现。
7. **预训练权重关键**：从预训练 RF 微调 **远优于** 同等时长从零训练；去掉 self-conditioning 或改用 FAPE 会显著掉点（Fig.2e 叙述；柱高待核实读图）。
8. **条件输入（任务相关）**：部分序列、fold（二级结构 / block-adjacency）、**固定功能 motif 坐标**、对称噪声、**interface hotspots**（binder 微调）。
9. **序列**：骨干出后用 **ProteinMPNN**；文称未大力探索「扩散内同时出序列」。

**与 [[生物学基础模型]] 接口一句：** 验证时用 **AF2 单序列预测**定义 in silico success——**不是**把 AF3 当作本流水线去噪器。

### 3.2 In silico success 字段（全文统一口径）

文定义：对 RFdiffusion 输出，AF2 单序列预测须同时满足：

| 条件 | 阈值 |
|---|---|
| 置信 | 平均 **pAE < 5** |
| 全局 | 相对设计骨干 **r.m.s.d. < 2 Å** |
| Motif（若有） | 功能位点骨干 **r.m.s.d. < 1 Å** |

文称该口径比 TM-score 类指标更严，且与实验成功相关（引用既往工作）。

### 3.3 能力谱（评测字段，非操作手册）

| 任务 | 文内可核主张 | 实验/结构锚（摘录） |
|---|---|---|
| **无条件单体** | 可出 α/β/混合拓扑；AF2/ESMFold 可贴近设计至约 **600** 残基量级叙事 | 部分 200/300 aa 设计 CD 与高热稳定（Extended Data Fig. 3） |
| **Fold 条件** | TIM barrel 等 in silico success 文报 **42.5% / 54.1%**（TIM / 另一 fold；Fig.2 叙述） | ≥8/11 TIM 实验表征有信号（文述） |
| **对称寡聚** | 点群对称；辅助接触势可抬成功率 | SEC：608 设计中至少 **87** 寡聚态与模型一致（95% CI）；nsEM/cryo 多例；二十面体 HE0902 等 |
| **Motif scaffolding 基准** | 25 题：RFdiffusion **23** vs Hallucination **15** vs RFjoint Inpainting **19**；23 题中 **19** 题成功率高于另两法 | 含 p53–MDM2：文报 **0.5 / 0.7 nM** binder（肽天然约 **600 nM**） |
| **Binder（五靶）** | Influenza A H1 **HA**、**IL-7Rα**、**PD-L1**、**InsR**、**TrkA**；每靶筛 **95** 设计 | 总体实验成功（BLI ≥ 阳性对照最大响应 **50%**）**19%**；相对旧 Rosetta 流水线约 **×100**；HA_20 **KD ≈ 28 nM**；cryo-EM **2.9 Å**，复合物相对设计 **0.63 Å**，binder alone **~0.60 Å** |

**Binder 方法要点（公开字段）：** 在复合物结构上微调；输入 **interface hotspots**；可选再条件于二级结构/block-adjacency；设计后按 AF2 界面/单体置信过滤。

## 四、站 2：BindCraft — AF2 反传的 one-shot binder 流水线

### 4.1 流水线架构（Fig.1a / Results / Methods）

用户输入：**靶标 PDB**、binder 长度范围、最终希望通过滤镜的设计数；**hotspot 可选**（残基/链）；省略则由组合损失驱动选址。

`
随机 binder 序列 + 靶标模板
 ↓ ColabDesign / AF2 multimer（5 个权重随机切换，反传）
多阶段序列优化（连续 logits → softmax → straight-through → one-hot 突变）
 ↓ 轨迹初筛（如 pLDDT、界面接触、clash）
MPNNsol：保留界面 ~4 Å 残基；核心/表面重设计（常 20 序列；T=0.1；骨干噪声 0）
 ↓ AF2 monomer 复合物重预测（单序列；3 recycles；2 模板模型）
Rosetta FastRelax + InterfaceAnalyzer
 ↓ 预定义滤镜
选出实验候选（文建议：滤镜通过 ≥100；常从 i_pTM top20 里挑 ~10）
`

**关键差异（相对 RFdiffusion / RIFdock 文述）：** 每步 **重预测 binder–靶标复合物**，允许靶标侧链/骨干柔顺；负 helicity loss 可压纯螺旋、抬高 β 含量（代价：in silico 成功率下降）。

### 4.2 设计损失项（Methods 默认权重）

| 项 | 默认权重（文） |
|---|---|
| Binder **pLDDT** | 0.1 |
| Interface **i_pTM** | 0.05 |
| Binder 内归一化 **pAE** | 0.4 |
| Binder–靶标归一化 **pAE** | 0.1 |
| Binder 内接触 | 1.0 |
| Binder–靶标接触（可 mask 非 hotspot） | 1.0 |
| Binder **Rg** | 0.3 |
| Helicity（惩罚/促进螺旋） | −0.3 |
| 可选 N/C 端接近（环插入/AAV 等） | 0.1 |

优化四阶段迭代规模（文）：连续空间约 **50+25**；softmax 约 **45**；STE **5**；离散突变 **15**（每步突变数 ≈ **0.05 × binder 长度**）。差轨迹可在约 50 步后早停；β 轨迹 recycles **1→3**。

### 4.3 最终滤镜字段（Methods）

| 滤镜 | 阈值（文） |
|---|---|
| 复合物 **pLDDT** | **> 0.8** |
| **i_pTM** | **> 0.5** |
| **i_pAE** | **< 0.35** |
| Rosetta 界面形状互补 | **> 0.55** |
| 未饱和界面氢键数 | **< 3** |
| Binder 表面疏水比例 | **< 35%** |
| 结合态 vs 游离态 binder RMSD | **< 3.5 Å** |

另：每个 AF2 轨迹最多放行 **2** 条 MPNNsol 序列以保界面多样性。In silico：初始 AF2 轨迹满意置信 **16.8–62.7%**；MPNNsol 后最终滤镜通过 **0.6–65.9%**（Extended Data Fig. 1g）。

### 4.4 实验评测字段（文自报；靶标作结果锚）

- **总览**：约 **12** 个挑战性靶标；亲和力多数 **nM**、一例 **μM**；实验成功 **10–100%**，平均 **46.3%**（Discussion）。
- **受体类（摘录可核句）**：PD-1：筛 **53**（Fc 融合），**13** 有结合，最佳表观 **Kd\* < 1 nM**；PD-L1：**7/9**，最佳表观 **Kd\* 615 nM**；IFNAR2：**3/9**，**Kd 260 nM**；CD45：**4/16**，最佳 **Kd 14.7 nM**。
- **其他类别（仅字段）**：可溶性 claudin 类似物、de novo β-barrel、尘螨/桦树过敏原、多结构域核酸酶（含 SpCas9 / Argonaute 等文内靶）、AAV 衣壳重靶向等——文报有结合/功能读出；**本笔记不展开核酸编辑或载体工程步骤**。
- **结构验证（Data availability）**：晶体 **9HAC / 9HAD / 9HAE / 9HAF**；模型 Zenodo **10.5281/zenodo.14249738**。
- **局限（Discussion 自述）**：大复合物 GPU 显存（例：约 **500** aa 复合体约 **30 GB**）；AF2 monomer 过滤可能剔真阳性；**i_pTM 利于是否结合、不相关于亲和力**；点突变效应 AF2 不敏感 → 辅以 Rosetta。
