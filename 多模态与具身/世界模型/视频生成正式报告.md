## 2. Sora 2：仅据官方博文 + System Card 的「已核实主张」

### 2.1 能力口径（博文，非参数）

仅摘要官方措辞，**不外推**架构：

| 项 | 官方声称（压缩） |
|----|------------------|
| 定位 | Flagship **video and audio** generation；同步对话与音效 |
| 叙事类比 | 原版 Sora ≈ 视频的「GPT-1」；Sora 2 ≈ 团队所称「GPT-3.5 moment for video」 |
| 物理 | 相对前代「过度乐观、变形凑 prompt」；举例：投篮不进则反弹而非瞬移进筐；强调要能 **model failure** |
| 可控 | 多镜头指令、世界状态保持；写实 / 电影 / 动漫风格 |
| 注入真实主体 | 短时 video+audio 录入后可把人/动物/物体放入生成场景（「characters」） |
| 变体名（产品） | **Sora 2**；实验性更高质量 **Sora 2 Pro**（ChatGPT Pro / sora.com） |
| 训练数据（System Card §2） | 泛称：公开网、第三方合作、用户/标注者提供；有过滤与安全分类器——**无**规模/配方表 |

## 3. 可核正式报告锚：*Video models are zero-shot learners and reasoners*

| 字段 | 值 |
|------|-----|
| 文献 | Wiedemer, Li, Vicol, Gu, Matarese, Swersky, Kim, Jaini, Geirhos（**Google DeepMind**） |
| 标识 | arXiv:**2509.20328**（抽取页眉见 v2 **29 Sep 2025**） |
| 项目页 | https://video-zero-shot.github.io/ |
| 对象模型 | **Veo 3**（公开 Vertex API；文内 model ID 例：`veo-3.0-generate-preview`）；对照 **Veo 2** |
| 方法本质 | **黑盒提示评测**（图像首帧 + 文本 → 生成视频），**不是** Veo/Sora 的训练配方 TR |

### 3.1 一句话抓手（可跟读）

大语言模型靠「大规模 + 生成式目标」长出零样本；作者问：**生成式视频模型是否同样走向通用视觉基础模型？** 在 **62** 项定性 + **7** 项定量任务、共约 **1.8 万** 段生成视频上，报告 Veo 3 可零样本做分割、边缘、编辑、直觉物理、 affordance、工具使用，以及迷宫/对称等早期视觉推理；并提出 **chain-of-frames（CoF）** 类比 CoT。

### 3.2 与「正式报告缺口」的关系

| 用途 | 说明 |
|------|------|
| **可核** | 公开 arXiv PDF；方法/数字可跟读 |
| **不是** | OpenAI Sora 2 官方长 TR；也 **不** 披露 Veo 内部权重配方 |
| **对本议题的价值** | 提供「视频生成模型 = 视觉通用零样本学习者」的 **学术正式报告** 锚点，填补「旗舰产品无长 TR」时的跟读空档 |

### 3.3 跟读时勿混淆的边界

- 文内 Vertex **prompt rewriter**（LLM）可能介入部分题；作者将 rewriter+生成器视为黑盒，并对关键推理题用独立 LLM（Gemini 2.5 Pro）对照。
- 定量上强调 **pass@k**、best-frame vs last-frame；专项模型（如 SAMv2）仍常更强——作者自比早期 GPT-3「通才未精专」。
- **不**把文中 Veo 成功样例数字写成 Sora 2 能力表。
