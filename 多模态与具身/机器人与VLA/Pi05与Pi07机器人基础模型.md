## 三、π₀.₅：开放世界泛化的 co-training 配方

### 3.1 问题与中心主张（文内）

VLA 常在「接近训练分布」的场景评测；长程家务（清厨房/卧室，**10–15 分钟**量级）若只靠暴力扩移动操作轨迹，覆盖不足。π₀.₅ 主张：用 **异质监督的统一序列建模** 做知识迁移——移动操作一手数据只需中等规模（文内 **约 400 小时**、约 **100** 个家庭环境），第一训练阶段 **97.6%** 样本来自 **非**「移动操作做家务」源（其他机器人 / web 等），仍能在 **训练未见** 的新家部署。

### 3.2 架构接口（相对 π₀ 的增量）

| 字段 | 文内要点 |
|---|---|
| 初始化 | 标准 web VLM；附录写明骨干 **PaliGemma**，**2B** VLM + **300M** action expert（与 π₀ 同宽配置族） |
| 联合分解 | $\pi(\mathbf{a},\hat{\ell}\mid o,\ell)=\pi(\mathbf{a}\mid o,\hat{\ell})\,\pi(\hat{\ell}\mid o,\ell)$——高层出语义子任务 $\hat{\ell}$，低层以 $\hat{\ell}$ 为条件出动作 chunk |
| 预训 | **全离散**：文本 / 目标框 / **FAST** 动作 token；**280k** steps；$\alpha=0$ |
| 后训 | 加入 **flow matching action expert**（随机初始化）；$\alpha=10$；再 **80k** steps；保留 NTP |
| 推理 | 先自回归出 $\hat{\ell}$，再 **10** 步 denoising 出连续动作；控制 **50 Hz**（action chunking） |
| 注意掩码 | 图像 / 文本前缀 / 连续动作 token 双向；FAST 与 flow 两路动作 **互不注意**，信息单向 VLM→action expert |

**与「两模型级联」对照（文内）：** 许多工作用独立 VLM 规划 + 独立低层策略；π₀.₅ 用 **同一套权重** 做 HL 与 LL，更接近 CoT / test-time compute，但 HL 频率仍低于 LL。

### 3.3 数据混合物（名称级）

| 代号 | 内容（压缩） | 阶段 |
|---|---|---|
| **MM** | 移动操作家务，~400h / ~100 家 | 预训+后训（后训滤成功且长度阈值下） |
| **ME** | 多环境 **非移动** 单/双臂（易搬运→更广家庭覆盖；本体不同） | 预训+后训 |
| **CE** | 实验室跨本体 + 开源 **OXE**（π₀ 数据扩展） | **仅预训**（后训省略以聚焦移动+多样环境） |
| **HL** | 人工子任务语义标注；先预测相关 bbox 再预测子任务 | 预训；后训保留多环境切片 |
| **WD** | caption / VQA / 定位（CapsFusion、COCO、Cambrian-7M、PixMo、VQAv2 等） | 预训+后训 |
| **VI** | 语言「teleop」：人用语言逐步指挥已学低层策略 → 高质量 HL 示范 | **仅后训** |

### 3.4 机器人与控制（汇总）

两型移动双臂：各 **6 DoF×2** + 夹爪 + 全向底盘 + 升降；四相机（前/后/双腕）；状态-动作约 **18–19 DoF**。模型直接出臂/爪/升降目标位姿与底盘速度，**PD** 跟踪，**无**额外轨迹规划/碰撞检测。HL 用四相机；LL 用腕+前视。

### 3.5 评测字段（辅；汇总级）

| 问题轴 | 设置 | 文内结论（定性+关键锚点） |
|---|---|---|
| 真房泛化 | **3** 个未见真房厨房+卧室；任务如 items in drawer / laundry basket / dishes in sink；进度量表见附录 | 图 7：能稳定完成多阶段任务；mock 与真房趋势一致 |
| 场景数缩放 | 移动数据地点 **3→104**；mock 四任务 + 语言跟随（ID/OOD 物体） | 地点↑ → 任务进度与语言跟随↑；104 地点接近「训时见过测试房」对照 |
| 混合物消融 | no WD / no ME / no CE / no ME&CE | ME/CE 对端到端进度关键；WD 对 **OOD 物体**语言跟随与 HL 质量更关键 |
| 博文公开语言跟随 %（辅核） | 同系 OOD/ID 物体评测（博文柱图） | ID follow：**86%**（no ME **66%** / no CE **74%**）；OOD follow：**94%**（no WD **80%** / no ME **33%**）；OOD success：**94%**（no WD **74%** / no ME **31%**） |
| vs π₀ | 同跨本体机器人数据、可比步数；另比 π₀-FAST+Flow（仅动作、无 HL/WD） | π₀.₅ **显著优于** π₀ 与增强版（图 12） |
| HL 必要性 | full / no WD / no VI / implicit HL / no HL / GPT-4 HL / human HL | full 最好，甚至优于 human HL；implicit HL（训含 HL、推不含）已获大部分增益；**VI 仅占 HL-MM 约 11% 却关键**；零样本 GPT-4 HL 最弱 |

**评分量表（附录，名称级）：** Dishes in Sink 满分 8；Items in Drawer 满分 4；Laundry in Basket 满分 3；Make the Bed 满分 5——报告为得分占比。

### 3.6 局限（文内）

仍会犯错：陌生把手、遮挡导致部分可观测、HL 被抽屉开合循环分心等；提示复杂度受标注限制；上下文/记忆偏短（跨房间、记物位置）。

## 四、π₀.₇：可操纵上下文 → 通用开箱与涌现能力

### 4.1 问题与中心主张（文内）

朴素混入多策略、失败轨迹、自洽 rollout 会导致 **模态平均 → 次优**。π₀.₇ 的关键：训练时给每条轨迹 **详细上下文 $C_t$**（不仅 what，还有 how），测试时可选用子集，使模型 **可操纵（steerable）**，从而吃下异质/次优数据并显现组合泛化。

博文（2026-04-16）同构强调：语言子步 + metadata + 控制模态 + 视觉子目标，把 Recap/π\*_0.6 等专家经验 **蒸馏回单一通用模型**。

### 4.2 架构接口（相对 π₀.₅ / π₀.₆-MEM）

| 字段 | 文内要点 |
|---|---|
| 总参 | 约 **5B**：Gemma3 **4B** VLM（含 ~400M 视觉）+ **860M** flow action expert + MEM 风格历史编码 |
| 记忆 | 最多 4 相机 × 最多 **6** 帧历史（1s stride）；历史整段 dropout **0.3** |
| 子目标图 | 最多 3 视图（通常省略后视）；**448×448**；由轻量 world model（**BAGEL 14B** MoT 初始化，CFM 目标）生成——**本卡不展开世界模型通史** |
| KI | Knowledge Insulation：骨干用 FAST 离散监督；action expert 注意骨干但 **梯度不回传** 骨干 |
| RTC | 训练时模拟 **0–12** step 延迟（50Hz 上至约 240ms） |
| 推理 | **5** denoising steps → 50-step chunk；执行 $\hat H\in\{15,25\}$；可对 metadata 做 **CFG**（$\beta\in\{1.3,1.7,2.2\}$） |

### 4.3 Prompt 组件（可独立 dropout）

| 组件 | 训练/测试用法（压缩） |
|---|---|
| **总任务语 $\ell$ + 子任务 $\hat\ell$** | 继承 π₀.₅；可 live coaching；可再训 HL 策略实现全自动 |
| **多视图子目标图 $g$** | 批内约 **25%** 样本带图；带图时 30% 丢掉文本子任务；测时异步刷新（子任务变或 **Δ=4s**） |
| **Episode metadata** | Speed（500-step 分桶）、Quality **1–5**、Mistake 段标签；整段 dropout 15% + 分量各 5%；测时常用 Quality=5、Mistake=false、Speed=该任务长度 **15th percentile** |
| **Control mode** | `joint` / `ee` 文本标记；**不** dropout |

示例串（文内）：`Task: peel vegetables. Subtask: pick up the peeler. Speed: 8000. Quality: 5. Mistake: false. Control Mode: joint.`

### 4.4 数据立场（相对经典「只保留高质量 demo」）

显式纳入：多平台演示、**失败/低质**演示、先前模型 **autonomous eval**（含 RL 后训专家 rollout；排除泛化评测任务本身）、开源机器人集、第一人称人类视频、web 多模态与视频-语言。Metadata 用于在混质数据上对齐「要哪种行为模式」。

### 4.5 评测字段（辅；汇总级）

| 轴 | 文内主张 / 关键数字 |
|---|---|
| **开箱灵巧** | 同模型对 espresso / laundry / box 等可达 **π\*_0.6 RL 专家**量级成功率与吞吐（洗衣/叠盒吞吐甚至更高，图 6）；无 metadata 或无 eval data 消融显著变差（图 7） |
| **需记忆任务** | 开箱可比 MEM 论文中的任务微调专家（图 8） |
| **未见环境指令跟随** | 4 未见厨房 + 2 未见卧室，14 场景、每场景 3–6 步开放指令；**显著优于 π₀.₅ / π₀.₆**（图 9） |
| **复杂指代 / 反偏差** | 非常规指代与「反向收台/反向冰箱→微波」；子目标图（GC）对反偏差关键（图 10–11） |
| **跨本体** | 静态双臂洗衣数据 → **UR5e 双臂**零样本折叠；任务进度 **85.6%**、成功率 **80%**，对照资深遥操作员零样本 UR5e：**90.9%** 进度 / **80.6%** 成功（10 人，人均约 **375h** 遥操作经验） |
| **组合泛化** | 短程新技能可纯语言开箱；长程（空气炸锅烤红薯、烤贝果等）靠 **语言 coaching**，再把 coaching 轨迹训 HL → 全自动接近 live coaching（图 14–16） |
| **混质可扩展** | 有 metadata 时扩大混质洗衣数据持续变好；无 metadata 则可能随低质数据变差（图 18 左）；去掉「任务多样性最高 20%」伤害组合泛化（图 18 右） |

**局限（文内）：** 分布内成功率常 **>90%**，未见任务/未见任务-本体组合约 **60–80%**；超大数据上「何谓真正未见」难以严格界定——作者将其视为组合泛化本质而非纯污点。

### 4.6 机器人平台（索引）

移动双臂、静态轻量双臂（BiPi）、**UR5e+Robotiq** 跨本体、单臂 6DoF 语言实验；多数 **50 Hz**，UR5e **20 Hz**；简单 PD（ee 指令经数值 IK）。
