# Robotics VLA 谱系（观测 → 动作）

> **定位**：具身 VLA 横切——立 **具身 Vision-Language-Action** 线：把预训练 VLM 接到 **闭环机器人控制**；相对 **[[多模态架构脉络]]**（多模态理解）与 **[[SpeechLLM语音语言模型]]**（观测→文本）的平行轴。
> **攻坚线**：**架构思想（主）**。
> **刻意不写**：**世界模型 / JEPA 表征预测 / MPC·CEM 规划正文**（见 **[[世界模型与VJEPA]]**）；本篇只保留一句交叉：VLA 是 **直接策略** $o\to a$，一般 **不显式** 学世界动力学。
> **禁止编造**：动作编码、骨干、数据量、Hz、成功率等一律取自官方 PDF（2026-09-22 CST）与 RT-2 项目页纯文本；评测表只引摘要级数字，不臆造未核对的分项。

## 二、何谓 VLA（本议题边界）

### 2.1 定义句（跟读）

RT-2 摘要原意压缩：用互联网尺度 VLM，**端到端**学习 **观测 → 动作**，同时保留 web 预训练带来的语义泛化；做法是把动作写成 **与自然语言同一格式的 token**，与轨迹数据一起进训练集——此类模型称 **vision-language-action（VLA）**。

相对相邻路线：

| 路线 | 数据流 | 本篇是否主写 |
|---|---|---|
| **级联规划**：VLM/LLM 出子目标 → 独立低层控制器 | 语言/子任务在中层 | 否（π₀ 可外挂 high-level VLM，仅一句） |
| **世界模型 + 规划**（[[世界模型与VJEPA]]） | 学 $s,a\to s'$ 或表征预测，再规划动作 | **否**；交叉一句见 §六 |
| **纯行为克隆 / Diffusion Policy 等小策略** | $o\to a$，无 Internet VLM 骨干 | 作对照基线提及，不展开配方 |
| **VLA（本篇）** | 图像（+语言指令）→ **策略直接输出动作** | **是** |

### 2.2 谱系三站（架构主轴）

`
Web VLM 预训练
 │
 ├─ RT-2（2023） 动作→离散 token，与语言共享输出头；co-fine-tune 机器人+web
 │
 ├─ OpenVLA（2024） 同一离散配方的开源复现/加强：Prismatic-7B + OXE 970k + LoRA
 │
 └─ π₀（2024→） 放弃自回归离散动作；VLM 骨干 + action expert，flow matching 出连续 action chunk
`

## 三、RT-2：动作即文本 token

### 3.1 骨干与实例

据 §3.1：在 **PaLI-X** 与 **PaLM-E** 上实例化为 **RT-2-PaLI-X**、**RT-2-PaLM-E**；规模从数十亿到 **55B**（文称当时用于直接闭环控制的最大模型量级之一）。

### 3.2 动作离散化（继承 RT-1）

据 §3.2（基于 Brohan et al. 2022 / RT-1）：

| 项 | 论文事实 |
|---|---|
| 动作空间 | 末端 **6-DoF** 位姿增量 + **夹爪开合** + **episode terminate** 离散命令 |
| 连续维 | 均匀 **256 bins** |
| 表示 | 8 个整数 ordinal → 拼成字符串目标，例如 `"1 128 91 241 5 101 127"` 形态 |
| 提示格式 | VQA 式：`Q: what action should the robot take to [task]? A:` |

**Tokenizer 挂钩（跟读）：**

- **PaLI-X**：≤1000 的整数各有独立 token → 直接把 bin 映到对应整数 token；
- **PaLM-E**：无方便数字 token → **覆盖词表中最少使用的 256 个 token** 作为动作词表（文称一种 symbol tuning）。

### 3.3 Co-fine-tuning 与输出约束

- **Co-fine-tune**：机器人轨迹 **与** 原始 web/VQA 数据同批混训（提高机器人数据采样权重），相对「只在机器人数据上 finetune」更利于泛化（§3.2、实验消融）。
- **Output constraint**：机器人任务解码时 **只采样合法 action token**；web 任务仍可用全自然语言词表。

### 3.4 实时与评测量级（边界内引用）

- 55B：**1–3 Hz**（多 TPU 云端 + 网络查询）；5B：约 **5 Hz**（§3.3）。
- 摘要：**~6k** evaluation trials；强调未见物体、未见指令、简单语义推理，以及 **chain-of-thought** 多步语义推理示例（选锤子式物体 / 提神饮料等——属定性能力叙事，本篇不重抄全部分项表）。

**可跟读金句：** 「express the actions as text tokens and incorporate them directly into the training set … in the same way as natural language tokens。」

## 四、OpenVLA：开源离散 VLA 工业化

### 4.1 动机（相对 RT-2 族）

摘要两点缺口：(1) 既有 VLA **多为闭源**；(2) **高效微调到新机器人/场景** 的实践不足。OpenVLA 给出 **7B**、**970k** 真实演示、代码/权重/HF 管线。

### 4.2 架构（Figure 2）

建在 **Prismatic-7B** VLM 上（§3.1）：

| 组件 | 声明 |
|---|---|
| 视觉 | **SigLIP + DINOv2** 双编码器，patch 特征 **通道维拼接**（约 600M 视觉侧） |
| 投影 | 小型 **2-layer MLP** |
| 语言骨干 | **Llama 2 7B** |
| VLM 数据 | Prismatic 在 LLaVA 1.5 混合上微调（约 1M 图文样本量级，§3.1） |

设计选择摘要（§3.4，BridgeData V2 小规模预实验）：Prismatic 相对 LLaVA / IDEFICS-1 在语言 grounding 上更好；输入 **224×224**（相对 384 无增益且省算力）；**解冻视觉编码器** 对 VLA 关键（与「VLM 常冻视觉」相反的经验）；需训到 action token 准确率 **>95%**，最终跑满 **27 epochs**。

### 4.3 动作编码：同系离散，量化边界改 quantile

仍遵循 Brohan et al.：**每维 256 bins** → 覆盖 Llama tokenizer **最少使用的 256 token**；损失为 **仅在 action token 上的 next-token CE**（§3.2）。

相对 RT-2 的显式改动：bin 边界取训练数据该维的 **1%–99% 分位数**（而非 min–max），以减轻异常值撑开区间、稀释有效分辨率。

### 4.4 数据与对照结果（摘要级）

- 数据：Open X-Embodiment 策展后的 **970k** 操作轨迹；限制为至少一路第三人称相机 + **单臂末端控制**；混合权重参考 Octo；DROID 曾加入但后期因准确率低而移除（§3.3）。
- 摘要声明：在 WidowX / Google Robot 共 **29** 任务上，绝对成功率相对闭源 **RT-2-X（55B）** 高 **16.5%**，参数约 **7×** 更少；微调设定相对 Diffusion Policy 等亦有优势声明（跟读时以文内图/表为准，勿外推到所有具身）。
- 部署：单卡 RTX **4090** 约 **6 Hz**（无编译/投机等加速）；支持 **LoRA**（文荐默认 rank **32**，约 **1.4%** 可训参量级）与量化服务（§3.5 / Table 1）。

**谱系位置：** 把 RT-2 的「动作 = token」配方 **开源化、可微调化**，仍属 **自回归离散动作** 分支。

## 五、π₀：从离散 token 到 flow matching

### 5.1 为何分叉

Introduction / Overview：先前 VLA（含 RT-2 式）用 **自回归离散化** 把动作当文本；文称这对 **高频（可达 50 Hz）** 与 **高灵巧** 任务构成主要挑战。π₀ 改用 **conditional flow matching**（扩散族变体）建模 **连续动作分布**，并配合 **action chunking**（文中任务取 horizon $H=50$）。

### 5.2 模型结构（§IV）

| 部件 | 事实 |
|---|---|
| VLM 骨干 | **PaliGemma**（约 **3B**），late-fusion：图像编码进与语言同一 embedding 空间 |
| 机器人条件 | 多路 RGB（2–3 路）、语言指令、本体感知 $q_t$（关节角等） |
| **Action expert** | 另设一组权重处理 **state / action** 槽位（类 MoE 两专家）；约 **+300M**，总参约 **3.3B** |
| 输出 | 动作 chunk $A_t=[a_t,\ldots,a_{t+H-1}]$；训练用 flow matching 损失，**非** CE over bins |
| 启发 | Transfusion：连续槽位 flow 损失 + 离散槽位 CE；推理 Euler **10** 步（$\delta=0.1$），可缓存观测前缀 KV |

形式目标（文中）：$p(A_t\mid o_t)$；损失
$L_\tau(\theta)=\mathbb{E}\,\|v_\theta(A_t^\tau,o_t)-u(A_t^\tau\mid A_t)\|^2$，线性–高斯概率路径 $A_t^\tau=\tau A_t+(1-\tau)\epsilon$。

> 文内「token」= 序列维上的槽位，**可离散可连续**——勿与 RT-2 的「动作=词表 ID」混读。

### 5.3 训练配方与具身

- **Pre-training：** 自有灵巧数据（文称 **7** 种机器人配置、**68** 任务；**903M** timesteps 量级，其中双臂为主）+ 开源子集（OXE Magic Soup / Bridge / DROID 等，混合中开源约占 **9.1%**）；任务–机器人组合按 $n^{0.43}$ 加权；动作/状态维零填充到最大配置（文称最大 **18** 维）。
- **Post-training：** 高质量任务专用数据，从约 **5** 小时到 **100+** 小时不等。
- 控制频率叙事：开源 OXE 类数据多为 **2–10 Hz**；自有灵巧任务可到 **50 Hz**（附录：如 50 Hz 平台每 **0.5 s** 推理一次并开环执行 chunk 内 25 步）。
- 可选用 **high-level VLM** 把「收拾桌子」拆成子指令（类 SayCan），π₀ 仍负责低层连续控制（§V-B）——**不是** 在 π₀ 里重写世界模型。

### 5.4 与离散 VLA 的对照句（文内）

文在 out-of-box 评测中写：部分灵巧任务上 **OpenVLA 因自回归动作表示而吃力**；π₀ 强调连续分布 + chunk 以换精度与流畅度。本笔记 **不** 把某一张成功率表抄成「全面碾压」——只固定架构结论：**动作接口从离散词表换成了 flow 向量场。**

## 七、跟读清单（可闭卷复述）

1. **VLA 定义：** 预训练 VLM + 统一序列接口输出机器人动作；RT-2 起名并验证 web 语义可迁到闭环控制。
2. **离散支：** 6-DoF(+夹爪…) → **256 bins/维** → 占用/覆盖 tokenizer 的动作 ID；损失 = action token 上的 CE；RT-2 强调 **co-fine-tune**；OpenVLA 用 **分位数 bin** + **SigLIP∥DINOv2 + Llama 2** + OXE **970k** + **LoRA**。
3. **连续支：** π₀ = **PaliGemma** + **action expert**；**flow matching** 出 $H=50$ 连续 chunk；总参约 **3.3B**；面向 **~50 Hz** 灵巧。
4. **划界：** 不写世界模型规划正文；不把闭源 API / 未核对分项表写成万能 SOTA。
