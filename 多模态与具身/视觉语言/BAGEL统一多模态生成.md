# 统一多模态生成：BAGEL（≠ 视频生成报告 / ≠ LDM·DiT）

> **主要来源**：[Emerging Properties in Unified Multimodal Pretraining](https://arxiv.org/abs/2505.14683)（Deng、Zhu 等，ByteDance Seed，简称 BAGEL，v1 2025-05-20，v3 2025-07-27）；[代码](https://github.com/ByteDance-Seed/Bagel) 与 [权重](https://huggingface.co/ByteDance-Seed/BAGEL-7B-MoT)（截至 2026-04-24）。
> **研究线**：架构思想（主：理解专家与生成专家共享自注意力的 MoT、双视觉编码器、交错数据预训练）；评测字段（辅：理解、文生图、编辑与智能编辑基准）
> **范围与相邻笔记**：
> - ≠ [[扩散生成式视觉与LLM]]：本篇不写图像潜扩散与 DiT 的历史，只写 BAGEL 如何把扩散式生成放进语言模型。
> - ≠ [[多模态架构脉络]]：本篇不写 CLIP → Flamingo → LLaVA 的理解侧通史。
> - ≠ [[视频生成模型脉络]]：BAGEL 用视频交错数据训练、能预测未来帧，但对象是统一基础模型，不是视频生成模型。
>
> **意义**：开源统一模型长期落后于 GPT-4o、Gemini 2.0 这类同时能看图和画图的闭源系统。BAGEL 的判断是瓶颈在架构和数据：它不用适配器去接外部扩散模型，而是让理解专家与生成专家在同一组自注意力里共享全部上下文，并在数万亿 token 的交错图文、视频与网页数据上预训练。结果是能力按「理解与生成 → 经典编辑 → 需要推理的智能编辑」的顺序随训练量涌现，7B 激活参数的模型在理解榜上超过同规模统一模型，在智能编辑上接近 Gemini 2.0，并开源了权重与代码。

---

## 一、问题背景

统一理解与生成的模型有三类设计（§2.1）：

| 类型 | 做法 | 问题 |
|---|---|---|
| 量化自回归 | 视觉离散成 token，与文本一起做下一 token 预测 | 实现简单，但生成质量经验上不如扩散模型，逐 token 生成也慢 |
| 外接扩散 | 语言模型经轻量适配器把语义条件交给外部扩散模型 | 收敛快、省数据，但语言模型的上下文被压成少量隐向量，形成显式瓶颈，长上下文多模态推理会丢信息 |
| 一体化 Transformer | 同一 Transformer 内同时做自回归理解与扩散式生成 | 算力更高，但全程没有瓶颈 |

BAGEL 选第三类，理由是最大化容量、避免启发式瓶颈，更适合在大规模交错数据上扩展（§1、§2.1）。

## 二、脉络

| 时间 | 工作 | 关键一步 |
|---|---|---|
| 2024-05 | [Chameleon](https://arxiv.org/abs/2405.09818) | 早期融合：图像离散成 token，与文本混合自回归 |
| 2024-08 | [Transfusion](https://arxiv.org/abs/2408.11039) | 同一 Transformer 对文本做下一 token 预测、对图像做扩散 |
| 2024-11 | [Mixture-of-Transformers](https://arxiv.org/abs/2411.04996) | 按模态拆分 Transformer 参数、共享全局自注意力 |
| 2025-01 | [Janus-Pro](https://arxiv.org/abs/2501.17811) | 理解与生成用不同视觉编码器的统一模型，BAGEL 的主要开源对照 |
| 2025-05 | BAGEL | MoT 加双视觉编码器，在交错图文、视频、网页数据上预训练，报告涌现性质 |

## 三、方法

### 3.1 架构（§2.2–2.4）

- **骨干与专家**：从 Qwen2.5 初始化，复制全部可训练参数得到一个同尺寸的生成专家（混合 Transformer，MoT）；生成专家只处理 VAE token，理解专家处理文本与 ViT token，两者在每层共享自注意力。总参数约为两倍（14B），但每个 token 只激活一个专家，计算量与稠密模型相同（7B 激活）。1.5B 规模的对照实验中，MoT 比稠密与只复制前馈层的 MoE 变体收敛更快、生成损失更低。
- **双视觉编码器**：理解用 SigLIP2-so400m/14，支持原生宽高比；生成用冻结的 FLUX VAE。
- **目标**：文本用下一 token 预测（交叉熵），图像用 Rectified Flow（均方误差），损失权重 0.25 : 1。
- **广义因果注意力**：同一样本按模态切段，后段可看前段；段内文本因果、图像双向。每张图准备带噪 VAE、干净 VAE 与 ViT 三套 token，后续内容只能看前面图像的干净表示。交错生成多张图时，按 Diffusion Forcing 给各图独立噪声级（[[DiffusionForcing族]]）。

### 3.2 数据与训练（§3–4）

- **交错数据**：视频来自公开在线视频等，用轻量 caption 模型描述帧间变化，得到 4500 万条时序交错序列；网页来自 OmniCorpus，经主题与规则过滤、在图前插入简短描述，得到 2000 万篇文档；另构造约 50 万条在生成前先写推理过程的样本（§3.3）。
- **四阶段**：对齐（只训连接层）→ 预训练（约 2.5T token）→ 继续训练（约 2.6T token，提高分辨率与交错数据比例）→ 监督微调（约 727 亿 token）（§4、Table 3）。
- **采样比**：1.5B 消融显示提高生成数据比例对生成损失更有利、对理解损失没有一致影响，因此生成样本显著多于理解样本（§4.1）。

## 四、结果

### 4.1 涌现性质（§6）

作者把「涌现」定义为早期训练阶段没有、后期才出现的能力。以达到峰值 85% 所需的训练 token 计：常规理解约 0.18T，文生图约 0.68T，经典编辑约 2.64T，需要推理的智能编辑约 3.61T。去掉 ViT token 对经典编辑影响很小，但让智能编辑下降 16%，说明语义视觉上下文对复杂编辑关键。

### 4.2 主要基准（§7）

| 能力 | 基准 | BAGEL | 对照 |
|---|---|---|---|
| 理解 | MMMU / MM-Vet（Table 4） | 55.3 / 67.2 | Janus-Pro 7B 低 14.3 / 17.1 分；Qwen2.5-VL 7B 为 58.6 / 67.1 |
| 理解 | MMBench（Table 4） | 85.0 | Qwen2.5-VL 7B 为 83.5 |
| 文生图 | GenEval（Table 5） | 0.82；用 LLM 改写提示后 0.88 | Janus-Pro-7B 0.80 |
| 世界知识文生图 | WISE（Table 6） | 0.52；先自写推理后 0.70 | GPT-4o 0.80 |
| 编辑 | GEdit-Bench-EN 总分（Table 7） | 6.52 | Gemini 2.0 6.32，GPT-4o 7.53 |
| 智能编辑 | IntelligentBench（Table 8） | 44.9；先自写推理后 55.3 | Gemini 2.0 57.6，GPT-4o 78.9 |

先写推理再生成在 RISEBench 上从 6.1 提到 11.9，在 KRIS-Bench 上从 56.21 提到 60.18（§7.4）。提高视频与导航数据比例微调后，模型还能做世界导航、旋转与多视角生成，但只有定性示例（§7.5）。

## 五、意义

BAGEL 说明统一多模态模型的上限主要取决于两点：理解与生成之间是否有信息瓶颈，以及数据是否足够「交错」。共享自注意力加分容量的专家既避免了外接扩散的瓶颈，又缓解了两种目标争夺参数；交错视频与网页数据则让编辑、导航等组合能力随训练量依次出现。它也是可复用的开源底座，例如 π0.7 用 BAGEL 14B 初始化生成子目标图像的轻量世界模型（[[Pi05与Pi07机器人基础模型]]）。

## 六、局限与待核实

- **作者自述（§7.6）**：特殊 IP、复杂文字渲染、复杂人体姿态、多实例同时生成仍困难；编辑中的物体换位、大量实例同时修改也常失败；复杂指令遵循上 BAGEL 与 Gemini 2.0 同样吃力，GPT-4o 最稳。作者建议加入含文字图像、扩大模型或做 RLHF。
- **闭源对照只在作答子集上计分**：IntelligentBench 上 GPT-4o 只答了 350 题中的 318 题，Gemini 2.0 答了 349 题，分数按作答部分计算（Table 8 注）；WISE 的 GPT-4o 分数取自他人测试（Table 6 注）。
- **理解侧并非全面领先**：MMMU 上 BAGEL 低于同规模的纯理解模型 Qwen2.5-VL 7B。
- **算力未公开**：论文没有给出总 GPU 时。
- **README 与论文口径**：仓库 README 记载 2025-06-15 修正了 KRIS-Bench 与 RISEBench 的评测，其表中这两项与论文 v3 一致；但 README 表中 BAGEL 的 IntelligentBench 为 44.0，论文 Table 8 与正文为 44.9，本篇按论文。
