# 扩散 / 生成式视觉与 LLM 交叉

> **主要来源**：[High-Resolution Image Synthesis with Latent Diffusion Models](https://arxiv.org/abs/2112.10752)（Rombach 等，LMU 慕尼黑 / Runway，简称 LDM，CVPR 2022，v2 2022-04-13）；[Scalable Diffusion Models with Transformers](https://arxiv.org/abs/2212.09748)（Peebles、Xie，UC Berkeley / NYU，简称 DiT，v2 2023-03-02）（截至 2025-07-27）。
> **研究线**：架构思想（主：潜空间扩散、交叉注意力条件、Transformer 去噪骨干）；数学原理（辅：去噪目标与无分类器引导）
> **范围与相邻笔记**：
> - ≠ [[多模态架构脉络]]：那篇写「看图说话」的理解与对话模型，本篇写「按文本出图」的生成模型。
> - ≠ [[视频生成模型脉络]]：本篇只写图像，视频怎样沿用这些做法在那篇。
>
> **意义**：扩散模型在 2021 年已在图像质量上超过 GAN，但在像素空间训练要数百 GPU 日，采样也慢。LDM 先训一个只做温和压缩的自编码器，再在它的潜空间里做扩散，并用交叉注意力把文本等条件接进去噪网络，把训练与采样成本降到单卡可做实验的量级；DiT 再把去噪网络从卷积 U-Net 换成标准 Transformer，表明生成质量随计算量（Gflops）稳定提升，在 ImageNet 类别条件生成上刷新纪录。两步合起来给出了今天文生图、文生视频的通用骨架：文本编码器给条件，潜空间里的 Transformer 去噪，解码器一次成像。LLM 在这条线上首先扮演的是条件编码器，而不是对话模型。

---

## 一、问题背景

「多模态」常被当成一件事，实际上有两条互不替代的能力：理解与对话学的是给定图像输出文本，生成学的是给定文本（或类别、布局）输出图像。两者训练目标、采样方式和评测（FID、IS 对 VQA、对话）都不同。生成线的瓶颈是成本：像素空间的扩散模型训练常要 150–1000 个 V100 日，在单张 A100 上生成 5 万张样本约需 5 天（LDM §1）。要在有限算力下保住质量与可控性，就得把扩散挪到维度更低、感知上等价的空间里。

## 三、方法

扩散模型由两个过程组成。前向过程固定、不需学习：按预设的噪声日程，在 $T$ 步里逐步往数据上叠加高斯噪声，直到接近纯噪声；第 $t$ 步的加噪样本记作 $x_t$，在 LDM 的潜空间里则是对编码 $z$ 加噪，记作 $z_t$。反向过程从纯噪声出发，由网络在每一步预测并去掉一部分噪声，迭代多步得到样本（LDM §3.2，DiT §3.1）。训练时只需让去噪网络 $\epsilon_\theta$ 预测前向过程加进去的噪声 $\epsilon$（DDPM），3.1 节的式子就是这一目标在潜空间上的条件版本，3.3 节的引导式沿用像素空间的记号 $x_t$。

### 3.1 LDM：感知压缩与语义生成分开（§1、§3）

1. **感知压缩**（§3.1）：自编码器把图像 $x\in\mathbb{R}^{H\times W\times 3}$ 编码为 $z=\mathcal{E}(x)\in\mathbb{R}^{h\times w\times c}$，下采样因子 $f=H/h$。用感知损失加局部对抗损失训练，使重建不模糊；潜空间用轻微 KL 正则或在解码器里加向量量化层两种方式约束。只训一次，之后冻结。
2. **潜空间扩散**（§3.2）：在 $z$ 上训练时间条件 U-Net 去噪，采样得到 $z$ 后经解码器一次还原成图像。因为 $z$ 保留二维结构，U-Net 的空间归纳偏置仍适用，不必像自回归路线那样把图像压得很狠。
3. **条件机制**（§3.3）：空间对齐的条件（语义图、低分辨率图、修复掩码）直接与输入拼接；文本等条件由领域编码器 $\tau_\theta$ 映成 token 序列，再通过交叉注意力接入 U-Net 中间层（查询来自图像特征，键值来自 $\tau_\theta(y)$）。条件 LDM 的训练目标（式 3）：

$$
L_{\mathrm{LDM}}=\mathbb{E}_{\mathcal{E}(x),y,\epsilon\sim\mathcal{N}(0,1),t}\Big[\lVert\epsilon-\epsilon_\theta(z_t,t,\tau_\theta(y))\rVert_2^2\Big]
$$

即预测加入的噪声；$\tau_\theta$ 与去噪网络联合训练。文生图实验中 $\tau_\theta$ 是用 BERT 分词器的 Transformer（§4.3.1）。

### 3.2 DiT：Transformer 去噪骨干（§3）

- **潜空间切块**：沿用 LDM 框架和现成的 Stable Diffusion 自编码器（下采样 8 倍，256×256 图像对应 32×32×4 的潜变量），按块大小 $p$ 切成 token 序列；$p$ 减半，token 数变为 4 倍，计算量至少变为 4 倍，参数量几乎不变（§3.2）。
- **条件注入**：比较了四种块设计：把时间步与类别作为额外 token 的上下文拼接、交叉注意力（约多 15% Gflops）、自适应层归一化（adaLN），以及把残差缩放初始化为零、使每块初始为恒等映射的 adaLN-Zero。adaLN-Zero 在整个训练过程中最好，此后全文采用（§3.2、Figure 5）。
- **规模档位**：S、B、L、XL 四档对应 ViT 的层数与宽度，配合不同 $p$ 覆盖 0.3–118.6 Gflops（§3.2）。

### 3.3 无分类器引导（DiT §3.1）

训练时随机把条件 $c$ 换成可学习的空嵌入 $\varnothing$，采样时把有条件与无条件预测外推：

$$
\hat\epsilon_\theta(x_t,c)=\epsilon_\theta(x_t,\varnothing)+s\cdot\big(\epsilon_\theta(x_t,c)-\epsilon_\theta(x_t,\varnothing)\big),\quad s>1
$$

$s$ 越大越贴合条件、多样性越低。LDM 与 DiT 的最好结果都用了引导（标 G 的变体）。

### 3.4 与 LLM 的接口

- **条件编码器**：LDM 的文本条件由与去噪网络联合训练的 Transformer 提供；DALL·E 2 改为先由文本生成 CLIP 图像嵌入再解码（DiT §2 提及）。LLM 在生成线里首先是提示编码器，不是对话模型。
- **骨干统一**：DiT 结论建议把它作为 DALL·E 2、Stable Diffusion 这类文生图模型的直接替换骨干（§6）；Stable Diffusion 3 改用把数据与噪声以直线相连的 Rectified Flow 训练，其 Transformer 让文本与图像 token 在同一网络中双向交换信息（SD3 摘要）。

## 四、结果

| 工作 | 评测 | 结果 |
|---|---|---|
| LDM | 压缩因子扫描，单张 A100、同参数同步数（§4.1） | LDM-4 到 LDM-16 在效率与保真之间平衡较好；训练 200 万步后 LDM-8 比像素空间的 LDM-1 的 FID 低 38 |
| LDM | CelebA-HQ 无条件生成 FID（Table 1） | 5.11，当时最好，优于此前的似然模型与 GAN |
| LDM | MS-COCO 256×256 文生图 FID，1.45B 参数、LAION-400M 训练（Table 2） | 23.31；加无分类器引导（$s$=1.5）为 12.63 |
| LDM | ImageNet 256×256 类别条件 FID（Table 3） | LDM-4-G 3.60 |
| DiT | ImageNet 256×256 类别条件 FID（Table 2、§5.1） | DiT-XL/2-G 2.27，此前最好为 LDM 的 3.60；算力 118.6 Gflops，LDM-4 为 103.6，像素空间 ADM 为 1120 |
| DiT | ImageNet 512×512 类别条件 FID（Table 3） | 3.04，此前最好为 ADM 的 3.85；算力 524.6 Gflops，ADM 为 1983 |
| DiT | 模型算力与采样算力（§5.2、Figure 10） | DiT-L/2 用 1000 步采样（每张 80.7 Tflops）的 FID-10K 为 25.9，DiT-XL/2 用 128 步（15.2 Tflops）为 23.7 |

DiT 的规模化结论（§5）：加深加宽或减小块大小都使 FID 在整个训练中持续下降，Gflops 相近的配置 FID 相近；固定模型档、减小块大小时参数几乎不变而 FID 下降，说明参数量不能决定质量；增加采样步数补不回模型算力的不足。

## 五、意义

LDM 把扩散从「只有大机构训得起」变成单卡可实验，并把文本条件接口定型为交叉注意力；DiT 把图像生成并入 Transformer 的规模化体系，此后的视频生成与统一理解生成模型（见第七节）多沿用潜空间去噪，并越来越多地采用 Transformer 骨干。对理解 LLM 而言，这条线说明「多模态」至少有两种接法：理解模型把视觉特征送进语言模型，生成模型把语言特征送进去噪网络。

## 六、局限与待核实

- **DiT 只做了类别条件**：DiT 的实验全部是 ImageNet 类别条件生成，文生图只是结论中的展望，不能当作文生图系统的结果。
- **LDM 的局限**（§5）：逐步采样仍慢于 GAN；$f$=4 自编码器的重建误差对需要像素级精度的任务（作者点名超分辨率）可能成为瓶颈。
- **LDM 版本差异**：v2 换用新训练的 1.45B 文生图模型并更新了文生图结果，ImageNet 类别条件结果也改为加大批量重训并加入引导（附录 A）；本篇按 v2，v1 的数字不同。
- **压缩因子的说法**：§4.1 先说 LDM-4 到 LDM-16 平衡较好，后又总结 LDM-4 与 LDM-8 最适合高质量合成，并指出 ImageNet 这类复杂数据集需要更低的压缩率；本篇两种说法都按原文保留。
- **评测口径**：FID 对引导强度敏感，带 G 与不带 G 的结果不能直接比较；DiT 用 Gflops 而非参数量衡量模型复杂度，与只报参数量的工作不可直接对比。
- **本篇不含**：视频生成与统一理解生成模型的结果分别在 [[视频生成模型脉络]] 与 [[BAGEL统一多模态生成]]。
