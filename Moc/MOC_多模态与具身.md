# MOC · 多模态与具身

## 综述

本页是**多模态理解 / 生成、世界模型与具身 VLA**的阅读枢纽：视觉—语言对齐与文档 / 长视频理解、图像与视频生成、语音与原生全模态、生成式与非生成式世界模型，以及本簇子节中的 VLA / 开源机器人栈。具身 / VLA **留在本页组 5**，不升专科顶级、不另建 MOC。

读材料时先分轴。一条是**理解轴**：CLIP → Flamingo → 视觉指令 → 原生多模态主张，以及文档压缩、音视联合理解。一条是**生成轴**：潜扩散 / DiT、视频生成与「世界模拟器」叙事，再对照非生成式世界模型（V-JEPA）与统一生成（BAGEL）。第三条是**具身轴**：感知—动作栈（VLA 谱系、LeRobot、π 系），与 Harness 的通用工具循环分读。史线 [[多模态与世界模型发展时间线]] **副挂本页**（主挂 [[MOC_发展时间线]]），作总览组并列读物。

与邻页划界：领域配方（医学 / 气候 / 材料 / 遥感等）见 [[MOC_专科基础模型]]；预训练缩放与 SFT 通论见 [[MOC_训练方法]]；旗舰通模**技术报告 / 系统卡**走模型报告树（体裁优先）——本页只收机制专题（如 [[QwenOmni音视频原生]]）；多模态越狱见 [[MOC_安全与评测]]（[[多模态越狱与OmniSafe]] 不列表挂本页）；通用榜单方法学见 [[MOC_评测与基准]]，[[MMMU多模态推理基准]] 作本簇推理基准切片**仍主挂本页**。

**本页管：** 视觉—语言理解与文档 / 长视频音视理解；图像 / 视频生成与统一多模态生成；语音与原生全模态机制；世界模型（生成式与非生成式）；具身 / VLA / 开源机器人栈（本簇子节）；本簇史线（副挂）；多模态主题向推理基准切片（MMMU）。

## 语音与原生全模态

解决语音怎样接入 LLM，以及文本 / 图像 / 音频 / 视频统一输入、流式出语音的原生全模态机制。[[SpeechLLM语音语言模型]] 立「音频编码器接 LLM、输出文本」坐标；[[SeamlessM4T语音翻译]] 偏统一语音翻译；[[QwenOmni音视频原生]]、[[StepAudio2语音旗舰]] 偏全模态 / 语音旗舰机制深读。组内建议：先 Speech-LLM 再 Omni / 旗舰；Seamless 按需并列。与厂商轨划界：本组管**机制专题**（如 Omni 的 Thinker–Talker、码本流式合成）；同厂旗舰通模技术报告整份配方自述主挂 [[MOC_厂商技术报告]]，本页不抢报告体裁。四篇均主挂本页。

## 具身与 VLA（本簇子节）

解决视觉—语言怎样接到闭环机器人控制，以及开源栈与 π 系机器人基础模型增量。本组是**本簇子节**：**不**升 [[MOC_专科基础模型]] 顶级，**不**新建独立 `MOC_具身`。[[视觉语言动作谱系]] 是组内入口与导读前沿落点（RT-2 → OpenVLA → π₀）；[[LeRobot开源栈]]、[[Pi05与Pi07机器人基础模型]] 接开源数据底座与 π 系增量。组内建议：先谱系再栈 / π 系。与专科划界：领域配方（医学 / 气候 / 材料 / 遥感等）留专科；本组管感知—动作栈。与 Harness 划界：通用工具循环 / 记忆层见 [[MOC_智能体Harness]]；本组不是 harness 通论。与世界模型划界：VLA 一般是直接策略，显式动力学 / 表征预测见组 4。三篇均主挂本页。
