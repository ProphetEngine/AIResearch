# MOC · 发展时间线

## 综述

本页是**史线枢纽**：不负责某一技术的机制深读，只回答三件事——总史从哪篇读；各主题簇的专题时间线在哪；读完一条史线后应转到哪个主题 MOC 继续（优先已新版式页的导读路线）。

库内史线分两类。一类是总史：从 Transformer 到当前主干的结构与范式演进，给尚无特定阅读目的的读者一张总图。另一类是专题时间线：预训练与架构、长上下文与注意力、对齐与强化学习、推理服务与投机解码、智能体工具与记忆，以及多模态、RAG、安全治理评测、系统卡披露等，各对应一个主题簇的先后节点。

**先总史还是先专题（两岔）：**

- **无特定主题**时 → 先读 [[Transformer至今发展脉络]]，建立总图后再按兴趣进入下方某一专题时间线。
- **已有阅读目的**（例如只关心服务侧、只关心对齐）→ **直接进入对应专题时间线**，再按该条末的衔接句进入主题 MOC；**不必先读完总史**。

专题时间线讲「节点谁先谁后」；机制、流派与导读路线在对应主题 MOC。本页列表挂靠史线篇；主题 MOC 侧对史线篇的副挂或跨 MOC 引用，目前以各页已定稿为准，不回头改已新版式主题页的列表。

## 导读路线

史线枢纽的导读以**路径选择**为主，不要求按「主线」读完所有专题。

- **入门**：[[Transformer至今发展脉络]]。无特定主题时的总图起点。该篇在本页**主挂**；架构类型「总览与史线」侧已作副挂并括注主挂发展时间线——本页不加反向括注。
- **主线（按需任选一条专题，无强制顺序）**：预训练与架构 → 读 [[预训练与架构发展时间线]]；长上下文与注意力 → 读 [[长上下文与注意力效率时间线]]；对齐与 RL → 读 [[对齐与强化学习发展时间线]]；Infra / Serving → 读 [[InfraServing发展时间线]]（投机解码脉络见进阶）；智能体工具记忆 → 读 [[智能体工具记忆发展时间线]]。选定一条即可转入对应主题 MOC，无需读完其余专题。
