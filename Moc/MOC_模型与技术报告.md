# MOC · 模型与技术报告

## 综述

本页是旗舰通模文档的**轻量枢纽**：先给开闭源代际总图与模型卡 / 系统卡字段通论，再把读者分到两条深读轨——要读训练、结构与推理**配方**，进 [[MOC_厂商技术报告]]；要读评测字段、风险与能力**披露**，进 [[MOC_系统卡与模型卡]]。枢纽本身不混列三十多篇单卡 / 单报告深读。

读旗舰材料需要两把尺子。一把是**谱系**：开放度、代际、thinking 形态、多模态与上下文，用来避免把产品切片当架构、把总参当激活参；开源分支的生态史由 LLaMA 里程碑单独展开。另一把是**规范**：模型卡与 SystemCard 各自回答什么字段、能支撑到哪一级复述，用来在读单张系统卡之前先统一口径。两把尺子都挂在本页；深读落在两轨。

与 [[MOC_前沿]] 的分工：按日短报仍主挂前沿；材料稳定后，技术报告向折入厂商轨，系统卡 / 模型卡向折入系统卡轨。短报稳定前不折入本页或两轨，只在此写清出口。

**本页管：** 开闭源旗舰谱系对照与 LLaMA 开源生态里程碑；模型卡 / SystemCard 规范通论；向厂商技术报告轨与系统卡与模型卡轨分流；说明短报折入规则。

## 导读路线

枢纽导读以**选轨**为主，不要求先读完某一张系统卡再读技术报告。

- **入门**：[[开源与闭源前沿模型谱系]]。先建立开闭源代际总图与四条读法坐标，再决定进哪一条轨。入门是谱系总图，不是「先读某一张系统卡」。
- **主线（二选一，无强制先后）**：要读结构 / 训练 / 推理配方 → 进入 [[MOC_厂商技术报告]] 的导读；要读披露字段与风险 → 进入 [[MOC_系统卡与模型卡]] 的导读。枢纽**不**把两轨深读拉回本页列表。
- **进阶**：[[LLaMA开源生态里程碑]]（谱系中开源一支的展开）；[[模型卡与SystemCard规范]]（读系统卡轨前的字段通论，主挂本页）。
- **前沿 / 史线**：披露先后见 [[SystemCard谱系时间线]]（跨 MOC 引用，主挂 [[MOC_发展时间线]]，副挂系统卡轨；本页不列表挂）；尚未折入的短报见 [[MOC_前沿]]。
