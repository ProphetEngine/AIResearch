# MOC · 训练方法

## 综述

预训练模型的能力取决于三件事：给定算力怎样分配参数与数据，数据从哪来、怎样筛选与配比，以及预训练之后怎样继续训练、微调与组合。本 MOC 收录的笔记沿这三件事组织，覆盖预训练、数据、优化与后训练前段的训练技巧。

第一条主干是规模定律与预训练范式。Kaplan 等（2020）与 Chinchilla（Hoffmann 等，2022）回答给定算力怎样配参数量与 token 数；2023 年以来，数据开始受限，推理成本压过训练成本，训练精度与模型结构成了可调变量，这些前提逐条松动，各自派生出扩展的缩放律。主预训练之后，中期训练用高质量数据退火、分段学习率与课程式拉长窗口，把剩余算力换成后期能力。

第二条主干是数据。真实网页语料的抽取、过滤与去重决定同等 token 预算下的有效信息密度，Nemotron-CC 在此基础上用分类器集成与合成改写支撑长程训练；另一条轴是由模型合成数据，或按教科书与习题形态组织，BeyondWeb 说明改写式合成的收益主要来自信息密度、风格与多样性的联合设计。各数据源占多少比例，可以先在小代理模型上搜索再迁移到大模型；多语种模型还要在同一权重内分配语种容量与采样。

第三条主干是优化与后训练前段。优化器从实现细节变成影响算力效率与稳定性的核心选择，AdamW 之后有 Muon；多 token 预测（MTP）的训练目标在监督微调（SFT）、预训练与强化学习（RL）三个阶段各需设计。指令微调把「按自然语言说明做事」当作训练目标，是此后对话模型与后训练流水线的起点；低秩适配（LoRA）一类参数高效微调只训练少量参数。在策略蒸馏（On-Policy Distillation，OPD）让学生自己采样、由教师逐 token 打分；模型合并在权重空间把多个同源微调模型合成一份权重；持续学习处理学会新知识与保住旧知识之间的张力。

本 MOC 讲训练期怎样塑造模型的基础能力。监督微调之后的偏好优化见 [[对齐脉络RLHF与偏好优化]]（跨 MOC 引用，主挂 [[MOC_对齐与强化学习]]）；混合专家（MoE）会改变缩放律中的有效前沿，MoE 结构见 [[混合专家架构]]（跨 MOC 引用，主挂 [[MOC_架构类型]]）。上下文蒸馏主挂 [[MOC_注意力与长上下文]]，分布式训练并行策略主挂 [[MOC_推理与基础设施]]，两篇在本 MOC 作副挂。测试时训练与测试时记忆两篇在推理阶段更新参数或记忆，已统一收在 [[MOC_推理时计算]] 的「测试时学习」组。

## 导读路线

- **入门**：[[规模定律与预训练范式]]，即「总览与史线」一组。它讲给定算力怎样配参数与 token，并划出数据来源、数据质量与中期训练三篇各自的分工，是全 MOC 的共同起点。
- **主线**：[[分词器与数据配比]] → [[合成数据与教科书式数据]]，再读 [[指令微调与SFT数据]] 与 [[LoRA与参数高效微调]]。前两篇接入门篇：分词器篇补 token 从哪来、怎样筛，合成数据篇在真实语料工程之外补「数据是否由模型合成」这一条轴。后两篇彼此正交：指令微调篇写 SFT 用什么数据，LoRA 篇写 SFT 更新哪些参数。
- **进阶**：按组分四条支线，彼此不依赖。
  - 缩放与预训练阶段：[[中期训练MidTraining范式]]。它回答通用预训练之后剩余预算换什么分布、步长与窗口；学习率是其中的旋钮，优化器谱系在下一条支线的优化器篇。
  - 数据：分词、配比、策展与合成：[[NemotronCC数据策展]] → [[数据配比优化方法]]；[[多语言与跨语种]] → [[SEA-LION低资源区域模型]]。网页策展通史在分词器篇，Nemotron-CC 的增量在其后一篇；配比优化篇以 Nemotron-CC 语料为源数据之一做配比搜索。多语篇讲同一权重如何服务多语，区域低资源的落地配方在 SEA-LION 一篇。
  - 优化与训练目标：[[优化器与训练稳定性]] → [[分布式训练并行策略]]（副挂，主挂 [[MOC_推理与基础设施]]）。优化器篇讲优化器族与训练稳定性，优化器状态的零冗余优化器（ZeRO）分片背景在并行策略篇。
  - 微调、蒸馏、合并与持续学习：[[OnPolicy蒸馏OPD范式]] → [[模型合并]] → [[持续学习]]，[[上下文蒸馏]]（副挂，主挂 [[MOC_注意力与长上下文]]）可随后读。OPD 与模型合并是把多个专家能力合成单模型的两条路；持续学习篇把合并列为高效持续学习的方向之一；上下文蒸馏篇中的 OPCD（On-Policy Context Distillation）是上下文蒸馏与在策略蒸馏的交叉，采样与损失沿用 OPD；DiSC 把文档切成前后段、以前段为上下文写入新知识，针对持续知识更新中的灾难性遗忘。
- **前沿**：[[缩放定律的扩展形态]]、[[BeyondWeb合成预训练]] 与 [[MTP训练范式]]，三篇并列。第一篇以入门篇的两条律为前置，整理数据受限、推理成本、精度、MoE 结构与蒸馏进入缩放律后的扩展形态，并从缩放律角度回应中期训练篇列出的「过训练如何判停」；第二篇以 Nemotron-CC 的高质量合成子集为最强公开基线，研究改写式合成预训练；第三篇在 SFT、预训练与 RL 三个阶段分别改写 MTP 的训练目标，它的两个跨 MOC 前置见「优化与训练目标」组说明。

## 微调、蒸馏、合并与持续学习

解决预训练之后怎样适配与更新模型。[[指令微调与SFT数据]] 讲监督微调（SFT）用什么数据，下游接收合成数据组的产出；[[LoRA与参数高效微调]] 讲 LoRA 等方法更新哪些参数，与前一篇正交；[[OnPolicy蒸馏OPD范式]] 讲在策略蒸馏（OPD），学生在自身采样上受教师监督，以 SFT 为对照；[[上下文蒸馏]] 把提示或文档条件行为压进参数，其中 OPCD 沿用 OPD 的采样与损失；[[模型合并]] 以 LoRA 增量可并回原权重为前提之一；[[持续学习]] 给出持续学习的地图，把参数高效微调、合并、蒸馏都列为手段，所以排在最后。基于人类反馈的强化学习（RLHF）流水线对 SFT 的用法见 [[对齐脉络RLHF与偏好优化]]。
