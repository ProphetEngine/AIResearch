# MOC · 安全

## 综述

本页是 **AI 安全**侧阅读枢纽：行为风险、红队与对抗、部署防御与护栏、监控与控制、安全论证、可解释与表征干预、隐私遗忘与水印，以及与对齐交界的规范 / 失对齐现象。排行榜可信度、污染检测、通用评测 harness 与领域**基准协议**已拆到 [[MOC_评测与基准]]；本页文件名保留以免断链，title 改为「安全」，避免读者以为仍混挂评测方法学。

读安全材料需要先分清两把尺子。一把是**行为与部署**：越狱 / 注入怎么攻、分类器与架构护栏怎么挡、隐瞒与 scheming 怎么监控、safety case 与 AI Control 怎么论证——主挂本页。另一把是**分数与协议**：榜单是否可比、数据是否污染、Inspect 怎么编排、某领域基准测什么字段——主挂评测页。史线 [[安全治理评测发展时间线]] 以红队 / 控制 / 治理为主轴，**副挂本页**（主挂 [[MOC_发展时间线]]）；评测页只作跨 MOC 散文指向，不列表挂。

与对齐的交界：[[可扩展监督与弱到强]]、[[审慎对齐与断路器]]、[[StatutoryAI法律规范对齐]] **主挂** [[MOC_对齐与强化学习]]，本页副挂；训练读法以对齐导读为准。[[奖励黑客与涌现失对齐]] 主挂本页（对齐侧保持跨 MOC，不写假双挂）。系统卡字段通论与单卡深读见枢纽规范与 [[MOC_系统卡与模型卡]]，本页不列表挂规范。

**本页管：** 红队与对抗；提示注入与部署分类器；安全论证与 AI Control / scheming；隐瞒与监控；思维链可监控与对齐伪装；机制可解释与激活 / 电路干预；隐私遗忘与水印；与对齐交界的规范对齐（副挂）与奖励黑客现象。

## 导读路线

- **入门**：[[安全红队与对抗评测]]。先建立红队 / 对抗评测谱系，再进防御与监控。入门是红队通史，不是「先读完对齐规范组」。
- **主线**：[[Prompt注入架构防御]] → [[安全论证SafetyCases]]（系统层防御 → 论证与控制前提）。
- **进阶**：[[AIControl协议与Scheming倾向]]、[[SHADEArena隐瞒与监控]]、[[思维链可监控性]]、[[宪法分类器防御]]；可解释线 [[机制可解释性入门]] → [[激活操控与表征工程]] / [[CircuitLasso与电路追踪]]。规范对齐三篇副挂本页，训练读法以 [[MOC_对齐与强化学习]] 导读为准。
- **前沿**：[[多模态越狱与OmniSafe]]、[[对齐伪装与谄媚行为]]、[[隐私与机器遗忘]] / [[Cascade与SAUL遗忘方法]]、[[LLM水印]]；史线坐标见 [[安全治理评测发展时间线]]（副挂本页，主挂 [[MOC_发展时间线]]）。
