# MOC · 评测与基准

## 综述

本页是**评测方法学与基准协议**侧阅读枢纽：排行榜与分数可比性、评测数据污染、开源通用评测 harness（Inspect），以及跨域 / 领域**基准**——回答「测什么、怎么打分、分数能否信」，而不是「如何防御」。行为风险、红队方法、注入护栏、Control 与可解释主挂 [[MOC_安全与评测]]（title「安全」）。

本页主挂仅五篇，体量小：不设「总览与史线」列表组。披露与治理的先后坐标仍读 [[安全治理评测发展时间线]]（**跨 MOC**；主挂 [[MOC_发展时间线]]，副挂安全页）——导读与综述须散文点明，避免读者以为评测簇无史线入口。

与 Harness 的划界：VendingBench / SWEBenchPro 等**智能体对象**任务基准仍主挂 [[MOC_智能体Harness]]；[[Inspect评测Harness]] 是通用评测框架，对象不是智能体任务基准，**主挂本页**，不进 Harness 列表。专科 [[辅导教学Agent评测]] 仍主挂专科，不迁。网络防御 / 恶意软件两篇进本页，因题面是基准字段与覆盖率，不是写防御系统；防御方法见安全页红队等。

**本页管：** 排行榜与分数可比性；评测数据污染；Inspect 等通用评测 harness；领域安全向基准协议（网络防御、恶意软件分析等）。

**本页不管：**

| 边界对象 | 归处 |
| --- | --- |
| 红队方法、注入防御、Control、可解释、隐私水印 | [[MOC_安全与评测]] |
| 智能体任务基准（SWE、浏览、经营、编排…） | [[MOC_智能体Harness]] |
| 系统卡里的评测表怎么读 | [[MOC_系统卡与模型卡]]；规范在枢纽 |
| 训练期奖励黑客机制深读 | 安全主挂；对齐跨 MOC |

## 导读路线

- **入门**：[[评测与排行榜可靠性]]。建立榜单 / thinking 可比性与常见误读。
- **主线**：[[评测数据污染检测与可靠性]] → [[Inspect评测Harness]]（污染与可信度 → 通用编排框架）。
- **进阶**：[[网络防御基准]]；[[恶意软件分析评测]]（领域基准，按需；组说明写清「测什么 / 怎么打分」，与安全页防御线分读）。
- **史线（散文，无本页列表）**：[[安全治理评测发展时间线]]（跨 MOC；主挂 [[MOC_发展时间线]]，副挂 [[MOC_安全与评测]]）。需要治理 / 红队先后坐标时读此篇，再回本页方法学或转安全页。

## 排行榜与污染

解决分数能不能比、数据是否被污染。[[评测与排行榜可靠性]] 是导读入门：排行榜与 thinking 可比性；[[评测数据污染检测与可靠性]] 接主线，讲污染怎样发现、怎样影响结论。组内建议先可靠性通论再进污染。红队方法与防御不在本组，见安全页。

- [[评测与排行榜可靠性]]
- [[评测数据污染检测与可靠性]]

## 评测 Harness

解决通用、可复现的评测脚手架怎样组织（对象不是某一智能体任务榜）。本组目前一篇：[[Inspect评测Harness]] **主挂本页**；**不**挂入 [[MOC_智能体Harness]] 列表（Harness 侧已划界：智能体对象基准仍在彼）。与 Harness「评测」组的边界：本组管通用评测框架；SWE / 浏览 / 经营 / 编排等任务基准仍主挂 Harness。

## 领域安全基准

解决领域场景下**测什么、怎么打分**——覆盖率、字段与协议，而不是「如何写防御系统」。[[网络防御基准]] 面向 SecOps / 网络防御评测字段与任务覆盖；[[恶意软件分析评测]] 面向恶意软件分析的基准协议。防御方法、红队谱系与护栏设计见安全页（[[安全红队与对抗评测]] 等）；本组只收基准侧。组内两篇并列、按需任选。
