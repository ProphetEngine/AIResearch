# MOC · 架构类型

## 综述

2017 年的 Transformer 只用注意力，去掉循环与卷积，使序列内部可以并行计算、任意两个位置一步相连，此后的大模型几乎都以它为骨架。本 MOC 收录的笔记回答一个问题：在这副骨架之上，模型的主干结构沿哪些方向演变，各自为了解决什么约束。

第一条主干是 Transformer 主干本身的定型。架构路线从 Encoder-only、Encoder–Decoder 与 Decoder-only 三分，收敛到以下一词预测为统一目标的 Decoder-only；归一化放在残差的哪个位置、残差能否扩展为多条流或带门控的读法，则决定了深层网络能否稳定训练。

第二条主干是稀疏化。混合专家架构让模型拥有很大的总参数量，而每个 token 只经过少数专家，使每 token 的激活参数与计算量近似保持常数；它的效果依赖路由器怎样选专家、怎样保持均衡与特化。在条件计算之外，按输入确定地址的大表查表提供了与专家并列的另一条稀疏轴。第三个方向是非 Transformer 与混合架构：线性注意力与状态空间模型以固定大小的状态替代 KV 缓存，混合架构研究它与注意力层怎样搭配；掩码扩散语言模型则提供了非自回归的文本生成路线。

本 MOC 讲主干结构，不展开注意力机制与长上下文的细节，二者见 [[MOC_注意力与长上下文]]。投机解码属于推理加速，相关笔记统一收在 [[MOC_推理与基础设施]] 的「投机解码」一组；推理时扩展、推理时搜索、自适应测试时算力与潜空间推理属于推理期投入算力的方法，相关笔记统一收在 [[MOC_推理时计算]]。
