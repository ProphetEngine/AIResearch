# MOC · 注意力与长上下文

## 综述

长上下文涉及两个问题：位置编码能否外推到更长的序列（能不能读），注意力的二次计算和随长度线性增长的键值缓存（KV 缓存）是否付得起（读不读得起）。本 MOC 收录的笔记围绕这两个问题组织，讲注意力机制本身怎样变形、KV 怎样少存少读、可复用的 KV 怎样跨请求保留。

第一条主干是「能读」与「读得起」的基础做法。位置编码一侧以旋转位置编码（RoPE）为共同起点，YaRN 一类方法按频段插值扩展窗口；系统一侧，分页注意力（PagedAttention）按块分页管理 KV，消除显存碎片。结构一侧，多头注意力（MHA）→ 多查询注意力（MQA）/分组查询注意力（GQA）→ 多头潜在注意力（MLA）从模型结构上减少每个 token 要存的 K/V，与分页管理互补。

第二条主干是在 softmax 注意力之内少读 KV。一类不改结构，在解码时只检索与当前查询最相关的 KV，或用模型自身的注意力分数按句挑选上下文；可训练稀疏注意力则把选块稀疏写进预训练计算图，使稀疏从推理期近似变成原生结构。另一类决定哪些 KV 可以不留：只有少数检索头需要完整 KV，其余流式头只保留注意力汇与近窗即可；这一做法以注意力汇现象为前提，汇的成因与门控、分母偏置等替代设计自成一题。分块 KV 压缩还会引入以步长为周期的新位置坐标，使检索准确率随相位周期起伏。

第三条主干是缓存复用与绕开上下文。前缀缓存跨请求复用相同前缀的 KV，层次化缓存把前缀命中范围从显存扩到主机内存与分布式存储；上下文蒸馏则把上下文带来的行为写进参数，推理时不再携带原上下文，与降低「带着上下文推理」成本的路线互补。

本 MOC 讲注意力机制与长上下文。缩放点积与多头注意力本身见 [[注意力与Transformer核心思想]]（跨 MOC 前置，主挂 [[MOC_架构类型]]）；用固定大小的状态替代 KV 缓存的线性注意力与状态空间模型、注意力与 Mamba 的混合设计主挂 [[MOC_架构类型]]，在本 MOC 作副挂。KV 的低比特量化见 [[KV缓存量化与压缩]]（跨 MOC 引用，主挂 [[MOC_推理与基础设施]]），它降低每个元素的比特数，与本 MOC 的结构压缩正交。

- **入门**：[[长上下文与注意力效率时间线]]（副挂，主挂 [[MOC_发展时间线]]），即「总览与史线」一组。它把长上下文拆成「能不能读」与「读不读得起」两个问题，依次串起位置编码与分页显存、KV 头共享与低秩压缩、推理期检索与驱逐、可训练稀疏注意力、线性注意力与混合架构，最后是压缩带来的系统性盲点；这一主题的共用背景集中写在该篇，是全 MOC 的共同起点。
- **主线**：[[长上下文位置编码与系统侧]] 与 [[注意力效率族MQA到MLA]]，两篇并列，互为补充。前者讲 RoPE、YaRN 扩窗与 PagedAttention 的分页管理，后者从模型结构上减少每个 token 的 KV。后者以 [[注意力与Transformer核心思想]] 中的多头注意力为前置。
- **进阶**：按两组分两条支线，组内各段彼此不依赖；第二条支线中的 DuoAttention 以第一条支线中门控篇所写的注意力汇现象为前提，宜在门控篇之后读。
  - 注意力变体与效率族：[[门控注意力与注意力汇]]；[[检索式注意力]] → [[原生稀疏注意力NSA]]；[[线性注意力与状态空间模型谱系]]（副挂，主挂 [[MOC_架构类型]]）→ [[混合Mamba与注意力架构设计菜谱]]（副挂，主挂 [[MOC_架构类型]]）。检索式注意力以位置编码篇为前置，不训练、在推理期按查询检索 KV，NSA 把选块稀疏写进预训练，是它的后续；线性注意力谱系是混合菜谱的前置，后者只写同预算对照给出的混合设计规律。

- **前沿**：[[分块KV压缩的相位敏感性]] 与 [[上下文蒸馏]]，两篇并列，同属 KV 压缩与缓存复用一组。前者为长上下文新增「相对压缩窗口的相位」这一位置坐标，在 DeepSeek-V4 家族上实测周期性检索失败；后者把上下文蒸进权重，与主线位置编码篇降低带上下文推理成本的路线互补。

## 注意力变体与效率族

解决「能读更长」：位置编码怎样外推、每个 token 要存的 K/V 怎样变少、注意力怎样稀疏或被替换。[[长上下文位置编码与系统侧]] 从原 Transformer 的正弦位置编码讲到 RoPE 外推与 PagedAttention 的 KV 分页管理，是本组与下一组的共同前置；[[注意力效率族MQA到MLA]] 从模型结构上减少 KV 头，依次为 MQA、GQA 与 MLA，以核心思想篇的多头注意力为前置；[[门控注意力与注意力汇]] 解释注意力权重和为一带来的注意力汇现象，以核心思想篇的缩放点积为上游；[[检索式注意力]] 接在位置编码篇之后，假定窗口与 KV 已就位、在解码时按需检索，并以门控篇给出的汇为成因；[[原生稀疏注意力NSA]] 讲可训练的稀疏注意力，头压缩一线止于 MLA。[[线性注意力与状态空间模型谱系]] 用固定大小的状态替代 KV 缓存，[[混合Mamba与注意力架构设计菜谱]] 以它为上游前置，比较线性原语与注意力层的混合方式。

## KV 压缩与缓存复用

解决「读得起」：KV 缓存哪些保留、怎样跨请求复用、能否把上下文写进参数。[[DuoAttention与KVzip]] 按注意力头区分流式头与检索头，流式头只保留汇与近窗，以门控篇为成因、以位置编码篇讲的 KV 膨胀为背景；[[分块KV压缩的相位敏感性]] 研究序列维分块压缩带来的位置周期性，并补充前一篇关于检索头的结论；[[Prompt前缀缓存]] 讨论预计算的前缀 KV 能否跨请求复用；[[HiCache层次化KV缓存]] 把引擎内前缀缓存扩到主机内存与分布式存储；[[上下文蒸馏]] 不再缓存上下文，而是把提示或文档蒸馏进参数，与位置编码篇降低长上下文推理成本的路线互补。KV 的低比特量化见 [[KV缓存量化与压缩]]，与驱逐、复用正交；引擎层的前缀复用见 [[推理引擎生态]]（跨 MOC 引用，主挂 [[MOC_推理与基础设施]]）。
