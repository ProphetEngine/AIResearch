# MOC · 厂商技术报告

## 综述

本页是旗舰通模**技术报告 / 训练与架构配方**的深读轨：按厂商与配方线收纳 MoE 基建、推理 RL、开源全栈与代码模型等报告，回答「这份报告里的结构、训练与推理激励怎么搭」。谱系总图与模型卡字段通论在枢纽 [[MOC_模型与技术报告]]；系统卡 / 模型卡披露深读在 [[MOC_系统卡与模型卡]]。

读本轨前宜先有枢纽入门篇 [[开源与闭源前沿模型谱系]] 的代际坐标；读完配方后可回到 [[MOC_训练方法]]、[[MOC_对齐与强化学习]]、[[MOC_推理时计算]] 看机制簇。[[DeepSeekR1推理训练深读]] **主挂本轨**（推理 RL 配方，不是系统卡）；对齐 / 推理时计算侧仅作跨 MOC 前置。[[Gemini25技术报告深读]] 走本轨；同厂模型卡篇在系统卡轨。名为「架构深读」但仍是旗舰通模配方的篇目主挂本轨，不进 [[MOC_架构类型]] 列表。

与 [[MOC_前沿]] 的分工：按日短报仍主挂前沿；技术报告向材料稳定后折入本轨。专科领域模型见 [[MOC_专科基础模型]]。

**本页管：** 厂商发布的技术报告与训练 / 架构 / 推理配方深读（含开源全栈配方、代码模型报告、闭源侧技术报告体裁）。

**本页不管：** 系统卡与模型卡字段 / 风险披露深读（见系统卡轨）；模型卡与 SystemCard 规范通论（主挂枢纽）；披露先后史线（主挂发展时间线）；按日短报；专科领域模型；通用架构类型通论（见 [[MOC_架构类型]]）。

## 导读路线

- **入门**：[[DeepSeekV3训练与MoE基建]]——开源旗舰配方与 MoE 基建的代表性技术报告。
- **主线**：[[DeepSeekR1推理训练深读]] → [[Qwen3技术报告深读]]。R1 给推理 RL 配方坐标（对齐 / 推理时计算跨 MOC 前置所依）；Qwen3 给另一条开源全能配方对照。
- **进阶（按系任选）**：DeepSeek 续篇 [[DeepSeekV32技术报告深读]] / [[DeepSeekV4技术报告深读]] / [[DeepSeekV41Flash深读]]；Qwen 续篇 [[Qwen38Next架构深读]] / [[Qwen3CoderNext技术报告深读]]；中文与其它开源 [[Kimik15技术报告深读]]、[[KimiK2技术报告深读]]、[[GLM45技术报告深读]]、[[MiniMaxM1技术报告深读]]、[[OLMo3全栈开放配方]]、[[Nemotron3Ultra技术报告深读]] 等。
- **前沿**：[[KimiK3技术报告]]、[[Gemma4技术报告深读]]、[[AXK2技术报告深读]]、[[Gemini25技术报告深读]]（较新或旁支配方；短报级更新仍在前沿）。

本轨不设「总览与史线」组：谱系总图在枢纽；组 1 首篇兼入门。

解决开源旗舰从 MoE 基建到推理 RL、再到后续代际的**技术报告配方**主线。[[DeepSeekV3训练与MoE基建]] 是导读入门：开源旗舰配方与 MoE 基建的代表性技术报告，也是跨 MOC 读训练方法时的常见前置出口（训练方法侧括注主挂本轨）。[[DeepSeekR1推理训练深读]] 给推理 RL 与可验证激励的旗舰坐标——**主挂本轨**；对齐 / 推理时计算侧仅作跨 MOC 前置，括注主挂本轨，**不**升为对齐或推理时计算的第二列表挂，也**不**进系统卡轨。[[DeepSeekV32技术报告深读]]、[[DeepSeekV4技术报告深读]]、[[DeepSeekV41Flash深读]] 为同系续篇，属导读进阶，可按代际任选，不强制读完组内全部。组内建议：入门 V3 → 主线坐标 R1 → 按需进续篇。系统卡字段与风险披露不在本组展开，见 [[MOC_系统卡与模型卡]]。
