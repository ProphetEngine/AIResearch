# MOC · 推理时计算

## 综述

模型训练完成后，能力并不完全由参数决定：同一个模型在推理阶段多花算力，往往能答对原本答不对的题。本 MOC 收录的笔记回答一个问题：推理期的额外算力可以投在哪里，各种投法之间是什么关系。与投机解码、量化等只求更快更省、不改变能力的推理加速不同，这里的方法都以更强的结果为目标。

第一条主干是测试时扩展与搜索。o1 与 DeepSeek-R1 表明，经强化学习训练出的长思维链可以随思考长度换取准确率；在此之外，同一题多次采样再投票或打分重排（自一致性、Best-of-N），以及在多个答案上做树搜索，是另一条不改权重的扩展路线。围绕这条主干，后续工作追问两个问题：固定预算下怎样按题目难度分配 token 与样本，怎样在单题内决定继续加宽还是加深答案树；把多次采样扩展为多个模型并行生成、分层聚合，则形成多模型协作的一支。

第二条主干是潜空间与连续推理。离散思维链每一步只能押注一个 token，连续路线改为在隐藏状态或概率加权的「概念 token」中推理，使一步内保留多个候选；从训练模型在潜空间推理，到不训练、只在推理期改变解码方式，连续思考所需的训练逐步减少。第三个方向是测试时学习：推理期不再冻结权重，而是用自监督或自奖励目标在线更新一部分参数（测试时训练），或把上下文写入可在测试时学习的神经记忆，它处在训练与推理的交界。

本 MOC 讲推理期怎样投入算力。训练出推理模型的强化学习与奖励建模主挂 [[MOC_对齐与强化学习]]；读本 MOC 前宜具备的背景是 [[DeepSeekR1推理训练深读]]（跨 MOC 前置，主挂 [[MOC_厂商技术报告]]）与 [[GRPO与DAPO算法族]]（跨 MOC 前置，主挂 [[MOC_对齐与强化学习]]）；打分重排所用的裁判可对照 [[过程奖励模型PRM谱系]]（副挂，主挂 [[MOC_对齐与强化学习]]）与 [[生成式奖励模型GenRM与奖励推理化]]（副挂，主挂 [[MOC_对齐与强化学习]]），前者逐步打分，后者让奖励模型本身在推理期并行采样再投票。推理加速与服务系统见 [[MOC_推理与基础设施]]；「线性 RNN 即在线学习」这一统一视角见 [[线性注意力与状态空间模型谱系]]（跨 MOC 引用，主挂 [[MOC_架构类型]]）。

## 导读路线

- **入门**：[[推理时扩展TestTimeScaling]]，即「总览与史线」一组。它把一次请求的推理算力粗记为思维链长度、候选数与验证成本三项（该篇注明这只是粗略记法，不是论文公式），树搜索是其中候选数一项的方法化；该篇还把本 MOC 的其余各篇定位为其中的方法切片或替代路线，是全 MOC 的共同起点。R1 的训练背景见 [[DeepSeekR1推理训练深读]]，可与入门篇同读。
- **主线**：[[自适应测试时算力]] 与 [[推理时树搜索ABMCTS]]，两篇并列，无先后依赖。前者按查询难度在题目之间分配 token 与样本，后者在单题内分配答案树的宽与深；两篇都以入门篇为上游。前者第六节（思维链压缩）中的 ThinkPrune 与 HMPO 基于 GRPO，见 [[GRPO与DAPO算法族]]；前者用作判据的奖励模型可对照 [[过程奖励模型PRM谱系]]；奖励模型自身的推理时扩展可对照 [[生成式奖励模型GenRM与奖励推理化]]。
- **进阶**：分两条支线，彼此不依赖。
  - 多模型协作：[[MixtureOfAgents与TUMIX]]（与主线两篇同属测试时扩展与搜索一组），以入门篇中的多数票与 Best-of-N 为基线，把多次采样扩展为多个模型并行生成、分层聚合。
  - 潜空间与连续推理：[[潜空间推理Coconut]] → [[SoftThinking连续概念空间推理]]。前者训练模型在连续潜空间推理，后者不训练、以前者为对照，按「连续思考所需训练逐步减少」的顺序读。
- **前沿**：[[测试时训练]] → [[测试时记忆Titans与嵌套学习]]。前者在推理期更新参数，以 [[GRPO与DAPO算法族]]（其中 PPO 与价值函数的部分）为前置，因其 TEMPO 一路先以标准可验证奖励强化学习（RLVR）训练、再在测试时交替更新；后者以前者脉络中介绍的 TTT 层（测试时训练层，Sun 等提出）为前置。RLVR 是否扩展能力边界的讨论另见 [[RLVR能力边界与熵机制]]（跨 MOC 引用，主挂 [[MOC_对齐与强化学习]]）。

## 测试时扩展与搜索

解决推理期多出来的算力怎样分配、怎样组织多次尝试与选择。[[自适应测试时算力]] 按题目难度分配 token 与样本；[[推理时树搜索ABMCTS]] 在单题内自适应决定加宽还是加深，两篇并列，没有前后依赖；[[MixtureOfAgents与TUMIX]] 把同一模型的多次采样推广为多个模型或多种工具策略并行再聚合，以总览篇的自一致性和 Best-of-N 为基线。重排与打分所用的裁判见两篇副挂：[[过程奖励模型PRM谱系]] 给逐步打分，[[生成式奖励模型GenRM与奖励推理化]] 让奖励模型本身在推理期并行采样再投票。两篇都可对照阅读，不是前置。

## 潜空间与连续推理

解决推理是否必须写成词。[[潜空间推理Coconut]] 训练模型在连续潜空间中推理，候选保留在连续思维内部；[[SoftThinking连续概念空间推理]] 不训练，在推理期把离散 token 换成概率加权的概念 token。后一篇以前一篇为训练式对照，所以排在后面。

## 测试时学习

解决在推理期更新参数或记忆。[[测试时训练]] 在单个测试实例或未标注测试集上更新参数；它的 TEMPO 一路先用标准 RLVR（PPO）训练，所以以 [[GRPO与DAPO算法族]]（其中 PPO 与价值函数的部分）为前置；[[RLVR能力边界与熵机制]] 一篇与 [[测试时训练]] 划界，不写测试时自奖励 RL 的方法。[[测试时记忆Titans与嵌套学习]] 以前者脉络中介绍的 TTT 层（Sun 等提出）为前置，转向神经记忆与嵌套学习。「线性 RNN 即在线学习」的统一视角见 [[线性注意力与状态空间模型谱系]]。
