# MOC · 系统卡与模型卡

## 综述

本页是旗舰通模**系统卡与模型卡**的深读轨：按厂商系收纳 GPT / Claude / Gemini / Grok 等披露字段、风险与能力叙述，回答「这张卡里评测与风险怎样写、能支撑到哪一级复述」。字段与披露约定的通论见枢纽 [[模型卡与SystemCard规范]]（跨 MOC 前置，主挂 [[MOC_模型与技术报告]]）；训练 / 结构 / 推理**配方**技术报告见 [[MOC_厂商技术报告]]。

披露先后坐标见 [[SystemCard谱系时间线]]：**主挂** [[MOC_发展时间线]]，本页「总览与史线」**副挂**；枢纽不列表挂该篇。读单卡前建议先过枢纽规范篇，再进本轨各组。

与 [[MOC_前沿]] 的分工：按日短报仍主挂前沿；系统卡 / 模型卡向材料稳定后折入本轨。行为风险 / 红队见 [[MOC_安全与评测]]；榜单字段可信度与评测协议见 [[MOC_评测与基准]]。

**本页管：** GPT / Claude / Gemini / Grok 等系统卡、模型卡深读与同系附录 / 更新；披露史线的副挂入口。

**本页不管：** 训练配方技术报告（见厂商轨）；模型卡 / SystemCard 规范通论（主挂枢纽，本轨导读跨 MOC 指向，不列表挂）；按日短报；专科领域模型；行为风险 / 红队通论（见安全页）；排行榜 / 污染 / 基准协议（见评测页）。
