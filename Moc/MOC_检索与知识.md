# MOC · 检索与知识

## 综述

本页是**外部语料 / 知识库检索增强**的阅读枢纽：经典一次取段 RAG、嵌入与重排、自适应检索与纠错、图谱 RAG、记忆式文档检索，以及智能体式分层检索接口。回答「如何从库外取回证据」，不回答「窗口里写什么」或「对话状态怎么记」。

与邻页的对照先写清。[[MOC_注意力与长上下文]] 管检索式注意力（查自身 KV）与长窗口；本页管库外索引。[[MOC_智能体Harness]] 管上下文工程与 Mem0 / 长程记忆等任务状态记忆；本页的 HippoRAG / Agentic RAG 仍是**文档检索**算法与接口，读完可转 Harness 看工具循环与生产记忆，但不把记忆层篇目拉进本页列表。旗舰通模配方与系统卡见模型报告树，本页不收。

史线 [[RAG发展时间线]] **副挂本页**（主挂 [[MOC_发展时间线]]）：从向量基建到经典 RAG、自适应 / 图谱、再到记忆式与智能体式。入门以通史机制篇为准，史线作总览组并列读物。

**本页管：** 面向外部语料的检索增强配方与接口；本簇史线（副挂）。

**本页不管：**

| 边界对象 | 归处 |
| --- | --- |
| 检索式注意力（查自身 KV）、长窗口替代检索 | [[MOC_注意力与长上下文]] |
| 智能体记忆层（Mem0 / 长程记忆 / MemoryR1…）、上下文工程 | [[MOC_智能体Harness]] |
| 旗舰通模配方 / 系统卡 | [[MOC_模型与技术报告]] 树 |

## 导读路线

- **入门**：[[检索增强与知识外挂]]。建立「参数记忆 + 非参数索引」与一次取段配方；需要先后坐标时并读 [[RAG发展时间线]]（副挂，主挂 [[MOC_发展时间线]]）。
- **主线**：[[SelfRAG与CorrectiveRAG]] → [[图谱检索GraphRAG]]。固定 top-K 之后：先控制流（何时检索 / 错了怎么办），再图结构（整库主题 / 社区摘要）。
- **进阶**：[[文本嵌入与重排序模型]]——检索器与重排器自身谱系；与主线正交，**可在入门后或主线中按需插入**。
- **前沿**：[[HippoRAG2与CatRAG]]、[[AgenticRAG分层检索接口]]——记忆式检索与智能体分层检索接口；与 Harness 记忆 / 工具组对照，机制主线仍在本页。

## 嵌入与重排

解决检索器与重排器自身怎样表示与打分，与「何时检索、用什么图结构」正交。本组目前一篇：[[文本嵌入与重排序模型]] 串嵌入、双塔与交叉编码等谱系。导读把本组放在**进阶**；组内读法上**可在入门（通史）之后、主线之中或之后按需插入**，不必等读完 Self-RAG / GraphRAG。与训练方法的交叉（嵌入训练 / 数据配比）按需见 [[MOC_训练方法]]，本组不展开训练通论。

## 自适应与图谱

解决固定 top-K 之后：控制流怎样决定何时检索、错了怎么办，以及整库怎样用图结构做主题 / 社区级综合。[[SelfRAG与CorrectiveRAG]] 是导读主线第一环（自省与纠错）；[[图谱检索GraphRAG]] 是主线第二环（社区摘要、全局 map-reduce；含 EraRAG 一类增量索引对照）。组内建议：先控制流再图谱；两篇均主挂本页。智能体工具循环不在本组展开，见 [[MOC_智能体Harness]]。

- [[SelfRAG与CorrectiveRAG]]
- [[图谱检索GraphRAG]]

## 记忆式与智能体式检索

解决记忆式文档图检索 / 查询自适应遍历，以及把检索做成分层工具接口交给智能体编排。[[HippoRAG2与CatRAG]]、[[AgenticRAG分层检索接口]] 属导读前沿，均主挂本页。与 Harness 的边界：本组管「如何从外部语料取回 / 分层检索接口」；对话与任务状态记忆（Mem0、长程记忆等）、上下文工程（写什么进窗）主挂 [[MOC_智能体Harness]]，本页只作对照出口，不迁挂。读完 Agentic RAG 可转 Harness 工具循环与生产记忆。
