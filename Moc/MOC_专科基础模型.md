# MOC · 专科基础模型

## 综述

专科基础模型回答的是：在某一应用领域里，通用预训练配方要改什么、补什么数据与评测，才能变成可用的领域系统。本 MOC 按**领域**收纳这类配方与领域向 agent / 评测，而不是按注意力、优化器或工具循环切分——后者各有自己的主题页。

领域多、单域笔记少，是本簇的常态：没有一篇能像规模定律那样当全簇通史。读者应先建立「本页管什么、不管什么」的地图，再按自己的领域进入对应组；不必假装存在一条覆盖医学、气候、材料与芯片的强制阅读顺序。

本页收录的主干大致三类。一类是**领域知识密集的文本专科**（医学、法律、教育）：配方、数据与安全约束绑定具体行业，评测也往往领域化（辅导教学评测即属此类，目前仍主挂本页；通用智能体榜在 Harness，安全 / 评测拆分后再议迁挂）。一类是**地球系统与观测**（天气气候、地球系统模型、遥感）以及其上的**领域 agent**（气候科学 agent）：预报与观测是模型，政策 / 科学任务外环是 agent，工具循环通论见 Harness。一类是**材料、芯片与非文本结构化数据**（材料仿真与生成、表与时序、芯片设计 AI），与多模态页以视觉 / 具身为主的主线划界。另有**开放式与科学发现**一篇主挂本页，与 Harness「多智能体与科研」副挂交叉：本页管「发现 / 开放式」的领域像，形式化证明骨架在数学原理。多语言与低资源区域模型在本页只作交叉入口，机制与数据配比主挂训练方法。

**本页管：** 按应用领域归档的基础模型与领域配方；领域向 agent 与领域绑定评测（气候科学 agent、LearnLM 与辅导教学评测）；开放式 / 科学发现基础模型主线；多语言 / 低资源区域模型的交叉入口（副挂）。

**本页不管：** 具身 / VLA / 世界模型 / 机器人栈见 [[MOC_多模态与具身]]；通用智能体 harness、工具循环、记忆层与智能体对象评测见 [[MOC_智能体Harness]]（气候 agent、辅导评测为领域例外，留本页）；多语配比与区域低资源训练机制见 [[MOC_训练方法]]；旗舰通模技术报告与系统卡见 [[MOC_模型与技术报告]]（MedGemma 等专科深读留本页）；形式化证明与可验证 RL 主线见 [[MOC_数学原理]]。[[生物学基础模型]] 仅保留既有列表挂靠，本库不扩写生物题。

需要总史坐标时，散文指向 [[Transformer至今发展脉络]]（跨 MOC 引用，主挂 [[MOC_发展时间线]]）——**不**把该篇拉进本页列表（其列表挂已满）。

## 导读路线

本簇**无**单一入门原子笔记。导读作一小例外：入门先读本页综述；主线、进阶、前沿均按领域或兴趣**任选**，无强制先后。

- **入门**：**先读本页综述**，建立管 / 不管与领域地图，再下到各组。需要通模史线坐标时，可并读 [[Transformer至今发展脉络]]（跨 MOC 引用，主挂 [[MOC_发展时间线]]）；本页不加其列表挂。
- **主线**（按领域任选一条，无强制先后）：[[天气气候基础模型]]（地球系统代表）｜[[MedGemma医学专科]]（医学代表）｜[[表格与时序基础模型]]（非文本结构化代表）。已有明确领域则直接进对应子主题组，不必读完三条。
